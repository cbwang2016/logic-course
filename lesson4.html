First-order Proofs & Gödel's Completeness Theorem一阶证明与哥德尔完备性定理

In Lesson 3 truth (⊨) was defined by looking inside structures. Now we build a symbol-pushing proof system (⊢) for first-order logic and prove Gödel's 1929 theorem: Γ ⊢ φ ⇔ Γ ⊨ φ. The hard direction builds a model out of pure syntax. 第 3 课里，“真”（⊨）是看着结构内部来定义的。这一课我们为一阶逻辑搭一台只摆弄符号的证明系统（⊢），并证明哥德尔 1929 年的定理：Γ ⊢ φ ⇔ Γ ⊨ φ。难的那个方向，要用纯粹的语法材料造出一个模型。

§1

Substitution and variable capture代入与变元捕获

The quantifier axiom says: from “for all x, φ” infer φ about any particular term t. Write φ[t/x] for φ with every free occurrence of x replaced by t. The danger: a variable of t can fall inside a quantifier that binds it. Then it is captured and the meaning changes. 量词公理说：由“对所有 x，φ”可以推出 φ 对任意一个具体的项 t 成立。记 φ[t/x] 为把 φ 中 x 的每个自由出现都换成 t 的结果。危险在于：t 中的变元可能落进约束它的量词辖域，于是被捕获，公式的意思就变了。

Definition. t is substitutable for x in φ if no free occurrence of x in φ lies within the scope of a quantifier ∀y or ∃y with y a variable of t. (Closed terms, e.g. constants, are always substitutable.) 定义. 若 φ 中 x 的自由出现都不落在 ∀y 或 ∃y（y 为 t 中的变元）的辖域内，就称 t 在 φ 中对 x 可代入。（闭项，例如常元，总是可代入的。）

Picture: coloured brackets under a formula show quantifier scopes; dashed arcs link each bound variable to its quantifier; gold = free occurrences of x. Bottom row: the result, with t in blue and captured variables in red. 图示：公式下方的彩色括线是量词辖域；虚线弧把每个约束变元连到约束它的量词；金色 = x 的自由出现。下面一行是代入结果，t 为蓝底，被捕获的变元为红色。

φ x t

Signature: variables u–z; constants a, b, c, d, e, 0, 1; unary f, h; binary g; unary predicates P, Q; binary R, S; equality.符号表：变元 u–z；常元 a, b, c, d, e, 0, 1；一元函数 f, h；二元函数 g；一元谓词 P, Q；二元谓词 R, S；等词。

Classic: ∀x∃y(y ≠ x) (“everything has something else”) is true in any structure with ≥ 2 elements, but the captured instance ∃y(y ≠ y) is false everywhere. The fix is not to forbid the substitution forever: rename the bound variable first (∃z(z ≠ x)), then substitute. 经典例子：∀x∃y(y ≠ x)（“每个东西都有别的东西”）在至少 2 个元素的结构中都为真，但被捕获的实例 ∃y(y ≠ y) 处处为假。补救办法不是永远禁止代入，而是先给约束变元改名（∃z(z ≠ x)），再代入。

§4

Soundness: truth flows down a derivation可靠性：真值沿推导往下流

Soundness Theorem. If Γ ⊢ φ then Γ ⊨ φ: every structure and assignment satisfying Γ satisfies φ.
Proof. Induction on the derivation. Axioms are valid (Q1 by the substitution lemma, which is where substitutability is needed; Q2 because x is not free in φ). Members of Γ hold by assumption. MP preserves truth. Gen: if x is not free in Γ, any variant s(x ↦ a) still satisfies Γ, hence φ, so ∀xφ holds. ∎ 可靠性定理. 若 Γ ⊢ φ，则 Γ ⊨ φ：满足 Γ 的每个结构和赋值也满足 φ。
证明. 对推导归纳。公理普遍有效（Q1 依赖代入引理，可代入条件正用在这里；Q2 是因为 x 在 φ 中不自由）。Γ 中的公式按假设成立。MP 保持真。Gen：若 x 在 Γ 中不自由，则把赋值改成 s(x ↦ a) 后 Γ 仍满足，因而 φ 也满足，所以 ∀xφ 成立。∎

Watch it happen. Γ = {∀x(P(x) → Q(x)), P(c)}. Pick a random model of Γ and watch every line light up green. Then pick an arbitrary structure: hypotheses may fail, but axiom lines never do. 亲眼看一遍。Γ = {∀x(P(x) → Q(x)), P(c)}。随机取一个 Γ 的模型，看每一行依次亮绿。再取一个任意结构：假设可能不成立，但公理行永远为真。

§5

The Completeness Theorem: a road map完备性定理：路线图

Gödel's Completeness Theorem (1929). For every set Γ of sentences and every sentence φ: Γ ⊨ φ ⇒ Γ ⊢ φ.
Equivalent form (Henkin 1949): every consistent set of sentences has a model. 哥德尔完备性定理（1929）. 对任意语句集 Γ 和语句 φ：Γ ⊨ φ ⇒ Γ ⊢ φ。
等价形式（亨金，1949）：每个一致的语句集都有模型。
Why the forms are equivalent (⇐). Suppose Γ ⊬ φ.两种形式为何等价（⇐）. 设 Γ ⊬ φ。
Then Γ ∪ {¬φ} is consistent: otherwise Γ ∪ {¬φ} ⊢ ⊥, so by the deduction theorem Γ ⊢ ¬φ → ⊥, hence Γ ⊢ φ.则 Γ ∪ {¬φ} 一致：否则 Γ ∪ {¬φ} ⊢ ⊥，由演绎定理 Γ ⊢ ¬φ → ⊥，从而 Γ ⊢ φ，矛盾。
By the model existence form, some 𝔄 ⊨ Γ ∪ {¬φ}. This 𝔄 is a counterexample, so Γ ⊭ φ. Contrapositive: Γ ⊨ φ ⇒ Γ ⊢ φ. (⇒ is similar: if Γ is consistent but had no model, Γ ⊨ ⊥, so Γ ⊢ ⊥.) ∎由模型存在形式，有 𝔄 ⊨ Γ ∪ {¬φ}。这个 𝔄 就是反例，故 Γ ⊭ φ。逆否即得：Γ ⊨ φ ⇒ Γ ⊢ φ。（⇒ 方向类似：若 Γ 一致却没有模型，则 Γ ⊨ ⊥，于是 Γ ⊢ ⊥。）∎

Henkin's proof of the model existence form has five stations. Click a box, or play the whole journey. 亨金对模型存在形式的证明分五站。点击方框，或者从头播放一遍。

The big idea: we have no structure to start from, only syntax. So we let the terms themselves be the elements. The two problems: (1) ∃xφ may be in Γ* without any term t with φ(t) in Γ* (fixed by witnesses), and (2) Γ* must decide every sentence so that “truth” in the term model is well-defined (fixed by maximality). 核心想法：我们手里没有现成的结构，只有语法。那就让项本身来充当元素。两个难点：(1) ∃xφ 属于 Γ*，却可能没有哪个项 t 使 φ(t) 属于 Γ*（用见证常元解决）；(2) Γ* 必须判定每个语句，项模型里的“真”才有确定的意义（用极大性解决）。
§6

Henkin witnesses and Lindenbaum's lemma亨金见证常元与林登鲍姆引理

Step 1: give every existential formula its own name for a witness. Each step attaches a fresh constant and records the Henkin axiom ∃xφ → φ(c_φ). 第一步：给每个存在公式的见证起一个专属名字。每一步都挂上一个新常元，并记下亨金公理 ∃xφ → φ(c_φ)。

Why adding Henkin axioms keeps Γ consistent为什么加入亨金公理后 Γ 仍一致

Let T be consistent and c a constant not occurring in T or φ. Suppose T ∪ {∃xφ → φ(c)} ⊢ ⊥.设 T 一致，常元 c 不在 T 和 φ 中出现。假设 T ∪ {∃xφ → φ(c)} ⊢ ⊥。
Deduction theorem: T ⊢ ¬(∃xφ → φ(c)). Propositionally this gives T ⊢ ∃xφ and T ⊢ ¬φ(c).由演绎定理：T ⊢ ¬(∃xφ → φ(c))。按命题逻辑可得 T ⊢ ∃xφ 且 T ⊢ ¬φ(c)。
Constants lemma: since c is new, the derivation of ¬φ(c) works with a fresh variable y in place of c, so T ⊢ ¬φ(y); by Gen, T ⊢ ∀y¬φ(y), i.e. T ⊢ ∀x¬φ.常元引理：c 是新常元，把 ¬φ(c) 的推导中的 c 全换成一个新变元 y 仍是推导，所以 T ⊢ ¬φ(y)；由 Gen，T ⊢ ∀y¬φ(y)，即 T ⊢ ∀x¬φ。
But ∃xφ is ¬∀x¬φ. So T proves both ∀x¬φ and its negation: T is inconsistent, contradiction. Each new axiom uses its own new constant, and a derivation of ⊥ uses finitely many axioms; adding those finitely many one at a time, layer by layer (so each constant is still new when its axiom is added), keeps consistency, so adding all of them at once is consistent too. ∎可 ∃xφ 就是 ¬∀x¬φ。于是 T 同时证明了 ∀x¬φ 及其否定，T 不一致，矛盾。每条新公理都用自己的新常元，而 ⊥ 的推导只用到有限条公理；把这有限条按层逐条加入（保证加入每条时它的常元仍是新的），一致性始终保持，所以一次全部加入也是一致的。∎

Lindenbaum: walk down the tree of all decisions林登鲍姆：沿“所有抉择之树”往下走

Same picture as in Lesson 2, now with first-order sentences. Here Γ = {∀x(P(x) → Q(x)), P(c)} plus the Henkin axioms (Γ_H). 和第 2 课同一幅图，只是换成一阶语句。这里 Γ = {∀x(P(x) → Q(x)), P(c)} 再加上亨金公理（记作 Γ_H）。

Lindenbaum's lemma. Γ* = ⋃ Tₙ is consistent (a derivation of ⊥ would use finitely many sentences, all in some Tₙ) and maximal (for each σ = σₙ, either σ or ¬σ went in). Key step: if Tₙ ∪ {σ} is inconsistent then Tₙ ⊢ ¬σ, so Tₙ ∪ {¬σ} is consistent. This is an existence proof: “is it consistent?” is not decidable in general. For uncountable languages, use Zorn's lemma instead of the enumeration. 林登鲍姆引理. Γ* = ⋃ Tₙ 是一致的（⊥ 的推导只用到有限多个语句，它们都在某个 Tₙ 中），也是极大的（对每个 σ = σₙ，σ 和 ¬σ 必有一个被加入）。关键一步：若 Tₙ ∪ {σ} 不一致，则 Tₙ ⊢ ¬σ，于是 Tₙ ∪ {¬σ} 一致。这是存在性证明：“是否一致”一般是不可判定的。对不可数语言，用佐恩引理代替枚举。

The term model: closed terms, glued by provable equality项模型：闭项按可证相等粘合

Universe of 𝔄: the equivalence classes [t] of closed terms (of the enlarged language L_ω), where t ∼ s iff (t = s) ∈ Γ*. Interpret f^𝔄([t]) = [f(t)] and P^𝔄 = {[t] : P(t) ∈ Γ*}. The equality axioms make this well defined. Toy version below: language {c, d, f}, and t ∼ s iff Γ ⊢ t = s for the equations you switch on. Watch classes merge, and how congruence (t ∼ s ⇒ f(t) ∼ f(s)) spreads each merge along the chain. The truth lemma: 𝔄 ⊨ σ ⇔ σ ∈ Γ*真引理：𝔄 ⊨ σ ⇔ σ ∈ Γ*

Atomic. 𝔄 ⊨ t = s ⇔ [t] = [s] ⇔ (t = s) ∈ Γ*, by definition; likewise for P(t). (Every closed term t denotes [t].)原子公式. 𝔄 ⊨ t = s ⇔ [t] = [s] ⇔ (t = s) ∈ Γ*，按定义即得；P(t) 同理。（每个闭项 t 的指称就是 [t]。）
¬ and →. 𝔄 ⊨ ¬σ ⇔ 𝔄 ⊭ σ ⇔ σ ∉ Γ* ⇔ ¬σ ∈ Γ*: the last step is maximality + consistency. Similarly (σ → τ) ∈ Γ* ⇔ σ ∉ Γ* or τ ∈ Γ*, because Γ* is maximal consistent, hence deductively closed.¬ 与 →. 𝔄 ⊨ ¬σ ⇔ 𝔄 ⊭ σ ⇔ σ ∉ Γ* ⇔ ¬σ ∈ Γ*，最后一步用的是极大性 + 一致性。同理 (σ → τ) ∈ Γ* ⇔ σ ∉ Γ* 或 τ ∈ Γ*，因为 Γ* 极大一致，从而对推导封闭。
∃ (⇐). If ∃xφ ∈ Γ*, the Henkin axiom gives φ(c_φ) ∈ Γ*; by induction 𝔄 ⊨ φ(c_φ), so 𝔄 ⊨ ∃xφ with witness [c_φ]. This is exactly where the witnesses are needed.∃（⇐）. 若 ∃xφ ∈ Γ*，由亨金公理 φ(c_φ) ∈ Γ*；由归纳假设 𝔄 ⊨ φ(c_φ)，故 𝔄 ⊨ ∃xφ，见证为 [c_φ]。见证常元正是在这里派上用场。
∃ (⇒). If 𝔄 ⊨ ∃xφ, some element witnesses it, and every element is [t] for a closed term t. So 𝔄 ⊨ φ(t), by induction φ(t) ∈ Γ*, and since φ(t) ⊢ ∃xφ, also ∃xφ ∈ Γ*. ∎ Hence 𝔄 ⊨ Γ* ⊇ Γ, and 𝔄 has at most |L| + ℵ₀ elements: a countable language gives a countable model (Lesson 5).∃（⇒）. 若 𝔄 ⊨ ∃xφ，有某个元素作见证，而每个元素都形如 [t]（t 为闭项）。于是 𝔄 ⊨ φ(t)，由归纳假设 φ(t) ∈ Γ*，又 φ(t) ⊢ ∃xφ，所以 ∃xφ ∈ Γ*。∎ 于是 𝔄 ⊨ Γ* ⊇ Γ，且 𝔄 至多有 |L| + ℵ₀ 个元素：可数语言给出可数模型（第 5 课）。
§8

Two corollaries: compactness and an enumeration of all valid sentences两个推论：紧致性，以及所有有效语句的枚举

Compactness Theorem for first-order logic一阶逻辑的紧致性定理

Γ has a model iff every finite subset of Γ has a model. Press the button to see why: a refutation can only touch finitely many premises. Γ 有模型当且仅当 Γ 的每个有限子集都有模型。按下按钮看原因：一个反驳只能碰到有限多个前提。

The valid sentences are recursively enumerable有效语句集是递归可枚举的

Derivations are finite strings over a countable alphabet; if the symbols of the language can be listed effectively, a machine can list all candidates #0, #1, #2, … and mechanically check each one. By completeness, the theorems it outputs are exactly the valid sentences. Below, a tiny genuine checker runs over candidates built from six formulas F₁–F₆ (in shortlex order). 推导是可数字母表上的有限串；只要语言的符号能被能行地列出，机器就可以把所有候选 #0, #1, #2, … 列出来，逐个机械地检查。由完备性定理，它输出的定理恰好就是全部有效语句。下面是一台真正的小检查器，候选由 F₁–F₆ 这六个公式按长度再字典序排出。

So validity is semi-decidable: if σ is valid, the machine eventually prints it; if not, you may wait forever. Church and Turing (1936) showed this cannot be improved: validity in first-order logic is undecidable (as soon as the language has a binary relation symbol; Lesson 11). The same machine with an r.e. set of axioms Γ enumerates {σ : Γ ⊨ σ}. 所以有效性是半可判定的：σ 有效时，机器迟早会把它打印出来；σ 无效时，你可能永远等下去。丘奇和图灵（1936）证明这已无法改进：一阶逻辑的有效性是不可判定的（只要语言中有一个二元关系符号；第 11 课）。若公理集 Γ 递归可枚举，同一台机器就能枚举 {σ : Γ ⊨ σ}。
§9

“Complete theory” vs “completeness theorem”“完全理论”与“完备性定理”

Completeness theorem完备性定理
A property of the proof system: for every Γ and φ, Γ ⊨ φ ⇒ Γ ⊢ φ. Proved once and for all (Gödel 1929). 是证明系统的性质：对任意 Γ 和 φ，Γ ⊨ φ ⇒ Γ ⊢ φ。一劳永逸地证明了（哥德尔 1929）。
Complete theory完全理论
A property of a particular theory T: for every sentence σ, T ⊢ σ or T ⊢ ¬σ. Some theories have it, most do not (and PA does not, by Gödel 1931). 是某个具体理论 T 的性质：对每个语句 σ，T ⊢ σ 或 T ⊢ ¬σ。有的理论具有它，大多数没有（PA 就没有，这是哥德尔 1931 年的结果）。

The completeness theorem translates “T decides σ” into a statement about models: T is complete iff all models of T satisfy the same sentences. Click the cells (language {<}; x ≤ y abbreviates x < y ∨ x = y). 完备性定理把“T 判定 σ”翻译成关于模型的话：T 完全当且仅当 T 的所有模型满足相同的语句。点击格子（语言为 {<}；x ≤ y 是 x < y ∨ x = y 的缩写）。

That DLO is complete is a real theorem (Cantor's back-and-forth, Lesson 5). For Th(ℕ,<) it is automatic, since Th(𝔐) always decides every sentence.
