Part V · Lesson 20

The Lévy hierarchy & absoluteness列维层级与绝对性

In Lesson 17 we measured arithmetic statements by counting unbounded number quantifiers. Here we do the same with set quantifiers. The count tells you which statements a smaller universe M is guaranteed to get right, and which ones forcing can never change. 第 17 课里，我们数无界的数量词来衡量算术命题的复杂度。这一课对集合量词做同样的事。数出来的层级决定了一个较小的宇宙 M 能保证判断对哪些命题，也决定了哪些命题力迫法永远改变不了。

Convention: we work in ZFC unless stated otherwise. “Transitive class M” means: x ∈ M and y ∈ x imply y ∈ M. 约定：除非另作说明，均在 ZFC 中工作。“传递类 M”指：x ∈ M 且 y ∈ x 时必有 y ∈ M。

§1 · Step 1

Bounded quantifiers: searching inside a given set有界量词：只在给定集合里搜索

Prerequisites前置知识: L14 · transitive sets传递集 L17 · bounded ∀n<m有界数量词 L8 · ordinals序数

Core idea: a formula whose quantifiers only range over elements of sets you already hold can be checked by looking at a small, fixed part of the universe. 核心思想：如果公式的量词只在手头已有集合的元素里取值，那么只需看宇宙中一小块固定的部分，就能判定它。

Definition (Δ₀ = Σ₀ = Π₀). The Δ₀ formulas of the language {∈} form the smallest class that contains the atomic formulas x ∈ y, x = y, is closed under ¬, ∧, ∨, →, ↔, and is closed under bounded quantification: ∃x∈y φ :≡ ∃x (x ∈ y ∧ φ) and ∀x∈y φ :≡ ∀x (x ∈ y → φ), where y is a variable different from x. 定义（Δ₀ = Σ₀ = Π₀）. 语言 {∈} 中的 Δ₀ 公式构成满足下列条件的最小类：包含原子公式 x ∈ y、x = y；对 ¬, ∧, ∨, →, ↔ 封闭；对有界量化封闭，即 ∃x∈y φ :≡ ∃x (x ∈ y ∧ φ)，∀x∈y φ :≡ ∀x (x ∈ y → φ)，其中 y 是与 x 不同的变元。

Examples. “x is transitive”: ∀y∈x ∀z∈y (z ∈ x). “x is an ordinal”: x is transitive and ∀y∈x ∀z∈x (y∈z ∨ y=z ∨ z∈y). This one is equivalent in ZF to the official definition, because Foundation supplies the well-foundedness. Pick a set and a property below and watch the search: it never leaves the picture of trcl({x}). 例子：“x 是传递集”：∀y∈x ∀z∈y (z ∈ x)。“x 是序数”：x 传递且 ∀y∈x ∀z∈x (y∈z ∨ y=z ∨ z∈y)。在 ZF 中它与正式定义等价，因为良基公理（正则公理）保证了良基性。下面选一个集合和一个性质，观察搜索过程：它从不走出 trcl({x}) 这幅图。

⚠ Common pitfall. “Bounded” means bounded by a variable or parameter. ∃z∈𝒫(x) is not a bounded quantifier as written: unfolded it is ∃w (w = 𝒫(x) ∧ ∃z∈w …), and w = 𝒫(x) is not Δ₀ (it is Π₁, see §5). Likewise ∃n∈ω is bounded only if ω is supplied as a parameter. Since “w = ω” is Δ₀, arithmetic statements are Δ₀ in the parameter ω. ⚠ 常见误区. “有界”指以变元或参数为界。∃z∈𝒫(x) 照字面不是有界量词：展开后是 ∃w (w = 𝒫(x) ∧ ∃z∈w …)，而 w = 𝒫(x) 不是 Δ₀ 的（它是 Π₁，见 §5）。同理，只有把 ω 当作参数给出时，∃n∈ω 才是有界的。由于“w = ω”是 Δ₀ 的，算术命题都是以 ω 为参数的 Δ₀ 命题。
§2 · Step 2

Σₙ and Πₙ: counting unbounded quantifier blocksΣₙ 与 Πₙ：数无界量词块

Prerequisites前置知识: §1 · Δ₀Δ₀ L17 · Σ⁰ₙ / Π⁰ₙ算术层级 L3 · prenex form前束范式

Core idea: exactly as in the arithmetical hierarchy, count the alternating blocks of unbounded quantifiers in front of a Δ₀ matrix. 核心思想：和算术层级完全一样，数一数 Δ₀ 母式前面无界量词交替的块数。

Definition (Lévy). Σ₀ = Π₀ = Δ₀. A formula is Σₙ₊₁ if it has the form ∃x₁…∃x_k ψ with ψ a Πₙ formula, and Πₙ₊₁ if it has the form ∀x₁…∀x_k ψ with ψ a Σₙ formula (k ≥ 1). These are syntactic classes. Every Σₙ or Πₙ formula is also Σₘ and Πₘ for every m > n: just add dummy quantifiers. 定义（列维）. Σ₀ = Π₀ = Δ₀。形如 ∃x₁…∃x_k ψ（ψ 为 Πₙ 公式，k ≥ 1）的公式称为 Σₙ₊₁ 公式；形如 ∀x₁…∀x_k ψ（ψ 为 Σₙ 公式）的称为 Πₙ₊₁ 公式。这些都是语法类。任何 Σₙ 或 Πₙ 公式对每个 m > n 也都是 Σₘ 和 Πₘ 公式，补上哑量词即可。

§3 · Step 3

Classification modulo a theory: ΣₙZF, ΠₙZF, ΔₙZF模理论分类：ΣₙZF、ΠₙZF、ΔₙZF

Prerequisites前置知识: §2 · Σₙ / ΠₙΣₙ / Πₙ L6 · Replacement替换公理 L14 · V_αV_α

Core idea: the Collection principle lets a bounded quantifier slide past an unbounded one, so modulo ZF only the unbounded blocks count. 核心思想：收集原理允许有界量词“穿过”无界量词，因此在模 ZF 的意义下，只有无界量词块才算数。

Definition. Let T be a theory. A formula φ is ΣₙT if there is a Σₙ formula ψ with the same free variables such that T ⊢ ∀x̄ (φ ↔ ψ). ΠₙT is defined in the same way. φ is ΔₙT if it is both ΣₙT and ΠₙT.
Collection lemma (provable in ZF). ∀x∈a ∃y φ ↔ ∃b ∀x∈a ∃y∈b φ. (→ is Collection, which ZF proves from Replacement plus the V_α hierarchy; ← is trivial.)
Consequence. For n ≥ 1, ΣₙZF is closed under ∧, ∨, ∃x, ∃x∈y and ∀x∈y; ΠₙZF is closed under ∧, ∨, ∀x, ∃x∈y and ∀x∈y; and ¬ turns ΣₙZF into ΠₙZF. 定义. 设 T 是一个理论。若存在自由变元相同的 Σₙ 公式 ψ，使得 T ⊢ ∀x̄ (φ ↔ ψ)，则称 φ 为 ΣₙT 公式；ΠₙT 同理。若 φ 既是 ΣₙT 又是 ΠₙT，则称它为 ΔₙT 公式。
收集引理（ZF 可证）. ∀x∈a ∃y φ ↔ ∃b ∀x∈a ∃y∈b φ。（→ 即收集原理，ZF 可由替换公理加上 V_α 层级证明；← 显然。）
推论. 当 n ≥ 1 时，ΣₙZF 对 ∧、∨、∃x、∃x∈y、∀x∈y 封闭；ΠₙZF 对 ∧、∨、∀x、∃x∈y、∀x∈y 封闭；¬ 把 ΣₙZF 变成 ΠₙZF。

Normalizer. Step through the rewriting. Each step moves the first bounded quantifier that stands in front of an unbounded one to the right. If the two quantifiers have the same type, they simply swap (pure logic). If the types differ, Collection (or its dual) creates a fresh unbounded quantifier and bounds the old one by it. 规范化器. 一步步看改写过程。每一步把第一个“挡在无界量词前面”的有界量词往右移。两个量词同类型时直接交换（纯逻辑）；类型不同时，用收集原理（或其对偶形式）引入一个新的无界量词，并让原来那个量词以它为界。

    A Δ₁ZF example: “x is finite”Δ₁ZF 的例子：“x 是有限集”

    ⚠ Common pitfall. “φ is Σ₁” and “φ is Σ₁ZF” are different claims. The second depends on the theory. Example: “x ∈ L”, i.e. ∃α (x ∈ L_α), is Σ₁ZF, but in ZF + V=L it is equivalent to x = x, which is Δ₀. Also, “ZF cannot prove φ is Πₙ” claims are always conditional on the consistency of ZF, since an inconsistent theory proves every equivalence. ⚠ 常见误区. “φ 是 Σ₁ 的”和“φ 是 Σ₁ZF 的”是两回事，后者依赖于理论。例：“x ∈ L”，即 ∃α (x ∈ L_α)，是 Σ₁ZF 的；但在 ZF + V=L 中它等价于 x = x，是 Δ₀ 的。另外，凡是“ZF 证明不了 φ 是 Πₙ 的”这类断言，都以 ZF 的一致性为前提，因为不一致的理论能证明任何等价式。
    §4 · Step 4

    Absoluteness, and why Δ₀ formulas are absolute for transitive classes绝对性，以及 Δ₀ 公式为何对传递类绝对

    Prerequisites前置知识: L14 · relativization φ^M相对化 φ^M §1 · Δ₀Δ₀

    Core idea: a bounded search started at x only visits elements of elements of x. If M is transitive, M can see all of them, so M and V give the same answer. 核心思想：从 x 出发的有界搜索只会访问 x 的元素的元素……若 M 是传递的，这些 M 全都看得见，于是 M 和 V 给出同样的答案。

    Definition. For a class M and a formula φ(x₁,…,xₙ), φM is φ with every quantifier ∃y / ∀y replaced by ∃y∈M / ∀y∈M. φ is absolute for M if ∀x̄∈M (φM(x̄) ↔ φ(x̄)). It is upward absolute if only “→” is required, and downward absolute if only “←” is required.
    Theorem. If M is a transitive class, every Δ₀ formula is absolute for M. No axioms need to hold in M.     定义. 对类 M 与公式 φ(x₁,…,xₙ)，φM 是把 φ 中每个量词 ∃y / ∀y 换成 ∃y∈M / ∀y∈M 后得到的公式。若 ∀x̄∈M (φM(x̄) ↔ φ(x̄))，则称 φ 对 M 绝对；只要求“→”时称为向上绝对，只要求“←”时称为向下绝对。
    定理. 若 M 是传递类，则每个 Δ₀ 公式都对 M 绝对，不需要 M 满足任何公理。

    Proof (induction on Δ₀ formulas)证明（对 Δ₀ 公式归纳）
    Atomic. (x∈y)M is literally x∈y, and the same holds for =. Nothing to prove.原子公式. (x∈y)M 就是 x∈y，等号同理，无需证明。
    Connectives. Relativization commutes with ¬, ∧, …, so the induction hypothesis passes straight through.联结词. 相对化与 ¬、∧ 等可交换，归纳假设直接传递下去。
    Bounded ∃. Let y, p̄ ∈ M. Then (∃x∈y ψ)M is ∃x∈M (x∈y ∧ ψM). Since M is transitive and y∈M, every x∈y is already in M, so “x∈M” is redundant. Together with ψM ↔ ψ (IH, applicable because x ∈ M) this gives ∃x (x∈y ∧ ψ). 有界 ∃. 设 y, p̄ ∈ M，则 (∃x∈y ψ)M 就是 ∃x∈M (x∈y ∧ ψM)。因为 M 传递且 y∈M，每个 x∈y 都已在 M 中，所以条件“x∈M”是多余的；再结合 ψM ↔ ψ（归纳假设，因 x ∈ M 而适用）即得 ∃x (x∈y ∧ ψ)。
    Bounded ∀. Same argument, or use ∀x∈y ψ ≡ ¬∃x∈y ¬ψ. ∎ The only property of M we used is transitivity, in the step “x ∈ y ∈ M ⇒ x ∈ M”. That is exactly where the non-transitive picture above breaks. 有界 ∀. 同理，或利用 ∀x∈y ψ ≡ ¬∃x∈y ¬ψ。∎ 我们用到的 M 的唯一性质就是传递性，即“x ∈ y ∈ M ⇒ x ∈ M”这一步。上面那幅不传递的图恰恰坏在这里。
    §5 · Step 5

    The absoluteness ladder: Σ₁ goes up, Π₁ goes down绝对性阶梯：Σ₁ 向上，Π₁ 向下

    Prerequisites前置知识: §4 · Δ₀ absolutenessΔ₀ 绝对性 L9 · cardinals基数 L5 · Löwenheim–SkolemLS 定理

    Core idea: a witness found inside M is still a witness in V, but V may hold witnesses (or counterexamples) that M cannot see. 核心思想：在 M 里找到的证据到了 V 里仍然是证据；但 V 可能有 M 看不见的证据（或反例）。

    Theorem. Let M be a transitive class. (1) Σ₁ formulas are upward absolute: for x̄ ∈ M, φM(x̄) → φ(x̄). (2) Π₁ formulas are downward absolute: for x̄ ∈ M, φ(x̄) → φM(x̄). (3) If M ⊨ T (each axiom of T relativized to M holds) and V ⊨ T, then Σ₁T formulas are upward absolute, Π₁T formulas are downward absolute, and Δ₁T formulas are absolute for M. 定理. 设 M 是传递类。 (1) Σ₁ 公式向上绝对：对 x̄ ∈ M 有 φM(x̄) → φ(x̄)。 (2) Π₁ 公式向下绝对：对 x̄ ∈ M 有 φ(x̄) → φM(x̄)。 (3) 若 M ⊨ T（T 的每条公理相对化到 M 后都成立）且 V ⊨ T，则 Σ₁T 公式向上绝对，Π₁T 公式向下绝对，Δ₁T 公式绝对。

    Below, M is a countable transitive set model of a large finite fragment of ZFC. Such an M exists in ZFC: reflect the fragment to some V_α (§7), take a countable elementary submodel (Löwenheim–Skolem), and apply the Mostowski collapse. Pick a statement and run the search. 下图中 M 是 ZFC 某个足够大的有限片段的可数传递集合模型。这样的 M 在 ZFC 中确实存在：先把该片段反射到某个 V_α（§7），再取可数初等子模型（勒文海姆–斯科伦），最后做莫斯托夫斯基坍塌。选一个命题，运行搜索。

    ⚠ Common pitfall. “ω₁M is countable in V but uncountable in M” is not a contradiction. “Countable” is Σ₁ (∃ a surjection from ω), and the surjection simply isn't an element of M. Absoluteness theorems speak about formulas with parameters in M; Π₁ downward absoluteness says nothing about upward transfer. ⚠ 常见误区. “ω₁M 在 V 中可数、在 M 中不可数”并不矛盾。“可数”是 Σ₁ 的（存在从 ω 出发的满射），只是那个满射不是 M 的元素而已。绝对性定理讨论的是参数在 M 中的公式；Π₁ 的向下绝对性对向上传递不作任何保证。
    §6 · Step 6

    Lévy absoluteness: H_κ is Σ₁-elementary in V列维绝对性：H_κ 是 V 的 Σ₁-初等子结构

    Prerequisites前置知识: §5 · upward absoluteness向上绝对 L5 · Löwenheim–SkolemLS 定理 L14 · Mostowski collapse莫斯托夫斯基坍塌

    Core idea: if a Σ₁ fact about small sets has a witness anywhere in V, it has a small witness. Shrink the witness with Löwenheim–Skolem and the Mostowski collapse. 核心思想：关于小集合的 Σ₁ 事实只要在 V 中某处有证据，就一定有小的证据。用勒文海姆–斯科伦定理加莫斯托夫斯基坍塌，把证据“压小”。

    Definition. H_κ = {x : |trcl(x)| < κ}, the sets of hereditary cardinality < κ. H_κ is transitive and H_κ ⊆ V_κ. H_ω₁ = HC is the set of hereditarily countable sets.
    Theorem (Lévy; ZFC). For every uncountable cardinal κ, H_κ ≺Σ₁ V: for every Σ₁ formula φ and all p̄ ∈ H_κ, φH_κ(p̄) ↔ φ(p̄).     定义. H_κ = {x : |trcl(x)| < κ}，即遗传基数小于 κ 的集合全体。H_κ 是传递集，且 H_κ ⊆ V_κ。H_ω₁ = HC 是遗传可数集全体。
    定理（列维；ZFC）. 对每个不可数基数 κ，H_κ ≺Σ₁ V：对每个 Σ₁ 公式 φ 及所有 p̄ ∈ H_κ，有 φH_κ(p̄) ↔ φ(p̄)。
    κ =
    Proof (the non-trivial direction ←)证明（非平凡方向 ←）
    → is §5 (1): H_κ is transitive. For ←, write φ ≡ ∃w ψ(w, p̄) with ψ Δ₀, and suppose V ⊨ ψ(w, p̄). Choose a regular θ > κ with w, p̄ ∈ H_θ. Then H_θ ⊨ ψ(w,p̄) by Δ₀ absoluteness. → 就是 §5 (1)：H_κ 是传递的。对 ←，记 φ ≡ ∃w ψ(w, p̄)，ψ 为 Δ₀，并设 V ⊨ ψ(w, p̄)。取正则基数 θ > κ 使 w, p̄ ∈ H_θ。由 Δ₀ 绝对性，H_θ ⊨ ψ(w,p̄)。
    Löwenheim–Skolem (uses AC): there is X ≺ (H_θ, ∈) with trcl({p̄}) ∪ {w} ⊆ X and |X| ≤ |trcl({p̄})| + ℵ₀ < κ. The strict inequality needs κ uncountable. 勒文海姆–斯科伦（用到选择公理）：存在 X ≺ (H_θ, ∈)，使 trcl({p̄}) ∪ {w} ⊆ X 且 |X| ≤ |trcl({p̄})| + ℵ₀ < κ。严格不等号要求 κ 不可数。
    Mostowski collapse π : X ≅ N, N transitive. Since trcl({p̄}) ⊆ X is transitive, π fixes it pointwise, so π(p̄) = p̄. Then N ⊨ ψ(π(w), p̄). 莫斯托夫斯基坍塌 π : X ≅ N，N 传递。由于 trcl({p̄}) ⊆ X 本身传递，π 在其上逐点不动，故 π(p̄) = p̄，于是 N ⊨ ψ(π(w), p̄)。
    N is transitive with |N| < κ, so every element of N, including π(w), lies in H_κ. By Δ₀ absoluteness (twice: N → V → H_κ), H_κ ⊨ ψ(π(w), p̄), hence H_κ ⊨ ∃w ψ. ∎ N 传递且 |N| < κ，所以 N 的每个元素（包括 π(w)）都属于 H_κ。两次运用 Δ₀ 绝对性（N → V → H_κ），得 H_κ ⊨ ψ(π(w), p̄)，从而 H_κ ⊨ ∃w ψ。∎
    ⚠ Common pitfall. The theorem stops at Σ₁. H_ω₁ is not Σ₂-elementary in V: “there is an uncountable set” is Σ₂ (∃x ∀f …), true in V, false in H_ω₁, where every set is countable (see E6). It also needs κ uncountable: in H_ω = V_ω, the Σ₁ sentence ∃x (x is a nonzero limit ordinal) (i.e. “an infinite set exists”) fails. ⚠ 常见误区. 定理只到 Σ₁ 为止。H_ω₁ 不是 V 的 Σ₂-初等子结构：“存在不可数集”是 Σ₂ 命题（∃x ∀f …），在 V 中为真，在 H_ω₁ 中却为假，因为那里每个集合都可数（见 E6）。定理还要求 κ 不可数：在 H_ω = V_ω 中，Σ₁ 命题 ∃x (x 是非零极限序数)（即“存在无穷集”）不成立。
    §7 · Step 7

    The reflection theorem (Lévy–Montague)反射定理（列维–蒙塔古）

    Prerequisites前置知识: L14 · V_αV_α L5 · Tarski–Vaught test塔斯基–沃特判别法 L13 · Tarski undefinability塔斯基不可定义性

    Core idea: for finitely many formulas, keep climbing until every witness question asked below the current level is answered below it. The limit of the climb reflects those formulas. 核心思想：对有限多个公式，一直往上爬，直到“当前高度以下提出的每个求证据问题，都能在该高度以下得到回答”。爬升的极限就反射了这些公式。

    Reflection theorem (a schema). For each finite list of formulas φ₁,…,φ_k, ZF proves: the class {α : ∀i ∀p̄∈V_α (φ_iV_α(p̄) ↔ φ_i(p̄))} is closed and unbounded in Ord.
    Σₙ version. For each fixed n ≥ 1, ZF ⊢ “the class C(n) = {α : V_α ≺Σₙ V} is closed unbounded”. This single sentence can be written down because Σₙ truth is definable (§8).     反射定理（定理模式）. 对每个有限公式列 φ₁,…,φ_k，ZF 证明：类 {α : ∀i ∀p̄∈V_α (φ_iV_α(p̄) ↔ φ_i(p̄))} 在 Ord 中闭且无界。
    Σₙ 版本. 对每个固定的 n ≥ 1，ZF ⊢“类 C(n) = {α : V_α ≺Σₙ V} 闭且无界”。之所以能写成单独一句话，是因为 Σₙ 真谓词可定义（§8）。
    Proof sketch证明概要
    Close the list under subformulas (still finite). For every subformula of the form ∃y ψ(y, p̄), let F(p̄) = the least γ such that, if some witness y exists, then one exists in V_γ (and 0 if none exists). 把公式列对子公式封闭（仍是有限的）。对每个形如 ∃y ψ(y, p̄) 的子公式，令 F(p̄) 为最小的 γ，使得只要存在证据 y，就有一个在 V_γ 中（若不存在证据则取 0）。
    Replacement: G(β) = sup{F(p̄) : p̄ ∈ V_β, over the finitely many ∃-subformulas} is an ordinal. 由替换公理，G(β) = sup{F(p̄) : p̄ ∈ V_β，取遍有限多个 ∃-子公式} 是一个序数。
    Given β, put β₀ = β+1 and βₖ₊₁ = max(βₖ + 1, G(βₖ)), and let α = sup βₖ, a limit ordinal > β. (This is the animation above.) 给定 β，令 β₀ = β+1，βₖ₊₁ = max(βₖ + 1, G(βₖ))，α = sup βₖ，这是大于 β 的极限序数（即上面的动画）。
    Any p̄ ∈ V_α lies in some V_βₖ, so its witnesses (if any) lie in V_{βₖ₊₁} ⊆ V_α. This is the Tarski–Vaught condition for our finitely many formulas, and induction on subformulas gives φ_iV_α ↔ φ_i on V_α. 任何 p̄ ∈ V_α 都落在某个 V_βₖ 中，于是它的证据（若存在）落在 V_{βₖ₊₁} ⊆ V_α 中。这就是这有限多个公式的塔斯基–沃特条件；对子公式归纳即得在 V_α 上 φ_iV_α ↔ φ_i。
    Closed: if each αξ (ξ < λ) reflects the list, then so does sup αξ, because V_sup = ⋃ Vαξ and witnesses for parameters in some Vαξ are found in that same Vαξ. ∎ 闭性：若每个 αξ（ξ < λ）都反射这些公式，则 sup αξ 也反射，因为 V_sup = ⋃ Vαξ，而参数在某个 Vαξ 中时，证据在同一个 Vαξ 中就能找到。∎
    ⚠ Common pitfall. The theorem does not say “ZF ⊢ ∃α V_α ≺ V”. That is not even a sentence of set theory: “V_α ≺ V” quantifies over all formulas, which would need a truth predicate for V, and by Tarski (L13) none is definable. What we get is one theorem per finite list of formulas (equivalently, per n, via C(n)). One consequence: if ZFC is consistent, it is not finitely axiomatizable. Otherwise reflecting its finitely many axioms would give ZFC ⊢ “some V_α ⊨ ZFC”, hence ZFC ⊢ Con(ZFC), contradicting Gödel II. ⚠ 常见误区. 反射定理不是说“ZF ⊢ ∃α V_α ≺ V”。后者根本不是集合论中的一句话：“V_α ≺ V”要对所有公式量化，这需要一个关于 V 的真谓词，而由塔斯基定理（第 13 课），这样的谓词不可定义。我们得到的是每个有限公式列各一条定理（等价地，借助 C(n)，每个 n 一条）。推论：若 ZFC 一致，它不可有限公理化。否则把那有限多条公理反射下去，得 ZFC ⊢“某个 V_α ⊨ ZFC”，从而 ZFC ⊢ Con(ZFC)，与哥德尔第二不完全性定理矛盾。
    §8 · Step 8

    Partial truth predicates: Σₙ-truth is definable, full truth is not部分真谓词：Σₙ 真可定义，完全真不可定义

    Prerequisites前置知识: L13 · Tarski, diagonal lemma塔斯基、对角线引理 §3 · closure of ΣₙZFΣₙZF 的封闭性

    Core idea: one formula can evaluate all formulas up to a fixed complexity n, and it has complexity n itself. No single formula can handle every level. 核心思想：一个公式可以对复杂度不超过 n 的所有公式求值，而它自身的复杂度也是 n；但没有任何一个公式能同时管住所有层级。

    Theorem. (a) There is a Δ₁ZF formula SatΔ₀(e, p) such that for each Δ₀ formula φ(x), ZF ⊢ ∀p (φ(p) ↔ SatΔ₀(⌜φ⌝, p)). The idea: evaluate φ inside the set trcl({p}). (b) For each n ≥ 1 there is a Σₙ formula SatΣₙ(e, p) such that for every Σₙ formula φ(x), ZF ⊢ ∀p (φ(p) ↔ SatΣₙ(⌜φ⌝, p)). (c) Tarski. There is no formula Tr(e, p) that does this for all formulas φ simultaneously. 定理. (a) 存在 Δ₁ZF 公式 SatΔ₀(e, p)，使得对每个 Δ₀ 公式 φ(x)，ZF ⊢ ∀p (φ(p) ↔ SatΔ₀(⌜φ⌝, p))。思路：在集合 trcl({p}) 内部对 φ 求值。 (b) 对每个 n ≥ 1，存在 Σₙ 公式 SatΣₙ(e, p)，使得对每个 Σₙ 公式 φ(x)，ZF ⊢ ∀p (φ(p) ↔ SatΣₙ(⌜φ⌝, p))。 (c) 塔斯基. 不存在一个公式 Tr(e, p) 能对所有公式 φ 同时做到这一点。

    Why no contradiction? Choose a candidate truth predicate and build its liar δ with the diagonal lemma: ZF ⊢ δ ↔ ¬Pred(⌜δ⌝). If δ lay inside Pred's domain, then δ ↔ Pred(⌜δ⌝) ↔ ¬δ. So δ must land outside that domain. 为什么不矛盾？选一个候选真谓词，用对角线引理造出它的说谎者 δ：ZF ⊢ δ ↔ ¬Pred(⌜δ⌝)。若 δ 落在 Pred 的管辖范围之内，就会有 δ ↔ Pred(⌜δ⌝) ↔ ¬δ。所以 δ 只能落在管辖范围之外。

    ⚠ Common pitfall. “Each SatΣₙ is definable” does not give a definable full truth predicate by taking the union over n. The union would be ∃n SatΣₙ(e,p), but n is a metatheoretic index and SatΣₙ is a different formula for each n. There is no single formula that takes n as an argument and still works for all n. ⚠ 常见误区. “每个 SatΣₙ 都可定义”并不能通过对 n 取并得到一个可定义的完全真谓词。那个并会是 ∃n SatΣₙ(e,p)，但 n 是元理论中的下标，每个 n 对应的 SatΣₙ 是不同的公式；不存在一个以 n 为变量、又对所有 n 都正确的单一公式。
    §9 · Step 9

    Shoenfield absoluteness: Σ¹₂ statements cannot be moved舍恩菲尔德绝对性：Σ¹₂ 命题纹丝不动

    Prerequisites前置知识: L18 · Σ¹ₙ, trees, Π¹₁ = well-foundedΣ¹ₙ、树、Π¹₁ 与良基 L15 · L可构成宇宙 L L16 · forcing力迫法 §5 · Δ₁ZF absoluteΔ₁ZF 绝对

    Core idea: a Σ¹₂ statement is equivalent to “a certain tree S on ω × ω₁ has an infinite branch”. Ill-foundedness of a tree is absolute, so any transitive model of ZF that contains all countable ordinals gives the same answer. 核心思想：一个 Σ¹₂ 命题等价于“ω × ω₁ 上的某棵树 S 有无穷分支”。树的非良基性是绝对的，所以只要 ZF 的传递模型包含所有可数序数，答案就相同。

    Shoenfield's absoluteness theorem. Let M be a transitive model of ZF (a set or a proper class) with ω₁ ⊆ M, and let a ∈ ω^ω ∩ M. Then every Σ¹₂(a) and every Π¹₂(a) sentence is absolute between M and V. In particular this holds for M = L[a] (or L when there is no parameter) and between V and any forcing extension V[G].
    Without ω₁ ⊆ M (e.g. M countable), only the easy half survives: Σ¹₂(a) sentences are still upward absolute.     舍恩菲尔德绝对性定理. 设 M 是 ZF 的传递模型（可以是集合，也可以是真类），ω₁ ⊆ M，且 a ∈ ω^ω ∩ M。则每个 Σ¹₂(a) 句子和每个 Π¹₂(a) 句子在 M 与 V 之间绝对。特别地，对 M = L[a]（无参数时即 L）成立，对 V 与任意力迫扩张 V[G] 之间也成立。
    若去掉 ω₁ ⊆ M（例如 M 可数），只剩容易的那一半：Σ¹₂(a) 句子仍然向上绝对。
    Proof sketch (for σ ≡ ∃x ∀y θ(x, y, a), θ arithmetical)证明概要（σ ≡ ∃x ∀y θ(x, y, a)，θ 为算术公式）
    Π¹₁ = well-foundedness (L18). There is a recursive way to assign to each x a tree T_x on ω (built from finite pieces of x and a) such that ∀y θ(x,y,a) ⟺ T_x is well-founded. Π¹₁ = 良基（第 18 课）. 可以递归地给每个 x 指派一棵 ω 上的树 T_x（由 x 和 a 的有限片段构造），使得 ∀y θ(x,y,a) ⟺ T_x 良基。
    Rank functions. A countable tree is well-founded iff it has an order-reversing map into ω₁ (a rank function). So σ ⟺ ∃x ∃f (f : T_x → ω₁ order-reversing). 秩函数. 可数树良基，当且仅当存在到 ω₁ 的保逆序映射（秩函数）。所以 σ ⟺ ∃x ∃f (f : T_x → ω₁ 保逆序)。
    The Shoenfield tree S. A node of S is a finite attempt (x↾n, f↾n): n digits of x and ordinal values below ω₁ for the first n nodes of T_x (in a fixed enumeration of ω^{<ω}) that respect the order so far. S is a tree on ω × ω₁. For an ordinal δ let S_δ be the subtree that only uses values < δ. It is defined from a and δ by an absolute (Δ₁ZF) recipe, so whenever δ ∈ M, M computes the same S_δ. Because ω₁ ⊆ M, this holds for every countable δ. 舍恩菲尔德树 S. S 的节点是有限的“尝试” (x↾n, f↾n)：x 的前 n 位，以及给 T_x 的前 n 个节点（按 ω^{<ω} 的某个固定枚举）指定的小于 ω₁ 的序数值，且到目前为止保持序关系。S 是 ω × ω₁ 上的树。对序数 δ，令 S_δ 为只用到 < δ 的值的子树。它由 a 和 δ 经绝对的（Δ₁ZF）方式定义，所以只要 δ ∈ M，M 算出的 S_δ 就是同一棵树。由于 ω₁ ⊆ M，这对每个可数 δ 都成立。
    Branches. An infinite branch of S_δ is exactly a pair (x, f) with f a rank function from T_x into δ. Since a well-founded countable tree has countable rank, σ ⟺ S_δ is ill-founded for some countable δ. Caution: we never use ω₁M = ω₁; that can fail even for M = L (when ω₁L is countable). 分支. S_δ 的无穷分支恰好是一对 (x, f)，其中 f 是从 T_x 到 δ 的秩函数。由于良基的可数树的秩可数，σ ⟺ 存在可数 δ 使 S_δ 非良基。注意：我们从不使用 ω₁M = ω₁；即使 M = L，它也可能不成立（当 ω₁L 可数时）。
    Absoluteness of well-foundedness. “S is well-founded” is Δ₁ZF (Π₁: no descending sequence; Σ₁: a rank function exists), hence absolute for transitive models of ZF (§5); so is “T_x is well-founded”. Up: if M ⊨ σ, take x ∈ M with M ⊨ “T_x well-founded”; then T_x really is well-founded, so σ. Down: if σ, some S_δ (δ countable, so δ ∈ M) is ill-founded, hence M ⊨ “S_δ ill-founded”; a branch in M yields x ∈ M with a rank function in M, so M ⊨ σ. ∎ If M is countable, M only contains the trees S_δ for δ < Ord ∩ M, and these may all be well-founded even though S is not. 良基性的绝对性. “S 良基”是 Δ₁ZF 的（Π₁ 形式：不存在无穷下降序列；Σ₁ 形式：存在秩函数），因而对 ZF 的传递模型绝对（§5）；“T_x 良基”同理。向上：若 M ⊨ σ，取 x ∈ M 使 M ⊨“T_x 良基”，则 T_x 确实良基，故 σ 成立。向下：若 σ 成立，则某个 S_δ（δ 可数，故 δ ∈ M）非良基，从而 M ⊨“S_δ 非良基”；M 中的一条分支给出 x ∈ M 以及 M 中的秩函数，所以 M ⊨ σ。∎ 若 M 可数，M 只含有 δ < Ord ∩ M 的树 S_δ，即使 S 非良基，这些树也可能全是良基的。
    Consequences.
    • Arithmetic sentences (Goldbach, Con(ZFC), …) and Σ¹₂ / Π¹₂ sentences have the same truth value in V, in L and in every forcing extension, so forcing alone cannot prove them independent.
    • If ZFC + V=L proves a Σ¹₂ or Π¹₂ sentence, then ZFC proves it.
    • From L to V: Σ¹₃ sentences are upward absolute and Π¹₃ sentences downward absolute.     推论.
    • 算术句子（哥德巴赫猜想、Con(ZFC) 等）以及 Σ¹₂ / Π¹₂ 句子在 V、L 和任何力迫扩张中真值相同，所以单靠力迫法无法证明它们独立。
    • 若 ZFC + V=L 证明了某个 Σ¹₂ 或 Π¹₂ 句子，则 ZFC 也能证明它。
    • 从 L 到 V：Σ¹₃ 句子向上绝对，Π¹₃ 句子向下绝对。
    ⚠ Sharpness. Σ¹₃ can move. “There is a non-constructible real”, ∃x (x ∉ L), is Σ¹₃, because “x ∈ L” is Σ¹₂ for reals x. It is false in L and true after adding a Cohen real. Similarly CH can be changed by forcing (L16), so CH is not ZFC-equivalent to any Σ¹₂ sentence (if ZFC is consistent). ⚠ 不可再推广. Σ¹₃ 就可能变。“存在不可构成的实数”，即 ∃x (x ∉ L)，是 Σ¹₃ 句子，因为对实数 x，“x ∈ L”是 Σ¹₂ 的。它在 L 中为假，添加一个科恩实数后为真。同理，CH 可以被力迫改变（第 16 课），所以（若 ZFC 一致）CH 不与任何 Σ¹₂ 句子 ZFC-等价。

    The hierarchy atlas: Σ⁰ₙ, Lévy Σₙ, Σ¹ₙ层级地图：Σ⁰ₙ、列维 Σₙ、Σ¹ₙ

    Prerequisites前置知识: L17 · Σ⁰ₙ算术层级 L18 · Σ¹ₙ分析层级 §6 · H_ω₁ ≺Σ₁ VH_ω₁ ≺Σ₁ V

    Core idea: all three hierarchies are “count the unbounded quantifiers”, but over different universes. Number quantifiers correspond to quantifiers over V_ω; real quantifiers correspond to quantifiers over H_ω₁, shifted by one level. 核心思想：三种层级都是“数无界量词”，只是论域不同。数量词对应 V_ω 上的量词；实数量词对应 H_ω₁ 上的量词，并且层级错开一位。

    Facts (n ≥ 1). (i) A ⊆ ω is Σ⁰ₙ ⟺ A is Σₙ-definable over (V_ω, ∈). (V_ω = H_ω is coded in ℕ by Ackermann's coding: m E k ⟺ the m-th binary digit of k is 1.) (ii) A ⊆ ω^ω is Σ¹ₙ₊₁ ⟺ A is Σₙ-definable over (H_ω₁, ∈). Lightface corresponds to no parameters; boldface to parameters from H_ω₁ (each coded by a real). (iii) (ZFC, by §6) For sets of reals, Σ₁ over H_ω₁ = Σ₁ over V with parameters in H_ω₁. Hence Σ¹₂ ⊆ Σ₁ZFC, Π¹₂ ⊆ Π₁ZFC, while Σ¹₁ and Π¹₁ are Δ₁ZF and arithmetical statements are Δ₀ in the parameter ω. 事实（n ≥ 1）. (i) A ⊆ ω 是 Σ⁰ₙ 的 ⟺ A 在 (V_ω, ∈) 上 Σₙ 可定义。（V_ω = H_ω 借阿克曼编码嵌入 ℕ：m E k ⟺ k 的第 m 个二进制位为 1。） (ii) A ⊆ ω^ω 是 Σ¹ₙ₊₁ 的 ⟺ A 在 (H_ω₁, ∈) 上 Σₙ 可定义。无参数（lightface，细体）对应无参数定义；带参数（boldface，粗体）对应以 H_ω₁ 中元素为参数（每个都可用实数编码）。 (iii)（ZFC，由 §6）对实数集而言，H_ω₁ 上的 Σ₁ = V 上以 H_ω₁ 元素为参数的 Σ₁。因此 Σ¹₂ ⊆ Σ₁ZFC，Π¹₂ ⊆ Π₁ZFC；而 Σ¹₁ 和 Π¹₁ 是 Δ₁ZF 的，算术命题则是以 ω 为参数的 Δ₀ 命题。

    ⚠ Common pitfall. “Σ¹ₙ ↔ Σₙ” is wrong: the index shifts, Σ¹ₙ₊₁ ↔ Σₙ(H_ω₁), and only for n ≥ 1. Also, the H_ω₁ ↔ V collapse holds only at level 1.
