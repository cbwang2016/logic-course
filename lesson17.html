Part V · Lesson 17

The Arithmetical Hierarchy & Turing Degrees算术层级与图灵度

In Lesson 11 every set was either decidable or not. Here we measure how undecidable a set is, in two ways that turn out to agree: by counting quantifier alternations in its definition, and by asking which oracle you need to compute it. Your old friend the diagonal argument shows that the ladder never stops. 在第 11 课里，一个集合要么可判定，要么不可判定。这一课我们要度量它有多不可判定，方法有两种：数一数定义中量词交替了几次，或者问一问计算它需要什么样的谕示。这两种度量最后是一致的。老朋友对角线法会告诉我们：这架梯子永远爬不到顶。

Step 1

Bounded quantifiers and Δ₀ formulas有界量词与 Δ₀ 公式

Prerequisites前置: L3 first-order formulasL3 一阶公式 L11 computabilityL11 可计算性 L12 language of arithmeticL12 算术语言

Core idea: a quantifier with a bound, like ∃y<x, only asks finitely many questions, so it is harmless. An unbounded ∃y may send you searching forever. 核心思想：带上界的量词（如 ∃y<x）只需检查有限多个情形，因此无害；无界的 ∃y 却可能让你永远搜下去。

We work in the language of arithmetic L_A = {0, S, +, ·, <}, interpreted in the standard model ℕ. Pick a formula and an input, then press Search. The red wall marks the bound. A bounded search hits the wall and stops. An unbounded search has no wall. 我们使用算术语言 L_A = {0, S, +, ·, <}，在标准模型 ℕ 中解释。选一个公式和一个输入，点搜索。红墙表示上界：有界搜索碰到墙就停；无界搜索没有墙。

x = 9
Definition. For a term t not containing y, the bounded quantifiers are abbreviations: ∀y<t φ :≡ ∀y (y<t → φ) and ∃y<t φ :≡ ∃y (y<t ∧ φ). The Δ₀ formulas (also written Σ₀ = Π₀) form the smallest class containing the atomic formulas and closed under ¬, ∧, ∨, → and bounded quantification.
Fact. Every Δ₀ formula defines a decidable (indeed primitive recursive) relation on ℕ: to evaluate it, you only ever check finitely many cases. 定义. 设项 t 中不含 y，有界量词是如下缩写： ∀y<t φ :≡ ∀y (y<t → φ)，∃y<t φ :≡ ∃y (y<t ∧ φ)。 Δ₀ 公式（也记作 Σ₀ = Π₀）是包含全部原子公式、对 ¬, ∧, ∨, → 及有界量词封闭的最小公式类。
事实. 每个 Δ₀ 公式在 ℕ 上定义的关系都是可判定的（其实是原始递归的）：求值时只需检查有限多个情形。
⚠ Common pitfall. “Δ₀-definable” is not the same as “decidable”. Every Δ₀-definable set is decidable, but not conversely: Δ₀-definable sets can all be decided in linear space, and the space hierarchy theorem gives decidable sets that cannot. The class of all decidable sets will be called Δ⁰₁ (Step 3). Note the different typography: Δ₀ is a class of formulas; Δ⁰₁ is a class of sets. ⚠ 常见误区. “Δ₀ 可定义”不等于“可判定”。Δ₀ 可定义集都可判定，反之不然：Δ₀ 可定义集都能在线性空间内判定，而空间层级定理给出了做不到这一点的可判定集。全体可判定集将记作 Δ⁰₁（第 3 步）。注意记号差别：Δ₀ 是公式类，Δ⁰₁ 是集合类。
Step 2

Σ⁰ₙ and Π⁰ₙ: count the alternating blocksΣ⁰ₙ 与 Π⁰ₙ：数交替的量词块

Prerequisites前置: Step 1 Δ₀第 1 步 Δ₀ L3 prenex formL3 前束范式

Core idea: only unbounded quantifiers count, and only the number of alternations between ∃ and ∀ matters. 核心思想：只有无界量词才算数，而且只有 ∃ 与 ∀ 之间交替的次数才重要。

Definition. For n ≥ 1, a formula is Σ⁰ₙ if it has the form ∃ȳ₁ ∀ȳ₂ ∃ȳ₃ … Qȳₙ θ, i.e. n nonempty blocks of unbounded quantifiers that alternate, starting with ∃, followed by a Δ₀ matrix θ. Π⁰ₙ is the same but starting with ∀. A set A ⊆ ℕ is Σ⁰ₙ (resp. Π⁰ₙ) if A = {m : ℕ ⊨ φ(m̄)} for some Σ⁰ₙ (resp. Π⁰ₙ) formula φ(x). Relations on ℕᵏ are treated the same way. 定义. 设 n ≥ 1。形如 ∃ȳ₁ ∀ȳ₂ ∃ȳ₃ … Qȳₙ θ 的公式称为 Σ⁰ₙ 公式：前面是 n 个非空、交替出现、以 ∃ 开头的无界量词块，后面跟一个 Δ₀ 母式 θ。以 ∀ 开头的则称为 Π⁰ₙ 公式。 若存在 Σ⁰ₙ（相应地 Π⁰ₙ）公式 φ(x) 使 A = {m : ℕ ⊨ φ(m̄)}，就称集合 A ⊆ ℕ 是 Σ⁰ₙ 集（相应地 Π⁰ₙ 集）。ℕᵏ 上的关系同理。

The prefix classifier量词前缀分类器

Build a quantifier prefix in front of a Δ₀ matrix θ, then press Normalize and watch the two collapsing rules run. 在 Δ₀ 母式 θ 前面搭一个量词前缀，然后按规范化，看两条压缩规则如何运作。

Normal-form lemma (true in ℕ).
(a) Like quantifiers merge. ∃y ∃z θ(y,z) ⟺ ∃w θ((w)₀,(w)₁), where w ↦ ((w)₀,(w)₁) inverts a Δ₀-definable pairing such as Cantor's ⟨y,z⟩ = (y+z)(y+z+1)/2 + y. Same for ∀∀. Since (w)₀, (w)₁ ≤ w, the decoding stays inside a Δ₀ matrix.
(b) Bounded quantifiers are absorbed. ∀y<t ∃z θ ⟺ ∃w ∀y<t ∃z<w θ: finitely many y need finitely many witnesses z, so one bound w covers them all (dually for ∃y<t ∀z). This is the collection (bounding) principle. It holds in ℕ, and PA proves every instance, but weak fragments of arithmetic may not.
(c) Closure. Σ⁰ₙ is closed under ∧, ∨, ∃y, ∃y<t, ∀y<t; Π⁰ₙ is closed under ∧, ∨, ∀y, ∃y<t, ∀y<t; and ¬ swaps Σ⁰ₙ with Π⁰ₙ. Hence every arithmetical formula is equivalent in ℕ to a Σ⁰ₙ or Π⁰ₙ formula for some n. 范式引理（在 ℕ 中成立）。
(a) 同类量词合并. ∃y ∃z θ(y,z) ⟺ ∃w θ((w)₀,(w)₁)，其中 w ↦ ((w)₀,(w)₁) 是某个 Δ₀ 可定义配对函数的逆，例如康托尔配对 ⟨y,z⟩ = (y+z)(y+z+1)/2 + y。∀∀ 同理。由于 (w)₀, (w)₁ ≤ w，解码仍可写在 Δ₀ 母式内。
(b) 有界量词被吸收. ∀y<t ∃z θ ⟺ ∃w ∀y<t ∃z<w θ：有限多个 y 只需有限多个见证 z，取一个足够大的界 w 就能把它们全部罩住（∃y<t ∀z 对偶处理）。这就是收集原理（有界化原理）。它在 ℕ 中成立，PA 能证明它的每个实例，但较弱的算术片段未必能证明。
(c) 封闭性. Σ⁰ₙ 对 ∧、∨、∃y、∃y<t、∀y<t 封闭；Π⁰ₙ 对 ∧、∨、∀y、∃y<t、∀y<t 封闭；¬ 把 Σ⁰ₙ 与 Π⁰ₙ 互换。因此每个算术公式在 ℕ 中都等价于某个 Σ⁰ₙ 或 Π⁰ₙ 公式。
⚠ Common pitfall. The classifier gives an upper bound. If a formula is Π⁰₂, the set it defines is Π⁰₂, but it may also be much simpler. For example, ∀y ∃z (z = y + x) is a Π⁰₂ formula that defines all of ℕ. To show a set is not simpler, you need a separate argument, such as completeness (Steps 4 and 7). ⚠ 常见误区. 分类器给出的只是上界。公式是 Π⁰₂ 的，它定义的集合当然是 Π⁰₂ 集，但也可能简单得多。例如 ∀y ∃z (z = y + x) 是 Π⁰₂ 公式，定义的却是整个 ℕ。要说明一个集合不能更简单，必须另外论证，例如利用完全性（第 4、7 步）。
Step 3

Δ⁰ₙ; Δ⁰₁ = decidable and Σ⁰₁ = r.e.Δ⁰ₙ；Δ⁰₁ = 可判定，Σ⁰₁ = 递归可枚举

Prerequisites前置: Step 2第 2 步 L11 universal machineL11 通用机 L11 decidable vs r.e.L11 可判定与递归可枚举

Core idea: Σ⁰₁ means “a yes-answer has a finite certificate you can search for”. If both “yes” and “no” have such certificates, run both searches side by side and you can decide. 核心思想：Σ⁰₁ 意味着“答案为‘是’时存在一个可以搜出来的有限凭据”。如果“是”和“否”都有这样的凭据，两路搜索并行跑，就能判定。

Definition. Δ⁰ₙ := Σ⁰ₙ ∩ Π⁰ₙ (a class of sets: A is Δ⁰ₙ iff it has both a Σ⁰ₙ definition and a Π⁰ₙ definition).
Kleene normal form theorem. There are a Δ₀-definable (in particular primitive recursive) relation T(e,x,s) and a primitive recursive U with φₑ(x) ≃ U(μs T(e,x,s)). Here T(e,x,s) says “s codes a halting computation of machine e on input x”. Hence Wₑ = dom φₑ = {x : ∃s T(e,x,s)} is Σ⁰₁. Conversely, if A = {x : ∃y θ(x,y)} with θ Δ₀, then A is the domain of the search “try y = 0, 1, 2, …”.
Theorem. (i) A is Σ⁰₁ ⟺ A is r.e.  (ii) A is decidable ⟺ A and ℕ∖A are both r.e.  Therefore Δ⁰₁ = the decidable sets. 定义. Δ⁰ₙ := Σ⁰ₙ ∩ Π⁰ₙ（这是集合类：A 是 Δ⁰ₙ 集，当且仅当它既有 Σ⁰ₙ 定义，也有 Π⁰ₙ 定义）。
克莱尼范式定理. 存在 Δ₀ 可定义（因而原始递归）的关系 T(e,x,s) 和原始递归函数 U，使得 φₑ(x) ≃ U(μs T(e,x,s))。这里 T(e,x,s) 的意思是“s 编码了机器 e 在输入 x 上的一个停机计算”。因此 Wₑ = dom φₑ = {x : ∃s T(e,x,s)} 是 Σ⁰₁ 集。反过来，若 A = {x : ∃y θ(x,y)} 且 θ 为 Δ₀，则 A 就是搜索程序“依次试 y = 0, 1, 2, …”的定义域。
定理. (i) A 是 Σ⁰₁ 集 ⟺ A 递归可枚举；(ii) A 可判定 ⟺ A 与 ℕ∖A 都递归可枚举。所以 Δ⁰₁ = 可判定集。

The race: two semi-deciders run in parallel赛跑：两个半判定程序并行运行

Lane 1 searches for a certificate that x ∈ A; lane 2 searches for a certificate that x ∉ A. We alternate steps (dovetailing). For a decidable set, exactly one lane always finishes. For K there is no lane 2 at all. 第 1 道搜索“x ∈ A”的凭据，第 2 道搜索“x ∉ A”的凭据，两道轮流走一步（交错执行）。对可判定集，总有且只有一道会跑到终点。对 K 来说，第 2 道根本不存在。

x = 7
⚠ Common pitfall. “Δ⁰₁ formula” is not a syntactic notion. The first quantifier of a formula is either ∃ or ∀, so no single prenex formula is “Δ”. Δ⁰ₙ is a property of sets: two different formulas, one Σ⁰ₙ and one Π⁰ₙ, define the same set in ℕ. And do not confuse Δ₀ (bounded formulas) with Δ⁰₁ (decidable sets). ⚠ 常见误区. “Δ⁰₁ 公式”不是语法概念。前束公式的第一个量词非 ∃ 即 ∀，没有哪一个公式本身是“Δ”的。Δ⁰ₙ 是集合的性质：有两个不同的公式，一个 Σ⁰ₙ、一个 Π⁰ₙ，在 ℕ 中定义同一个集合。另外，别把 Δ₀（有界公式）与 Δ⁰₁（可判定集）混为一谈。
Step 4

The picture: the arithmetical hierarchy ladder全景：算术层级阶梯图

Prerequisites前置: Step 2第 2 步 Step 3第 3 步 L11 reductionsL11 归约

Core idea: each level sits inside the next in a diamond pattern, and famous sets live at exact levels. 核心思想：各层以菱形方式逐级包含，著名的集合都恰好落在确定的层上。

Arrows mean ⊆ (all of them are strict, see Step 5). Click a class for its definition, or a coloured set to see its defining formula and exact level. Notation: Wₑ,ₛ is the finite part of Wₑ enumerated within s steps, so “x ∈ Wₑ,ₛ” is Δ₀ in e, x, s. 箭头表示 ⊆（全部是真包含，见第 5 步）。点击类查看定义，点击彩色的集合查看定义公式与确切层级。记号：Wₑ,ₛ 表示 s 步之内枚举出的 Wₑ 的有限部分，所以“x ∈ Wₑ,ₛ”关于 e, x, s 是 Δ₀ 的。

Definition. Let Γ be one of Σ⁰ₙ, Π⁰ₙ. A set A is Γ-complete if A ∈ Γ and B ≤_m A for every B ∈ Γ (many-one reduction, Step 7).
Classification theorem (standard; see Soare, Ch. IV). K is Σ⁰₁-complete; Fin = {e : Wₑ finite} is Σ⁰₂-complete; Inf = {e : Wₑ infinite} and Tot = {e : φₑ total} are Π⁰₂-complete; Cof = {e : Wₑ cofinite} and Rec = {e : Wₑ decidable} are Σ⁰₃-complete; Cpl = {e : Wₑ ≡_T K} is Σ⁰₄-complete. 定义. 设 Γ 为 Σ⁰ₙ 或 Π⁰ₙ。若 A ∈ Γ，并且对每个 B ∈ Γ 都有 B ≤_m A（多一归约，见第 7 步），就称 A 是 Γ-完全集。
分类定理（经典结果，见 Soare 第 IV 章）：K 是 Σ⁰₁-完全的；Fin = {e : Wₑ 有限} 是 Σ⁰₂-完全的；Inf = {e : Wₑ 无限} 与 Tot = {e : φₑ 全函数} 是 Π⁰₂-完全的；Cof = {e : Wₑ 余有限} 与 Rec = {e : Wₑ 可判定} 是 Σ⁰₃-完全的；Cpl = {e : Wₑ ≡_T K} 是 Σ⁰₄-完全的。
⚠ Common pitfall. A dot on Σ⁰₂ means exactly there: in Σ⁰₂ but not in Π⁰₂ (so in particular not in Δ⁰₂ and not in any lower level). Membership alone (“Fin is Σ⁰₂”) is the easy upper bound; “not lower” comes from completeness plus the hierarchy theorem. Also note Σ⁰ₙ ∪ Π⁰ₙ ≠ Δ⁰ₙ₊₁: the middle diamond is not empty (try K ⊕ K̄). ⚠ 常见误区. 点落在 Σ⁰₂ 上表示恰好在这一层：属于 Σ⁰₂ 但不属于 Π⁰₂（因而也不属于 Δ⁰₂ 及更低各层）。“Fin 是 Σ⁰₂ 集”只是容易的上界；“不会更低”要靠完全性加上层级定理。另外 Σ⁰ₙ ∪ Π⁰ₙ ≠ Δ⁰ₙ₊₁：中间的菱形并不空（看看 K ⊕ K̄）。
Step 5

The hierarchy theorem: the ladder never collapses层级定理：阶梯永不坍缩

Prerequisites前置: Step 4第 4 步 L11 halting by diagonalizationL11 停机问题与对角线 L1 diagonal argumentL1 对角线论证

Core idea: Σ⁰ₙ has a universal set listing all Σ⁰ₙ sets as rows. Flip the diagonal and you get a Π⁰ₙ set that is no row. 核心思想：Σ⁰ₙ 有一个通用集，把所有 Σ⁰ₙ 集列成一行一行。翻转对角线，就得到一个不在任何一行中的 Π⁰ₙ 集。

Row e is the section U⁽ᵉ⁾ = {x : (e,x) ∈ Uₙ}; ● means x ∈ U⁽ᵉ⁾. Every Σ⁰ₙ set appears as some row. Press Diagonalize, then Suppose D is row e₀. 第 e 行是截面 U⁽ᵉ⁾ = {x : (e,x) ∈ Uₙ}；● 表示 x ∈ U⁽ᵉ⁾。每个 Σ⁰ₙ 集都会作为某一行出现。先点对角化，再点假设 D 是第 e₀ 行。

Hierarchy theorem. For every n ≥ 1:
(1) There is a Σ⁰ₙ set Uₙ ⊆ ℕ² such that the Σ⁰ₙ subsets of ℕ are exactly its sections U⁽ᵉ⁾.
(2) Σ⁰ₙ ≠ Π⁰ₙ. Consequently Δ⁰ₙ ⊊ Σ⁰ₙ, Δ⁰ₙ ⊊ Π⁰ₙ, and Σ⁰ₙ ∪ Π⁰ₙ ⊊ Δ⁰ₙ₊₁. 层级定理. 对每个 n ≥ 1：
(1) 存在 Σ⁰ₙ 集 Uₙ ⊆ ℕ²，使得 ℕ 的 Σ⁰ₙ 子集恰好是它的各个截面 U⁽ᵉ⁾。
(2) Σ⁰ₙ ≠ Π⁰ₙ。从而 Δ⁰ₙ ⊊ Σ⁰ₙ、Δ⁰ₙ ⊊ Π⁰ₙ，且 Σ⁰ₙ ∪ Π⁰ₙ ⊊ Δ⁰ₙ₊₁。

Step 1 · A universal Σ⁰₁ set第 1 步 · Σ⁰₁ 通用集

U₁ = {(e,x) : x ∈ Wₑ} = {(e,x) : ∃s T(e,x,s)} is Σ⁰₁ by Kleene normal form, and every Σ⁰₁ set is some Wₑ. 由克莱尼范式，U₁ = {(e,x) : x ∈ Wₑ} = {(e,x) : ∃s T(e,x,s)} 是 Σ⁰₁ 集，而每个 Σ⁰₁ 集都是某个 Wₑ。

Step 2 · Climbing one level第 2 步 · 上升一层

A Σ⁰ₙ₊₁ set has the form {x : ∃y R(x,y)} with R Π⁰ₙ; its complement is Σ⁰ₙ, so (coding the pair by ⟨x,y⟩) it is a section of Uₙ. Put Uₙ₊₁(e,x) :⟺ ∃y ¬Uₙ(e, ⟨x,y⟩). This is Σ⁰ₙ₊₁, and its sections are exactly the Σ⁰ₙ₊₁ sets. Σ⁰ₙ₊₁ 集形如 {x : ∃y R(x,y)}，其中 R 为 Π⁰ₙ；R 的补集是 Σ⁰ₙ 的，所以（用 ⟨x,y⟩ 编码二元组）它是 Uₙ 的某个截面。令 Uₙ₊₁(e,x) :⟺ ∃y ¬Uₙ(e, ⟨x,y⟩)，它是 Σ⁰ₙ₊₁ 的，其截面恰好是全体 Σ⁰ₙ₊₁ 集。

Step 3 · The diagonal第 3 步 · 对角线

Let D = {x : (x,x) ∉ Uₙ}. It is Π⁰ₙ (negation of a Σ⁰ₙ condition with x substituted twice). If D were Σ⁰ₙ, then D = U⁽ᵉ⁾ for some e, and e ∈ D ⟺ (e,e) ∉ Uₙ ⟺ e ∉ U⁽ᵉ⁾ = D. Contradiction. So D ∈ Π⁰ₙ ∖ Σ⁰ₙ, and its complement is in Σ⁰ₙ ∖ Π⁰ₙ. 令 D = {x : (x,x) ∉ Uₙ}。它是 Π⁰ₙ 集（把 x 代入两处后取 Σ⁰ₙ 条件的否定）。若 D 是 Σ⁰ₙ 集，则存在 e 使 D = U⁽ᵉ⁾，于是 e ∈ D ⟺ (e,e) ∉ Uₙ ⟺ e ∉ U⁽ᵉ⁾ = D，矛盾。所以 D ∈ Π⁰ₙ ∖ Σ⁰ₙ，其补集属于 Σ⁰ₙ ∖ Π⁰ₙ。

Step 4 · All inclusions are strict第 4 步 · 所有包含都是真包含

D̄ ∈ Σ⁰ₙ∖Δ⁰ₙ and D ∈ Π⁰ₙ∖Δ⁰ₙ. For the top: D̄ ⊕ D = {2x : x ∈ D̄} ∪ {2x+1 : x ∈ D} is in Δ⁰ₙ₊₁ (both halves are), but it is neither Σ⁰ₙ nor Π⁰ₙ, because D and D̄ are many-one reducible to it via x ↦ 2x+1 and x ↦ 2x, and Σ⁰ₙ, Π⁰ₙ are closed downward under ≤_m. ∎ D̄ ∈ Σ⁰ₙ∖Δ⁰ₙ，D ∈ Π⁰ₙ∖Δ⁰ₙ。至于顶部：D̄ ⊕ D = {2x : x ∈ D̄} ∪ {2x+1 : x ∈ D} 属于 Δ⁰ₙ₊₁（两半都是），却既不是 Σ⁰ₙ 也不是 Π⁰ₙ，因为 D 与 D̄ 分别经 x ↦ 2x+1 与 x ↦ 2x 多一归约到它，而 Σ⁰ₙ、Π⁰ₙ 对 ≤_m 向下封闭。∎

⚠ Common pitfall. The diagonal set D is not “outside arithmetic”. It sits one notch away, in Π⁰ₙ. Diagonalizing against a list only escapes that list. Also, Δ⁰ₙ has no universal set (no Δ⁰ₙ set U ⊆ ℕ² whose sections are exactly the Δ⁰ₙ sets): the same diagonal would build a Δ⁰ₙ set missing from the list. That is why Δ classes are less tidy than Σ and Π. ⚠ 常见误区. 对角集 D 并没有跑到“算术之外”，它只偏离了一格，落在 Π⁰ₙ 中。对一份清单做对角化，只能逃出这份清单。另外，Δ⁰ₙ 没有通用集（不存在这样的 Δ⁰ₙ 集 U ⊆ ℕ²，其截面恰好是全体 Δ⁰ₙ 集）：同样的对角线会造出一个清单里没有的 Δ⁰ₙ 集。所以 Δ 类不如 Σ、Π 类规整。
Step 6

Oracle machines, Turing reducibility, Turing degrees谕示机、图灵归约与图灵度

Prerequisites前置: L11 Turing machinesL11 图灵机 L6 equivalence classesL6 等价类

Core idea: give a machine a black box that instantly answers “is n ∈ B?”. Whatever the machine can then decide is “computable from B”. 核心思想：给机器配一个黑盒，它能瞬间回答“n ∈ B 吗？”。机器借此能判定的一切，就叫“由 B 可计算”。

x = 4
Oracle B (black box; purple = bits actually queried, i.e. the use)谕示 B（黑盒；紫色为实际被查询的位，即“使用”）
Definition. An oracle Turing machine is a Turing machine with an extra instruction “query n”, answered in one step by an oracle set X. Φₑ^X denotes the partial function computed by the e-th such machine with oracle X.
A ≤_T B (A is Turing reducible to B) iff there is an e with Φₑ^B = χ_A (total, the characteristic function of A). A ≡_T B iff A ≤_T B and B ≤_T A. This is an equivalence relation; its classes are the Turing degrees, written deg(A) or bold a, partially ordered by deg(A) ≤ deg(B) :⟺ A ≤_T B. The degree of the computable sets is 0.
Use principle. A halting computation Φₑ^X(x) asks only finitely many questions. So if Y agrees with X on those questions, Φₑ^Y(x) gives the same answer. 定义. 谕示图灵机是多了一条指令“询问 n”的图灵机，由谕示集 X 一步作答。Φₑ^X 表示第 e 台这种机器以 X 为谕示时计算的部分函数。
A ≤_T B（A 图灵归约于 B）当且仅当存在 e 使 Φₑ^B = χ_A（全函数，即 A 的特征函数）。 A ≡_T B 当且仅当 A ≤_T B 且 B ≤_T A。这是等价关系，其等价类称为图灵度，记作 deg(A) 或粗体 a，偏序由 deg(A) ≤ deg(B) :⟺ A ≤_T B 给出。可计算集所在的度记为 0。
使用原理. 一个停机的计算 Φₑ^X(x) 只问了有限多个问题。所以只要 Y 在这些问题上与 X 一致，Φₑ^Y(x) 就给出同样的结果。
⚠ Common pitfall. A ≤_T B says nothing about A ⊆ B, about size, or about efficiency. The oracle machine may ask many questions, choose later questions based on earlier answers, and post-process the answers (all four demos do some of this). Also, ≤_T is a preorder on sets; it becomes a partial order only on degrees. ⚠ 常见误区. A ≤_T B 与 A ⊆ B、集合大小、计算效率都毫无关系。谕示机可以问许多问题，可以根据之前的回答决定下一个问题，也可以对回答再加工（上面四个演示各有体现）。另外，≤_T 在集合上只是预序，到了图灵度上才成为偏序。
Step 7

Many-one vs Turing reducibility; completeness多一归约与图灵归约；完全性

Prerequisites前置: Step 6第 6 步 L11 reductionsL11 归约

Core idea: a many-one reduction is a Turing reduction with exactly one question whose answer must be passed on unchanged. That restriction keeps Σ and Π apart. 核心思想：多一归约是一种特殊的图灵归约：只问一个问题，而且回答必须原样交出。正是这个限制把 Σ 和 Π 区分开来。

Definition. A ≤_m B iff there is a total computable f with ∀x (x ∈ A ⟺ f(x) ∈ B).
Facts. (1) A ≤_m B ⟹ A ≤_T B. (2) For n ≥ 1, Σ⁰ₙ and Π⁰ₙ are closed downward under ≤_m: if B ∈ Σ⁰ₙ and A ≤_m B, then x ∈ A ⟺ ∃y (f(x) = y ∧ y ∈ B) is Σ⁰ₙ. (3) Σ⁰₁ is not closed downward under ≤_T: K̄ ≤_T K but K̄ is not r.e. Hence K̄ ≰_m K, and ≤_T is strictly coarser than ≤_m.
Completeness (Step 4) is always meant with respect to ≤_m. If A is Σ⁰ₙ-complete, then Ā is Π⁰ₙ-complete (the same f works). 定义. A ≤_m B 当且仅当存在可计算全函数 f，使 ∀x (x ∈ A ⟺ f(x) ∈ B)。
事实. (1) A ≤_m B ⟹ A ≤_T B。(2) 当 n ≥ 1 时，Σ⁰ₙ 与 Π⁰ₙ 对 ≤_m 向下封闭：若 B ∈ Σ⁰ₙ 且 A ≤_m B，则 x ∈ A ⟺ ∃y (f(x) = y ∧ y ∈ B) 是 Σ⁰ₙ 的。(3) Σ⁰₁ 对 ≤_T 不向下封闭：K̄ ≤_T K，但 K̄ 不是递归可枚举的。所以 K̄ ≰_m K，≤_T 比 ≤_m 严格更粗。
完全性（第 4 步）总是相对于 ≤_m 而言。若 A 是 Σ⁰ₙ-完全的，则 Ā 是 Π⁰ₙ-完全的（用同一个 f 即可）。

Step 8

The jump and Post's theorem图灵跳跃与波斯特定理

Prerequisites前置: Step 5第 5 步 Step 6第 6 步 Step 7第 7 步

Core idea: relativize the halting problem to an oracle and you climb one rung. Each rung of the jump ladder is exactly one level of the quantifier hierarchy. 核心思想：把停机问题相对化到谕示上，就上了一级台阶。跳跃阶梯的每一级，恰好对应量词层级的一层。

Definition. The jump of A is A′ = {e : Φₑ^A(e)↓}, the halting problem for machines with oracle A. Iterate: ∅⁽⁰⁾ = ∅, ∅⁽ⁿ⁺¹⁾ = (∅⁽ⁿ⁾)′. So ∅′ ≡ K (indeed ∅′ = K up to the harmless difference between plain and oracle machine indices).
Jump theorem. (i) A′ is r.e. in A; (ii) A′ ≰_T A, so A <_T A′; (iii) B is r.e. in A ⟺ B ≤_m A′; (iv) A ≤_T B ⟹ A′ ≤_m B′. By (iv) the jump is well defined on degrees: a ↦ a′, with a < a′. 定义. A 的跳跃是 A′ = {e : Φₑ^A(e)↓}，即以 A 为谕示的机器的停机问题。迭代：∅⁽⁰⁾ = ∅，∅⁽ⁿ⁺¹⁾ = (∅⁽ⁿ⁾)′。于是 ∅′ ≡ K（若不计普通机器与谕示机器编号上的无关紧要的差别，可直接说 ∅′ = K）。
跳跃定理. (i) A′ 关于 A 递归可枚举；(ii) A′ ≰_T A，故 A <_T A′；(iii) B 关于 A 递归可枚举 ⟺ B ≤_m A′；(iv) A ≤_T B ⟹ A′ ≤_m B′。由 (iv)，跳跃在图灵度上有良定义：a ↦ a′，且 a < a′。

Post's theorem. For every n ≥ 0:
(a) B ∈ Σ⁰ₙ₊₁ ⟺ B is r.e. in ∅⁽ⁿ⁾;
(b) ∅⁽ⁿ⁺¹⁾ is Σ⁰ₙ₊₁-complete;
(c) B ∈ Δ⁰ₙ₊₁ ⟺ B ≤_T ∅⁽ⁿ⁾.
Hence a set is arithmetical (in some Σ⁰ₙ) iff it is ≤_T ∅⁽ⁿ⁾ for some n. 波斯特定理. 对每个 n ≥ 0：
(a) B ∈ Σ⁰ₙ₊₁ ⟺ B 关于 ∅⁽ⁿ⁾ 递归可枚举；
(b) ∅⁽ⁿ⁺¹⁾ 是 Σ⁰ₙ₊₁-完全的；
(c) B ∈ Δ⁰ₙ₊₁ ⟺ B ≤_T ∅⁽ⁿ⁾。
因此，一个集合是算术集（属于某个 Σ⁰ₙ）当且仅当它对某个 n 满足 ≤_T ∅⁽ⁿ⁾。

Step 9

The structure of the degrees图灵度的结构

Prerequisites前置: Step 6第 6 步 Step 8第 8 步 L8 partial ordersL8 偏序

Core idea: the degrees are not a ladder. Between 0 and 0′ there are incomparable degrees, built by diagonalizing against every reduction one at a time. 核心思想：图灵度不是一架单线梯子。在 0 与 0′ 之间存在互不可比较的度，构造方法是逐一对每个归约进行对角化。

Theorems (all provable in ZFC).
• Kleene–Post (1954). There are sets A, B ≤_T ∅′ with A ≰_T B and B ≰_T A. So the degrees are not linearly ordered.
• Post's problem (1944). Is there an r.e. degree strictly between 0 and 0′? Friedberg (1957), Muchnik (1956): yes. There are r.e. sets A, B with A ≰_T B and B ≰_T A; then 0 < deg(A), deg(B) < 0′. The proof introduced the priority method (finite injury). We state it without proof.
• The degrees form an upper semilattice: deg(A ⊕ B) is the least upper bound of deg(A) and deg(B). They do not form a lattice, since some pairs have no greatest lower bound. There are 2^ℵ₀ degrees, each degree contains only countably many sets, and each degree has only countably many degrees below it.
• ω-jump. ∅⁽ω⁾ = {⟨n,x⟩ : x ∈ ∅⁽ⁿ⁾}. Every arithmetical set is ≤_m ∅⁽ω⁾, but ∅⁽ω⁾ is not arithmetical: if it were Σ⁰ₙ, then ∅⁽ⁿ⁺¹⁾ ≤_m ∅⁽ω⁾ would be Σ⁰ₙ, contradicting the hierarchy theorem. 定理（都可在 ZFC 中证明）。
• 克莱尼–波斯特（1954）. 存在集合 A, B ≤_T ∅′，使 A ≰_T B 且 B ≰_T A。所以图灵度不是线性序。
• 波斯特问题（1944）. 是否存在严格介于 0 与 0′ 之间的递归可枚举度？弗里德伯格（1957）、穆奇尼克（1956）：存在。有递归可枚举集 A、B 使 A ≰_T B 且 B ≰_T A，从而 0 < deg(A), deg(B) < 0′。其证明开创了优先方法（有穷损害），这里只陈述不证明。
• 图灵度构成上半格：deg(A ⊕ B) 是 deg(A) 与 deg(B) 的最小上界。它不构成格，因为有些对没有最大下界。图灵度共有 2^ℵ₀ 个，每个度只含可数多个集合，每个度之下也只有可数多个度。
• ω-跳跃. ∅⁽ω⁾ = {⟨n,x⟩ : x ∈ ∅⁽ⁿ⁾}。每个算术集都 ≤_m ∅⁽ω⁾，但 ∅⁽ω⁾ 本身不是算术集：若它是 Σ⁰ₙ 的，则 ∅⁽ⁿ⁺¹⁾ ≤_m ∅⁽ω⁾ 也是 Σ⁰ₙ 的，与层级定理矛盾。

Interactive: the Kleene–Post finite-extension construction互动：克莱尼–波斯特有限扩张构造

We build A = ⋃ σₛ and B = ⋃ τₛ from finite strings. Requirements: R₂ₑ: A ≠ Φₑ^B and R₂ₑ₊₁: B ≠ Φₑ^A. To meet R₂ₑ, take the first unused position n = |σ| and ask: is there τ′ ⊇ τ with Φₑ^{τ′}(n)↓? If yes, extend τ to such a τ′ and put the opposite bit into A at n. If no, put 0 at n: then Φₑ^B(n) diverges for every B extending τ. Either way R₂ₑ is met forever, by the use principle. That question is Σ⁰₁, so ∅′ can answer it, and this is why A, B ≤_T ∅′. 我们用有限串逐步搭出 A = ⋃ σₛ 与 B = ⋃ τₛ。要求：R₂ₑ: A ≠ Φₑ^B，R₂ₑ₊₁: B ≠ Φₑ^A。为满足 R₂ₑ，取第一个空位 n = |σ|，然后问：是否存在 τ′ ⊇ τ 使 Φₑ^{τ′}(n)↓？若存在，就把 τ 延长为这样的 τ′，并在 A 的第 n 位放入相反的值。若不存在，就在第 n 位放 0：此时对任何延长 τ 的 B，Φₑ^B(n) 都发散。无论哪种情况，由使用原理，R₂ₑ 都永久满足。这个问题是 Σ⁰₁ 的，∅′ 能回答，这正是 A, B ≤_T ∅′ 的原因。

⚠ Common pitfall. Kleene–Post and Friedberg–Muchnik are different theorems. The Kleene–Post sets are Δ⁰₂ but need not be r.e.: the construction asks ∅′ questions, and an r.e. construction cannot do that. Making A and B r.e. requires guessing and repairing mistakes, which is what the priority method does. Also, Post's problem asks for an r.e. intermediate degree. Non-r.e. degrees between 0 and 0′ (Kleene–Post) do not answer it. ⚠ 常见误区. 克莱尼–波斯特定理与弗里德伯格–穆奇尼克定理是两回事。克莱尼–波斯特构造出的集合是 Δ⁰₂ 的，但未必是递归可枚举的：构造中要向 ∅′ 提问，而递归可枚举的构造做不到这一点。要让 A、B 递归可枚举，就得边猜边修正错误，这正是优先方法所做的。另外，波斯特问题问的是递归可枚举的中间度；介于 0 与 0′ 之间的非递归可枚举度（克莱尼–波斯特）并不回答这个问题。

Σ⁰ₙ is closed downward under ≤_m (Step 7), so S ∈ Σ⁰ₙ. Hence Σ⁰ₙ₊₁ ⊆ Σ⁰ₙ, so Π⁰ₙ ⊆ Σ⁰ₙ₊₁ ⊆ Σ⁰ₙ, contradicting the hierarchy theorem. So TA is not arithmetical. ∎ (For (3): TA ≤_T ∅⁽ω⁾ because a sentence of level n is decided by asking ∅⁽ⁿ⁾ via Tr_Σₙ ≤_m ∅⁽ⁿ⁾; and ∅⁽ω⁾ ≤_m TA because each statement “x ∈ ∅⁽ⁿ⁾” is expressed by an arithmetical sentence computed from n and x.) Σ⁰ₙ 对 ≤_m 向下封闭（第 7 步），所以 S ∈ Σ⁰ₙ。于是 Σ⁰ₙ₊₁ ⊆ Σ⁰ₙ，从而 Π⁰ₙ ⊆ Σ⁰ₙ₊₁ ⊆ Σ⁰ₙ，与层级定理矛盾。所以 TA 不是算术集。∎（关于 (3)：TA ≤_T ∅⁽ω⁾，因为层级为 n 的句子可以借助 Tr_Σₙ ≤_m ∅⁽ⁿ⁾ 去问 ∅⁽ⁿ⁾；而 ∅⁽ω⁾ ≤_m TA，因为每个命题“x ∈ ∅⁽ⁿ⁾”都能由 n 与 x 算出的一个算术句子来表达。）

⚠ Common pitfall. Tarski's theorem forbids a single formula defining all of truth. It does not forbid partial truth predicates, and those exist at every level. Also, “not arithmetical” is about definability in ℕ, not about provability (that is Gödel's theorem, L12). Finally, a sentence's level says nothing about whether we know its truth value: the twin prime conjecture is a Π⁰₂ sentence whose truth value is still open. ⚠ 常见误区. 塔斯基定理禁止的是用一个公式定义全部的真，并不禁止部分真谓词，而部分真谓词在每一层都存在。另外，“不是算术集”说的是在 ℕ 中的可定义性，而不是可证性（那是哥德尔定理，L12）。最后，句子的层级与我们是否知道它的真假毫无关系：孪生素数猜想是一个 Π⁰₂ 句子，至今悬而未决。

They end exactly at the Church–Kleene ordinal ω₁^CK, where quantifiers over sets of numbers (Σ¹₁, Π¹₁) take over. 我们停在了 ∅⁽ω⁾。为什么要停？沿着可计算序数继续跳跃，∅⁽ω+1⁾、∅⁽ω·2⁾、…，就得到超算术集。它们恰好止于丘奇–克莱尼序数 ω₁^CK，从那里开始，对数集的量词（Σ¹₁、Π¹₁）接管一切。
