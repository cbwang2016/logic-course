§2

The formula factory: an inductive definition公式工厂：归纳定义

Definition. Form is the smallest set of strings such that: (1) every atom p, q, r, … is in it; (2) if φ is in it, so is ¬φ; (3) if φ, ψ are in it, so are (φ∧ψ), (φ∨ψ), (φ→ψ), (φ↔ψ). 定义. 合式公式集 Form 是满足下列条件的最小字符串集合： (1) 每个原子命题 p, q, r, … 都属于它； (2) 若 φ 属于它，则 ¬φ 也属于它； (3) 若 φ, ψ 属于它，则 (φ∧ψ), (φ∨ψ), (φ→ψ), (φ↔ψ) 也属于它。

“Smallest” means: start from the atoms and keep applying the rules. Whatever you reach in finitely many steps is a formula, and nothing else is. Each press of the button below runs the factory one more round. Watch the rings grow (atoms {p, q}). “最小”的意思是：从原子出发，反复使用规则，有限步能造出来的才是公式，其余一概不算。下面每按一次按钮，工厂就多运转一轮。看圆环一圈圈往外长（原子取 {p, q}）。

Is this string a formula? (strict official rules)这个字符串是公式吗？（严格按官方规则）

Strict mode: every binary connective needs its own parentheses, exactly as in rule (3). If the string passes, you see the formation sequence, the factory's receipt. 严格模式：每个二元联结词都必须自带一对括号，和规则 (3) 一字不差。通过的话会显示构造序列，也就是工厂开出的“出厂证明”。

§3

Parse trees and unique readability语法树与唯一可读性

Every formula is secretly a tree. The root is the main connective, the last rule the factory applied. Hover a node to see the subformula it heads. 每个公式背后都藏着一棵树。树根是主联结词，也就是工厂最后一步用的那条规则。鼠标停在节点上，可以看到它统领的子公式。

(friendly input: outer parentheses optional; ¬ binds tighter than ∧, then ∨, →, ↔; → groups to the right)（宽松输入：最外层括号可省；结合力 ¬ ＞ ∧ ＞ ∨ ＞ → ＞ ↔；→ 向右结合）

The parenthesis mountain: how to find the main connective括号山：怎样找到主联结词

Scan left to right: ( goes up one level, ) goes down one. In the official form, the main binary connective is the only binary connective at height 1 (a ¬ may also sit at height 1, but ¬ is unary). That fact is the heart of the unique readability proof. 从左往右扫：遇 ( 上一层，遇 ) 下一层。在官方写法下，主二元联结词是高度为 1 的唯一二元联结词（高度 1 处也可能有 ¬，但 ¬ 是一元的）。这正是唯一可读性定理证明的核心。

Why we need parentheses: p ∧ q ∨ r without rules为什么非要括号：没有约定时的 p ∧ q ∨ r

Drop the parentheses and one string can come out of the factory in two ways. Two trees means two meanings. Flip the switches to find a valuation where the trees disagree. 去掉括号，同一个字符串就可能有两种造法。两棵树，两种意思。拨动开关，找一个让两棵树结果不同的赋值。

((p ∧ q) ∨ r)
(p ∧ (q ∨ r))
Unique Readability Theorem. Every formula is exactly one of: an atom; ¬φ for a unique φ; or (φ∘ψ) for a unique triple φ, ∘, ψ. So every formula has exactly one tree, and we may define functions on formulas by recursion on the tree. 唯一可读性定理. 每个公式恰好属于以下一种情形：原子命题；¬φ，且 φ 唯一；或 (φ∘ψ)，且 φ、∘、ψ 唯一。所以每个公式恰好对应一棵树，我们就可以沿着树递归地定义公式上的函数。
§4

Valuations: truth flows up the tree赋值：真值沿着树往上流

A valuation v assigns 0 or 1 to each atom, and that is all it does. Recursion along the tree then extends it to every formula: leaves first, root last. Flip the switches and watch the values climb. 赋值 v 只做一件事：给每个原子命题指定 0 或 1。然后沿着树递归，就能算出任何公式的值：先算叶子，最后算树根。拨动开关，看真值一层层往上爬。

v̄(¬φ) = 1 − v̄(φ)  ·  v̄(φ∧ψ) = min  ·  v̄(φ∨ψ) = max  ·  v̄(φ→ψ) = 0 ⇔ v̄(φ)=1, v̄(ψ)=0  ·  v̄(φ↔ψ) = 1 ⇔ v̄(φ)=v̄(ψ)
§5

Truth tables: all valuations at once真值表：一次看遍所有赋值

With n atoms there are only 2ⁿ relevant valuations, so checking every one of them is a finite job. The colored strip is the formula's “fingerprint”: one square per row. n 个原子命题只有 2ⁿ 种相关赋值，逐一检查是有限的工作量。下面的彩色条是公式的“指纹”，每格对应一行。

Tautology ⊨ φ: all green.
Satisfiable: at least one green.
Unsatisfiable: all red. 重言式 ⊨ φ：全绿。
可满足：至少一格绿。
不可满足（矛盾式）：全红。
Press Negate on a tautology: every square flips, so all green turns into all red. That is the duality φ is a tautology ⇔ ¬φ is unsatisfiable. 对重言式按取否定：每一格翻转，全绿变全红。这就是对偶关系：φ 是重言式 ⇔ ¬φ 不可满足。
§6

Semantic consequence Γ ⊨ φ: a picture of inclusion语义后承 Γ ⊨ φ：一张“包含关系”的图

Each tile is one valuation, so the grid is the whole “space of possible worlds”. Γ ⊨ φ means: in every world where all premises hold (blue frame), the conclusion also holds (green). In set language, Mod(Γ) ⊆ Mod(φ). A red tile is a counterexample: premises true, conclusion false. 每块砖代表一个赋值，整张格子就是“所有可能世界”。Γ ⊨ φ 的意思是：凡是前提全真的世界（蓝框），结论也真（绿色）。用集合的话说就是 Mod(Γ) ⊆ Mod(φ)。红砖就是反例：前提都真，结论却假。




§7

Material implication: when is a promise broken?实质蕴涵：承诺什么时候算食言？

A parent says: “If you ace the exam, I'll take you out for dinner.” Click each of the four situations. Was the promise broken? 家长说：“你要是考满分，我就请你吃大餐。”点开四种情形，看看哪种算说话不算数？

Only one case breaks the promise: ace and no dinner, which is 1 → 0. If you didn't ace the exam, the promise was never put to the test, so it isn't broken and it counts as true. This is called vacuous truth. The connective → knows nothing about cause and effect; it only looks at the two truth values. 只有一种情形算食言：考了满分却没请客，即 1 → 0。没考满分时承诺根本没被“触发”，谈不上违背，所以算真。这叫空真（vacuous truth）。→ 不管因果，只看两边的真值。
§8

Connection to Cantor: countably many formulas, uncountably many valuations与康托尔的联系：公式可数，赋值不可数

Formulas: a list公式：可以排成一列

Each formula is a finite string. Write the atom pₙ as the letter p followed by the digits of n; then the alphabet is finite, so only finitely many strings have any given length. Sort by length, then alphabetically, and every formula gets a finite place in line. (The demo uses only p₀, p₁.) 每个公式都是有限符号串。把原子 pₙ 写成字母 p 后接 n 的各位数字，字母表就是有限的，于是每种长度的符号串只有有限多个。先按长度、再按字典序排队，每个公式都排在某个有限的位置上。（演示中只用 p₀、p₁。）

Valuations: no list can catch them all赋值：任何列表都抓不全

A valuation on atoms p₀, p₁, p₂, … is an infinite 0/1 sequence, an element of {0,1}^ℕ. Suppose someone hands you a list of them. Run the diagonal argument: 原子 p₀, p₁, p₂, … 上的赋值就是一个无穷 0/1 序列，即 {0,1}^ℕ 的元素。假设有人给你一份赋值清单，跑一遍对角线论证：

The tension: there are 2^ℵ₀ valuations, but each formula only “sees” finitely many atoms. Question for later: if every finite part of an infinite set Γ of formulas can be satisfied, can all of Γ be satisfied at once? The answer is the Compactness Theorem, coming in Lesson 2. 矛盾的张力：赋值有 2^ℵ₀ 个，可每个公式只“看得见”有限个原子。留个问题：如果无穷公式集 Γ 的每个有限子集都可满足，Γ 整体能同时满足吗？答案就是第 2 课的紧致性定理。

E6Challenge: monotone formulas挑战：单调公式

Claim: a formula built using only ∧ and ∨ (no ¬, →, ↔) is never a tautology and never unsatisfiable. True, or is there a flaw? Try to break it: type ∧/∨ formulas below and look for a counterexample. 命题：只用 ∧ 和 ∨ 构造的公式（不含 ¬、→、↔）既不可能是重言式，也不可能不可满足。成立吗，还是有漏洞？试着推翻它：在下面输入 ∧/∨ 公式找反例。

Proof. Let 𝟙 be the all-1 valuation and 𝟘 the all-0 valuation. By structural induction, every ∧∨-formula φ has v̄𝟙(φ)=1 and v̄𝟘(φ)=0. Atoms: true by definition. Step: min/max of (1,1) is 1, and min/max of (0,0) is 0. So 𝟙 satisfies φ (φ is not unsatisfiable) and 𝟘 falsifies φ (φ is not a tautology). The claim is true. ∎
Take-away: with only ∧ and ∨ you can never express “always true” or “always false”, so {∧, ∨} is not functionally complete; something like ¬ has to be added. 证明. 令 𝟙 为全 1 赋值，𝟘 为全 0 赋值。对公式结构归纳：每个 ∧∨ 公式 φ 都满足 v̄𝟙(φ)=1、v̄𝟘(φ)=0。原子：按定义成立。归纳步：(1,1) 取 min/max 还是 1，(0,0) 取 min/max 还是 0。所以 𝟙 满足 φ（不是矛盾式），𝟘 弄假 φ（不是重言式）。命题成立。∎
启示：只用 ∧ 和 ∨，永远写不出“恒真”或“恒假”，所以 {∧, ∨} 不是功能完备的，必须再添上 ¬ 之类的联结词。
