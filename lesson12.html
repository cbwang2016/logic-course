Gödel's Incompleteness Theorems哥德尔不完全性定理

Arithmetic can talk about numbers, numbers can code formulas, and so arithmetic can talk about its own formulas and proofs. Push that one step further and you get a sentence that says “I am not provable”. Every step below is a machine you can run. 算术能谈论数，数能给公式编码，于是算术就能谈论它自己的公式和证明。再往前走一步，就得到一个说“我不可证”的句子。下面每一步都是一台可以亲手运行的机器。

§1

Gödel numbering: formulas become numbers哥德尔编码：公式变成数

Give every symbol a code. A string s₁s₂…sₖ gets the number ⌜s₁…sₖ⌝ = 2^c(s₁) · 3^c(s₂) · 5^c(s₃) ⋯ pₖ^c(sₖ), where pₖ is the k-th prime. Unique factorization guarantees we can always decode. Click symbols or type (aliases: * ~ -> A E & |). 给每个符号指定一个代码。符号串 s₁s₂…sₖ 的编码为 ⌜s₁…sₖ⌝ = 2^c(s₁) · 3^c(s₂) · 5^c(s₃) ⋯ pₖ^c(sₖ)，其中 pₖ 是第 k 个素数。算术基本定理（唯一分解）保证总能解码回去。点击符号或直接输入（可用替代写法：* ~ -> A E & |）。

Decoding: peel off one prime at a time解码：一次剥掉一个素数

Divide out 2 as often as possible, then 3, then 5, … The exponents are the symbol codes. A skipped prime or an unknown exponent means the number codes no string. 先尽量除以 2，再除以 3、5、……，得到的指数就是各符号的代码。若中途跳过某个素数，或指数不是任何符号的代码，这个数就不编码任何符号串。

A proof is a finite sequence of formulas ⟨φ₁,…,φₙ⟩; code it as 2^⌜φ₁⌝ · 3^⌜φ₂⌝ ⋯ pₙ^⌜φₙ⌝. Below is the 3-line proof of 1+1=2 from §3. The numbers are absurdly large, but only their existence matters: everything about syntax becomes arithmetic. 证明就是有限的公式序列 ⟨φ₁,…,φₙ⟩，把它编码成 2^⌜φ₁⌝ · 3^⌜φ₂⌝ ⋯ pₙ^⌜φₙ⌝。下面是 §3 中 1+1=2 的三行证明。这些数大得离谱，但要紧的只是它们存在：关于语法的一切，都变成了关于数的命题。

The proof checker: “x codes a proof of y” is decidable证明检验机：“x 编码了 y 的一个证明”是可判定的

Checking a proof is purely mechanical: is each line an axiom, or does it follow from earlier lines by a rule? Below is a toy fragment of Q (axioms Q3–Q6 plus a rewriting rule). Edit any line or justification and run the checker. Justifications: Q3…Q6, or Rw i,j = take line j and replace one occurrence of the left side of line i, on the right of “=”, by its right side. 检验证明是纯机械的事：每一行要么是公理，要么由前面的行按规则得到。下面是 Q 的一个玩具片段（公理 Q3–Q6 加一条改写规则）。可以随意改动任何一行或理由，再运行检验机。理由写法：Q3…Q6，或 Rw i,j：取第 j 行，把其等号右边中第 i 行左边那一项的某一处出现换成第 i 行的右边。

Representability. Every decidable relation R ⊆ ℕᵏ is representable in Q: there is a formula φ_R such that R(n₁,…,nₖ) ⇒ Q ⊢ φ_R(n̄₁,…,n̄ₖ) and ¬R(n₁,…,nₖ) ⇒ Q ⊢ ¬φ_R(n̄₁,…,n̄ₖ). If T has a decidable set of axioms, then Proof_T(x,y) is decidable (and primitive recursive if the axiom set is, as for PA), so it is represented by a formula Prf_T(x,y). Define the provability predicate Prov_T(y) :≡ ∃x Prf_T(x,y), a Σ₁ formula. 可表示性. 每个可判定关系 R ⊆ ℕᵏ 都在 Q 中可表示：存在公式 φ_R，使得 R(n₁,…,nₖ) ⇒ Q ⊢ φ_R(n̄₁,…,n̄ₖ)，且 ¬R(n₁,…,nₖ) ⇒ Q ⊢ ¬φ_R(n̄₁,…,n̄ₖ)。若 T 的公理集可判定，则 Proof_T(x,y) 是可判定的（若公理集是原始递归的，比如 PA，它还是原始递归的），因而可由某个公式 Prf_T(x,y) 表示。定义可证性谓词 Prov_T(y) :≡ ∃x Prf_T(x,y)，它是一个 Σ₁ 公式。
Notice the asymmetry in the lamps: Prf_T has a YES lamp and a NO lamp (decidable). Prov_T only has a YES lamp: if T ⊢ φ then Q ⊢ Prov_T(⌜φ⌝), but when T ⊬ φ the search for a proof just runs forever. That gap is where incompleteness lives. 注意两盏灯的不对称：Prf_T 既有“是”灯也有“否”灯（可判定）；Prov_T 只有“是”灯：若 T ⊢ φ，则 Q ⊢ Prov_T(⌜φ⌝)；而当 T ⊬ φ 时，搜索证明的过程只会永远跑下去。不完全性就藏在这道缝里。
§4

The diagonal lemma: a fixed point for every property对角线引理（不动点引理）：每个性质都有不动点

Diagonal Lemma. For every formula ψ(x) with one free variable there is a sentence G such that Q ⊢ G ↔ ψ(⌜G⌝). “G says of itself that it has property ψ.” 对角线引理. 对任意只含一个自由变元的公式 ψ(x)，存在语句 G，使得 Q ⊢ G ↔ ψ(⌜G⌝)。也就是说，G“断言它自己具有性质 ψ”。

Click any cell, choose ψ, then build the fixed point. 表格的行是全体公式 φₙ(x)，列是编码 ⌜φₘ⌝。第 (n, m) 格是语句 φₙ(⌜φₘ⌝)。对角格 (n, n) 把公式自己的编码喂给它自己，其编码为 sub(⌜φₙ⌝, ⌜φₙ⌝)。点击任意格子，选好 ψ，再构造不动点。

Same diagonal, different twist同一条对角线，不同的“扭转”

The construction, step by step构造过程，逐步展开

1. sub(m, n) := the code of the result of substituting the numeral n̄ for x in the formula with code m. It is primitive recursive, so it is representable in Q by a formula Sub(x, y, z): for all m, n, Q ⊢ ∀z (Sub(m̄, n̄, z) ↔ z = k̄) where k = sub(m, n). 1. 令 sub(m, n) 为：把编码为 m 的公式中的 x 替换成数字项 n̄ 后所得公式的编码。它是原始递归函数，故在 Q 中可由某个公式 Sub(x, y, z) 表示：对一切 m, n，有 Q ⊢ ∀z (Sub(m̄, n̄, z) ↔ z = k̄)，其中 k = sub(m, n)。
2. Diagonalize and twist: D(x) :≡ ∃z (Sub(x, x, z) ∧ ψ(z)), informally “ψ(sub(x, x))”. 2. 取对角并“扭转”：D(x) :≡ ∃z (Sub(x, x, z) ∧ ψ(z))，直观上就是“ψ(sub(x, x))”。
3. D is itself a formula, so it is some row: let d = ⌜D⌝. Put G :≡ D(d̄), the diagonal cell of row D. 3. D 本身也是一个公式，所以它就是表中的某一行：令 d = ⌜D⌝，再令 G :≡ D(d̄)，即 D 这一行的对角格。
4. By the definition of sub: sub(d, d) = ⌜D(d̄)⌝ = ⌜G⌝. 4. 由 sub 的定义：sub(d, d) = ⌜D(d̄)⌝ = ⌜G⌝。
5. By representability, Q ⊢ ∀z (Sub(d̄, d̄, z) ↔ z = ⌜G⌝). Hence Q ⊢ G ↔ ∃z (z = ⌜G⌝ ∧ ψ(z)) ↔ ψ(⌜G⌝). ∎ Every T ⊇ Q proves it too. 5. 由可表示性，Q ⊢ ∀z (Sub(d̄, d̄, z) ↔ z = ⌜G⌝)。于是 Q ⊢ G ↔ ∃z (z = ⌜G⌝ ∧ ψ(z)) ↔ ψ(⌜G⌝)。∎ 任何包含 Q 的理论 T 自然也能证明它。
§5

The Gödel sentence: “I am not provable”哥德尔语句：“我不可证”

Apply the diagonal lemma to ψ(x) = ¬Prov_T(x): we get G with T ⊢ G ↔ ¬Prov_T(⌜G⌝). G looks into the mirror and sees a claim about its own code. Run the three thought experiments. 对 ψ(x) = ¬Prov_T(x) 应用对角线引理，得到 G，满足 T ⊢ G ↔ ¬Prov_T(⌜G⌝)。G 照镜子，看到的是一句关于它自己编码的断言。依次运行下面三个思想实验。

First Incompleteness Theorem (Gödel 1931, Rosser 1936). Let T be a consistent, recursively axiomatized theory that contains Q (more generally, interprets Q). Then there is a sentence that T neither proves nor refutes (for T in the language of arithmetic, a Π₁ sentence). Gödel's own proof needed ω-consistency for the second half; Rosser's sentence needs only consistency. 第一不完全性定理（哥德尔 1931，罗瑟 1936）. 设 T 是一致的、递归可公理化的、包含 Q（更一般地，能解释 Q）的理论，则存在一个语句，T 既不能证明它，也不能否证它（若 T 的语言就是算术语言，可取为 Π₁ 语句）。哥德尔原来的证明在后一半用到了 ω-一致性；罗瑟的语句只需要一致性。

Hypothesis switchboard: what if we drop one?假设开关板：去掉一条会怎样？

Rosser's trick: a race between proofs罗瑟技巧：证明之间的赛跑

Rosser's sentence R says: ∀x (Prf(x, ⌜R⌝) → ∃y < x Prf(y, ⌜¬R⌝)), “if I have a proof, my negation has a shorter one”. Click a lane to place a proof code and see who wins. Bounded checks (∃y < x) are finite, so T can verify them: that is why plain consistency suffices. 罗瑟语句 R 说的是：∀x (Prf(x, ⌜R⌝) → ∃y < x Prf(y, ⌜¬R⌝))，即“如果我有证明，那么我的否定有一个更短的证明”。点击跑道放置证明的编码，看谁先到。有界检验（∃y < x）只涉及有限多个数，T 能逐一核实，所以只需一致性就够了。

§6

A second proof, via the halting problem第二种证明：借道停机问题

From Lesson 11: no algorithm decides whether program e halts on input e. Now imagine T were complete (and sound). Then a machine could answer every halting question just by dovetailing two searches: one for a T-proof of H(ē) (“e halts on e”, a Σ₁ sentence), one for a proof of ¬H(ē). Pick a program and watch the imagined decider. 第 11 课讲过：没有算法能判定程序 e 在输入 e 上是否停机。现在设想 T 是完全的（并且可靠）。那么只要把两个搜索交替进行（dovetailing）就能回答每个停机问题：一路搜 H(ē)（“e 在 e 上停机”，是 Σ₁ 语句）的 T-证明，另一路搜 ¬H(ē) 的证明。选一个程序，看这台假想的判定机怎么运转。

1. Let T be consistent, recursively axiomatized, contain Q, and be sound (all its theorems true in ℕ). Suppose, for contradiction, T is complete. 1. 设 T 一致、递归可公理化、包含 Q，并且可靠（所有定理在 ℕ 中都真）。反设 T 是完全的。
2. “e halts on input e” can be written as a Σ₁ sentence H(ē) ≡ ∃s Halt(ē, ē, s), since the step-by-step computation relation is decidable, hence representable. 2. “e 在输入 e 上停机”可写成 Σ₁ 语句 H(ē) ≡ ∃s Halt(ē, ē, s)，因为“第 s 步之内停机”这一关系是可判定的，从而可表示。
3. If e halts, H(ē) is a true Σ₁ sentence, so Q ⊢ H(ē) and hence T ⊢ H(ē). If e does not halt, H(ē) is false, so by soundness T ⊬ H(ē), and by completeness T ⊢ ¬H(ē). 3. 若 e 停机，则 H(ē) 是真的 Σ₁ 语句，故 Q ⊢ H(ē)，从而 T ⊢ H(ē)。若 e 不停机，则 H(ē) 为假，由可靠性 T ⊬ H(ē)，再由完全性 T ⊢ ¬H(ē)。
4. T's theorems can be effectively listed, so the dovetailed search always stops and answers correctly. That decides the halting problem, contradicting Lesson 11. Hence T is incomplete. ∎ 4. T 的定理可以能行地逐个列出，所以交替搜索总会停下，并且答案正确。这就判定了停机问题，与第 11 课矛盾。所以 T 不完全。∎
Fine print. This proof uses soundness, which is stronger than consistency, and it does not exhibit a specific undecided sentence. Replacing the halting set by a pair of recursively inseparable c.e. sets brings the hypothesis down to plain consistency. 注意. 这个证明用到了可靠性，比一致性强，而且它没有给出一个具体的不可判定语句。把停机集换成一对递归不可分的递归可枚举集，就能把假设削弱到仅需一致性。
§7

The second incompleteness theorem: T cannot prove its own consistency第二不完全性定理：T 证明不了自己的一致性

Write Con(T) :≡ ¬Prov_T(⌜0 = 1⌝). The first theorem's argument “if T is consistent, then T ⊬ G” can be carried out inside T, provided Prov_T obeys three derivability conditions (the Hilbert–Bernays–Löb conditions). Click a condition to light up where it is used. 记 Con(T) :≡ ¬Prov_T(⌜0 = 1⌝)。第一定理的论证“若 T 一致，则 T ⊬ G”可以在 T 内部重演，前提是 Prov_T 满足三条可推导性条件（希尔伯特–贝尔奈斯–勒布条件）。点击某条条件，看它在证明中的哪里被用到。

1. D3 with φ = G: T ⊢ Prov(⌜G⌝) → Prov(⌜Prov(⌜G⌝)⌝).1. 对 φ = G 用 D3：T ⊢ Prov(⌜G⌝) → Prov(⌜Prov(⌜G⌝)⌝)。D3
2. From T ⊢ G → ¬Prov(⌜G⌝) (fixed point), D1 then D2 give T ⊢ Prov(⌜G⌝) → Prov(⌜¬Prov(⌜G⌝)⌝). 2. 由 T ⊢ G → ¬Prov(⌜G⌝)（不动点），先用 D1 再用 D2，得 T ⊢ Prov(⌜G⌝) → Prov(⌜¬Prov(⌜G⌝)⌝)。D1D2
3. For any φ, applying D1 to the tautology φ → (¬φ → 0=1) and then D2 twice gives T ⊢ Prov(⌜φ⌝) ∧ Prov(⌜¬φ⌝) → Prov(⌜0=1⌝). Take φ = Prov(⌜G⌝) and combine with 1 and 2: T ⊢ Prov(⌜G⌝) → Prov(⌜0=1⌝). 3. 对任意 φ，把 D1 用于重言式 φ → (¬φ → 0=1)，再用两次 D2，得 T ⊢ Prov(⌜φ⌝) ∧ Prov(⌜¬φ⌝) → Prov(⌜0=1⌝)。取 φ = Prov(⌜G⌝)，结合 1 和 2：T ⊢ Prov(⌜G⌝) → Prov(⌜0=1⌝)。D1D2
4. Contrapose: T ⊢ Con(T) → ¬Prov(⌜G⌝), and by the fixed point T ⊢ Con(T) → G. (This is the first theorem, proved inside T.) 4. 取逆否：T ⊢ Con(T) → ¬Prov(⌜G⌝)，再由不动点得 T ⊢ Con(T) → G。（这正是在 T 内部证明的第一定理。）
5. If T ⊢ Con(T), then T ⊢ G, which is impossible for consistent T by the first theorem. Hence T ⊬ Con(T). ∎ 5. 若 T ⊢ Con(T)，则 T ⊢ G；但由第一定理，一致的 T 证不出 G。所以 T ⊬ Con(T)。∎
Second Incompleteness Theorem. If T is consistent, recursively axiomatized, and extends PA (a weaker base such as IΣ₁ suffices), with Prov_T the standard provability predicate, then T ⊬ Con(T). 第二不完全性定理. 若 T 一致、递归可公理化、并且是 PA 的扩张（IΣ₁ 这样更弱的基础理论也够用），Prov_T 取标准的可证性谓词，则 T ⊬ Con(T)。

Hilbert's program meets the consistency tower希尔伯特纲领与“一致性之塔”

Hilbert hoped to prove the consistency of all of mathematics by finitary means. Each press adds Con of the floor below: every floor proves the consistency of those beneath it, never its own. 希尔伯特希望用有穷方法证明全部数学的一致性。每按一次，就把下面一层的 Con 加进来：每一层都能证明下面各层的一致性，却永远证明不了自己的。

Consequences. (1) Hilbert's program in its original form is impossible: any consistent T containing finitary arithmetic cannot prove its own consistency, let alone that of stronger theories. (2) PA + ¬Con(PA) is consistent (if PA is), yet it is false in ℕ: a consistent but unsound theory. (3) Consistency proofs still exist, but they must use more: Gentzen proved Con(PA) using induction up to the ordinal ε₀, and ZFC proves Con(PA) outright. 推论. (1) 原始形式的希尔伯特纲领无法实现：任何包含有穷算术的一致理论 T 都证明不了自身的一致性，更不用说更强理论的一致性。(2) PA + ¬Con(PA) 是一致的（只要 PA 一致），但它在 ℕ 中为假：一个一致却不可靠的理论。(3) 一致性证明依然存在，只是必须借助更强的东西：根岑用直到序数 ε₀ 的超限归纳证明了 Con(PA)，ZFC 更是可以直接证明 Con(PA)。

E6Henkin's question亨金的问题

Let H be a sentence with PA ⊢ H ↔ Prov_PA(⌜H⌝) (“I am provable”). Gödel's sentence is unprovable. What about H? 设 H 满足 PA ⊢ H ↔ Prov_PA(⌜H⌝)（“我是可证的”）。哥德尔语句不可证，那 H 呢？

Proof. From PA ⊢ H ↔ Prov(⌜H⌝) we get in particular PA ⊢ Prov(⌜H⌝) → H. That is exactly the hypothesis of Löb's theorem with φ = H, so PA ⊢ H. H is provable (and, PA being sound, true). ∎ 证明. 由 PA ⊢ H ↔ Prov(⌜H⌝)，特别地有 PA ⊢ Prov(⌜H⌝) → H。这正是勒布定理在 φ = H 时的前提，所以 PA ⊢ H。H 可证（由于 PA 可靠，它也为真）。∎
