Part V · Lesson 19

Borel & Projective Hierarchies博雷尔层级与投影层级

In L17–L18 we classified sets of natural numbers and reals by how many quantifiers a computable definition needs. Now we allow an arbitrary real number as a parameter. The result is the boldface hierarchy of descriptive set theory. It measures how hard a set of reals is to build from open sets by complements, countable unions and projections. 在第 17–18 课里，我们按照可计算定义需要多少个量词，对自然数集和实数集做了分类。现在允许用任意一个实数作参数，得到的就是描述集合论中的粗体（boldface）层级。它衡量的是：从开集出发，经过取补、可数并、投影，要多少步才能造出一个实数集。

§1

Polish spaces: Cantor space and Baire space as infinite trees波兰空间：把康托尔空间与贝尔空间看成无穷树

Prerequisites:前置： L7 building ℝ第 7 课 构造 ℝ L17 reals as sequences第 17 课 实数即序列

A point of Cantor space 2^ω is an infinite 0/1 sequence, so it is an infinite path through the full binary tree. A finite string s is a node, and the basic open set N_s is the set of all paths through s, i.e. the whole cone (subtree) above s. Each node sits exactly above its piece of the Cantor middle-thirds set, so you can see the homeomorphism. 康托尔空间 2^ω 的一个点就是一个无穷 0/1 序列，也就是满二叉树上的一条无穷路径。有限串 s 是一个节点，基本开集 N_s 就是经过 s 的所有路径，即 s 上方整棵锥（子树）。每个节点都正好画在它所对应的那一段康托尔三分集上方，同胚关系一目了然。

Definitions. A Polish space is a separable topological space whose topology comes from some complete metric. Baire space 𝒩 = ω^ω carries the product of discrete topologies, with complete metric d(x,y) = 2^(−n), where n is least with x(n) ≠ y(n). For s ∈ ω^{<ω}, N_s = {x : s ⊂ x}; these sets form a countable basis. A tree is a set T ⊆ ω^{<ω} closed under initial segments, and [T] = {x : ∀n x↾n ∈ T} is its set of infinite branches.
Facts. (1) F ⊆ ω^ω is closed ⇔ F = [T] for some tree T. (2) 2^ω is compact and homeomorphic to the Cantor set. ω^ω is homeomorphic to the irrationals, via continued fractions x ↦ [0; 1+x(0), 1+x(1), …]. (3) Every Polish space is a continuous image of ω^ω (if nonempty), and every uncountable Polish space contains a homeomorphic copy of 2^ω. 定义. 波兰空间是可分的拓扑空间，且其拓扑可由某个完备度量诱导。贝尔空间 𝒩 = ω^ω 取离散拓扑的乘积拓扑，完备度量为 d(x,y) = 2^(−n)，其中 n 是使 x(n) ≠ y(n) 的最小者。对 s ∈ ω^{<ω}，令 N_s = {x : s ⊂ x}，这些集合构成一组可数拓扑基。树是对初始段封闭的集合 T ⊆ ω^{<ω}，[T] = {x : ∀n x↾n ∈ T} 是它的无穷分支集。
事实. (1) F ⊆ ω^ω 是闭集 ⇔ 存在树 T 使 F = [T]。(2) 2^ω 紧致，且同胚于康托尔集；ω^ω 通过连分数 x ↦ [0; 1+x(0), 1+x(1), …] 同胚于无理数集。(3) 每个非空波兰空间都是 ω^ω 的连续像；每个不可数波兰空间都含有 2^ω 的同胚拷贝。
⚠ Common pitfall. “Polish” is a property of the topology, not of a chosen metric. The irrationals with the usual metric are not complete, yet they form a Polish space, since another compatible metric (transported from ω^ω) is complete. Also, N_s is clopen: its complement is the finite union of the cones N_t with |t| = |s|, t ≠ s. ⚠ 常见误区. “波兰”是拓扑的性质，不是某个选定度量的性质。无理数集在通常度量下不完备，但它仍是波兰空间，因为另有一个相容度量（从 ω^ω 搬过来）是完备的。另外，N_s 是既开又闭的：它的补集是有限个锥 N_t（|t| = |s|, t ≠ s）之并。
§2

The boldface Borel hierarchy: complement, then countable union粗体博雷尔层级：先取补，再取可数并

Prerequisites:前置： §1 L8 ordinals第 8 课 序数 L9 ω₁, cofinality第 9 课 ω₁ 与共尾性 L10 choice第 10 课 选择公理

Start from the open sets. Two moves are allowed: take complements, and take countable unions. Each time a countable union has to swallow sets of the opposite kind, you go up one level. Press the operations below and watch what class the result is guaranteed to lie in. 从开集出发，只允许两种动作：取补集、取可数并。每当可数并要吞下“对面那一类”的集合时，层级就上升一级。点击下面的运算，看看结果保证落在哪一类。

Every set in the class该类中的每个集合:
Σ⁰₁
Definition (X metrizable, e.g. Polish; 1 ≤ α < ω₁). Σ⁰₁(X) = open sets. Π⁰_α(X) = {X ∖ A : A ∈ Σ⁰_α(X)}. For α > 1: A ∈ Σ⁰_α(X) ⇔ A = ⋃ₙ Aₙ with each Aₙ ∈ Π⁰_{βₙ}(X) for some βₙ < α. Δ⁰_α = Σ⁰_α ∩ Π⁰_α. Classical names: Σ⁰₂ = F_σ, Π⁰₂ = G_δ, Σ⁰₃ = G_δσ, Π⁰₃ = F_σδ.
Theorem. (i) Σ⁰_α ∪ Π⁰_α ⊆ Δ⁰_{α+1}, and the classes increase with α. (ii) Σ⁰_α is closed under countable unions, finite intersections and continuous preimages, and Π⁰_α dually. (iii) (ZFC) B(X) = ⋃_{α<ω₁} Σ⁰_α(X) = ⋃_{α<ω₁} Π⁰_α(X), where B(X), the Borel sets, is the smallest σ-algebra containing the open sets. 定义（X 可度量化，例如波兰空间；1 ≤ α < ω₁）。 Σ⁰₁(X) = 开集；Π⁰_α(X) = {X ∖ A : A ∈ Σ⁰_α(X)}； 当 α > 1：A ∈ Σ⁰_α(X) ⇔ A = ⋃ₙ Aₙ，其中每个 Aₙ ∈ Π⁰_{βₙ}(X)，βₙ < α。 Δ⁰_α = Σ⁰_α ∩ Π⁰_α。经典记号：Σ⁰₂ = F_σ, Π⁰₂ = G_δ, Σ⁰₃ = G_δσ, Π⁰₃ = F_σδ。
定理. (i) Σ⁰_α ∪ Π⁰_α ⊆ Δ⁰_{α+1}，且各类随 α 递增。(ii) Σ⁰_α 对可数并、有限交、连续原像封闭，Π⁰_α 对偶地封闭。(iii) （ZFC）B(X) = ⋃_{α<ω₁} Σ⁰_α(X) = ⋃_{α<ω₁} Π⁰_α(X)，其中博雷尔集族 B(X) 是包含全体开集的最小 σ-代数。
Step 1 (closed ⇒ G_δ). If F is closed and nonempty, F = ⋂ₙ {x : d(x,F) < 1/n}, an intersection of open sets. (If F = ∅, it is open anyway.) So Π⁰₁ ⊆ Π⁰₂, and dually Σ⁰₁ ⊆ Σ⁰₂. This uses the metric.第 1 步（闭集 ⇒ G_δ）。若 F 是非空闭集，则 F = ⋂ₙ {x : d(x,F) < 1/n}，是开集的交（F = ∅ 时它本身就是开集）。故 Π⁰₁ ⊆ Π⁰₂，对偶地 Σ⁰₁ ⊆ Σ⁰₂。这一步用到了度量。
Step 2. For α > 1, the definition puts every Π⁰_β (β < α) inside Σ⁰_α (a one-term union). Combined with Step 1 and induction, Σ⁰_β ⊆ Σ⁰_α and Π⁰_β ⊆ Π⁰_α for β ≤ α. Hence Σ⁰_α ⊆ Π⁰_{α+1} and Π⁰_α ⊆ Σ⁰_{α+1}, which gives (i).第 2 步. 当 α > 1 时，按定义每个 Π⁰_β（β < α）都含于 Σ⁰_α（只取一项的并）。结合第 1 步做归纳，得 β ≤ α 时 Σ⁰_β ⊆ Σ⁰_α、Π⁰_β ⊆ Π⁰_α。于是 Σ⁰_α ⊆ Π⁰_{α+1}，Π⁰_α ⊆ Σ⁰_{α+1}，这就是 (i)。
Step 3 (why ω₁ suffices). The union ⋃_{α<ω₁} Σ⁰_α contains the open sets and is closed under complements. Given Aₙ ∈ Σ⁰_{αₙ}, the ordinal β = sup(αₙ + 1) is < ω₁ because ω₁ is regular. Then Aₙ ∈ Π⁰_{αₙ+1} with αₙ + 1 ≤ β < β+1, so ⋃Aₙ ∈ Σ⁰_{β+1}. So the union is a σ-algebra, and it is contained in every σ-algebra containing the open sets. Play with the ruler below.第 3 步（为什么到 ω₁ 就够了）。并集 ⋃_{α<ω₁} Σ⁰_α 包含开集，且对补集封闭。给定 Aₙ ∈ Σ⁰_{αₙ}，由于 ω₁ 是正则基数，序数 β = sup(αₙ + 1) < ω₁。此时 Aₙ ∈ Π⁰_{αₙ+1}，且 αₙ + 1 ≤ β < β+1，所以 ⋃Aₙ ∈ Σ⁰_{β+1}。因此这个并集是 σ-代数；而它又含于任何包含开集的 σ-代数之中。下面的尺子可以动手试试。

The ω₁ ruler: countably many levels never reach ω₁ω₁ 标尺：可数多个层级永远够不到 ω₁

⚠ Common pitfall. “ω₁ is regular” is not provable in ZF alone. It uses countable choice (a countable union of countable sets is countable), and choosing a witness level for each Aₙ uses choice again. In the Feferman–Lévy model of ZF, ℝ is a countable union of countable sets and ω₁ is singular, so the stratification above breaks down. Throughout this lesson we work in ZFC. ⚠ 常见误区. “ω₁ 是正则的”单靠 ZF 证不出来。它要用可数选择（可数个可数集之并可数），而为每个 Aₙ 挑一个见证层级也要用选择。在 ZF 的 Feferman–Lévy 模型中，ℝ 是可数个可数集之并，ω₁ 是奇异的，上面的分层就失效了。本课始终在 ZFC 中工作。
§3

The nested-diamond picture, with sets at exact levels嵌套菱形图：把集合放到它“恰好”所在的层

Prerequisites:前置：§1§2 L17 arithmetical diamond第 17 课 算术层级菱形

A set is at an exact level when we know both an upper bound (it is in the class) and a lower bound (it is not in the dual class). Click an example: the classes that contain it light up green, and the explanation gives both bounds. 要说一个集合恰好在某一层，需要两件事：上界（它属于该类）与下界（它不属于对偶类）。点一个例子：包含它的类会亮成绿色，说明文字给出上下两个界。

Exact level. A is properly Σ⁰_α if A ∈ Σ⁰_α ∖ Π⁰_α. Then A also lies in Δ⁰_{α+1}, Σ⁰_β, Π⁰_β for all β > α, but in none of Π⁰_α, Δ⁰_α, or any lower class. A is properly Δ⁰_α if A ∈ Δ⁰_α but A ∉ ⋃_{β<α}(Σ⁰_β ∪ Π⁰_β). 恰好层级. 若 A ∈ Σ⁰_α ∖ Π⁰_α，称 A 恰为 Σ⁰_α。此时 A 也属于 Δ⁰_{α+1} 以及所有 β > α 的 Σ⁰_β、Π⁰_β，但不属于 Π⁰_α、Δ⁰_α，也不属于任何更低的类。若 A ∈ Δ⁰_α 但 A ∉ ⋃_{β<α}(Σ⁰_β ∪ Π⁰_β)，称 A 恰为 Δ⁰_α。
⚠ Common pitfall. “Countable ⇒ simple” is only half true. Every countable set is Σ⁰₂ (a countable union of closed singletons). But a countable dense subset of a perfect Polish space, such as ℚ or “eventually 0”, is never Π⁰₂ (§4). Level is about topology, not size. ⚠ 常见误区. “可数 ⇒ 简单”只对了一半。每个可数集都是 Σ⁰₂（可数个闭单点集之并）。但完全波兰空间中的可数稠密子集（比如 ℚ、“最终为 0”）永远不是 Π⁰₂（见 §4）。层级刻画的是拓扑复杂度，而不是大小。
§4

An exact level, proved: ℚ is Σ⁰₂ but not Π⁰₂证明一个恰好层级：ℚ 是 Σ⁰₂ 而不是 Π⁰₂

Prerequisites:前置：§2§3 L7 completeness of ℝ第 7 课 ℝ 的完备性

Upper bound: ℚ ∩ [0,1] = ⋃ₙ Fₙ with Fₙ = {k/n : 0 ≤ k ≤ n} (n ≥ 1) finite, hence closed. Lower bound: suppose ℚ = ⋂ₙ Uₙ with Uₙ open. Each Uₙ ⊇ ℚ is dense. Also ℝ ∖ {q} is dense open for each rational q. Interleave the two families and shrink closed intervals so that each interval sits inside the next dense open set. By completeness the intervals share a point, and that point would be rational and irrational at once. 上界：ℚ ∩ [0,1] = ⋃ₙ Fₙ，其中 Fₙ = {k/n : 0 ≤ k ≤ n}（n ≥ 1）是有限集，因而是闭集。下界：设 ℚ = ⋂ₙ Uₙ，Uₙ 为开集。每个 Uₙ ⊇ ℚ 都稠密；对每个有理数 q，ℝ ∖ {q} 也是稠密开集。把两族集合交错排列，逐步缩小闭区间，让每个区间都落在下一个稠密开集里。由完备性，这些区间有公共点，而这个点既是有理数又是无理数。

Baire Category Theorem (ZF + DC suffices; for separable spaces even ZF). In a complete metric space, a countable intersection of dense open sets is dense, in particular nonempty.
Corollary. ℚ ∈ Σ⁰₂(ℝ) ∖ Π⁰₂(ℝ), and dually ℝ∖ℚ ∈ Π⁰₂ ∖ Σ⁰₂. The same proof works for any countable dense set in a Polish space without isolated points. For example, {x ∈ 2^ω : x is eventually 0} is properly Σ⁰₂. 贝尔纲定理（ZF + DC 即可；对可分空间甚至 ZF 就够）。在完备度量空间中，可数个稠密开集之交仍稠密，特别地非空。
推论. ℚ ∈ Σ⁰₂(ℝ) ∖ Π⁰₂(ℝ)；对偶地，ℝ∖ℚ ∈ Π⁰₂ ∖ Σ⁰₂。同样的证明适用于任何无孤立点的波兰空间中的可数稠密集，例如 {x ∈ 2^ω : x 最终为 0} 恰为 Σ⁰₂。
Step 1. Suppose ℚ = ⋂ₙ Uₙ, each Uₙ open. Since ℚ ⊆ Uₙ and ℚ is dense, every Uₙ is dense open.第 1 步. 设 ℚ = ⋂ₙ Uₙ，每个 Uₙ 为开集。由于 ℚ ⊆ Uₙ 且 ℚ 稠密，每个 Uₙ 都是稠密开集。
Step 2. Enumerate ℚ = {q₀, q₁, …}. Each Vₖ = ℝ ∖ {qₖ} is dense open, and ⋂ₖ Vₖ = ℝ ∖ ℚ.第 2 步. 把 ℚ 枚举为 {q₀, q₁, …}。每个 Vₖ = ℝ ∖ {qₖ} 都是稠密开集，且 ⋂ₖ Vₖ = ℝ ∖ ℚ。
Step 3. Baire: U₀ ∩ V₀ ∩ U₁ ∩ V₁ ∩ ⋯ is nonempty. (The animation is exactly its proof: nested closed intervals I₀ ⊇ I₁ ⊇ ⋯, lengths → 0, with I_{2n} ⊆ Uₙ, I_{2k+1} ⊆ Vₖ.)第 3 步. 由贝尔纲定理，U₀ ∩ V₀ ∩ U₁ ∩ V₁ ∩ ⋯ 非空。（动画演示的正是它的证明：一列套闭区间 I₀ ⊇ I₁ ⊇ ⋯，长度趋于 0，且 I_{2n} ⊆ Uₙ，I_{2k+1} ⊆ Vₖ。）
Step 4. But that intersection is ℚ ∩ (ℝ∖ℚ) = ∅. Contradiction, so ℚ is not G_δ. ∎第 4 步. 然而这个交集等于 ℚ ∩ (ℝ∖ℚ) = ∅，矛盾。所以 ℚ 不是 G_δ。∎
§5

The hierarchy never collapses: universal sets + diagonalization层级永不坍缩：万有集 + 对角线

Prerequisites:前置：§1§2 L1 diagonal第 1 课 对角线 L17 hierarchy theorem第 17 课 层级定理

This is the same trick as in L17, with real codes in place of program indices. Fix an enumeration s₀ = 0, s₁ = 1, s₂ = 00, s₃ = 01, … of all binary strings. A real y ∈ 2^ω codes the open set U_y = ⋃{N_{sₙ} : y(n) = 1}. Every open set has a code. Each row of the matrix is one coded open set, each column is a point, and a ✓ means “point ∈ set”. Points and codes are both elements of 2^ω, so the matrix has a diagonal. 这和第 17 课是同一个把戏，只是把程序编号换成了实数编码。固定所有二进制串的一个枚举 s₀ = 0, s₁ = 1, s₂ = 00, s₃ = 01, …。实数 y ∈ 2^ω 编码开集 U_y = ⋃{N_{sₙ} : y(n) = 1}，每个开集都有编码。矩阵的每一行是一个被编码的开集，每一列是一个点，✓ 表示“点 ∈ 集合”。点和编码都是 2^ω 的元素，所以矩阵有对角线。

Definition. U ⊆ 2^ω × X is universal for a class Γ(X) if U ∈ Γ(2^ω × X) and Γ(X) = {U_y : y ∈ 2^ω}, where U_y = {x : (y,x) ∈ U}.
Theorem (Lebesgue 1905). For X separable metrizable and 1 ≤ α < ω₁, Σ⁰_α(X) and Π⁰_α(X) have 2^ω-universal sets. If X is an uncountable Polish space, then Σ⁰_α(X) ≠ Π⁰_α(X) for every 1 ≤ α < ω₁. Hence Δ⁰_α ⊊ Σ⁰_α ⊊ Δ⁰_{α+1}, and the hierarchy has exactly ω₁ distinct levels. 定义. 若 U ∈ Γ(2^ω × X) 且 Γ(X) = {U_y : y ∈ 2^ω}（其中 U_y = {x : (y,x) ∈ U}），则称 U ⊆ 2^ω × X 是类 Γ(X) 的万有集。
定理（Lebesgue 1905）。设 X 可分可度量化，1 ≤ α < ω₁，则 Σ⁰_α(X) 与 Π⁰_α(X) 都有 2^ω-万有集。若 X 是不可数波兰空间，则对每个 1 ≤ α < ω₁ 都有 Σ⁰_α(X) ≠ Π⁰_α(X)。因此 Δ⁰_α ⊊ Σ⁰_α ⊊ Δ⁰_{α+1}，层级恰有 ω₁ 个互不相同的层。
Step 1 (α = 1). U = ⋃ₙ ({y : y(n)=1} × N_{sₙ}) is open in 2^ω × 2^ω and universal for Σ⁰₁(2^ω). Its complement is universal for Π⁰₁.第 1 步（α = 1）。U = ⋃ₙ ({y : y(n)=1} × N_{sₙ}) 是 2^ω × 2^ω 中的开集，且对 Σ⁰₁(2^ω) 万有；它的补集对 Π⁰₁ 万有。
Step 2 (induction). Fix βₙ < α with every β < α occurring infinitely often, and universal sets Vₙ for Π⁰_{βₙ}. Split y into countably many reals (y)ₙ(k) = y(⟨n,k⟩). Then U = {(y,x) : ∃n ((y)ₙ, x) ∈ Vₙ} is Σ⁰_α and universal for Σ⁰_α.第 2 步（归纳）。取 βₙ < α，使每个 β < α 都出现无穷多次，并取 Π⁰_{βₙ} 的万有集 Vₙ。把 y 拆成可数多个实数 (y)ₙ(k) = y(⟨n,k⟩)。则 U = {(y,x) : ∃n ((y)ₙ, x) ∈ Vₙ} 属于 Σ⁰_α，且对 Σ⁰_α 万有。
Step 3 (diagonal). Let D = {y : (y,y) ∉ U}. It is the preimage of the Π⁰_α set U^c under the continuous map y ↦ (y,y), so D ∈ Π⁰_α. If D ∈ Σ⁰_α, then D = U_{y₀} for some y₀, and y₀ ∈ D ⇔ (y₀,y₀) ∉ U ⇔ y₀ ∉ D. Contradiction. So D ∈ Π⁰_α(2^ω) ∖ Σ⁰_α(2^ω).第 3 步（对角线）。令 D = {y : (y,y) ∉ U}。它是 Π⁰_α 集 U^c 在连续映射 y ↦ (y,y) 下的原像，所以 D ∈ Π⁰_α。若 D ∈ Σ⁰_α，则有 y₀ 使 D = U_{y₀}，于是 y₀ ∈ D ⇔ (y₀,y₀) ∉ U ⇔ y₀ ∉ D，矛盾。故 D ∈ Π⁰_α(2^ω) ∖ Σ⁰_α(2^ω)。
Step 4 (transfer). An uncountable Polish X contains a closed copy K of 2^ω. Traces on a closed subspace satisfy Σ⁰_α(K) = {A ∩ K : A ∈ Σ⁰_α(X)}, and likewise for Π. So Σ⁰_α(X) = Π⁰_α(X) would force Σ⁰_α(K) = Π⁰_α(K), contradicting Step 3. ∎第 4 步（迁移）。不可数波兰空间 X 含有 2^ω 的闭拷贝 K。闭子空间上的迹满足 Σ⁰_α(K) = {A ∩ K : A ∈ Σ⁰_α(X)}，Π 同理。所以若 Σ⁰_α(X) = Π⁰_α(X)，则 Σ⁰_α(K) = Π⁰_α(K)，与第 3 步矛盾。∎
⚠ Common pitfall. Countable spaces are different: in ω or ℚ every subset is Σ⁰₂, so the hierarchy collapses. Strictness needs an uncountable Polish space. Also, Δ⁰₁ has no universal set: the same diagonal argument shows that. ⚠ 常见误区. 可数空间不一样：在 ω 或 ℚ 里，每个子集都是 Σ⁰₂，层级坍缩了。严格性需要不可数波兰空间。另外，Δ⁰₁ 没有万有集，同一个对角线论证就能说明这一点。
§6

Lightface vs boldface: “boldface = lightface + a real parameter”细体与粗体：“粗体 = 细体 + 一个实数参数”

Prerequisites:前置： L11 c.e. sets第 11 课 可计算可枚举集 L17 Σ⁰ₙ第 17 课 Σ⁰ₙ L18 Σ¹ₙ, HYP第 18 课 Σ¹ₙ 与 HYP§5

A lightface Σ⁰₁ set is an effectively open set: a union of cones N_{sₙ} over a computably enumerable set of indices n. A boldface Σ⁰₁ set may use any set of indices. That set is just a real a, and given a as an oracle, the union is Σ⁰₁(a). §7

Analytic sets: shadows of closed sets, and Suslin's theorem解析集：闭集的影子，以及 Suslin 定理

Prerequisites:前置：§1§2 L18 Σ¹₁ = ∃ real第 18 课 Σ¹₁ = ∃ 实数

Shine light straight down on a closed set C ⊆ X × ω^ω. Its shadow on X is p[C] = {x : ∃y (x,y) ∈ C}. Drag the vertical scan line: x is in the shadow exactly when the line meets C, i.e. the section C_x is nonempty. The existential quantifier ∃y ranges over a real, which is the extra power of Σ¹₁ over Borel. 用光垂直向下照射一个闭集 C ⊆ X × ω^ω，它在 X 上的影子就是 p[C] = {x : ∃y (x,y) ∈ C}。拖动竖直扫描线：x 在影子里，当且仅当扫描线碰到 C，也就是截面 C_x 非空。存在量词 ∃y 跑遍的是一个实数，这正是 Σ¹₁ 比博雷尔多出来的能力。

Definition / Theorem (X Polish, A ⊆ X). The following are equivalent, and A is then called analytic (Σ¹₁): (i) A = ∅ or A = f[ω^ω] for a continuous f; (ii) A = p[F] for a closed F ⊆ X × ω^ω; (iii) A = p[B] for a Borel B ⊆ X × Y, Y Polish; (iv) A = f[B], B Borel in a Polish Y, f continuous (or just Borel). Π¹₁ (coanalytic) = complements; Δ¹₁ = Σ¹₁ ∩ Π¹₁.
Lusin Separation Theorem. Disjoint analytic sets A, B are separated by a Borel set C: A ⊆ C, C ∩ B = ∅.
Suslin's Theorem (1917). Borel(X) = Δ¹₁(X). If X is uncountable, Σ¹₁(X) ≠ Π¹₁(X), so some analytic sets are not Borel. Example: on the space of trees on ω, IF = {T : [T] ≠ ∅} = {T : ∃y ∀n y↾n ∈ T} is Σ¹₁ but not Borel, and its complement WF is Π¹₁ but not Borel. 定义 / 定理（X 为波兰空间，A ⊆ X）。下列条件等价，满足时称 A 为解析集（Σ¹₁）： (i) A = ∅ 或存在连续 f 使 A = f[ω^ω]； (ii) 存在闭集 F ⊆ X × ω^ω 使 A = p[F]； (iii) 存在波兰空间 Y 与博雷尔集 B ⊆ X × Y 使 A = p[B]； (iv) A = f[B]，B 为某波兰空间 Y 中的博雷尔集，f 连续（或仅为博雷尔函数）。 Π¹₁（余解析集）是解析集的补集；Δ¹₁ = Σ¹₁ ∩ Π¹₁。
卢津分离定理. 不相交的解析集 A、B 可被博雷尔集 C 分离：A ⊆ C，C ∩ B = ∅。
Suslin 定理（1917）。Borel(X) = Δ¹₁(X)。若 X 不可数，则 Σ¹₁(X) ≠ Π¹₁(X)，所以存在非博雷尔的解析集。例：在 ω 上的树构成的空间中，IF = {T : [T] ≠ ∅} = {T : ∃y ∀n y↾n ∈ T} 是 Σ¹₁ 但不是博雷尔集；它的补集 WF 是 Π¹₁ 但不是博雷尔集。
Step 1 (countable unions are harmless). If each Aₘ is Borel-separable from each Bₙ (by Cₘₙ), then ⋃Aₘ is separated from ⋃Bₙ by ⋃ₘ⋂ₙ Cₘₙ. Contrapositive: if ⋃Aₘ, ⋃Bₙ are not separable, some pair Aₘ, Bₙ is not.第 1 步（可数并无碍）。若每个 Aₘ 都能与每个 Bₙ 被博雷尔集 Cₘₙ 分离，则 ⋃ₘ⋂ₙ Cₘₙ 分离 ⋃Aₘ 与 ⋃Bₙ。逆否：若 ⋃Aₘ, ⋃Bₙ 不可分离，则必有某一对 Aₘ, Bₙ 不可分离。
Step 2 (descend the trees). Write A = f[ω^ω], B = g[ω^ω] (both nonempty; otherwise trivial). Suppose they are not separable. Since f[N_s] = ⋃ₖ f[N_{s⌢k}], Step 1 lets us pick s₀ ⊂ s₁ ⊂ ⋯ and t₀ ⊂ t₁ ⊂ ⋯ with |sₖ| = |tₖ| = k and f[N_{sₖ}], g[N_{tₖ}] never separable.第 2 步（沿树下降）。写 A = f[ω^ω]，B = g[ω^ω]（二者非空，否则平凡）。设它们不可分离。由于 f[N_s] = ⋃ₖ f[N_{s⌢k}]，用第 1 步可以选出 s₀ ⊂ s₁ ⊂ ⋯ 与 t₀ ⊂ t₁ ⊂ ⋯，|sₖ| = |tₖ| = k，且 f[N_{sₖ}] 与 g[N_{tₖ}] 始终不可分离。
Step 3 (contradiction). Let x = ⋃sₖ, y = ⋃tₖ. Then f(x) ∈ A, g(y) ∈ B, so f(x) ≠ g(y). Take disjoint open U ∋ f(x), V ∋ g(y). By continuity, f[N_{sₖ}] ⊆ U and g[N_{tₖ}] ⊆ V for large k, so the open (hence Borel) set U separates them. Contradiction. This proves Lusin separation.第 3 步（矛盾）。令 x = ⋃sₖ, y = ⋃tₖ。则 f(x) ∈ A，g(y) ∈ B，故 f(x) ≠ g(y)。取不相交开集 U ∋ f(x), V ∋ g(y)。由连续性，k 充分大时 f[N_{sₖ}] ⊆ U，g[N_{tₖ}] ⊆ V，于是开集（从而是博雷尔集）U 把它们分开了，矛盾。卢津分离定理得证。
Step 4 (Suslin). If A and X∖A are both analytic, separate them by a Borel C: A ⊆ C ⊆ A, so A = C is Borel. Conversely, Borel sets are analytic (by (iii) with B itself), and their complements are Borel too. Hence Δ¹₁ = Borel. ∎第 4 步（Suslin）。若 A 与 X∖A 都是解析集，用博雷尔集 C 分离它们：A ⊆ C ⊆ A，所以 A = C 是博雷尔集。反之，博雷尔集是解析集（由 (iii)，取 B 为它自身），它们的补集也是博雷尔集。故 Δ¹₁ = 博雷尔。∎
📜 Lebesgue's famous mistake. In his 1905 memoir on analytically representable functions, Lebesgue “proved” that the projection of a Borel subset of the plane is Borel. The argument assumed that projection commutes with decreasing intersections, as it does with unions. Press Lebesgue's step above for a counterexample. In 1916 the young Suslin, a student in Lusin's Moscow seminar, found the error. His 1917 note introduced analytic sets and proved that some are not Borel. In his preface to Lusin's 1930 book, Lebesgue wrote that the proof was “simple, short, but false”, and called it a fruitful error. 📜 勒贝格的著名错误. 勒贝格在 1905 年关于可解析表示函数的长文中“证明”了：平面博雷尔集的投影仍是博雷尔集。论证默认投影与递减交可交换，就像它与并可交换一样。点击上面的勒贝格那一步可以看到反例。1916 年，卢津莫斯科讨论班上的年轻学生 苏斯林发现了这个错误，并在 1917 年的短文中引入解析集，证明了存在非博雷尔的解析集。勒贝格后来在为卢津 1930 年专著所写的序言中说，那个证明“简单、简短，但是错的”，并称之为一个富有成果的错误。
⚠ Common pitfall. The picture is only schematic. The hidden axis must be ω^ω (or ℝ with closed replaced by G_δ), not a compact interval. A projection of a closed subset of ℝ × ℝ is σ-compact, hence just Σ⁰₂. All the non-Borel complexity comes from projecting along a non-σ-compact factor. ⚠ 常见误区. 这幅图只是示意。被投影掉的那根轴必须是 ω^ω（或者用 ℝ 但把闭集换成 G_δ），而不能是紧区间。ℝ × ℝ 中闭集的投影是 σ-紧的，因而只是 Σ⁰₂。非博雷尔的复杂性完全来自沿非 σ-紧因子做投影。
§8

The projective hierarchy: project, complement, project, …投影层级：投影、取补、再投影……

Prerequisites:前置：§7 L18 analytical hierarchy第 18 课 分析层级

Projection adds an existential real quantifier ∃y, and complement turns ∃ into ∀. Alternate them and you climb the projective ladder. Press the buttons, or let the token climb by itself. Watch for the move that does not climb. 投影添上一个实数存在量词 ∃y，取补把 ∃ 变成 ∀。两者交替进行，就爬上了投影阶梯。点按钮，或者让小球自己爬。注意哪一步不会上升。

Δ¹₁
Definition (X Polish, n ≥ 1). Π¹ₙ(X) = complements of Σ¹ₙ(X) sets. A ∈ Σ¹ₙ₊₁(X) ⇔ A = p[C] for some C ∈ Π¹ₙ(X × ω^ω). Δ¹ₙ = Σ¹ₙ ∩ Π¹ₙ. Projective sets: ⋃ₙ Σ¹ₙ.
Normal form. A ∈ Σ¹ₙ ⇔ x ∈ A ⇔ ∃y₁ ∀y₂ ∃y₃ ⋯ Q yₙ (x, y₁, …, yₙ) ∈ B with B Borel and yᵢ ∈ ω^ω. (B can even be taken closed or open, depending on the parity of n.)
Theorem (ZFC). Each Σ¹ₙ is closed under countable unions and intersections, Borel preimages and ∃^{ω^ω}; Π¹ₙ under ∀^{ω^ω}. Σ¹ₙ ∪ Π¹ₙ ⊆ Δ¹ₙ₊₁. For uncountable X, Σ¹ₙ ≠ Π¹ₙ for every n (universal sets + diagonal, as in §5). 定义（X 为波兰空间，n ≥ 1）。Π¹ₙ(X) 是 Σ¹ₙ(X) 集的补集；A ∈ Σ¹ₙ₊₁(X) ⇔ 存在 C ∈ Π¹ₙ(X × ω^ω) 使 A = p[C]；Δ¹ₙ = Σ¹ₙ ∩ Π¹ₙ。投影集：⋃ₙ Σ¹ₙ。
范式. A ∈ Σ¹ₙ ⇔ x ∈ A ⇔ ∃y₁ ∀y₂ ∃y₃ ⋯ Q yₙ (x, y₁, …, yₙ) ∈ B，其中 B 为博雷尔集，yᵢ ∈ ω^ω（按 n 的奇偶，B 甚至可取为闭集或开集）。
定理（ZFC）。每个 Σ¹ₙ 对可数并、可数交、博雷尔原像以及 ∃^{ω^ω} 封闭；Π¹ₙ 对 ∀^{ω^ω} 封闭。Σ¹ₙ ∪ Π¹ₙ ⊆ Δ¹ₙ₊₁。若 X 不可数，则对每个 n 都有 Σ¹ₙ ≠ Π¹ₙ（万有集 + 对角线，同 §5）。
⚠ Common pitfall. Two projections in a row do not climb: ∃y₁∃y₂ collapses to one ∃y, because ω^ω × ω^ω ≅ ω^ω (interleave the digits). Only alternation of ∃ and ∀ counts, exactly as with number quantifiers in L17. ⚠ 常见误区. 连续两次投影不会上升：∃y₁∃y₂ 可以合并成一个 ∃y，因为 ω^ω × ω^ω ≅ ω^ω（把两串数字交错排列）。只有 ∃ 与 ∀ 的交替才算数，这和第 17 课中数量词的情形完全一样。
§9

Regularity properties: where ZFC stops, and what L and large cardinals say正则性质：ZFC 管到哪里为止，L 与大基数又怎么说

Prerequisites:前置：§7§8 L10 Vitali set第 10 课 维塔利集 L15 L第 15 课 L L25 determinacy第 25 课 决定性

Three “niceness” properties of a set of reals. Pick a theory (column header) to see what it proves (✓), refutes (✗), or leaves undecided (?). Click any cell for the reason. The pattern: ZFC settles level 1, and the fight starts one level up. 实数集的三种“良好”性质。选一个理论（列标题），看它证明了什么（✓）、否证了什么（✗）、又对什么不置可否（?）。点任一格可看理由。规律是：ZFC 搞定第 1 层，再往上一层就开始争夺了。

Definitions (A ⊆ ℝ, or any Polish space). PSP: A is countable or contains a nonempty perfect (closed, no isolated points) subset, so |A| ≤ ℵ₀ or |A| = 2^ℵ₀. LM: A is Lebesgue measurable. BP: A △ U is meager for some open U.
ZFC theorems. Every Σ¹₁ set has PSP (Suslin), and is LM and BP (Lusin–Sierpiński). Hence Π¹₁ sets are LM and BP (closed under complement). By AC, some sets have none of the three (Vitali set, Bernstein set).
V = L (Gödel). There is a Δ¹₂ (lightface!) well-ordering of ℝ. From it come a Δ¹₂ set that is neither LM nor BP, and an uncountable Π¹₁ set with no perfect subset.
Large cardinals. A measurable cardinal implies that all Σ¹₂ sets have all three properties (Solovay). PD (projective determinacy) implies that all projective sets do; PD follows from infinitely many Woodin cardinals (Martin–Steel 1989; see L25). 定义（A ⊆ ℝ，或任一波兰空间）。完美集性质 PSP：A 可数，或含有非空完美子集（闭且无孤立点），从而 |A| ≤ ℵ₀ 或 |A| = 2^ℵ₀。LM：A 勒贝格可测。BP（Baire 性质）：存在开集 U 使 A △ U 是贫集。
ZFC 定理. 每个 Σ¹₁ 集都有 PSP（Suslin），且 LM、BP（卢津–谢尔品斯基）。因此 Π¹₁ 集也 LM 且 BP（这两条性质对补集封闭）。由选择公理，存在三条性质都不满足的集合（维塔利集、伯恩斯坦集）。
V = L（哥德尔）。存在 ℝ 的 Δ¹₂（细体！）良序。由它可以得到一个既不 LM 也不 BP 的 Δ¹₂ 集，以及一个不含完美子集的不可数 Π¹₁ 集。
大基数. 存在可测基数蕴涵所有 Σ¹₂ 集三条性质都有（Solovay）。PD（投影决定性）蕴涵所有投影集都有；而 PD 可由无穷多个伍丁基数推出（Martin–Steel 1989；见第 25 课）。
⚠ Common pitfall. “?” does not mean “unknown to mathematicians”. It means independent of that theory, assuming suitable consistency. E.g. ZFC does not prove PSP for Π¹₁ sets (it fails in L). Conversely, by Solovay, “every Π¹₁ set has PSP” ⇔ ω₁^{L[a]} < ω₁ for all reals a, which implies that ω₁ is inaccessible in L. So its consistency needs (and is equiconsistent with) an inaccessible cardinal. ⚠ 常见误区. “?” 不是“数学家还不知道”，而是独立于该理论（在适当的一致性假设下）。例如 ZFC 证不出 Π¹₁ 集都有 PSP（它在 L 中不成立）。反过来，由 Solovay，“每个 Π¹₁ 集都有 PSP” ⇔ 对所有实数 a 有 ω₁^{L[a]} < ω₁，这蕴涵 ω₁ 在 L 中是不可达基数。所以它的一致性需要（并且等一致于）一个不可达基数。
§10

Wadge's hierarchy (a glimpse): comparing sets by a gameWadge 层级（一瞥）：用博弈比较集合

Prerequisites:前置：§3§5 L25 determinacy第 25 课 决定性

Lipschitz game G_L(A,B): players I and II alternate bits. I builds x, II builds y, and II wins iff x ∈ A ⇔ y ∈ B. A winning strategy for II is a recipe that turns x into y continuously (each output bit depends only on the bits seen so far), i.e. a reduction of A to B. You play I below. II reduces A = “x contains a 1” (open) to B = “y has infinitely many 1s” (Π⁰₂). Lipschitz 博弈 G_L(A,B)：玩家 I 与 II 轮流写比特，I 写出 x，II 写出 y；II 获胜当且仅当 x ∈ A ⇔ y ∈ B。II 的必胜策略就是一个把 x 连续地变成 y 的方法（每个输出比特只依赖已看到的比特），也就是从 A 到 B 的一个归约。下面你来当 I，II 把 A =“x 含有 1”（开集）归约到 B =“y 有无穷多个 1”（Π⁰₂）。

Definition. A ≤_W B iff A = f⁻¹[B] for some continuous f: ω^ω → ω^ω (the same definitions and results hold in 2^ω, which the demo uses). A winning strategy for II in G_L(A,B) gives A ≤_W B. A winning strategy for I gives B ≤_W ω^ω ∖ A.
Wadge's Lemma. If G_L(A,B) is determined, then A ≤_W B or B ≤_W ω^ω ∖ A. In ZFC this holds for all Borel A, B (Martin's Borel determinacy). Under PD it holds for projective sets, and under AD (which contradicts AC) for all sets. Martin–Monk: under the same determinacy, ≤_W is well-founded.
Picture. Antichains have size ≤ 2. The degrees form a well-ordered tower of pairs {[A], [¬A]} (non-self-dual) and single self-dual degrees. The Borel hierarchy levels reappear as particular rungs: for Borel A ⊆ ω^ω with A ∈ Σ⁰_α ∖ Π⁰_α, every Σ⁰_α subset of ω^ω is ≤_W A (A is Σ⁰_α-complete). 定义. A ≤_W B 当且仅当存在连续 f: ω^ω → ω^ω 使 A = f⁻¹[B]（在 2^ω 中定义与结论完全相同，上面的演示用的就是 2^ω）。II 在 G_L(A,B) 中有必胜策略可得 A ≤_W B；I 有必胜策略可得 B ≤_W ω^ω ∖ A。
Wadge 引理. 若 G_L(A,B) 是决定的，则 A ≤_W B 或 B ≤_W ω^ω ∖ A。在 ZFC 中它对所有博雷尔集 A、B 成立（Martin 的博雷尔决定性定理）；在 PD 下对投影集成立；在 AD（与选择公理矛盾）下对所有集合成立。Martin–Monk：在同样的决定性假设下，≤_W 是良基的。
图景. 反链大小 ≤ 2。Wadge 度排成一座良序的塔，塔上交替出现成对的 {[A], [¬A]}（非自对偶）和单独的自对偶度。博雷尔层级作为塔上特定的横档重新出现：若博雷尔集 A ⊆ ω^ω 满足 A ∈ Σ⁰_α ∖ Π⁰_α，则 ω^ω 的每个 Σ⁰_α 子集都 ≤_W A（A 是 Σ⁰_α-完全的）。
⚠ Common pitfall. Wadge's lemma is not a ZFC theorem about arbitrary sets. With AC one can diagonalize against all 2^ℵ₀ continuous maps and build sets that violate its conclusion. Its scope is exactly as wide as the determinacy you have. ⚠ 常见误区. Wadge 引理不是关于任意集合的 ZFC 定理。借助选择公理，可以对全部 2^ℵ₀ 个连续映射做对角线，构造出违反其结论的集合。你有多大范围的决定性，它就在多大范围内成立。
