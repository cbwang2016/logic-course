Well-orders, Ordinals, Transfinite Induction良序、序数与超限归纳

Counting keeps going after 0, 1, 2, …. Ordinals are the numbers that measure the length of a well-ordered line, and they let induction run past infinity. Every picture below can be clicked, zoomed or stepped through. 数数并不止于 0, 1, 2, …。序数度量的是良序“队伍”的长度，有了它，归纳法可以越过无穷继续走。下面每张图都可以点击、放大或单步演示。

§1

Well-orders: the descending chain hunt良序：寻找无穷降链

Definition. A linear order (X, <) is a well-order if every nonempty subset of X has a least element. Equivalently (using Dependent Choice for ⇐): there is no infinite strictly descending sequence x₀ > x₁ > x₂ > ⋯. 定义. 线序 (X, <) 称为良序，如果 X 的每个非空子集都有最小元。等价地（⇐ 方向要用相关选择公理）：不存在无穷严格递降序列 x₀ > x₁ > x₂ > ⋯。

§3

Von Neumann ordinals: each ordinal is the set of the smaller ones冯·诺伊曼序数：每个序数就是比它小的序数之集

Definition. A set α is an ordinal if it is transitive (x ∈ α ⇒ x ⊆ α) and well-ordered by ∈. Then β < α means β ∈ α, and α = {β : β < α}. Every ordinal is exactly one of: 0 = ∅; a successor β+1 = β ∪ {β}; a limit λ = ⋃λ = sup{β : β < λ}. 定义. 集合 α 称为序数，如果它是传递集（x ∈ α ⇒ x ⊆ α），并且被 ∈ 良序。此时 β < α 就是 β ∈ α，而 α = {β : β < α}。每个序数恰是下列三者之一：0 = ∅；后继序数 β+1 = β ∪ {β}；极限序数 λ = ⋃λ = sup{β : β < λ}。

§4

Every well-order is isomorphic to exactly one ordinal每个良序恰好同构于唯一一个序数

The recipe: send each element x to the set of images of everything below it, f(x) = {f(y) : y ◁ x}. In practice that means the least element goes to 0 and the next one to 1, and when an infinite run is used up, the next element goes to the limit ω. The ordinal that comes out is the order type. 做法是：把每个元素 x 送到它下面所有元素的像构成的集合，f(x) = {f(y) : y ◁ x}。实际效果就是：最小元送到 0，下一个送到 1，……，一段无穷序列用完之后，下一个元素送到极限 ω。最后得到的序数叫做序型。

Why exactly one? (proof sketch)为什么恰好一个？（证明梗概）

Lemma 1. If (W, ◁) is a well-order and g: W → W is order-preserving, then x ⊴ g(x) for all x. Proof: otherwise take the least x with g(x) ◁ x; applying g gives g(g(x)) ◁ g(x), so y = g(x) is a smaller counterexample. Contradiction. 引理 1. 若 (W, ◁) 是良序，g: W → W 保序，则对所有 x 有 x ⊴ g(x)。证明：否则取使 g(x) ◁ x 的最小 x；两边作用 g 得 g(g(x)) ◁ g(x)，于是 y = g(x) 是更小的反例，矛盾。
Lemma 2. A well-order is not isomorphic to any proper initial segment of itself (an isomorphism onto {y : y ◁ a} would send a below a, contradicting Lemma 1). In particular, two distinct ordinals α ∈ β are never isomorphic, since α is a proper initial segment of β. This gives uniqueness. 引理 2. 良序不同构于自身的任何真前段（若同构于 {y : y ◁ a}，就会把 a 送到 a 之下，与引理 1 矛盾）。特别地，两个不同的序数 α ∈ β 绝不同构，因为 α 是 β 的真前段。这就得到了唯一性。
Existence. Let A = {a ∈ W : the initial segment below a is isomorphic to some ordinal α_a}. By Replacement, a ↦ α_a gives a set of ordinals, and it is downward closed, so it is an ordinal α. The map a ↦ α_a is an isomorphism A ≅ α. If A ≠ W, A is an initial segment {y : y ◁ c} where c is the least element outside A; but then c ∈ A. Contradiction, so W ≅ α. 存在性. 令 A = {a ∈ W : a 下方的前段同构于某个序数 α_a}。由替换公理，a ↦ α_a 的像是一个序数之集，而且向下封闭，所以它本身是一个序数 α，且 a ↦ α_a 是同构 A ≅ α。若 A ≠ W，令 c 为 A 外的最小元，则 A = {y : y ◁ c}，于是 c ∈ A，矛盾。故 W ≅ α。

§6

Cantor normal form calculator (ordinals below ε₀)康托尔范式计算器（ε₀ 以下的序数）

Cantor Normal Form Theorem. Every ordinal α > 0 can be written uniquely as α = ωβ₁·c₁ + ωβ₂·c₂ + ⋯ + ωβₖ·cₖ with α ≥ β₁ > β₂ > ⋯ > βₖ and positive integers cᵢ. Below ε₀ = sup{ω, ωω, ωωω, …} the exponents are smaller than α, so the form can be expanded all the way down. 康托尔范式定理. 每个序数 α > 0 都可以唯一地写成 α = ωβ₁·c₁ + ωβ₂·c₂ + ⋯ + ωβₖ·cₖ，其中 α ≥ β₁ > β₂ > ⋯ > βₖ，cᵢ 为正整数。在 ε₀ = sup{ω, ωω, ωωω, …} 以下，指数都比 α 小，可以一层层展开到底。
Rules the calculator uses: absorption ωa + ωb = ωb when a < b; products (for α > 0) α·ωb = ωa₁+b for b ≥ 1 (a₁ = leading exponent of α), and α·n (n ≥ 1) multiplies only the leading coefficient; powers 2ω = ω and αλ = ωa₁·λ for limit λ and α ≥ ω. 计算器用到的规则：吸收律 当 a < b 时 ωa + ωb = ωb；乘法（设 α > 0）当 b ≥ 1 时 α·ωb = ωa₁+b（a₁ 为 α 的首项指数），而 α·n（n ≥ 1）只把首项系数乘 n；乘幂 2ω = ω，当 λ 为极限序数且 α ≥ ω 时 αλ = ωa₁·λ。

§7

Transfinite induction and recursion: climbing past ω超限归纳与超限递归：越过 ω 继续爬

Transfinite induction. Let P be a property of ordinals. If
(0) P(0);
(S) P(β) ⇒ P(β+1);
(L) for limit λ: P(β) for all β < λ ⇒ P(λ),
then P(α) holds for every ordinal α. 超限归纳法. 设 P 是序数的性质。若
(0) P(0)；
(S) P(β) ⇒ P(β+1)；
(L) 对极限序数 λ：对一切 β < λ 有 P(β) ⇒ P(λ)，
则 P 对所有序数成立。
Transfinite recursion. Given a start value a and a rule G, there is a unique class function F on the ordinals with
F(0) = a,  F(β+1) = G(F(β)),  F(λ) = sup{F(β) : β < λ} (or ⋃) for limit λ. 超限递归定理. 给定初值 a 和规则 G，存在唯一的序数上的类函数 F，满足
F(0) = a，F(β+1) = G(F(β))，对极限序数 λ 有 F(λ) = sup{F(β) : β < λ}（或取并）。

The climber below is proving P step by step. Ordinary induction only gets through the gold and grey steps; the purple limit landings need the third clause. Choose a recursion and watch its values being computed along the way. 下面的小人在一步步地验证 P。普通的数学归纳法只能走过金色和灰色的台阶，紫色的极限平台必须靠第三条。选一个递归定义，看它的值在攀登途中一个个算出来。

Why transfinite induction works超限归纳法为什么成立

Suppose P fails for some ordinal γ. The set {α ≤ γ : ¬P(α)} = {α ∈ γ+1 : ¬P(α)} is a nonempty subset of the well-ordered set γ+1, so it has a least element α₀. 假设 P 对某个序数 γ 不成立。集合 {α ≤ γ : ¬P(α)} = {α ∈ γ+1 : ¬P(α)} 是良序集 γ+1 的非空子集，因此有最小元 α₀。
α₀ is 0, a successor or a limit. α₀ = 0 contradicts (0). α₀ = β+1 means P(β) holds (β < α₀), so (S) gives P(α₀). If α₀ is a limit, P holds below α₀, so (L) gives P(α₀). Every case is a contradiction. ∎ α₀ 要么是 0，要么是后继，要么是极限。α₀ = 0 与 (0) 矛盾；α₀ = β+1 时 P(β) 成立（因 β < α₀），由 (S) 得 P(α₀)；α₀ 是极限时 P 在 α₀ 以下处处成立，由 (L) 得 P(α₀)。每种情形都矛盾。∎
Recursion is proved the same way: by induction, for each α there is a unique function on α+1 obeying the rules (“attempts” agree where they overlap), and by Replacement their union is F. 递归定理的证明如出一辙：用归纳法证明对每个 α，在 α+1 上恰有一个满足规则的函数（不同的“尝试”在公共部分上一致），再用替换公理把它们并起来，就得到 F。
§8

The Burali–Forti paradox: there is no set of all ordinals布拉利–福尔蒂悖论：不存在由全体序数构成的集合

1. Suppose the ordinals form a set Ω.1. 假设全体序数构成一个集合 Ω。
2. Ω is transitive: an element of an ordinal is again an ordinal, so α ∈ Ω ⇒ α ⊆ Ω.2. Ω 是传递集：序数的元素仍是序数，所以 α ∈ Ω ⇒ α ⊆ Ω。
3. Ω is well-ordered by ∈: any two ordinals are comparable, and a nonempty set S of ordinals has least element ⋂S. So Ω is itself an ordinal.3. Ω 被 ∈ 良序：任意两个序数可比较，非空序数集 S 有最小元 ⋂S。所以 Ω 本身也是序数。
4. Then Ω ∈ Ω, i.e. Ω < Ω. But no ordinal is a member of itself (∈ is irreflexive on a well-order, and Foundation forbids it anyway). Contradiction. The ordinals form a proper class Ord. ∎4. 于是 Ω ∈ Ω，即 Ω < Ω。但没有序数属于它自身（良序中 ∈ 是反自反的，正则公理也禁止）。矛盾。全体序数构成一个真类 Ord。∎
Compare Russell's paradox (Lesson 6): there, “the set of all sets” would contain {x : x ∉ x}; here, “the set of all ordinals” would be an ordinal longer than itself. Same lesson: collections that are too big are classes, not sets. 对比第 6 课的罗素悖论：“全体集合之集”会含有 {x : x ∉ x}；这里“全体序数之集”会成为一个比自己还长的序数。教训相同：太大的汇集只能是类，不是集合。
§9

Hartogs' theorem: every set is outrun by some ordinal哈托格斯定理：每个集合都会被某个序数超过

Theorem (Hartogs, ZF, no Choice). For every set X there is an ordinal h(X) that does not inject into X. The least one is h(X) = {α : α injects into X}, the Hartogs number of X. 定理（哈托格斯，ZF，不用选择公理）. 对每个集合 X，都存在一个不能单射到 X 的序数 h(X)。最小的那个是 h(X) = {α : α 可单射到 X}，称为 X 的哈托格斯数。

Concretely, list all well-orders of all subsets of X and sort them by order type. Each type that occurs is an ordinal that injects into X, and the first type that never occurs is h(X). 具体做法：列出 X 的所有子集上的所有良序，按序型分组。出现过的每个序型都是能单射进 X 的序数，第一个从未出现的序型就是 h(X)。

1. Let 𝒲 = {(A, R) : A ⊆ X, R a well-order of A}. It is a set by Power Set and Separation (𝒲 ⊆ 𝒫(X) × 𝒫(X × X)).1. 令 𝒲 = {(A, R) : A ⊆ X，R 是 A 上的良序}。由幂集公理和分离公理，它是集合（𝒲 ⊆ 𝒫(X) × 𝒫(X × X)）。
2. Each (A, R) has a unique order type (§4). By Replacement, H = {type(A, R) : (A, R) ∈ 𝒲} is a set of ordinals. It is exactly {α : α injects into X}: an injection α → X transports the order of α onto its image.2. 每个 (A, R) 有唯一的序型（§4）。由替换公理，H = {type(A, R) : (A, R) ∈ 𝒲} 是一个序数之集。它恰好等于 {α : α 可单射到 X}：单射 α → X 把 α 的序搬到像集上。
3. H is downward closed (restrict the injection), so H is a transitive set of ordinals, i.e. an ordinal.3. H 向下封闭（把单射限制到更小的序数上即可），所以 H 是传递的序数集，也就是一个序数。
4. If H injected into X, then H ∈ H, which is impossible. So H does not inject into X, and it is the least such ordinal. ∎ For X = ℕ, H is the set of all countable ordinals: the first uncountable ordinal ω₁, the star of Lesson 9.4. 如果 H 能单射到 X，就有 H ∈ H，这不可能。所以 H 不能单射到 X，而且是这样的序数里最小的。∎ 当 X = ℕ 时，H 就是全体可数序数之集，即第一个不可数序数 ω₁，它是第 9 课的主角。

E4Find the flaw in a bogus induction找出错误归纳证明的漏洞

(a) “Every ordinal is finite. Proof: 0 is finite, and if α is finite then so is α+1. By transfinite induction, every ordinal is finite.”“每个序数都是有限的。证明：0 有限；若 α 有限则 α+1 有限。由超限归纳法，所有序数都有限。”

(b) “For every ordinal α, α + 1 = 1 + α.” Bogus proof by transfinite induction on α:“对每个序数 α，α + 1 = 1 + α。”下面是一个错误的超限归纳证明：

(A) 0 + 1 = 1 = 1 + 0.
(B) (α+1)+1 = (1+α)+1 = 1+(α+1) (induction hypothesis, associativity归纳假设、结合律)
(C) λ limit极限: 1+λ = sup{1+β : β < λ} (definition of +加法的定义)
(D) = sup{β+1 : β < λ} = λ + 1 (induction hypothesis, then “take the sup”归纳假设，然后“取上确界”)
