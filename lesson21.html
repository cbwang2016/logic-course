Part V · Lesson 21

Ordinal Notations & Fast-Growing Hierarchies序数记号与快速增长层级

Countable ordinals are infinite objects, but many of them have finite names that a computer can compare. With those names we can measure the strength of theories (PA ↦ ε₀), build functions that outgrow anything PA can prove total, and find true arithmetic statements PA cannot prove: Goodstein's theorem and the hydra. 可数序数是无穷对象，但其中许多都有计算机能比较大小的有限名字。借助这些名字，我们可以度量理论的强度（PA ↦ ε₀），构造出比 PA 能证明为全函数的任何函数都长得更快的函数，还能找到 PA 证明不了的真算术命题：古德斯坦定理和九头蛇游戏。

Step 1第 1 步

Why notations: ordinals as finite trees为什么要记号：把序数写成有限的树

Prerequisites预备知识: L8 · ordinals, CNF序数、康托尔范式 L11 · computability可计算性 L18 · ω₁CK

A notation system turns (some) countable ordinals into finite terms that an algorithm can compare.记号系统把（一部分）可数序数变成有限的项，并且有算法能比较它们的大小。

Definition (notation system). A notation system is a pair (T, ≺) where T ⊆ ℕ (think: a set of finite terms, coded as numbers) is recursive, ≺ is a recursive binary relation on T, and (T, ≺) is a well-order. Its order type is the ordinal it describes; the term in position α is “a notation for α”. In practice one also asks that basic operations (successor, +, fundamental sequences) be recursive, usually even primitive recursive. 定义（记号系统）. 记号系统是一对 (T, ≺)，其中 T ⊆ ℕ（可理解为一族有限的项，编码成自然数）是递归集，≺ 是 T 上的递归二元关系，且 (T, ≺) 是良序。它的序型就是它所描述的序数；排在第 α 位的项称为“α 的记号”。实际使用时通常还要求基本运算（后继、加法、基本序列）递归，一般甚至是原始递归的。
Cantor normal form (L8). Every ordinal α > 0 can be written uniquely as α = ωβ₁·c₁ + ωβ₂·c₂ + … + ωβₖ·cₖ with β₁ > β₂ > … > βₖ and positive integers cᵢ. If α < ε₀ (Step 2), every exponent satisfies βᵢ < α, so we may expand the exponents again and again; the process stops after finitely many rounds. The result is the hereditary CNF: a finite tree. 康托尔范式（第 8 课）. 每个序数 α > 0 都可以唯一地写成 α = ωβ₁·c₁ + ωβ₂·c₂ + … + ωβₖ·cₖ，其中 β₁ > β₂ > … > βₖ，cᵢ 为正整数。若 α < ε₀（见第 2 步），则每个指数都满足 βᵢ < α，于是可以对指数反复展开，有限轮后必然停止，得到遗传康托尔范式：一棵有限的树。

Type an ordinal below ε₀ (use w or ω, ^, +, * or ·, parentheses). The tree is its hereditary CNF: each blue node is a term ω□·c, whose child is the exponent; gold leaves are natural numbers. Click a blue node to fold or unfold its exponent. 输入一个小于 ε₀ 的序数（可用 w 或 ω、^、+、* 或 ·、括号）。下面的树就是它的遗传康托尔范式：每个蓝色节点是一项 ω□·c，它的子树是指数；金色叶子是自然数。点击蓝色节点可以折叠或展开它的指数。

The comparison algorithm比较算法

Comparing two CNF terms is a recursive procedure: compare leading exponents (recursively!), then leading coefficients, then the rest. This is what makes ≺ recursive, and it is exactly why CNF below ε₀ is a notation system. 比较两个康托尔范式是一个递归过程：先（递归地！）比较首项指数，再比较首项系数，然后比较剩下的部分。正因为如此 ≺ 是递归的，这也正是 ε₀ 以下的康托尔范式构成记号系统的原因。

⚠ Common pitfall · 常见误区
A notation system is syntax; its well-foundedness is a real mathematical theorem, not something you can check by running the comparison algorithm (being well-founded is a Π¹₁ property, L18). Also, there are only countably many finite terms, so only countably many ordinals can ever get notations; for recursive systems these are exactly the ordinals below ω₁CK (Step 8). 记号系统是语法；它是良基的，这是一个需要证明的数学定理，不是运行比较算法就能检验的（良基性是 Π¹₁ 性质，见第 18 课）。另外，有限的项只有可数多个，所以至多可数多个序数能拥有记号；对递归记号系统来说，能被表示的恰好是小于 ω₁CK 的序数（见第 8 步）。

Step 2第 2 步

ε₀: the limit of the ω-towerε₀：ω 塔的极限

Prerequisites预备知识: Step 1第 1 步 L8 · ordinal exponentiation, sup序数幂、上确界

Stack ω's forever; the limit ε₀ is the first ordinal that CNF can no longer break into smaller pieces.把 ω 无限地往上摞；极限 ε₀ 是康托尔范式第一次无法拆成更小部分的序数。

The ruler below runs from 0 to ε₀ (not to scale: each new marker covers half the remaining distance). Press the button to add a storey to the tower. The curved arrows show the map α ↦ ωα: it sends each marker to the next. At ε₀ the arrow loops back to itself. 下面的标尺从 0 延伸到 ε₀（不按比例：每个新刻度占剩余距离的一半）。按按钮给塔加一层。弧形箭头表示映射 α ↦ ωα：它把每个刻度送到下一个刻度。到了 ε₀，箭头绕回自己。

Definition & Theorem. Put ω₀ = 1, ωₙ₊₁ = ωωₙ (so ω₁ = ω, ω₂ = ωω, …; in this lesson ωₙ always means a storey of this tower, so here ω₁ is not the first uncountable ordinal) and ε₀ = supn ωₙ. Then (a) ωε₀ = ε₀; (b) ε₀ is the least ordinal α with ωα = α; (c) ε₀ is countable. Consequently every α < ε₀ has CNF exponents βᵢ < α, while the CNF of ε₀ itself is the useless ε₀ = ωε₀. 定义与定理. 令 ω₀ = 1，ωₙ₊₁ = ωωₙ（于是 ω₁ = ω，ω₂ = ωω，…；本课中 ωₙ 一律指这座塔的第 n 层，所以这里的 ω₁ 不是第一个不可数序数），ε₀ = supn ωₙ。则 (a) ωε₀ = ε₀；(b) ε₀ 是满足 ωα = α 的最小序数 α；(c) ε₀ 可数。因此每个 α < ε₀ 的康托尔范式指数都满足 βᵢ < α；而 ε₀ 本身的康托尔范式是毫无用处的 ε₀ = ωε₀。
(a) β ↦ ωβ is continuous at limits (by the definition of ordinal exponentiation), so ωε₀ = supn ωωₙ = supn ωₙ₊₁ = ε₀. (a) 由序数幂的定义，β ↦ ωβ 在极限处连续，所以 ωε₀ = supn ωωₙ = supn ωₙ₊₁ = ε₀。
(b) Let ωα = α. Induction on n: ω₀ = 1 ≤ ωα = α; and if ωₙ ≤ α then ωₙ₊₁ = ωωₙ ≤ ωα = α (exponentiation is monotone). So every ωₙ ≤ α, hence ε₀ ≤ α. (b) 设 ωα = α。对 n 归纳：ω₀ = 1 ≤ ωα = α；若 ωₙ ≤ α，则 ωₙ₊₁ = ωωₙ ≤ ωα = α（幂运算单调）。所以每个 ωₙ ≤ α，从而 ε₀ ≤ α。
(c) Each ωₙ is countable (by induction: ωβ is countable for countable β), and a countable union of countable sets is countable. (This uses a little choice in general; here we can avoid it, because the CNF terms give explicit enumerations.) (c) 每个 ωₙ 都可数（归纳：β 可数则 ωβ 可数），可数个可数集之并仍可数。（一般情形要用到一点选择公理；这里可以避免，因为康托尔范式的项直接给出了枚举。）
Consequence. If α < ε₀ and α = ωβ₁c₁ + …, then β₁ ≤ ωβ₁ ≤ α, and β₁ = α would force ωα = α, which by (b) is impossible below ε₀. So β₁ < α. ∎ 推论. 若 α < ε₀ 且 α = ωβ₁c₁ + …，则 β₁ ≤ ωβ₁ ≤ α；若 β₁ = α，则 ωα = α，由 (b) 这在 ε₀ 以下不可能。所以 β₁ < α。∎
⚠ Common pitfall · 常见误区
“ε₀ is so big it must be uncountable.” No: ε₀ is a countable ordinal, far below the first uncountable ordinal. Another slip: “ε₀ + 1 = ωε₀+1”. In fact ωε₀+1 = ωε₀·ω = ε₀·ω, much bigger than ε₀ + 1. “ε₀ 这么大，一定不可数吧。”错：ε₀ 是可数序数，远小于第一个不可数序数。另一个常见错误是“ε₀ + 1 = ωε₀+1”。其实 ωε₀+1 = ωε₀·ω = ε₀·ω，比 ε₀ + 1 大得多。

Step 3第 3 步

Fundamental sequences: a ladder up to each limit基本序列：通往每个极限序数的梯子

Prerequisites预备知识: Step 1第 1 步 Step 2第 2 步

To compute with a limit ordinal λ we fix, once and for all, a concrete increasing sequence λ[0] < λ[1] < … converging to λ.要拿极限序数 λ 做计算，就一劳永逸地选定一个具体的递增序列 λ[0] < λ[1] < …，让它收敛到 λ。

Definition. A fundamental sequence for a limit ordinal λ is a strictly increasing sequence (λ[n])n∈ℕ of ordinals with supn λ[n] = λ. Standard assignment used in this lesson (Wainer / Buchholz–Wainer style). Write a limit α < ε₀ as α = β + ωγ in CNF (so γ > 0 and the last exponent of β is ≥ γ):
• if γ = δ + 1: α[n] = β + ωδ·n;
• if γ is a limit: α[n] = β + ωγ[n];
• at ε₀: ε₀[n] = ωₙ, i.e. ε₀[0] = 1, ε₀[n+1] = ωε₀[n].
Successor ordinals have no fundamental sequence. 定义. 极限序数 λ 的基本序列是一个严格递增的序数序列 (λ[n])n∈ℕ，满足 supn λ[n] = λ。本课采用的标准指派（Wainer / Buchholz–Wainer 风格）：把极限序数 α < ε₀ 按康托尔范式写成 α = β + ωγ（γ > 0，β 的最后一个指数 ≥ γ）：
• 若 γ = δ + 1：α[n] = β + ωδ·n；
• 若 γ 是极限序数：α[n] = β + ωγ[n]；
• 在 ε₀ 处：ε₀[n] = ωₙ，即 ε₀[0] = 1，ε₀[n+1] = ωε₀[n]。
后继序数没有基本序列。

Choose α and watch its ladder. The rungs α[0], α[1], … climb towards α (dashed top) but never reach it. The slider picks which rung to highlight. 选一个 α，看它的梯子。梯级 α[0], α[1], … 一步步逼近 α（顶端虚线），但永远到不了。滑块选择高亮哪一级。

n = 3

Every descent ends每次下降都会结束

Fix n. Starting from α, repeatedly replace a limit λ by λ[n] and a successor β+1 by β. Each move goes strictly down, so by well-foundedness you reach 0 after finitely many moves. With n fixed, the number of “−1” moves is exactly α with ω replaced by n (e.g. ωω at n = 3 needs 3³ = 27 of them). 固定 n。从 α 出发，反复把极限 λ 换成 λ[n]、把后继 β+1 换成 β。每一步都严格下降，所以由良基性，有限步后必到 0。n 固定时，“减一”的步数恰好等于把 α 中的 ω 换成 n 所得的数（例如 ωω 在 n = 3 时需要 3³ = 27 次）。

⚠ Common pitfall · 常见误区
(1) The fundamental sequence is a choice, not something determined by λ. Other books use, e.g., ε₀[0] = 0 or ε₀[0] = ω; all values computed from them shift. (2) λ[n] is not “the n-th ordinal below λ”: between λ[n] and λ[n+1] there are infinitely many ordinals; the ladder only has to be cofinal. (1) 基本序列是一种选择，并不由 λ 唯一确定。别的书可能用 ε₀[0] = 0 或 ε₀[0] = ω 等约定，由此算出的各种数值都会随之平移。(2) λ[n] 不是“λ 以下第 n 个序数”：λ[n] 与 λ[n+1] 之间有无穷多个序数，梯子只需要共尾即可。

Step 4第 4 步

Goodstein sequences: huge growth, guaranteed death古德斯坦序列：疯狂增长，却注定归零

Prerequisites预备知识: Step 1第 1 步 Step 3第 3 步 L12 · Gödel, unprovable truths哥德尔、不可证的真命题

The numbers explode, but the shadow ordinals (replace the base by ω) strictly decrease, so the sequence must hit 0.数值爆炸式增长，但它们的“影子序数”（把底数换成 ω）严格递减，所以序列必然归零。

Definition. The hereditary base-b notation of m writes m = Σ cᵢ·beᵢ (0 < cᵢ < b, exponents decreasing) and then writes every exponent eᵢ in hereditary base-b notation again, until only numbers < b appear. The Goodstein sequence of m: g₀ = m; to get gk+1 from gk > 0, write gk in hereditary base k+2, replace every k+2 by k+3 (“bump the base”), then subtract 1. Stop when 0 is reached. 定义. m 的遗传 b 进制表示：先写 m = Σ cᵢ·beᵢ（0 < cᵢ < b，指数递减），再把每个指数 eᵢ 也写成遗传 b 进制，如此反复，直到只剩小于 b 的数。m 的古德斯坦序列：g₀ = m；若 gk > 0，把 gk 写成遗传 k+2 进制，把其中每个 k+2 换成 k+3（“换底”），再减 1，得到 gk+1。到 0 为止。
m =

Bars: number of decimal digits of gk (log scale). The ordinal column on the left never goes up.柱：gk 的十进制位数（对数刻度）。左边表格的序数列从不上升。

Goodstein's theorem (Goodstein 1944). For every m, the Goodstein sequence of m reaches 0.
Kirby–Paris theorem (1982). The arithmetic sentence “for every m, the Goodstein sequence of m reaches 0” (a Π⁰₂ sentence) is not provable in PA. It is provable in PA + TI(ε₀) (transfinite induction up to ε₀, Step 6), and of course in ZF. 古德斯坦定理（Goodstein 1944）. 对每个 m，m 的古德斯坦序列都会到达 0。
柯比–帕里斯定理（1982）. 算术语句“对每个 m，m 的古德斯坦序列都到达 0”（一个 Π⁰₂ 语句）在 PA 中不可证。它在 PA + TI(ε₀)（直到 ε₀ 的超限归纳，见第 6 步）中可证，在 ZF 中当然也可证。
1. The shadow. Let ok be the hereditary base-(k+2) form of gk with the base replaced by ω. Bumping the base does not change the shadow at all: the tree is the same, only the base label changes. 1. 影子. 把 gk 的遗传 k+2 进制表示中的底数换成 ω，记为 ok。换底完全不改变影子：树形不变，只是底数的标签变了。
2. Subtracting 1 lowers the shadow. If the last term is a digit c > 0, it becomes c − 1. Otherwise the last term c·be becomes (c−1)·be + Σi<e(b−1)·bi; in the shadow, ωo(e)·c is replaced by ωo(e)·(c−1) plus terms with exponents o(i) < o(e). Either way the new ordinal is strictly smaller (CNF comparison of Step 1). 2. 减 1 会让影子变小. 若最后一项是数字 c > 0，它变成 c − 1。否则最后一项 c·be 变成 (c−1)·be + Σi<e(b−1)·bi；在影子里，ωo(e)·c 被换成 ωo(e)·(c−1) 再加上指数 o(i) < o(e) 的若干项。两种情形下新序数都严格变小（用第 1 步的康托尔范式比较）。
3. Well-foundedness. So o₀ > o₁ > o₂ > … is a strictly decreasing sequence of ordinals below ε₀. There is no infinite such sequence, so it stops, which happens only when gk = 0. ∎
Note where the strength lies: step 3 uses that ε₀ is well-founded, exactly what PA cannot prove (Step 6). 3. 良基性. 于是 o₀ > o₁ > o₂ > … 是 ε₀ 以下严格递减的序数序列。这样的序列不可能无穷长，所以它会停下，而停下只能是因为 gk = 0。∎
注意力量来自哪里：第 3 步用到了 ε₀ 的良基性，这恰恰是 PA 证明不了的（见第 6 步）。
⚠ Common pitfall · 常见误区
“PA cannot prove that the sequence for m = 4 terminates.” Wrong: for each fixed m, “the sequence of m terminates” is a true Σ⁰₁ sentence, and PA proves every true Σ⁰₁ sentence (just by verifying the finite computation). What PA cannot prove is the single universal statement “for all m”. (For m = 4 the values reach their maximum at base 3·2402 653 209, and the sequence reaches 0 when the base is 3·2402 653 211 − 1.) “PA 证明不了 m = 4 时的序列会终止。”错：对每个固定的 m，“m 的序列终止”是一个真的 Σ⁰₁ 语句，而 PA 能证明所有真的 Σ⁰₁ 语句（把有限的计算验证一遍即可）。PA 证明不了的是那一条全称语句“对所有 m”。（m = 4 时，数值在底数为 3·2402 653 209 时达到最大，在底数为 3·2402 653 211 − 1 时归零。）

Step 5第 5 步

The hydra game (Kirby–Paris)九头蛇游戏（柯比–帕里斯）

Prerequisites预备知识: Step 1第 1 步 Step 4第 4 步

Each chop can grow many new heads, but the hydra's ordinal always drops, so Hercules always wins.每砍一刀都可能长出许多新头，但九头蛇的序数总在下降，所以赫拉克勒斯必胜。

Rules. A hydra is a finite rooted tree; its heads are the leaves other than the root. At step n = 1, 2, 3, … Hercules chops one head h. Let p be h's parent. If p is the root, h is simply removed. Otherwise let g be p's parent (h's grandparent). Remove h; then attach n new copies of the (already shrunk) subtree rooted at p as new children of g. Hercules wins when only the root is left.
Ordinal of a hydra. o(leaf) = 0, and for a node with children c₁,…,cₖ: o = ωo(c₁) ⊕ … ⊕ ωo(cₖ), where ⊕ is the natural (Hessenberg) sum: add the CNF terms and sort them, so the order of the children does not matter. 规则. 九头蛇是一棵有限有根树；除根以外的叶子是它的头。在第 n 步（n = 1, 2, 3, …），赫拉克勒斯砍掉一个头 h。设 p 是 h 的父节点。若 p 是根，就只把 h 去掉。否则设 g 为 p 的父节点（即 h 的祖父节点）：去掉 h，再把以 p 为根的（已经去掉 h 的）子树复制 n 份，作为 g 的新子节点接上。只剩根时赫拉克勒斯获胜。
九头蛇的序数. o(叶) = 0；对子节点为 c₁,…,cₖ 的节点，o = ωo(c₁) ⊕ … ⊕ ωo(cₖ)，其中 ⊕ 是自然和（黑森伯格和）：把各项康托尔范式合并后重新排序，所以子节点的先后顺序无关紧要。

Click a red head to chop it. The current step number n is the number of copies that regrow. 点击红色的头把它砍掉。当前步数 n 就是重新长出的副本数。

Theorem (Kirby–Paris 1982). Every strategy kills every hydra in finitely many steps: the ordinal strictly decreases with each chop and lies below ε₀. However, the arithmetized statement “every (recursive) strategy kills every hydra” is not provable in PA. 定理（柯比–帕里斯 1982）. 任何策略都能在有限步内杀死任何九头蛇：每砍一刀序数都严格下降，而且它小于 ε₀。然而，算术化的命题“每个（递归）策略都能杀死每条九头蛇”在 PA 中不可证。
Root case. If p is the root, the root loses one summand ω⁰ = 1, so its ordinal drops by 1.根的情形. 若 p 是根，根少了一个加项 ω⁰ = 1，序数减 1。
General case. Before the chop, p has ordinal β ⊕ 1 = β + 1, where β is p's ordinal after removing h. In g, the summand ωβ+1 is replaced by n + 1 summands ωβ, i.e. by ωβ·(n+1) < ωβ+1. So o(g) drops. 一般情形. 砍之前 p 的序数是 β ⊕ 1 = β + 1，其中 β 是去掉 h 后 p 的序数。在 g 中，加项 ωβ+1 被换成 n + 1 个加项 ωβ，即 ωβ·(n+1) < ωβ+1。所以 o(g) 变小。

Definition (Veblen). A function on ordinals is normal if it is strictly increasing and continuous at limits.
• φ₀(β) = ωβ.
• For α > 0, φα is the function that enumerates, in increasing order, the class Cα = {γ : φδ(γ) = γ for all δ < α}.
