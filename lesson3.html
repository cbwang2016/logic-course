Part I · Lesson 3

First-Order Logic: Languages, Structures, Truth一阶逻辑：语言、结构与真

Propositional atoms are opaque: p is just “some statement”. First-order logic opens the atoms up. It talks about elements, the relations between them, and says “for all” and “there exists”. Truth is no longer a row in a table. It is a relation between a formula and a structure, and on this page you can draw the structures yourself. 命题逻辑里的原子是不透明的，p 只代表“某个命题”。一阶逻辑把原子打开：它谈论个体、个体之间的关系，还能说“对所有”和“存在”。真不再是真值表里的一行，而是公式与结构之间的一种关系。本页的结构都可以由你亲手画出来。

§1

A language is a choice of symbols语言就是选定一套符号

Definition. A first-order language (signature) L is a set of non-logical symbols: constant symbols c, function symbols f with an arity n ≥ 1, and relation symbols R with an arity n ≥ 1. Every language also shares the same logical symbols: variables x, y, z, …, the connectives ¬ ∧ ∨ → ↔, the quantifiers ∀ ∃, equality =, and parentheses. 定义. 一个一阶语言（签名）L 是一组非逻辑符号：常元符号 c、带元数 n ≥ 1 的函数符号 f、带元数 n ≥ 1 的关系符号（谓词符号）R。所有语言共用同一套逻辑符号：变元 x, y, z, …、联结词 ¬ ∧ ∨ → ↔、量词 ∀ ∃、等词 = 以及括号。

Pick a preset or build your own language. The left box never changes; the right box is your choice. Press “Generate” to see terms and atomic formulas the language can produce. 选一个预设，或者自己搭一个语言。左边的框永远不变，右边的框由你决定。点“生成”，看看这个语言能写出哪些项和原子公式。

Terms are names: they denote elements. Atomic formulas are claims: they are true or false. Note that = is a logical symbol, so t₁ = t₂ is an atomic formula in every language, even one with no relation symbols. 项是名字，指称个体；原子公式是断言，有真假之分。注意 = 是逻辑符号，所以在任何语言里 t₁ = t₂ 都是原子公式，哪怕这个语言一个关系符号都没有。
§2

Terms are trees, and a structure evaluates them项是树，结构负责给它求值

Terms form the smallest set containing all variables and constants and closed under: if t₁,…,tₙ are terms and f is n-ary, then f(t₁,…,tₙ) is a term. Given a structure 𝔐 and an assignment s (a map from variables to elements), the value is defined by recursion on the tree: x^𝔐[s] = s(x), c^𝔐[s] = c^𝔐, f(t₁,…,tₙ)^𝔐[s] = f^𝔐(t₁^𝔐[s], …, tₙ^𝔐[s]). 项是满足下列条件的最小集合：包含所有变元和常元；若 t₁,…,tₙ 是项、f 是 n 元函数符号，则 f(t₁,…,tₙ) 是项。给定结构 𝔐 和赋值 s（从变元到个体的映射），项的值沿着树递归定义：x^𝔐[s] = s(x)，c^𝔐[s] = c^𝔐，f(t₁,…,tₙ)^𝔐[s] = f^𝔐(t₁^𝔐[s], …, tₙ^𝔐[s])。

Language {0, S, +, ·}. Change the assignment with the steppers or switch the structure, and watch values flow up the tree. Same term, different structure, different value: the symbols themselves mean nothing until a structure interprets them. 语言取 {0, S, +, ·}。用加减按钮改赋值，或者换一个结构，看值怎样沿树往上流。同一个项，换个结构，值就变了：符号本身没有意义，要等结构来解释。

§3

Free and bound variables: who binds whom自由变元与约束变元：谁约束了谁

Each quantifier ∀x / ∃x binds the occurrences of x in its scope that are not already bound by a closer quantifier. The arcs below are drawn by the parser. Hover a quantifier or a variable to light up its binding. Red wavy occurrences are free: nothing binds them, so their meaning must come from the assignment. 每个量词 ∀x / ∃x 约束它辖域内尚未被更内层量词约束的 x 的出现。下面的弧线由语法分析器自动画出。鼠标停在量词或变元上，可以高亮它的约束关系。红色波浪线标出的是自由出现：没有量词约束它，它的意思只能由赋值来提供。

Input conventions. Type ∀ ∃ with the keys, or write Ax, Ey, forall x, exists y. Variables are u v w x y z (optionally with digits or primes). A quantifier binds as tightly as ¬: ∀x E(x,y) ∧ P(x) means (∀x E(x,y)) ∧ P(x). Use parentheses, or a dot as in ∀x. φ, to extend the scope as far right as possible. 输入约定. 用按键输入 ∀ ∃，或者写 Ax、Ey、forall x、exists y。变元为 u v w x y z（可带数字或撇号）。量词的结合力与 ¬ 相同：∀x E(x,y) ∧ P(x) 表示 (∀x E(x,y)) ∧ P(x)。要扩大辖域，就加括号，或者像 ∀x. φ 那样加一个点，使辖域向右延伸到尽头。

Substitution and variable capture代入与变元捕获

φ[t/x] replaces every free occurrence of x by the term t. Danger: if t contains a variable that a quantifier in φ binds, the substituted copy gets captured and the meaning changes. The fix is to rename the bound variable first (α-renaming), which never changes meaning. φ[t/x] 把 x 的每个自由出现替换成项 t。危险在于：如果 t 中的某个变元恰好被 φ 里的量词约束，代进去的那份拷贝就会被捕获，意思随之改变。解决办法是先给约束变元改名（换名，α-变换），换名不改变公式的意思。

§4

Structures you can draw, and Tarski's definition of truth可以画出来的结构，以及塔斯基的真值定义

Definition. For the language {E} (one binary relation), a structure 𝔊 = (G, E^𝔊) is a non-empty set G (the domain) with a binary relation E^𝔊 ⊆ G × G. That is exactly a directed graph, loops allowed. 定义. 对语言 {E}（一个二元关系符号），一个结构 𝔊 = (G, E^𝔊) 由非空集合 G（论域）和一个二元关系 E^𝔊 ⊆ G × G 组成。这恰好就是一个允许自环的有向图。

𝔊 ⊨ E(x,y)[s] ⇔ (s(x), s(y)) ∈ E^𝔊  ·  𝔊 ⊨ x = y[s] ⇔ s(x) = s(y)
𝔊 ⊨ ¬φ[s] ⇔ 𝔊 ⊭ φ[s]  ·  ∧ ∨ → ↔ as in Lesson 1同第 1 课
𝔊 ⊨ ∀x φ[s] ⇔ for every对每个 a ∈ G: 𝔊 ⊨ φ[s(x|a)]
𝔊 ⊨ ∃x φ[s] ⇔ for some存在 a ∈ G: 𝔊 ⊨ φ[s(x|a)]
Why the assignment? The clause for ∀x φ must talk about φ, which may have x free, so truth has to be defined for formulas with free variables, relative to s. Coincidence lemma (by induction on φ): whether 𝔐 ⊨ φ[s] depends only on s restricted to FV(φ). So for a sentence σ the assignment is irrelevant and we simply write 𝔐 ⊨ σ. Watch the trace: s(x|a) changes only the value of x. 为什么需要赋值？ ∀x φ 的定义条款要谈论 φ，而 φ 里 x 可能自由出现，所以必须对含自由变元的公式、相对于 s 来定义真。合同引理（对 φ 归纳可证）：𝔐 ⊨ φ[s] 是否成立只取决于 s 在 FV(φ) 上的取值。因此对语句 σ 而言，赋值无关紧要，直接写 𝔐 ⊨ σ。留意求值过程：s(x|a) 只改动 x 的值。
§5

Truth as a game: Verifier vs Falsifier把真变成博弈：验证者对证伪者

Hintikka's evaluation game on 𝔐 ⊨ φ. Verifier claims the current formula is true, Falsifier claims it is false. At ∃x and ∨ the claimant chooses (a witness, a disjunct); at ∀x and ∧ the opponent chooses (a challenge, a conjunct). At ¬ the two players swap roles. φ → ψ is played as ¬φ ∨ ψ. At an atomic formula the structure decides. Pick a side and play against a computer that plays perfectly. 在 𝔐 ⊨ φ 上玩欣蒂卡（Hintikka）语义博弈。验证者主张当前公式为真，证伪者主张为假。遇到 ∃x 和 ∨，由主张为真的一方选择（找证据、选析取支）；遇到 ∀x 和 ∧，由对手选择（出挑战、选合取支）。遇到 ¬，双方互换立场。φ → ψ 按 ¬φ ∨ ψ 来玩。走到原子公式时，由结构裁决。选一边，和一台从不失误的电脑对弈。

Theorem. 𝔐 ⊨ φ[s] if and only if Verifier has a winning strategy in the game for φ starting from s. Proof sketch: induction on φ. The game is finite (each move strips one symbol). For ∃xψ: if 𝔐 ⊨ ∃xψ[s], pick a witness a and continue with the strategy for ψ from s(x|a) given by the induction hypothesis; conversely a winning first move a yields 𝔐 ⊨ ψ[s(x|a)]. The other cases are the same, with ¬ swapping the roles. That is exactly how the computer above chooses its moves. 定理. 𝔐 ⊨ φ[s] 当且仅当在从 s 出发的 φ 博弈中验证者有必胜策略。证明梗概：对 φ 归纳。博弈是有限的（每走一步就剥掉一个符号）。对 ∃xψ：若 𝔐 ⊨ ∃xψ[s]，就选一个证据 a，然后按归纳假设给出的、从 s(x|a) 出发的 ψ 的策略走下去；反之，若第一步选 a 能必胜，则 𝔐 ⊨ ψ[s(x|a)]。其余情形同理，只是 ¬ 让双方互换立场。上面的电脑正是这样选步的。
§6

Definable sets: a formula with one free variable cuts out a subset可定义集：带一个自由变元的公式切出一个子集

A formula φ(x) with free variable x defines φ(𝔐) = {a ∈ M : 𝔐 ⊨ φ[a]}. Edit the graph or the formula; the defined set lights up in gold. 自由变元为 x 的公式 φ(x) 定义了集合 φ(𝔐) = {a ∈ M : 𝔐 ⊨ φ[a]}。改图或改公式，被定义的集合会以金色亮起。

φ(x) =
A limit on definability. If π is an automorphism of 𝔐 (an isomorphism 𝔐 → 𝔐, see §8), then 𝔐 ⊨ φ[a] ⇔ 𝔐 ⊨ φ[π(a)]. So every definable set (without parameters) is closed under automorphisms. In a directed 3-cycle, the rotation is an automorphism moving any element to any other, so the only definable subsets are ∅ and the whole domain. Try it. 可定义性的界限. 若 π 是 𝔐 的自同构（即同构 𝔐 → 𝔐，见 §8），则 𝔐 ⊨ φ[a] ⇔ 𝔐 ⊨ φ[π(a)]。所以每个（不带参数的）可定义集在自同构下封闭。在有向三元环里，旋转是一个自同构，能把任一元素移到任一其他元素，因此可定义子集只有 ∅ 和整个论域。动手试试。

One sentence, three structures: (ℕ,<), (ℤ,<), (ℚ,<)同一个语句，三个结构：(ℕ,<)、(ℤ,<)、(ℚ,<)

Language {<}. A sentence is neither true nor false on its own; it is true or false in a structure. Pick a sentence and watch the witness or the counterexample appear on each number line. (These structures are infinite, so the verdicts are proved, not computed: the animation shows the key element of each proof.) 语言取 {<}。一个语句本身无所谓真假，只有放到某个结构里才有真假。选一个语句，看每条数轴上出现的证据或反例。（这些结构是无穷的，所以结论是证出来的，不是算出来的：动画展示的是每个证明中的关键元素。）

§8

Isomorphism preserves truth同构保持真

Definition. An isomorphism π : 𝔊 ≅ ℌ is a bijection G → H with E^𝔊(a,b) ⇔ E^ℌ(π(a), π(b)) for all a, b. (For a general language: π also commutes with every constant and function symbol and preserves every relation in both directions.) 定义. 同构 π : 𝔊 ≅ ℌ 是一个双射 G → H，使得对所有 a, b 都有 E^𝔊(a,b) ⇔ E^ℌ(π(a), π(b))。（一般语言下，π 还要与每个常元、函数符号交换，并双向保持每个关系。）

Theorem. If π : 𝔐 ≅ 𝔑, then for every formula φ and assignment s: 𝔐 ⊨ φ[s] ⇔ 𝔑 ⊨ φ[π∘s].定理. 若 π : 𝔐 ≅ 𝔑，则对任意公式 φ 和赋值 s：𝔐 ⊨ φ[s] ⇔ 𝔑 ⊨ φ[π∘s]。
Atomic. First, by induction on terms, π(t^𝔐[s]) = t^𝔑[π∘s]. Then 𝔐 ⊨ E(t₁,t₂)[s] ⇔ (t₁^𝔐[s], t₂^𝔐[s]) ∈ E^𝔐 ⇔ (π(t₁^𝔐[s]), π(t₂^𝔐[s])) ∈ E^𝔑 (π is an isomorphism) ⇔ 𝔑 ⊨ E(t₁,t₂)[π∘s]. For = use that π is injective. 原子公式. 先对项归纳得 π(t^𝔐[s]) = t^𝔑[π∘s]。于是 𝔐 ⊨ E(t₁,t₂)[s] ⇔ (t₁^𝔐[s], t₂^𝔐[s]) ∈ E^𝔐 ⇔ (π(t₁^𝔐[s]), π(t₂^𝔐[s])) ∈ E^𝔑（π 是同构）⇔ 𝔑 ⊨ E(t₁,t₂)[π∘s]。等式的情形用 π 是单射。
Connectives. Immediate from the induction hypothesis, since both sides use the same truth-table clauses.联结词. 由归纳假设直接可得，两边用的是同一套真值表条款。
Quantifier. 𝔐 ⊨ ∃xψ[s] ⇔ some a ∈ M has 𝔐 ⊨ ψ[s(x|a)] ⇔ (IH) 𝔑 ⊨ ψ[π∘s(x|a)] = ψ[(π∘s)(x|π(a))] ⇔ some b ∈ N has 𝔑 ⊨ ψ[(π∘s)(x|b)]. The last step uses that π is surjective: every b is some π(a). ∀ is dual. ∎ 量词. 𝔐 ⊨ ∃xψ[s] ⇔ 存在 a ∈ M 使 𝔐 ⊨ ψ[s(x|a)] ⇔（归纳假设）𝔑 ⊨ ψ[π∘s(x|a)] = ψ[(π∘s)(x|π(a))] ⇔ 存在 b ∈ N 使 𝔑 ⊨ ψ[(π∘s)(x|b)]。最后一步用到 π 是满射：每个 b 都是某个 π(a)。∀ 的情形对偶。∎

Isomorphic ⇒ same sentences true (elementarily equivalent). For finite structures in a finite language the converse also holds: a single sentence can describe a finite structure up to isomorphism. For infinite structures the converse fails badly: (ℚ,<) and (ℝ,<) satisfy exactly the same sentences but are not even equinumerous (Cantor!). That is Lesson 5. 同构 ⇒ 满足同样的语句（初等等价）。对有限语言下的有限结构，反过来也成立：一个语句就能在同构意义下刻画一个有限结构。对无穷结构，逆命题彻底失效：(ℚ,<) 与 (ℝ,<) 满足完全相同的语句，却连基数都不相等（康托尔！）。这是第 5 课的内容。
