Part I · Lesson 2

Proofs, Soundness, Completeness, Compactness证明、可靠性、完备性、紧致性

In Lesson 1, truth meant checking valuations. Now we build a machine that never looks at truth: it only shuffles strings by fixed rules. The big theorem of this lesson is that the machine proves exactly the semantic consequences: Γ ⊢ φ ⇔ Γ ⊨ φ. 第 1 课里，“真”靠检查赋值来判定。这一课我们造一台从不过问真假的机器：它只按固定规则摆弄符号串。本课的核心定理是：这台机器能证出的，恰好就是全部语义后承，即 Γ ⊢ φ ⇔ Γ ⊨ φ。

§1

Two machines: the proof machine ⊢ and the truth checker ⊨两台机器：证明机 ⊢ 与真值检验机 ⊨

Pick an example. The proof machine (left) checks each line by pattern matching only. Switch on the blindfold: the atoms become shapes and the proof is still valid, because it never used meaning. The truth checker (right) ignores proofs and looks at every valuation. 选一个例子。左边的证明机只靠模式匹配逐行检查。打开“蒙眼”开关：原子变成了图形，证明照样成立，因为它从头到尾没用到含义。右边的真值检验机不管证明，只看所有赋值。

⊢ Proof machine (syntax)证明机（语法）

⊨ Truth checker (semantics)真值检验机（语义）

Definition. A proof of φ from Γ is a finite sequence φ₁, …, φₙ = φ in which every φₖ is an axiom, a member of Γ, or follows from two earlier lines by MP. We write Γ ⊢ φ if such a sequence exists. Γ ⊨ φ (Lesson 1) means every valuation satisfying Γ satisfies φ. 定义. 从 Γ 出发对 φ 的一个证明是有限序列 φ₁, …, φₙ = φ，其中每个 φₖ 要么是公理，要么属于 Γ，要么由前面两行经分离规则（MP）得到。若这样的序列存在，记作 Γ ⊢ φ。Γ ⊨ φ（第 1 课）则表示：满足 Γ 的每个赋值都满足 φ。
§2

The Hilbert system: three axiom schemas and one rule希尔伯特系统：三条公理模式，一条推理规则

From now on the official connectives are ¬ and →; the others are abbreviations (φ∨ψ := ¬φ→ψ, φ∧ψ := ¬(φ→¬ψ)). Lesson 1 showed {¬, →} is enough. An axiom schema is a template: replace φ, ψ, χ by any formulas, the same formula for every copy of the same letter, and you get an axiom. 从现在起，官方联结词只有 ¬ 和 →，其余都是缩写（φ∨ψ := ¬φ→ψ，φ∧ψ := ¬(φ→¬ψ)）。第 1 课已经说明 {¬, →} 够用。公理模式是一个模板：把 φ、ψ、χ 换成任意公式（同一字母处处换成同一个公式），得到的就是一条公理。

Rule MP (modus ponens). From φ and φ → ψ, infer ψ. That's the only rule. 分离规则 MP（肯定前件式）. 由 φ 和 φ → ψ 推出 ψ。这是唯一的推理规则。

Instance detector实例检测器

Type a formula. The detector tries to lay each schema over it like a stencil. If one fits, the parts that φ, ψ, χ cover are coloured. If none fits, it says where the stencil breaks. 输入一个公式，检测器把每条模式像模板一样往上套。套上了，就把 φ、ψ、χ 盖住的部分涂上颜色；套不上，就指出模板在哪里卡住。

§4

The deduction theorem: turning a hypothesis into an “if”演绎定理：把假设变成“如果”

Deduction Theorem. Γ ∪ {φ} ⊢ ψ  ⇒  Γ ⊢ φ → ψ. (The converse is one MP step.) 演绎定理. Γ ∪ {φ} ⊢ ψ  ⇒  Γ ⊢ φ → ψ。（反方向只需一步 MP。）

The proof is an algorithm: put “φ →” in front of every line, then repair each line with a small patch. Three kinds of patch, one per case. Each original line (left) and its patch (right) share a colour. 它的证明是一个算法：在每一行前面加上“φ →”，再给每一行打一个小补丁。补丁分三种，各对应一种情形。左边每一行和它在右边的补丁颜色相同。

Soundness Theorem. If Γ ⊢ φ then Γ ⊨ φ.可靠性定理. 若 Γ ⊢ φ，则 Γ ⊨ φ。

Proof by induction on the length of the proof. Two facts suffice, and you can watch both. 对证明的长度做归纳。只需要两个事实，下面都可以亲眼看到。

§6

Consistency and Lindenbaum's lemma: walking down an infinite tree一致性与林登鲍姆引理：沿着无穷树往下走

Definitions. Γ is consistent if there is no ψ with Γ ⊢ ψ and Γ ⊢ ¬ψ. Γ is maximal consistent if it is consistent and, for every formula φ, φ ∈ Γ or ¬φ ∈ Γ.
Key lemma. If Δ is consistent, then at least one of Δ ∪ {φ}, Δ ∪ {¬φ} is consistent. (Sketch: an inconsistent set proves everything. If Δ ∪ {¬φ} is inconsistent, it proves φ, so Δ ⊢ ¬φ → φ by the deduction theorem, and Δ ⊢ φ via the theorem ⊢ (¬φ → φ) → φ. Symmetrically, if Δ ∪ {φ} is inconsistent, then Δ ⊢ ¬φ via ⊢ (φ → ¬φ) → ¬φ. Both together would make Δ inconsistent.) 定义. 若不存在 ψ 使得 Γ ⊢ ψ 且 Γ ⊢ ¬ψ，则称 Γ 是一致的（协调的）。若 Γ 一致，并且对每个公式 φ 都有 φ ∈ Γ 或 ¬φ ∈ Γ，则称 Γ 是极大一致集。
关键引理. 若 Δ 一致，则 Δ ∪ {φ} 与 Δ ∪ {¬φ} 中至少有一个一致。（证明梗概：不一致的集合能推出一切。若 Δ ∪ {¬φ} 不一致，它推得出 φ，由演绎定理 Δ ⊢ ¬φ → φ，再借定理 ⊢ (¬φ → φ) → φ 得 Δ ⊢ φ。同理，若 Δ ∪ {φ} 不一致，借 ⊢ (φ → ¬φ) → ¬φ 得 Δ ⊢ ¬φ。两者同时成立，Δ 就不一致了。）

Lindenbaum's lemma: every consistent Γ extends to a maximal consistent Δ. List all formulas φ₀, φ₁, φ₂, … (Lesson 1, §8: there are countably many). At level n, add φₙ or ¬φₙ, whichever keeps the set consistent. Click your way down. A red branch would make the set inconsistent and is blocked. 林登鲍姆引理：每个一致集 Γ 都能扩充成极大一致集 Δ。把全体公式排成 φ₀, φ₁, φ₂, …（第 1 课 §8：公式只有可数多个）。第 n 层在 φₙ 与 ¬φₙ 中选一个加进去，前提是加完仍一致。点击节点一路往下走。红色分支会导致不一致，走不通。

Here Γ = {p₀ → p₁,  p₁ → ¬p₂}. (For this demo the machine tests consistency of the current finite set with a truth table. That shortcut borrows a fact we only prove in §7: for a finite set, consistent ⇔ satisfiable, by soundness plus completeness. The proof of Lindenbaum's lemma itself only needs the key lemma.) 这里取 Γ = {p₀ → p₁,  p₁ → ¬p₂}。（演示中，机器用真值表检验当前这个有限集是否一致。这个捷径借用了 §7 才证明的事实：对有限集，一致 ⇔ 可满足（由可靠性加完备性）。林登鲍姆引理的证明本身只需要上面的关键引理。）

§7

The Completeness Theorem完备性定理

Completeness Theorem. If Γ ⊨ φ then Γ ⊢ φ. Together with soundness: ⊢ = ⊨. (Post, 1921, proved the case Γ = ∅, “every tautology is provable”, for the axioms of Principia Mathematica; the general form with premises Γ is proved below.) 完备性定理. 若 Γ ⊨ φ，则 Γ ⊢ φ。结合可靠性定理：⊢ = ⊨。（波斯特于 1921 年针对《数学原理》的公理系统证明了 Γ = ∅ 的情形，即“每个重言式都可证”；带前提 Γ 的一般形式见下面的证明。）

We prove the contrapositive: from Γ ⊬ φ we build a counterexample valuation. Step through the chain. 证明其逆否命题：由 Γ ⊬ φ 出发，造出一个反例赋值。逐步走完这条链。

Step 1. Suppose Γ ⊬ φ. Then Γ ∪ {¬φ} is consistent. Otherwise Γ ∪ {¬φ} ⊢ φ (from an inconsistent set everything follows, via the theorem ⊢ ¬ψ → (ψ → φ)). The deduction theorem gives Γ ⊢ ¬φ → φ, and with the theorem ⊢ (¬φ → φ) → φ, MP gives Γ ⊢ φ. Contradiction. 第 1 步. 设 Γ ⊬ φ，则 Γ ∪ {¬φ} 一致。否则 Γ ∪ {¬φ} ⊢ φ（不一致的集合什么都推得出，用的是定理 ⊢ ¬ψ → (ψ → φ)）。由演绎定理得 Γ ⊢ ¬φ → φ，再结合定理 ⊢ (¬φ → φ) → φ 用 MP 得 Γ ⊢ φ，矛盾。
Step 2 (Lindenbaum, §6). Extend Γ ∪ {¬φ} to a maximal consistent set Δ: Δ = ⋃ₙ Δₙ. Δ is consistent because a proof of a contradiction from Δ would use only finitely many hypotheses, all in some single Δₙ. 第 2 步（林登鲍姆，§6）. 把 Γ ∪ {¬φ} 扩充成极大一致集 Δ：Δ = ⋃ₙ Δₙ。Δ 是一致的：从 Δ 推出矛盾的证明只用到有限个假设，它们全落在某一个 Δₙ 里。
Step 3. Define the valuation v(p) = 1 ⇔ p ∈ Δ for each atom p. 第 3 步. 对每个原子命题 p，定义赋值 v(p) = 1 ⇔ p ∈ Δ。
Step 4 (Truth Lemma). For every formula ψ: v̄(ψ) = 1 ⇔ ψ ∈ Δ. Induction on ψ. Atoms: by definition. ¬ψ: by maximality and consistency, ¬ψ ∈ Δ ⇔ ψ ∉ Δ ⇔ v̄(ψ) = 0 ⇔ v̄(¬ψ) = 1. ψ → χ: Δ is deductively closed (if Δ ⊢ θ then θ ∈ Δ, else ¬θ ∈ Δ and Δ is inconsistent). If ψ ∉ Δ, then ¬ψ ∈ Δ, and ⊢ ¬ψ → (ψ → χ) puts ψ → χ ∈ Δ. If χ ∈ Δ, A1 puts ψ → χ ∈ Δ. If ψ ∈ Δ and χ ∉ Δ, then ψ → χ ∉ Δ, since otherwise MP would put χ in Δ. These three cases match the truth table of →. 第 4 步（真值引理）. 对每个公式 ψ：v̄(ψ) = 1 ⇔ ψ ∈ Δ。对 ψ 归纳。 原子：按定义。¬ψ：由极大性与一致性，¬ψ ∈ Δ ⇔ ψ ∉ Δ ⇔ v̄(ψ) = 0 ⇔ v̄(¬ψ) = 1。 ψ → χ：Δ 对推演封闭（若 Δ ⊢ θ 而 θ ∉ Δ，则 ¬θ ∈ Δ，Δ 就不一致了）。若 ψ ∉ Δ，则 ¬ψ ∈ Δ，由 ⊢ ¬ψ → (ψ → χ) 得 ψ → χ ∈ Δ；若 χ ∈ Δ，由 A1 得 ψ → χ ∈ Δ；若 ψ ∈ Δ 而 χ ∉ Δ，则 ψ → χ ∉ Δ，否则用 MP 就得 χ ∈ Δ。三种情形恰好对上 → 的真值表。
Step 5. Γ ⊆ Δ and ¬φ ∈ Δ, so v satisfies Γ and v̄(φ) = 0. Hence Γ ⊭ φ. Contrapositive: Γ ⊨ φ ⇒ Γ ⊢ φ. ∎ 第 5 步. Γ ⊆ Δ 且 ¬φ ∈ Δ，所以 v 满足 Γ 而 v̄(φ) = 0，即 Γ ⊭ φ。取逆否：Γ ⊨ φ ⇒ Γ ⊢ φ。∎
Equivalent form: every consistent set is satisfiable. You watched a small piece of exactly this construction in §6: the path through the tree is the model. 等价说法：每个一致集都可满足。§6 里你看到的正是这个构造的一小段：树里走出的那条路径就是模型。
§8

Compactness: König's tree of partial valuations紧致性：柯尼希树与部分赋值

Compactness Theorem. A set Γ of formulas is satisfiable if and only if every finite subset of Γ is satisfiable. 紧致性定理. 公式集 Γ 可满足，当且仅当 Γ 的每个有限子集都可满足。

Atoms p₀, p₁, p₂, …. A node at depth n is a partial valuation of p₀ … pₙ₋₁ (left edge = 0, right edge = 1). Let Γₙ be the formulas of Γ that mention only p₀ … pₙ₋₁. Each “check” prunes every node at the new depth that falsifies some formula of Γₙ; its whole subtree dies. If Γ is finitely satisfiable, every level keeps a survivor (Γₙ may be infinite, but over n atoms there are only finitely many formulas up to equivalence, so Γₙ is equivalent to a finite subset of Γ), and König's lemma then gives an infinite branch: a valuation satisfying all of Γ. 原子为 p₀, p₁, p₂, …。深度为 n 的节点是 p₀ … pₙ₋₁ 上的部分赋值（左边 = 0，右边 = 1）。令 Γₙ 为 Γ 中只涉及 p₀ … pₙ₋₁ 的那些公式。每次“检查”都会在新的一层剪掉弄假 Γₙ 中某个公式的节点，它下面的整棵子树也随之死掉。若 Γ 有限可满足，每一层都有幸存者（Γₙ 可能是无穷集，但 n 个原子上的公式在等价意义下只有有限多个，所以 Γₙ 等价于 Γ 的某个有限子集），柯尼希引理就给出一条无穷分支，也就是满足整个 Γ 的赋值。

König's lemma, step by step柯尼希引理，分步证明

Lemma. Every infinite, finitely branching tree has an infinite branch.引理. 每棵无穷且有限分叉的树都有一条无穷分支。
Call a node big if infinitely many nodes lie below it. The root is big, because the tree is infinite.若某节点下方有无穷多个节点，就称它是大节点。树是无穷的，所以根是大节点。
If a node is big, one of its children is big: finitely many children, and a finite union of finite sets would be finite (pigeonhole).若某节点是大的，它必有一个孩子是大的：孩子只有有限个，而有限个有限集之并仍是有限集（抽屉原理）。
Start at the root and always step to a big child. This never stops and traces an infinite branch. ∎ (In general, making infinitely many such choices uses a weak form of choice, dependent choice; in our binary tree we can always take the leftmost big child, so no choice is needed.)
Applied to our tree: survivors at depth n = valuations of p₀…pₙ₋₁ satisfying Γₙ. Over n atoms there are only finitely many formulas up to equivalence, so Γₙ is equivalent to a finite subset of Γ; finite satisfiability therefore means every level is nonempty, and the tree is infinite. The branch satisfies every formula of Γ, since each formula lies in some Γₙ. 从根出发，每一步都走向一个大孩子。这个过程永不停止，走出一条无穷分支。∎（一般情形下，做无穷多次这样的选择要用到选择公理的弱形式，即依赖选择公理；在我们的二叉树中，总可以取最左边的大孩子，因此无需任何选择。）
用到我们的树上：深度 n 的幸存者，就是 p₀…pₙ₋₁ 上满足 Γₙ 的赋值。n 个原子上的公式在等价意义下只有有限多个，所以 Γₙ 等价于 Γ 的某个有限子集；于是“有限可满足”意味着每一层都非空，树是无穷的。而 Γ 的每个公式都属于某个 Γₙ，因此这条分支满足整个 Γ。
Second proof, for free: compactness also follows from completeness, because proofs are finite (Exercise E4). König needs countably many atoms; for uncountably many, one uses Zorn's lemma (Lesson 10) or Tychonoff's theorem on {0,1}P, which is where the name “compactness” comes from. 第二种证明，白送：紧致性也可以由完备性推出，因为证明都是有限长的（见练习 E4）。柯尼希引理只适用于可数多个原子；原子不可数时，要用佐恩引理（第 10 课）或 {0,1}P 上的吉洪诺夫定理，“紧致性”这个名字就是从这里来的。
§9

Application: colouring infinite graphs (De Bruijn–Erdős)应用：无穷图的着色（德布鲁因–埃尔德什定理）

The graph continues forever to the right. Use one atom cv,i for “vertex v gets colour i”, and let Γ say: each vertex gets at least one colour, at most one colour, and adjacent vertices get different colours. A valuation satisfying Γ is a k-colouring. A finite subset of Γ mentions only finitely many vertices. So if every finite subgraph is k-colourable, the whole infinite graph is. 这张图向右无限延伸。对每个顶点 v 和颜色 i 引入原子 cv,i，意为“v 染第 i 种颜色”。令 Γ 规定：每个顶点至少染一种颜色、至多染一种颜色、相邻顶点颜色不同。满足 Γ 的赋值就是一个 k-着色。Γ 的有限子集只涉及有限个顶点，所以只要每个有限子图都能 k-着色，整个无穷图就能 k-着色。

colours颜色数 k:   finite window有限窗口: 4

Click a vertex to cycle its colour. Hover a vertex to see its formulas in Γ.点击顶点循环切换颜色；鼠标停在顶点上，可以看到它在 Γ 里对应的公式。

De Bruijn–Erdős (1951), plus the Four Colour Theorem: every infinite planar graph is 4-colourable, because each finite subgraph is a finite planar graph. (For uncountable graphs, use compactness for arbitrarily many atoms, which needs a weak form of the Axiom of Choice.) 德布鲁因–埃尔德什定理（1951），再加上四色定理：每个无穷平面图都能 4-着色，因为它的每个有限子图都是有限平面图。（对不可数图，要用任意多原子的紧致性定理，这需要选择公理的一种弱形式。）
