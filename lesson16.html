§2

Cohen forcing: finite pieces of a real科恩力迫：实数的有限碎片

Definition. A forcing poset is (P, ≤, 𝟙) with a largest element 𝟙. Elements are conditions; q ≤ p reads “q is stronger than (extends, refines) p”: it carries more information. p, q are compatible if some r ≤ p, q; otherwise incompatible, p ⊥ q.
Cohen forcing Fn(ω,2): the finite partial functions p : ω ⇀ 2, with q ≤ p ⇔ q ⊇ p and 𝟙 = ∅. Two conditions are compatible iff they agree on their common domain. 定义. 力迫偏序是带最大元 𝟙 的偏序 (P, ≤, 𝟙)。其元素称为条件；q ≤ p 读作“q 比 p 更强”（q 加细了 p），即 q 携带的信息更多。若存在 r ≤ p, q，称 p, q 相容，否则称不相容，记作 p ⊥ q。
科恩力迫 Fn(ω,2)：由所有有限部分函数 p : ω ⇀ 2 组成，q ≤ p ⇔ q ⊇ p，𝟙 = ∅。两个条件相容当且仅当它们在公共定义域上取值一致。

Picture 1: the tree. The finite binary strings (conditions with domain an initial segment {0,…,n−1}) are dense in Fn(ω,2) and give an equivalent forcing, so we often draw the tree 2<ω (root 𝟙 = ∅ on top, stronger = lower). Click a node to select p (blue; its cone of extensions lights up), then another for q (orange). 图一：二叉树。有限 0/1 串（定义域为前段 {0,…,n−1} 的条件）在 Fn(ω,2) 中稠密，给出等价的力迫，所以常画成树 2<ω：树根 𝟙 = ∅ 在最上面，越往下越强。点一个节点选作 p（蓝色，它的所有加细会亮起来），再点一个作为 q（橙色）。

Picture 2: partial functions. Click cells to cycle blank → 0 → 1. The domain need not be an initial segment. 图二：部分函数。点格子循环切换：空 → 0 → 1。定义域不必是前段。

§3

Dense sets and generic filters稠密集与脱殊滤子

Definitions. D ⊆ P is dense if ∀p ∃q ≤ p (q ∈ D): no matter what you already know, you can still get into D. G ⊆ P is a filter if 𝟙 ∈ G; p ∈ G, p ≤ q ⇒ q ∈ G; and any two elements of G have a common extension in G. G is M-generic if it is a filter meeting every dense D ⊆ P with D ∈ M. 定义. 若 ∀p ∃q ≤ p (q ∈ D)，称 D ⊆ P 稠密：不管已经知道了什么，总还能加细进 D。 若 𝟙 ∈ G；p ∈ G, p ≤ q ⇒ q ∈ G；且 G 中任两个元素在 G 内有公共加细，则称 G ⊆ P 为滤子。 若滤子 G 与每个属于 M 的稠密集 D ⊆ P 都相交，称 G 为 M-脱殊滤子。

Two families of dense sets in M matter most: Dn = {p : n ∈ dom p} (eventually every bit gets decided) and Dx = {p : p ⊥ x} for each real x ∈ M (eventually we disagree with x). Pick a set; green nodes are its members. Then click any node p: the density machine walks down to some q ≤ p in the set, or shows that none exists. M 中最重要的两族稠密集：Dn = {p : n ∈ dom p}（每一位迟早会被确定）和 Dx = {p : p ⊥ x}，其中 x ∈ M 是任一实数（迟早会与 x 分道扬镳）。选一个集合，绿色节点是它的元素。然后点任意节点 p：稠密性机器会往下走到集合中的某个 q ≤ p，或者表明根本不存在这样的 q。

A filter through Cohen forcing is a set of conditions that are all pieces of one (possibly partial) function. Meeting every Dn makes g = ⋃G a total function ω → 2, a real. Meeting every Dx makes g ≠ x for every x ∈ M, so g ∉ M. 科恩力迫中的滤子，就是一族同属于某个（可能是部分的）函数的碎片。与每个 Dn 相交，使 g = ⋃G 成为全函数 ω → 2，也就是一个实数；与每个 Dx 相交，使 g 不等于任何 x ∈ M，从而 g ∉ M。
§4

The generic game is Cantor's diagonal argument脱殊游戏就是康托尔对角线论证

From outside, M is countable, so its reals form a list x₀, x₁, x₂, … and its dense sets form a list too. Your job: build a descending chain p₀ ≥ p₁ ≥ … meeting the requirements in order. The current requirement is highlighted. Append bits yourself, or press Cantor move, which flips the diagonal bit xₖ(k). 从外面看 M 是可数的，所以它的实数能排成一列 x₀, x₁, x₂, …，它的稠密集也能排成一列。你的任务：造一条递降链 p₀ ≥ p₁ ≥ …，依次满足清单上的要求。当前要求会高亮。你可以自己往后添位，也可以按康托尔一步，它把对角线上的 xₖ(k) 翻转过来。

Compare with Cantor (L1 §8, L9): Cantor's theorem says no list of reals is complete. The generic real is the same diagonal real, built against M's list. The twist: M cannot see the list (inside M, its reals are uncountable), so g is a real that M “should have had” but doesn't. 与康托尔对照（第 1 课 §8、第 9 课）：康托尔定理说，任何实数清单都不完整。脱殊实数正是同一个对角线实数，只是针对的是 M 的清单。妙处在于：M 自己看不见这份清单（在 M 内部，它的实数是不可数的），所以 g 是 M “本该有、却没有”的实数。
§5

Generic filters exist (Rasiowa–Sikorski), and are new脱殊滤子存在（拉肖瓦–西科尔斯基引理），而且是新的

Lemma (Rasiowa–Sikorski). If 𝒟 is a countable family of dense subsets of P and p ∈ P, there is a filter G ∋ p meeting every D ∈ 𝒟. In particular, for a countable transitive M and P ∈ M, an M-generic G ∋ p exists. 引理（拉肖瓦–西科尔斯基）. 若 𝒟 是 P 的可数个稠密子集组成的族，p ∈ P，则存在滤子 G ∋ p 与每个 D ∈ 𝒟 相交。特别地，若 M 是可数传递模型且 P ∈ M，则存在 M-脱殊滤子 G ∋ p。
1. Since M is countable, so is {D ∈ M : D dense in P}. List it: D₀, D₁, D₂, …由于 M 可数，{D ∈ M : D 在 P 中稠密} 也可数，排成一列：D₀, D₁, D₂, …
2. Let p₀ = p. Given pₙ, density of Dₙ gives pₙ₊₁ ≤ pₙ with pₙ₊₁ ∈ Dₙ. (Countably many choices; DC suffices.)令 p₀ = p。已有 pₙ 时，由 Dₙ 的稠密性取 pₙ₊₁ ≤ pₙ 且 pₙ₊₁ ∈ Dₙ。（只做可数次选择，依赖选择公理 DC 即可。）
3. Let G = {q ∈ P : ∃n pₙ ≤ q}. It contains 𝟙, is upward closed, and any q, q′ ∈ G lie above some common pₙ (take the larger index), which is in G. So G is a filter.令 G = {q ∈ P : ∃n pₙ ≤ q}。它含 𝟙、向上封闭；任意 q, q′ ∈ G 都在某个共同的 pₙ 之上（取较大的下标），而 pₙ ∈ G。所以 G 是滤子。
4. pₙ₊₁ ∈ G ∩ Dₙ for every n. ∎对每个 n，pₙ₊₁ ∈ G ∩ Dₙ。∎
5. Bonus: G ∉ M. In Cohen forcing every p has two incompatible extensions p⌢0, p⌢1. If G ∈ M, then D = P ∖ G ∈ M, and D is dense (at most one of the two extensions lies in G). Genericity gives G ∩ (P ∖ G) ≠ ∅. Absurd.附赠：G ∉ M。在科恩力迫中，每个 p 都有两个互不相容的加细 p⌢0, p⌢1。若 G ∈ M，则 D = P ∖ G ∈ M，且 D 稠密（两个加细至多一个在 G 中）。由脱殊性 G ∩ (P ∖ G) ≠ ∅，荒谬。
Why countability is essential: over V itself there is no generic. If G met every dense set in V, then for the real g = ⋃G, the dense set Dg ∈ V would be met by some p ∈ G, so p ⊥ g, yet p ⊆ g. (Exercise E5.) 为什么必须可数：对 V 本身不存在脱殊滤子。假如 G 与 V 中每个稠密集都相交，取实数 g = ⋃G，稠密集 Dg ∈ V 就会被某个 p ∈ G 碰到，于是 p ⊥ g，可是 p ⊆ g。（见练习 E5。）
§6

Names: how M talks about sets it doesn't have yet名字：M 如何谈论它还没有的集合

Definition (by ∈-recursion, inside M). A P-name is a set τ of pairs (σ, p) where each σ is a P-name and p ∈ P. Read (σ, p) ∈ τ as “σ will be in τ if p turns out true”. Its value under a filter G:
val(τ, G) = τG = { val(σ, G) : ∃p ∈ G (σ, p) ∈ τ }
M[G] = {val(τ, G) : τ ∈ M is a P-name}. Ground sets have check names x̌ = {(y̌, 𝟙) : y ∈ x} with val(x̌, G) = x, and Γ = {(p̌, p) : p ∈ P} names G itself. 定义（在 M 内按 ∈-递归）. P-名字是由序对 (σ, p) 组成的集合 τ，其中每个 σ 是 P-名字，p ∈ P。(σ, p) ∈ τ 读作“如果 p 成真，σ 就进入 τ”。它在滤子 G 下的取值为
val(τ, G) = τG = { val(σ, G) : ∃p ∈ G (σ, p) ∈ τ }
M[G] = {val(τ, G) : τ ∈ M 是 P-名字}。基础模型中的集合有典范名字 x̌ = {(y̌, 𝟙) : y ∈ x}，满足 val(x̌, G) = x；而 Γ = {(p̌, p) : p ∈ P} 是 G 自身的名字。

Edges whose condition is in G light up, and values are computed from the leaves up. (Numbers are von Neumann ordinals: 0 = ∅, 1 = {0}, 2 = {0,1}.) 下面把一个名字画成树：每条边是一个序对 (σ, p)，边上标着它的条件。选定脱殊实数的前几位，于是 G = {p : p ⊆ g}。条件属于 G 的边会亮起，取值从叶子往上计算。（数字是冯·诺伊曼序数：0 = ∅, 1 = {0}, 2 = {0,1}。）

§7

The forcing relation: conditions decide statements力迫关系：条件“判定”命题

Forcing. p ⊩ φ(τ₁,…,τₙ) means: for every M-generic G ∋ p, M[G] ⊨ φ(val(τ₁,G),…).
Forcing Theorem. (1) Definability: for each formula φ there is a relation ⊩*φ, defined in M by recursion on φ, that coincides with ⊩ on M. (2) Truth Lemma: M[G] ⊨ φ(val(τ₁,G),…) ⇔ ∃p ∈ G p ⊩ φ(τ₁,…,τₙ). 力迫. p ⊩ φ(τ₁,…,τₙ) 的意思是：对每个含 p 的 M-脱殊滤子 G，都有 M[G] ⊨ φ(val(τ₁,G),…)。
力迫定理. (1) 可定义性：对每个公式 φ，有一个在 M 中按 φ 的结构递归定义的关系 ⊩*φ，它在 M 上与 ⊩ 一致。(2) 真值引理：M[G] ⊨ φ(val(τ₁,G),…) ⇔ ∃p ∈ G p ⊩ φ(τ₁,…,τₙ)。

Pick a statement about the generic real ġ. Each node is colored: green = p ⊩ φ, red = p ⊩ ¬φ, grey = p doesn't decide. Then click a path downward, playing the generic: watch where it gets decided. 选一个关于脱殊实数 ġ 的命题。节点着色：绿＝p ⊩ φ，红＝p ⊩ ¬φ，灰＝p 尚未判定。然后扮演脱殊滤子，沿树往下点出一条路径，看看命题在哪一步被判定。

Two lessons. (1) For each φ, {p : p ⊩ φ or p ⊩ ¬φ} is dense: any condition can be strengthened to decide φ. Since that set is in M (definability!), the generic meets it; this is the engine of the Truth Lemma. (2) Forcing is not “the condition contains a witness”. ∅ ⊩ ġ ≠ x̌ although ∅ contains no bit at all: it is forced because the generic must meet the dense set Dx. 两点体会。(1) 对每个 φ，集合 {p : p ⊩ φ 或 p ⊩ ¬φ} 是稠密的：任何条件都能加细到判定 φ。又因为这个集合属于 M（这就是可定义性的用处！），脱殊滤子一定碰到它。这正是真值引理的发动机。(2) 力迫不是“条件里含有证据”。∅ ⊩ ġ ≠ x̌，可 ∅ 一位都没确定：之所以被力迫，是因为脱殊滤子必然与稠密集 Dx 相交。
§8

M[G] is a model of ZFC: the smallest one containing M and GM[G] 是 ZFC 的模型：含 M 与 G 的最小模型

Generic Model Theorem. Let M be a ctm of ZFC, P ∈ M, G M-generic. Then M[G] is a ctm of ZFC, M ⊆ M[G], G ∈ M[G], Ord ∩ M[G] = Ord ∩ M, and M[G] is the smallest transitive model N of ZF with M ⊆ N and G ∈ N. (For a ctm of a sufficiently large finite fragment, the same holds for any prescribed finite fragment.) 脱殊模型定理. 设 M 是 ZFC 的可数传递模型，P ∈ M，G 是 M-脱殊滤子。则 M[G] 是 ZFC 的可数传递模型，M ⊆ M[G]，G ∈ M[G]，Ord ∩ M[G] = Ord ∩ M，而且 M[G] 是满足 M ⊆ N、G ∈ N 的 ZF 传递模型 N 中最小的一个。（若 M 只是某个足够大的有限片段的模型，则对任意预先指定的有限片段同样成立。）

§9

Getting ¬CH: ℵ₂ Cohen reals, and the ccc keeps ℵ₂ alive得到 ¬CH：加入 ℵ₂ 个科恩实数，靠可数链条件保住 ℵ₂

In M, let P = Fn(ω₂ × ω, 2) (finite partial functions, ω₂ = ω₂^M). A generic G gives ⋃G : ω₂ × ω → 2: a grid with ω₂ columns, each column gα(n) = ⋃G(α, n) a real. One condition fills only finitely many cells. Click two column headers to compare columns α and β. 在 M 中取 P = Fn(ω₂ × ω, 2)（有限部分函数，ω₂ = ω₂^M）。脱殊滤子 G 给出 ⋃G : ω₂ × ω → 2：一张有 ω₂ 列的格子图，每一列 gα(n) = ⋃G(α, n) 都是一个实数。一个条件只填有限多个格。点两个列标题，比较第 α 列与第 β 列。

So α ↦ gα is injective, by density of Dαβ = {p : ∃n (p(α,n), p(β,n) defined and different)}. Hence M[G] ⊨ 2^ℵ₀ ≥ |ω₂^M|. But is ω₂^M still ω₂ in M[G]? A new set could be a collapsing bijection. The cure is a combinatorial property of P. 由 Dαβ = {p : ∃n (p(α,n), p(β,n) 均有定义且不等)} 的稠密性，α ↦ gα 是单射，于是 M[G] ⊨ 2^ℵ₀ ≥ |ω₂^M|。可是 ω₂^M 在 M[G] 中还是 ω₂ 吗？新加进来的集合可能恰好是一个把它“坍缩”掉的双射。解药是 P 的一个组合性质。

ccc. P has the countable chain condition if every antichain (set of pairwise incompatible conditions) is countable.
Δ-system lemma. Every uncountable family of finite sets has an uncountable subfamily {aξ} forming a Δ-system: there is a root r with aξ ∩ aη = r for all ξ ≠ η.
Hence Fn(I, 2) is ccc for every I: given uncountably many conditions, their domains form an uncountable family (each finite domain carries only finitely many conditions); thin to a Δ-system of domains with root r; only finitely many (2|r|) patterns on r, so two conditions agree on r, and their domains meet only in r: they are compatible. 可数链条件（ccc）. 若 P 的每个反链（两两不相容的条件之集）都可数，称 P 满足可数链条件。
Δ-系统引理. 任何不可数的有限集族都含有一个不可数子族 {aξ} 构成 Δ-系统：存在根 r，使得对所有 ξ ≠ η 都有 aξ ∩ aη = r。
所以对任意 I，Fn(I, 2) 满足 ccc：任给不可数多个条件，它们的定义域构成不可数族（每个有限定义域上只有有限多个条件）；先把定义域细化成根为 r 的 Δ-系统；条件在 r 上只有有限种（2|r| 种）取法，于是有两个条件在 r 上取值相同，而它们的定义域只在 r 处相交，故二者相容。

A finite stand-in for the argument: rows are conditions, columns are coordinates. Find a Δ-system (gold = root), then let the pigeonhole find two that agree on the root. 用有限的例子演示这个论证：每行是一个条件，每列是一个坐标。先找出 Δ-系统（金色为根），再用抽屉原理找出在根上取值相同的两个条件。

Theorem. If P ∈ M is ccc in M, then M and M[G] have the same cardinals (and cofinalities). Key lemma (approximation): any function f : A → B in M[G] with A, B ∈ M is covered by some F ∈ M with f(a) ∈ F(a) and F(a) countable in M. (Proof: exercise E4.) So ω₂^M = ω₂M[G] and M[G] ⊨ 2^ℵ₀ ≥ ℵ₂, i.e. ¬CH. (If moreover M ⊨ GCH, counting names gives exactly M[G] ⊨ 2^ℵ₀ = ℵ₂; see E6.) 定理. 若 P ∈ M 在 M 中满足 ccc，则 M 与 M[G] 的基数（以及共尾性）完全相同。关键引理（逼近引理）：M[G] 中任意函数 f : A → B（A, B ∈ M）都能被某个 F ∈ M 覆盖：f(a) ∈ F(a)，且 F(a) 在 M 中可数。（证明见练习 E4。）于是 ω₂^M = ω₂M[G]，M[G] ⊨ 2^ℵ₀ ≥ ℵ₂，即 ¬CH。（若还有 M ⊨ GCH，数一数名字可得恰好 M[G] ⊨ 2^ℵ₀ = ℵ₂；见练习 E6。）
§10

Putting it together: CH is independent of ZFC合起来：连续统假设独立于 ZFC

The flowchart combines Lessons 14, 15 and 16. Step through it. 这张流程图把第 14、15、16 课连成一体。一步一步走一遍。

Theorem (Gödel 1938, Cohen 1963). If ZF is consistent, then so are ZFC + CH and ZFC + ¬CH. Hence, if ZFC is consistent, it proves neither CH nor ¬CH.
Metamathematical fine print. ZFC cannot prove “there is a ctm of ZFC” (unless ZFC is inconsistent; by Gödel's second theorem). The proof is: suppose ZFC + ¬CH ⊢ ⊥. The proof uses a finite set Φ of axioms. Choose a finite Ψ ⊆ ZFC so large that ZFC proves “for every ctm M ⊨ Ψ and every M-generic G for P = Fn(ω₂M × ω, 2), M[G] ⊨ Φ”. By reflection, LS and collapse, ZFC proves that a ctm of Ψ exists, and by Rasiowa–Sikorski that a generic over it exists. Then ZFC proves that Φ has a model, hence is consistent, while ZFC also proves “Φ ⊢ ⊥”. So ZFC is inconsistent. This argument is finitary: it is a proof in PA of Con(ZFC) → Con(ZFC + ¬CH). 定理（哥德尔 1938，科恩 1963）. 若 ZF 一致，则 ZFC + CH 与 ZFC + ¬CH 都一致。因此只要 ZFC 一致，它既证明不了 CH，也证明不了 ¬CH。
元数学上的细节. ZFC 证明不了“存在 ZFC 的可数传递模型”（除非 ZFC 不一致；由哥德尔第二不完全性定理）。正确的论证是：设 ZFC + ¬CH ⊢ ⊥，这个证明只用到有限个公理 Φ。取有限的 Ψ ⊆ ZFC 足够大，使 ZFC 能证明“对 Ψ 的任一可数传递模型 M 及 P = Fn(ω₂M × ω, 2) 的任一 M-脱殊滤子 G，M[G] ⊨ Φ”。由反射原理、LS 定理与传递化坍塌，ZFC 证明 Ψ 有可数传递模型，再由拉肖瓦–西科尔斯基引理证明其上存在脱殊滤子，从而证明 Φ 有模型、因而一致；而 ZFC 同时也证明“Φ ⊢ ⊥”。所以 ZFC 不一致。整个论证是有穷的：它是 PA 中关于 Con(ZFC) → Con(ZFC + ¬CH) 的一个证明。
