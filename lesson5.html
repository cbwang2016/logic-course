Compactness & Löwenheim–Skolem紧致性与勒文海姆–斯科伦定理

First-order logic cannot count past “finite”, cannot pin down ℕ, and cannot control the size of its models. This lesson shows why, with pictures you can drive. We assume Gödel's completeness theorem (Lesson 4). 一阶逻辑数不清“有限”，刻画不了 ℕ，也管不住自己模型的大小。本课用一组可以亲手操作的图来说明原因。前提是第 4 课的哥德尔完备性定理。

§1

The Compactness Theorem for first-order logic一阶逻辑的紧致性定理

Compactness Theorem. A set Γ of first-order sentences has a model if and only if every finite subset of Γ has a model. Equivalently: Γ ⊨ φ iff Δ ⊨ φ for some finite Δ ⊆ Γ. 紧致性定理. 一阶语句集 Γ 有模型，当且仅当 Γ 的每个有限子集都有模型。等价说法：Γ ⊨ φ 当且仅当存在有限的 Δ ⊆ Γ 使 Δ ⊨ φ。

Proof idea: proofs are finite. Suppose Γ had no model. Completeness turns that into a formal proof of ⊥ from Γ, and a proof is a finite object. Press “Trace premises” to see which premises it actually uses. 证明思路：证明是有限的。假设 Γ 没有模型，完备性定理把这件事变成一个从 Γ 推出 ⊥ 的形式证明，而证明是有限对象。按“追踪前提”，看看它实际用到了哪些前提。

1. Assume every finite Δ ⊆ Γ has a model, but Γ has none.1. 设 Γ 的每个有限子集 Δ 都有模型，而 Γ 本身没有模型。
2. “Γ has no model” means Γ ⊨ ⊥. By Gödel's completeness theorem, Γ ⊢ ⊥.2. “Γ 没有模型”就是 Γ ⊨ ⊥。由哥德尔完备性定理，Γ ⊢ ⊥。
3. A derivation is a finite sequence of formulas, so it cites only finitely many premises Δ ⊆ Γ (the gold boxes). Hence Δ ⊢ ⊥.3. 推导是有限长的公式序列，只引用了有限多个前提 Δ ⊆ Γ（图中金色方框），所以 Δ ⊢ ⊥。
4. By soundness, Δ ⊨ ⊥, so the finite set Δ has no model. This contradicts 1. ∎4. 由可靠性定理，Δ ⊨ ⊥，即有限集 Δ 没有模型，与 1 矛盾。∎

Language: only “=”. Let λₙ say “there are at least n elements” and μₙ say “there are at most n elements”. Click sentences to put them into a finite set Δ. The picture shows a model of Δ, or explains why there is none. 语言里只有“=”。令 λₙ 表示“至少有 n 个元素”，μₙ 表示“至多有 n 个元素”。点击语句把它放进有限集 Δ，右边会画出 Δ 的一个模型，或者说明为什么没有模型。

§2

“Finite” is not first-order“有限”不是一阶性质

Move the slider. Each box is a structure in the empty language; it lights up when it satisfies λₙ. The infinite box is lit for every n, so the models of {λ₁, λ₂, λ₃, …} are exactly the infinite structures. 拖动滑块。每个方框是空语言上的一个结构，满足 λₙ 时就亮起。无穷的那个方框对每个 n 都亮着，所以 {λ₁, λ₂, λ₃, …} 的模型恰好是全体无穷结构。

n = 3
Theorem. If a set of sentences T has arbitrarily large finite models, then T has an infinite model. 定理. 若语句集 T 有任意大的有限模型，则 T 有无穷模型。
Proof. Consider T ∪ {λₙ : n ≥ 1}. A finite subset mentions only λₙ with n ≤ N for some N; a finite model of T with at least N elements satisfies it. By compactness the whole set has a model: a model of T that satisfies every λₙ, so it is infinite. ∎ 证明. 考虑 T ∪ {λₙ : n ≥ 1}。它的任一有限子集只涉及 n ≤ N 的 λₙ，T 的任何至少有 N 个元素的有限模型都满足它。由紧致性，整个集合有模型；这个模型是 T 的模型，又满足每个 λₙ，所以是无穷的。∎
Corollary 1. No set of sentences has exactly the finite structures as its models. (Such a set would have arbitrarily large finite models and no infinite one.) 推论 1. 不存在一个语句集，其模型恰好是全体有限结构。（否则它有任意大的有限模型，却没有无穷模型。）
Corollary 2. “Infinite” is axiomatized by the infinite set {λₙ}, but by no single sentence σ. If σ held exactly in the infinite structures, ¬σ would hold exactly in the finite ones, contradicting Corollary 1. 推论 2. “无穷”可以用无穷集 {λₙ} 公理化，却不能用单个语句 σ 公理化。若 σ 恰好在无穷结构中成立，则 ¬σ 恰好在有限结构中成立，与推论 1 矛盾。
§3

A nonstandard model of arithmetic算术的非标准模型

Add a new constant c to the language of arithmetic and take Γ = Th(ℕ, 0, 1, +, ·, <) ∪ {c > n̄ : n ∈ ℕ}, where n̄ = 1+⋯+1. Click sentences to build a finite Δ ⊆ Γ. The true ℕ always satisfies Δ: just interpret c as a large enough number. 在算术语言里加一个新常元 c，令 Γ = Th(ℕ, 0, 1, +, ·, <) ∪ {c > n̄ : n ∈ ℕ}，其中 n̄ = 1+⋯+1。点击语句组成有限集 Δ ⊆ Γ。真正的 ℕ 总能满足 Δ，只要把 c 解释成一个足够大的数。

What the model looks like这个模型长什么样

Every model of Th(ℕ) begins with a copy of ℕ (the standard part). Each nonstandard element sits in a ℤ-block {…, x−1, x, x+1, …}, and the blocks are ordered densely, with no first and no last block. Click a ⊕ to produce a new block in that gap. Th(ℕ) 的每个模型都以 ℕ 的一个拷贝开头（标准部分）。每个非标准元素落在一个 ℤ 块 {…, x−1, x, x+1, …} 里，各块之间稠密排列，没有第一块，也没有最后一块。点击 ⊕，在那个空隙里造出一个新块。

Every countable nonstandard model of arithmetic (of PA, in particular of Th(ℕ)) has order type ω + ζ·η: ℕ, followed by ℚ-many copies of ℤ. So Th(ℕ) does not pin down ℕ up to isomorphism, even among countable models. The set of standard elements is not definable in the model: if it were, induction would force it to be everything. 每个可数非标准算术模型（PA 的模型，特别是 Th(ℕ) 的模型）的序型都是 ω + ζ·η：先是 ℕ，后面跟着按 ℚ 排列的许多个 ℤ 拷贝。所以即使只看可数模型，Th(ℕ) 也不能在同构意义下确定 ℕ。标准元素全体在模型中不可定义：如果可定义，归纳法就会迫使它等于整个模型。

De Bruijn–Erdős theorem. A graph G is k-colorable iff every finite subgraph of G is k-colorable. 德布鲁因–埃尔德什定理. 图 G 可 k 着色，当且仅当 G 的每个有限子图都可 k 着色。

The graph continues forever to the right. You only ever see a finite window. Click vertices to cycle their color. Clashing edges turn red. “Auto-color” searches the window by backtracking. 这个图向右无限延伸，你看到的永远只是一个有限窗口。点击顶点切换颜色，同色相邻的边会变红。“自动着色”用回溯法搜索整个窗口。

Color each v by the unique i with pv,i true. ∎ (For uncountable G this uses compactness for uncountably many variables, which needs a weak form of choice.) 4. 由命题逻辑的紧致性定理（第 2 课），存在满足整个 Γ 的赋值。把 v 染成使 pv,i 为真的那个唯一的 i。∎（G 不可数时要用到不可数多个变元的紧致性，这需要选择公理的一个弱形式。）
§5

Downward Löwenheim–Skolem: the Skolem hull向下勒文海姆–斯科伦定理：斯科伦闭包

Downward LS. Let M be an L-structure and X ⊆ M. Then there is an elementary substructure N ≼ M with X ⊆ N and |N| ≤ |X| + |L| + ℵ₀. In particular, every theory in a countable language with an infinite model has a countably infinite model. 向下勒文海姆–斯科伦定理. 设 M 是 L-结构，X ⊆ M。则存在初等子结构 N ≼ M，使 X ⊆ N 且 |N| ≤ |X| + |L| + ℵ₀。特别地，可数语言中的理论若有无穷模型，就有可数无穷模型。

Inside the big structure (ℝ, <, +), start from a few seeds and close them under Skolem functions: for each formula ∃y φ(x̄, y), a function picking a witness. Here: x ↦ −x, x ↦ x/n (witness for ∃y y+⋯+y = x, with n summands) and (x, y) ↦ x + y, x − y. The picture only uses n = 2, 3. Each press adds one layer. 在大结构 (ℝ, <, +) 里，从几个种子出发，对斯科伦函数取闭包：对每个公式 ∃y φ(x̄, y)，取一个负责挑选见证的函数。这里用 x ↦ −x、x ↦ x/n（给 ∃y y+⋯+y = x（n 个加项）提供见证）以及 (x, y) ↦ x + y、x − y。图中只用 n = 2, 3。每按一次多加一层。

Tarski–Vaught test. A substructure N ⊆ M is elementary (N ≼ M) iff for every formula φ(x̄, y) and every tuple ā from N: if M ⊨ ∃y φ(ā, y), then there is b ∈ N with M ⊨ φ(ā, b). Note that truth is always evaluated in M. A set closed under Skolem functions passes the test by construction. 塔斯基–沃特判别法. 子结构 N ⊆ M 是初等子结构（N ≼ M），当且仅当对每个公式 φ(x̄, y) 和 N 中的每组元素 ā：若 M ⊨ ∃y φ(ā, y)，则存在 b ∈ N 使 M ⊨ φ(ā, b)。注意真假始终在 M 中判定。对斯科伦函数封闭的集合，按构造就通过这个判别法。
1. For each formula ∃y φ(x̄, y) of L fix a Skolem function fφ: Mⁿ → M with M ⊨ φ(ā, fφ(ā)) whenever M ⊨ ∃y φ(ā, y). (This uses the axiom of choice.)1. 对 L 的每个公式 ∃y φ(x̄, y)，取定斯科伦函数 fφ: Mⁿ → M，使得只要 M ⊨ ∃y φ(ā, y)，就有 M ⊨ φ(ā, fφ(ā))。（这里用到选择公理。）
2. X₀ = X, Xn+1 = Xₙ ∪ {fφ(ā) : φ ∈ L, ā ∈ Xₙ}, N = ⋃ₙ Xₙ. That is exactly the layers in the picture.2. 令 X₀ = X，Xn+1 = Xₙ ∪ {fφ(ā) : φ ∈ L, ā ∈ Xₙ}，N = ⋃ₙ Xₙ。这正是图中一层层长出来的点。
3. Counting: there are |L| + ℵ₀ formulas and each layer has size ≤ |X| + |L| + ℵ₀; a countable union keeps that bound.3. 计数：公式共 |L| + ℵ₀ 个，每层大小 ≤ |X| + |L| + ℵ₀，可数并仍不超过这个界。
4. N is closed under the functions (term φ: ∃y (y = f(x̄))) so it is a substructure, and it passes Tarski–Vaught by construction, so N ≼ M. ∎ For (ℝ,<,+), with suitably chosen Skolem functions, the hull of {1} is ℚ, and that of {1, √2} is ℚ + ℚ√2. Both countable. (The Skolem functions can be chosen this way because both sets are divisible ordered subgroups and hence already elementary substructures of (ℝ,<,+); other choices of Skolem functions give other countable hulls.)4. N 对函数封闭（考虑公式 ∃y (y = f(x̄))），所以是子结构；它按构造通过塔斯基–沃特判别法，故 N ≼ M。∎ 在 (ℝ,<,+) 中，适当选取斯科伦函数，{1} 的闭包是 ℚ，{1, √2} 的闭包是 ℚ + ℚ√2，都可数。（之所以能这样选，是因为这两个集合都是可除有序子群，本身已是 (ℝ,<,+) 的初等子结构；换一组斯科伦函数，会得到别的可数闭包。）
§6

Substructure vs elementary substructure子结构与初等子结构

Definition. M ⊆ N is an elementary substructure, M ≼ N, if for every formula φ(x̄) and every tuple ā from M: M ⊨ φ(ā) ⇔ N ⊨ φ(ā). Being merely a substructure only guarantees this for quantifier-free φ. Also M ≡ N (elementarily equivalent) means: the same sentences are true. M ≼ N implies M ≡ N, but not conversely. 定义. 若 M ⊆ N，且对每个公式 φ(x̄) 和 M 中的每组元素 ā 都有 M ⊨ φ(ā) ⇔ N ⊨ φ(ā)，则称 M 是 N 的初等子结构，记作 M ≼ N。仅仅是子结构，只能保证无量词公式满足这一点。M ≡ N（初等等价）指两者满足相同的语句。M ≼ N 蕴涵 M ≡ N，反之不然。

Pick a pair. Click each formula row to evaluate it at the given parameters in both structures. Blue = the small structure M, grey = the big one N. A witness found in N is green if it lies in M and red if it does not. 选一对结构，点击每一行公式，在给定参数下分别在两个结构中求值。蓝色是小结构 M，灰色是大结构 N。在 N 中找到的见证若落在 M 里就画成绿色，否则画成红色。

§7

Skolem's paradox斯科伦悖论

ZFC is a theory in the countable language {∈}. If it is consistent, it has a model, so by downward LS it has a countable model M. But ZFC proves “ℝ is uncountable”, so M ⊨ “ℝ is uncountable”. Yet M contains only countably many elements, so ℝM has only countably many members. Toggle the point of view. ZFC 是可数语言 {∈} 中的理论。如果它一致，它就有模型，于是由向下 LS 定理，它有可数模型 M。可 ZFC 能证明“ℝ 不可数”，所以 M ⊨ “ℝ 不可数”。然而 M 只有可数个元素，ℝM 的成员也只有可数个。切换视角看看。

Resolution 1. “X is uncountable” means “there is no surjection ω → X”. Inside M this quantifies only over functions that are elements of M.化解 1. “X 不可数”的意思是“不存在从 ω 到 X 的满射”。在 M 内部，这个量词只管 M 中的函数。
Resolution 2. The enumeration f: ℕ → ℝM that exists in V is simply not an element of M. M is missing the very function that would make its ℝ countable.化解 2. 在 V 中存在的枚举 f: ℕ → ℝM 恰恰不是 M 的元素。M 里缺的正是能让它的 ℝ 变得可数的那个函数。
Moral. “Countable” and “uncountable” are not absolute: they depend on which functions the model contains. The argument yields no contradiction in ZFC, only a mismatch between the model's view and ours.启示. “可数”与“不可数”不是绝对的，取决于模型里有哪些函数。这个论证并没有在 ZFC 中导出矛盾，只是模型内部的看法与我们外部的看法不一致。

Upward Löwenheim–Skolem and the spectrum of a theory向上勒文海姆–斯科伦定理与理论的模型谱

Upward LS. If T has an infinite model and κ ≥ |L| + ℵ₀, then T has a model of cardinality exactly κ. 向上勒文海姆–斯科伦定理. 若 T 有无穷模型且 κ ≥ |L| + ℵ₀，则 T 有基数恰为 κ 的模型。

The construction in two moves: blow the model up with κ new constants, then shrink it back to exactly κ. 构造分两步：先用 κ 个新常元把模型“吹大”，再把它“削”到恰好 κ。

§9

Categoricity: Cantor's back-and-forth范畴性：康托尔的来回论证

Theorem (Cantor). Any two countable dense linear orders without endpoints are isomorphic. So DLO is ℵ₀-categorical. 定理（康托尔）. 任意两个可数、无端点的稠密线序都同构。因此 DLO 是 ℵ₀-范畴的。

Top: A = ℚ ∩ (0,1), listed by denominator. Bottom: B = dyadic rationals in (0,1), listed by 2ᵏ. Both are countable DLOs without endpoints. Forth steps take the first unmatched a and find a partner b in the right gap; back steps do the same from B. Because the map preserves order, the matching lines never cross. 上方：A = ℚ ∩ (0,1)，按分母排成一列。下方：B = (0,1) 中的二进有理数，按 2ᵏ 排成一列。两者都是可数、无端点的稠密线序。“去”的一步取 A 中第一个尚未配对的 a，在正确的空隙里为它找到 b；“回”的一步从 B 出发做同样的事。映射保序，所以配对线永不交叉。

Why it works. At every stage the matching is a finite order-isomorphism p. Given a new a, it falls in some gap between matched points (or beyond all of them); B is dense without endpoints, so the corresponding gap in B is nonempty, and the enumeration of B eventually reaches a point in it. Step 2n handles aₙ (so the union is total) and step 2n+1 handles bₙ (so it is onto). The union of the chain p₀ ⊆ p₁ ⊆ ⋯ is an isomorphism A ≅ B. ∎ 为什么行得通. 每个阶段的配对都是一个有限保序同构 p。新来的 a 落在已配对点之间的某个空隙里（或在所有点之外）；B 稠密且无端点，所以 B 中对应的空隙非空，B 的枚举迟早会走到其中的点。第 2n 步处理 aₙ（保证并是全函数），第 2n+1 步处理 bₙ（保证是满射）。链 p₀ ⊆ p₁ ⊆ ⋯ 的并就是同构 A ≅ B。∎
Łoś–Vaught test. If T has no finite models and is κ-categorical for some κ ≥ |L| + ℵ₀, then T is complete. (Proof: if T ⊬ σ and T ⊬ ¬σ, then T∪{σ} and T∪{¬σ} have infinite models, hence by LS models of size κ; they are isomorphic, yet disagree on σ.) So DLO is complete, and (ℚ,<) ≡ (ℝ,<). Łoś–Vaught 判别法. 若 T 没有有限模型，且对某个 κ ≥ |L| + ℵ₀ 是 κ-范畴的，则 T 是完全理论。（证明：若 T ⊬ σ 且 T ⊬ ¬σ，则 T∪{σ} 与 T∪{¬σ} 都有无穷模型，由 LS 定理都有大小为 κ 的模型；它们同构，却对 σ 给出不同真值。）所以 DLO 是完全的，且 (ℚ,<) ≡ (ℝ,<)。
Not categorical at 2^ℵ₀. ℝ and ℝ∖{0} are both DLOs without endpoints of size 2^ℵ₀, but ℝ is Dedekind-complete and ℝ∖{0} is not (the negatives have no supremum). The back-and-forth needs countability: it runs through an ω-enumeration. 在 2^ℵ₀ 处不是范畴的. ℝ 和 ℝ∖{0} 都是大小为 2^ℵ₀ 的无端点稠密线序，但 ℝ 是戴德金完备的，ℝ∖{0} 不是（负数没有上确界）。来回论证离不开可数性：它要沿着一个 ω 型枚举走下去。
Cantor, twice. The diagonal method shows that no list hits every real; the back-and-forth method uses two lists to build a bijection step by step. Both are “walk down an ω-sequence and handle the n-th item at stage n”. 两个康托尔. 对角线方法说明任何清单都列不全实数；来回方法则利用两份清单一步一步地造出双射。二者是同一个套路：沿着 ω 序列走，在第 n 步处理第 n 项。
