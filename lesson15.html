Gödel's Constructible Universe L哥德尔可构成宇宙 L

Build the universe again, but at each successor step keep only the subsets you can define. The result, L, is a thin inner model in which AC and GCH hold. This gives Gödel's 1938 theorem: if ZF is consistent, so is ZFC + GCH. In particular CH cannot be disproved. 把宇宙重新造一遍，但每到后继步只保留那些可定义的子集。得到的 L 是一个“瘦”的内模型，AC 和 GCH 在其中都成立。由此得到哥德尔 1938 年的定理：若 ZF 一致，则 ZFC + GCH 也一致。特别地，CH 不可能被否证。

§1

Def(X): the definable power setDef(X)：可定义幂集

Definition. For a set X, Def(X) = { {x ∈ X : (X, ∈) ⊨ φ[x, a₁, …, aₙ]} : φ a formula of {∈}, a₁, …, aₙ ∈ X }. These are the subsets of X that can be defined over (X, ∈) with parameters from X. Always Def(X) ⊆ 𝒫(X). Note that the quantifiers of φ range over X only. 定义. 对集合 X，Def(X) = { {x ∈ X : (X, ∈) ⊨ φ[x, a₁, …, aₙ]} : φ 为 {∈} 语言的公式，a₁, …, aₙ ∈ X }，即在结构 (X, ∈) 上、以 X 中元素为参数可定义的 X 的子集全体。总有 Def(X) ⊆ 𝒫(X)。注意 φ 中的量词只在 X 中取值。

Pick X, type a formula φ(x) (x free; parameters are written as sets such as 2 or {1}), and see the defined subset light up. Every subset you define is collected in the grid of all 2|X| subsets. Can you collect them all? 选一个 X，输入公式 φ(x)（x 为自由变元；参数直接写成集合，如 2 或 {1}），看被定义的子集亮起来。你定义出的每个子集都会收进下方 2|X| 个子集的格子里。能集齐吗？

For finite X, Def(X) = 𝒫(X). Any S = {s₁, …, sₖ} ⊆ X is defined by x = s₁ ∨ … ∨ x = sₖ with parameters s₁, …, sₖ (and ∅ by x ≠ x). §2

The constructible hierarchy Lα可构成层级 Lα

Definition (Gödel 1938). L₀ = ∅,   Lα+1 = Def(Lα),   Lλ = ⋃α<λ Lα (λ limit),   L = ⋃α∈Ord Lα. Compare V: the only change is 𝒫 ↦ Def. Each Lα is transitive, Lα ⊆ Vα, and Lα ∩ Ord = α. 定义（哥德尔 1938）. L₀ = ∅，Lα+1 = Def(Lα)，λ 为极限序数时 Lλ = ⋃α<λ Lα，L = ⋃α∈Ord Lα。与 V 相比，唯一的改动是 𝒫 ↦ Def。每个 Lα 都是传递集，Lα ⊆ Vα，且 Lα ∩ Ord = α。

Slide α. For finite α the two hierarchies coincide (§1), so Lω = Vω. From ω+1 on, Cantor separates them: |Lα| = |α| for infinite α, while V jumps by a power set at every step. 拖动 α。α 有限时两个层级完全重合（§1），所以 Lω = Vω。从 ω+1 起，康托尔定理把它们分开：α 无穷时 |Lα| = |α|，而 V 每一步都要取一次幂集。

Why |Def(X)| = |X| for infinite X: names versus subsets为什么无穷 X 有 |Def(X)| = |X|：名字与子集

Every element of Def(X) has a name: a formula together with a finite tuple of parameters. For X = Lω there are only countably many names. Press Name a set to watch names produce subsets of ω, then Diagonalize against the list of all names. Def(X) 的每个元素都有一个名字：一个公式加上一组有限的参数。对 X = Lω，名字只有可数多个。按 取一个名字 看名字如何生成 ω 的子集，再按 对角化，针对全体名字的列表做对角线论证。

Tarski meets Gödel. Lω+1 ∩ 𝒫(ω) is exactly the family of arithmetical sets, since (Vω, ∈) and (ℕ, +, ×) define the same sets. The set of (codes of) true arithmetic sentences is not arithmetical (Lesson 13), so it is not in Lω+1. It is definable over Lω+1, though, so it lies in Lω+2. 塔斯基遇见哥德尔. Lω+1 ∩ 𝒫(ω) 恰好是全体算术集，因为 (Vω, ∈) 与 (ℕ, +, ×) 可定义的集合相同。真算术语句（的编码）之集不是算术集（第 13 课），因此不在 Lω+1 中；但它在 Lω+1 上可定义，所以属于 Lω+2。
§3

L inside V: two cones, one spineV 中的 L：两个锥，一根脊柱

L is a thin cone inside V. They agree up to ω, and both contain every ordinal: α ⊆ Lα and α = {x ∈ Lα : x is an ordinal}, which is Δ₀-definable, so α ∈ Lα+1. Slide the stage, then toggle the hypothesis V = L and follow a real r ⊆ ω. L 是 V 里面一个细长的锥。两者在 ω 以下完全一致，而且都含有所有序数：α ⊆ Lα，且 α = {x ∈ Lα : x 是序数}，这是 Δ₀ 可定义的，所以 α ∈ Lα+1。拖动层级，再切换假设 V = L，跟踪一个实数 r ⊆ ω。

§4

L is the smallest inner model, and L ⊨ V = LL 是最小的内模型，并且 L ⊨ V = L

Theorem (ZF). (1) L is a transitive class containing all ordinals, and L ⊨ ZF: for each axiom σ of ZF, ZF ⊢ σL. (2) If M is a transitive class with Ord ⊆ M and M ⊨ ZF, then L ⊆ M. (3) L ⊨ V = L. 定理（ZF）. (1) L 是包含全体序数的传递类，并且 L ⊨ ZF：对 ZF 的每条公理 σ 都有 ZF ⊢ σL。(2) 若 M 是传递类，Ord ⊆ M 且 M ⊨ ZF，则 L ⊆ M。(3) L ⊨ V = L。

(1) Click each axiom to see why it holds in L.(1) 点击每条公理，看它为什么在 L 中成立。

(2)–(3) Build L inside another inner model M. The recursion α ↦ Lα uses only Def, and Def is absolute for transitive models of ZF. So M, building its own L step by step, gets exactly the same Lα's. (2)–(3) 在另一个内模型 M 里构造 L。递归 α ↦ Lα 只用到 Def，而 Def 对 ZF 的传递模型绝对。所以 M 一步步造出的“它自己的 L”，每一层 Lα 都与真正的一样。

Def is absolute. Code formulas as elements of Vω. “S = Def(X)” is defined by recursion on formulas through the satisfaction relation of (X, ∈), using only bounded quantifiers and ω-recursion. Such notions are Δ₁ZF, hence absolute for transitive models of ZF (a finite fragment is enough). Def 是绝对的. 把公式编码为 Vω 的元素。“S = Def(X)”是借助 (X, ∈) 的满足关系、对公式递归定义的，只用到有界量词和 ω 上的递归。这类概念是 Δ₁ZF 的，因而对 ZF 的传递模型绝对（有限片段就够了）。
So α ↦ Lα is absolute. Absolute operations stay absolute under transfinite recursion. Hence LαM = Lα for every ordinal α ∈ M. 所以 α ↦ Lα 是绝对的. 绝对的运算经超限递归后仍然绝对。因此对每个序数 α ∈ M 都有 LαM = Lα。
Minimality. If Ord ⊆ M, then LM = ⋃α LαM = ⋃α Lα = L, and LM ⊆ M. For a set model M the same argument gives LM = Lo(M), where o(M) = M ∩ Ord. 最小性. 若 Ord ⊆ M，则 LM = ⋃α LαM = ⋃α Lα = L，而 LM ⊆ M。对集合模型 M，同样的论证给出 LM = Lo(M)，其中 o(M) = M ∩ Ord。
L ⊨ V = L. Take M = L: then LL = L, i.e. L ⊨ “every set is constructible”. Running the construction again inside L creates nothing new. L ⊨ V = L. 取 M = L，则 LL = L，即 L ⊨ “每个集合都可构成”。在 L 内部再做一遍构造，什么新东西也造不出来。
§5

L ⊨ AC: a definable well-order <LL ⊨ AC：可定义的良序 <L

The order. Every x ∈ L first appears at some stage Lα+1, defined over Lα by some formula φ with parameters. Put x <L y iff (i) x appears at an earlier stage; or (ii) same stage, and the least formula code defining x is smaller; or (iii) same stage and formula, and x's least parameter tuple is <L-lexicographically smaller (using the order already built on Lα). By recursion on α this well-orders L, and the definition is absolute, so L ⊨ “V is well-ordered”. No choice is needed: every choice is made by the formula. 这个序. 每个 x ∈ L 都在某个阶段 Lα+1 首次出现，由 Lα 上某个带参数的公式 φ 定义。令 x <L y 当且仅当：(i) x 出现的阶段更早；或 (ii) 阶段相同，而定义 x 的最小公式编码更小；或 (iii) 阶段与公式都相同，而 x 的最小参数组按 <L 的字典序更小（这里用到 Lα 上已经造好的序）。对 α 递归可知它是 L 的良序，并且这个定义是绝对的，所以 L ⊨ “V 可良序”。整个过程无需选择公理：每一次“选择”都由公式替我们做了。

Toy ladder for L₄ = V₄. We use only the formulas “x ≠ x” (code 0) and “x = p₁ ∨ … ∨ x = pₖ” (code k) with p₁ <L … <L pₖ. At finite stages these define every subset, so this is an honest instance of (i)–(iii). Press Sort, then pick a nonempty A ⊆ L₄ below: the choice function picks its <L-least element. L₄ = V₄ 上的玩具阶梯. 这里只用公式“x ≠ x”（编码 0）和“x = p₁ ∨ … ∨ x = pₖ”（编码 k），并要求 p₁ <L … <L pₖ。在有限阶段，这些公式已经能定义每个子集，所以这是 (i)–(iii) 的一个忠实实例。按 排序，再在下方选一个非空的 A ⊆ L₄：选择函数挑出它的 <L-最小元。

§6

L ⊨ GCH: condensationL ⊨ GCH：凝聚引理

Condensation Lemma. If δ is a limit ordinal and X ≺ (Lδ, ∈), then the Mostowski collapse of X is Lγ for some γ ≤ δ.
Theorem. Assume V = L. Then for every infinite cardinal κ, 𝒫(κ) ⊆ Lκ⁺, hence 2κ = κ⁺. Since L ⊨ V = L, we get L ⊨ GCH. 凝聚引理. 若 δ 为极限序数且 X ≺ (Lδ, ∈)，则 X 的莫斯托夫斯基坍塌是某个 Lγ，γ ≤ δ。
定理. 设 V = L。则对每个无穷基数 κ 有 𝒫(κ) ⊆ Lκ⁺，从而 2κ = κ⁺。由于 L ⊨ V = L，得 L ⊨ GCH。

Step through the proof. The picture follows one subset A ⊆ κ, which might first appear very high up, and shows why it must in fact appear below κ⁺. 逐步走一遍证明。图中跟踪一个子集 A ⊆ κ：它也许在很高的地方才首次出现，下面说明它其实必定在 κ⁺ 以下就已出现。

1 · Where is A? Let A ⊆ κ. By V = L, A ∈ Lδ for some limit δ > κ. A priori δ could be enormous, far above κ⁺. 1 · A 在哪里？ 设 A ⊆ κ。由 V = L，存在极限序数 δ > κ 使 A ∈ Lδ。先验地看，δ 可能极大，远在 κ⁺ 之上。
2 · Shrink (Löwenheim–Skolem). Take an elementary submodel X ≺ (Lδ, ∈) with κ ∪ {A} ⊆ X and |X| = κ. X is scattered across all of Lδ, but it is small. 2 · 缩小（勒文海姆–斯科伦）. 取初等子模型 X ≺ (Lδ, ∈)，使 κ ∪ {A} ⊆ X 且 |X| = κ。X 散布在整个 Lδ 中，但它很小。
3 · Collapse (Mostowski). ∈ on X is well-founded and extensional (X ≺ Lδ), so there is π : (X, ∈) ≅ (M, ∈) with M transitive. The dots fall down. 3 · 坍塌（莫斯托夫斯基）. X 上的 ∈ 良基且外延（因 X ≺ Lδ），故存在 π : (X, ∈) ≅ (M, ∈)，M 传递。图中的点纷纷落下。
4 · Nothing below κ moves. Since κ ⊆ X, induction gives π(α) = {π(β) : β ∈ α ∩ X} = α for all α < κ. Hence π(A) = {π(α) : α ∈ A} = A, so A ∈ M. 4 · κ 以下纹丝不动. 由于 κ ⊆ X，归纳可得对所有 α < κ 有 π(α) = {π(β) : β ∈ α ∩ X} = α。于是 π(A) = {π(α) : α ∈ A} = A，所以 A ∈ M。
5 · Condensation. M = Lγ for some γ. Since |γ| ≤ |Lγ| = |M| = κ, we have γ < κ⁺. So A ∈ Lγ ⊆ Lκ⁺. 5 · 凝聚. M = Lγ 对某个 γ 成立。由 |γ| ≤ |Lγ| = |M| = κ 得 γ < κ⁺。所以 A ∈ Lγ ⊆ Lκ⁺。
6 · Count. A was arbitrary, so 𝒫(κ) ⊆ Lκ⁺, and |Lκ⁺| = κ⁺ (§2). Therefore 2κ ≤ κ⁺, and by Cantor 2κ = κ⁺. ∎ 6 · 计数. A 是任意的，所以 𝒫(κ) ⊆ Lκ⁺，而 |Lκ⁺| = κ⁺（§2）。因此 2κ ≤ κ⁺，再由康托尔定理得 2κ = κ⁺。∎
For κ = ω this says that every constructible real appears before stage ω₁. That is the heart of “L ⊨ CH”: the reals of L are lined up by the order of their first appearance, in order type at most ω₁. 取 κ = ω：每个可构成实数都在第 ω₁ 层之前出现。这正是“L ⊨ CH”的核心：L 中的实数按首次出现的先后排队，序型至多为 ω₁。

Why L cannot give ¬CH. Inner models only shrink the universe. If V = L, then by minimality the only inner model containing all ordinals is L itself, which satisfies CH. So no inner-model construction can ever produce ¬CH: if a definable class N provably gave an inner model of ¬CH, then carrying out the construction inside L would give an inner model of L containing all ordinals, hence L itself, satisfying ¬CH. Cohen's idea was to go the other way: enlarge a model by adding new reals. That is forcing. L 为何给不出 ¬CH. 内模型只会把宇宙变小。若 V = L，由最小性，包含全体序数的内模型只有 L 自己，而 L 满足 CH。所以任何内模型构造都造不出 ¬CH：若某个可定义类 N 可证地给出 ¬CH 的内模型，那么在 L 内部执行这一构造，就得到 L 的一个包含全体序数的内模型，也就是 L 本身，它却满足 ¬CH。科恩的想法是反其道而行之：给模型添加新的实数，把它放大。这就是力迫法。
