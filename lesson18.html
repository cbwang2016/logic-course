Part V · Lesson 18

Analytical Hierarchy, Hyperarithmetic Sets, ω₁CK分析层级、超算术集与 ω₁CK

In Lesson 17 we only quantified over numbers, and the jumps ∅′, ∅″, … climbed the arithmetical ladder. Now we allow quantifiers over infinite sequences (“reals”). One such quantifier already captures “this tree has no infinite branch” and “this order is a well-order”. Following that thread leads to computable ordinals, a wall at ω₁CK, and Kleene's theorem: the sets definable both ways, Δ¹₁, are exactly the sets computable from a transfinite iterate of the jump ∅(α) with α < ω₁CK. 第 17 课只对自然数量化，跳跃 ∅′、∅″、…… 爬的是算术层级的梯子。现在允许对无穷序列（“实数”）量化。仅一个这样的量词就能表达“这棵树没有无穷分支”“这个序是良序”。顺着这条线走下去，会遇到可计算序数、ω₁CK 处的一堵墙，以及克莱尼定理：两种方式都能定义的集合 Δ¹₁，恰好就是能由某个超限迭代跳跃 ∅(α)（α < ω₁CK）计算出来的集合。

Conventions: “real” means an element of Baire space ωω (or of 2ω when said). ⟨·,·⟩ is a fixed recursive pairing, f↾n = ⟨f(0),…,f(n−1)⟩, φe is the e-th partial recursive function. Unless marked otherwise, classes are lightface (no real parameters). 约定：“实数”指贝尔空间 ωω 的元素（特别说明时指 2ω）。⟨·,·⟩ 是固定的递归配对函数，f↾n = ⟨f(0),…,f(n−1)⟩，φe 是第 e 个部分递归函数。除非另有说明，所有类都是细体的（不带实数参数）。

Step 1 · Second-order arithmetic二阶算术
Prerequisites前置: L17 arithmetical hierarchy Σ⁰ₙ/Π⁰ₙ算术层级 Σ⁰ₙ/Π⁰ₙL11 recursive relations递归关系

Quantifying over reals: Σ¹ₙ and Π¹ₙ对实数量化：Σ¹ₙ 与 Π¹ₙ

Core idea: count only the alternations of function quantifiers. Number quantifiers can always be pushed inside and swallowed. 核心思想：只数函数量词的交替次数。数量词总能被推到里面“吞掉”。

Definition. The language of second-order arithmetic has number variables m, n, … (ranging over ω) and function variables f, g, … (ranging over ωω). A formula is arithmetical if it has no function quantifiers (free function variables are allowed). A relation R ⊆ ωk × (ωω)l (x below stands for a tuple of numbers and reals) is Σ¹₁ if R(x) ⇔ ∃f A(x, f) and Π¹₁ if R(x) ⇔ ∀f A(x, f), with A arithmetical; Σ¹ₙ₊₁ if R(x) ⇔ ∃f P(x, f) with P Π¹ₙ, and Π¹ₙ₊₁ if R(x) ⇔ ∀f S(x, f) with S Σ¹ₙ; Δ¹ₙ = Σ¹ₙ ∩ Π¹ₙ. All formulas are read in the standard model (ω, ωω) and contain no real parameters (lightface). 定义. 二阶算术的语言有数变元 m, n, …（取值于 ω）和函数变元 f, g, …（取值于 ωω）。不含函数量词的公式称为算术公式（允许出现自由函数变元）。关系 R ⊆ ωk × (ωω)l（下文 x 代表由数与实数组成的元组）称为 Σ¹₁ 的，若 R(x) ⇔ ∃f A(x, f)；称为 Π¹₁ 的，若 R(x) ⇔ ∀f A(x, f)，其中 A 为算术公式； Σ¹ₙ₊₁：R(x) ⇔ ∃f P(x, f)，P 为 Π¹ₙ；Π¹ₙ₊₁：R(x) ⇔ ∀f S(x, f)，S 为 Σ¹ₙ； Δ¹ₙ = Σ¹ₙ ∩ Π¹ₙ。所有公式都在标准模型 (ω, ωω) 中解释，且不含实数参数（细体）。

Build a quantifier prefix in front of a recursive matrix R, then press Collapse. Watch the number quantifiers (gold) slide into the matrix and equal function quantifiers (purple) merge. 在递归母式 R 前面拼一个量词前缀，然后按化简。观察数量词（金色）滑进母式，相邻同类函数量词（紫色）合并。

Why the moves are legal. (1) Same-type quantifiers commute. (2) ∀n ∃f A(n,f) ⇔ ∃g ∀n A(n, gn) where gn(m) = g(⟨n,m⟩): pack countably many witnesses into one real (this uses countable choice for reals, available in ZFC). Dually ∃n ∀f ⇔ ∀g ∃n. So every number quantifier can be moved to the right past function quantifiers. (3) ∃f ∃g ⇔ ∃h with h = f ⊕ g (h(2k) = f(k), h(2k+1) = g(k)). (4) Every arithmetical matrix is Δ¹₁: add a dummy quantifier ∃f or ∀f. 这些变形为什么合法. (1) 同类量词可交换。(2) ∀n ∃f A(n,f) ⇔ ∃g ∀n A(n, gn)，其中 gn(m) = g(⟨n,m⟩)：把可数个见证打包成一个实数（用到实数的可数选择，ZFC 中可用）。对偶地 ∃n ∀f ⇔ ∀g ∃n。所以任何数量词都可以越过函数量词移到右边。(3) ∃f ∃g ⇔ ∃h，h = f ⊕ g（h(2k) = f(k)，h(2k+1) = g(k)）。(4) 任何算术母式都是 Δ¹₁ 的：添一个哑量词 ∃f 或 ∀f 即可。
Normal form theorem (Kleene). A ⊆ ω is Π¹₁ iff there is a recursive R ⊆ ω × ω with n ∈ A ⇔ ∀f ∈ ωω ∃m R(n, f↾m); dually Σ¹₁ iff n ∈ A ⇔ ∃f ∀m R(n, f↾m). The same holds for subsets of ωω with R(x↾m, f↾m). Every arithmetical set is Δ¹₁, and the hierarchy is proper: Σ¹ₙ ∪ Π¹ₙ ⊊ Δ¹ₙ₊₁. 范式定理（克莱尼）. A ⊆ ω 是 Π¹₁ 的，当且仅当存在递归关系 R ⊆ ω × ω，使得 n ∈ A ⇔ ∀f ∈ ωω ∃m R(n, f↾m)；对偶地，A 是 Σ¹₁ 的当且仅当 n ∈ A ⇔ ∃f ∀m R(n, f↾m)。对 ωω 的子集同样成立（换成 R(x↾m, f↾m)）。每个算术集都是 Δ¹₁ 的，并且层级是真包含的：Σ¹ₙ ∪ Π¹ₙ ⊊ Δ¹ₙ₊₁。
⚠ Common pitfall常见误区The collapse gives an upper bound. “Defined by a Σ¹₁ formula” does not mean “not arithmetical”: ∃f (f(0) = n ∧ n is even) defines a recursive set. Also, function quantifiers over the compact space 2ω are weaker: with R recursive, ∀f ∈ 2ω ∃m R(n, f↾m) ⇔ ∃k ∀σ ∈ 2k ∃m ≤ k R(n, σ↾m), which is Σ⁰₁ (that is Kőnig's lemma, Step 2). The real power needs ωω. 化简得到的只是上界。“能用 Σ¹₁ 公式定义”不等于“不是算术集”：∃f (f(0) = n ∧ n 是偶数) 定义的是递归集。另外，对紧空间 2ω 的函数量词要弱得多：R 递归时，∀f ∈ 2ω ∃m R(n, f↾m) ⇔ ∃k ∀σ ∈ 2k ∃m ≤ k R(n, σ↾m)，这只是 Σ⁰₁（即第 2 步的柯尼希引理）。真正的威力来自 ωω。
Step 2 · Trees树
Prerequisites前置: §1 normal form范式L8 well-founded relations良基关系

Π¹₁ = “a recursive tree has no infinite branch”Π¹₁ = “某棵递归树没有无穷分支”

Core idea: the normal form ∀f ∃m R(n, f↾m) says exactly that the tree of “still-alive” finite sequences has no infinite path. 核心思想：范式 ∀f ∃m R(n, f↾m) 说的恰好是：由“尚未失败”的有限序列构成的树没有无穷路径。

Definitions. A tree on ω is a set T ⊆ ω<ω closed under initial segments. A branch (infinite path) is f ∈ ωω with f↾m ∈ T for all m; [T] is the set of branches. T is well-founded (WF) if [T] = ∅. For WF T the rank is ρ(σ) = sup{ρ(τ) + 1 : τ a child of σ in T} (leaves get 0), and ρ(T) = ρ(⟨⟩).
Tree form of Π¹₁. Given R recursive, put Tn = {σ : ∀k ≤ |σ| ¬R(n, σ↾k)}. Then (Tn) is uniformly recursive and n ∈ A ⇔ ∀f ∃m R(n, f↾m) ⇔ Tn is WF. Conversely “T is WF” is ∀f ∃m (f↾m ∉ T), a Π¹₁ statement about T. 定义. ω 上的树是对前段封闭的集合 T ⊆ ω<ω。分支（无穷路径）是满足“对所有 m 都有 f↾m ∈ T”的 f ∈ ωω；[T] 表示全体分支。若 [T] = ∅，称 T 良基（WF）。良基树的秩定义为 ρ(σ) = sup{ρ(τ) + 1 : τ 是 σ 在 T 中的子结点}（叶子为 0），ρ(T) = ρ(⟨⟩)。
Π¹₁ 的树形式. 给定递归 R，令 Tn = {σ : ∀k ≤ |σ| ¬R(n, σ↾k)}。则 (Tn) 一致递归，且 n ∈ A ⇔ ∀f ∃m R(n, f↾m) ⇔ Tn 良基。反过来，“T 良基”即 ∀f ∃m (f↾m ∉ T)，是关于 T 的 Π¹₁ 陈述。

Tree explorer. Click a child to walk down; click a node higher up to back up. Try to find an infinite branch. In the ω-branching trees press “more →” to see further children (there are infinitely many). 树探险. 点子结点往下走，点上方的结点可以退回。试着找一条无穷分支。在 ω 分叉的树里按“更多 →”查看后面的子结点（子结点有无穷多个）。

Kőnig's lemma. Every infinite finitely branching tree has an infinite branch. Proof: if σ has infinitely many nodes above it and finitely many children, one child also has infinitely many above it (pigeonhole); keep choosing such a child. The “broom” tree shows that ω-branching breaks the pigeonhole step: the root has infinitely many nodes above it, yet every child has only finitely many. 柯尼希引理. 每棵无穷的有限分叉树都有无穷分支。证明：若 σ 上方有无穷多个结点而子结点只有有限个，则由抽屉原理，某个子结点上方也有无穷多个结点；不断选这样的子结点即可。“扫帚树”说明 ω 分叉会让抽屉原理这一步失效：根上方有无穷多个结点，可每个子结点上方都只有有限个。
Intuition直观Showing a tree is ill-founded takes one object, a branch (∃f). Showing it is well-founded means every attempt dies, ∀f, and for ω-branching trees no finite amount of searching can certify that. This asymmetry is the whole story of Σ¹₁ vs Π¹₁. 要说明一棵树非良基，只需一个对象：一条分支（∃f）。要说明它良基，就得每一次尝试都失败（∀f），而对 ω 分叉的树，任何有限的搜索都无法证实这一点。Σ¹₁ 与 Π¹₁ 的差别全在于这种不对称。
⚠ Common pitfall常见误区“The tree has nodes at every level, so it has a branch.” True for finitely branching trees, false in general (the broom). Also: a WF tree can be infinite and have infinite rank; WF says no infinite path, not “finite”. “每一层都有结点，所以一定有分支。”对有限分叉的树成立，一般情形不成立（扫帚树）。另外，良基树可以是无穷的，秩也可以是无穷序数；良基说的是没有无穷路径，不是“有限”。
Step 3 · WO
Prerequisites前置: L8 well-orders, order types良序与序型§2 trees, rank树与秩

WO: codes of well-orders, and rank = order typeWO：良序的编码，秩 = 序型

Core idea: a real x ∈ 2ω can code a linear order on (part of) ω. Well-foundedness of that order is a Π¹₁ property of x, and it is the hardest one. 核心思想：一个实数 x ∈ 2ω 可以编码 ω（的一部分）上的线序。这个序是否良基，是 x 的一个 Π¹₁ 性质，而且是最难的一个。

Definition. For x ∈ 2ω let m ≤x n ⇔ x(⟨m,n⟩) = 1, with field Fx = {n : x(⟨n,n⟩) = 1}. LO = {x : ≤x is a linear order of Fx}, an arithmetical (Π⁰₁) set. WO = {x ∈ LO : ∀f ∈ ωω ∃k ¬(f(k+1) <x f(k))} (no infinite descending sequence), a Π¹₁ set. For x ∈ WO, |x| = the order type of ≤x; every countable ordinal is |x| for some x.
Theorem. WO is Π¹₁-complete: for every Π¹₁ set A ⊆ ωω there is a recursive (hence continuous) F with A = F−1[WO]. (Send x to the Kleene–Brouwer order of Tx; Tx is WF iff that order is a well-order.) Similarly the index set W = {e : φe is the characteristic function of some x ∈ WO} is Π¹₁-complete among subsets of ω. In particular WO is not Σ¹₁ and W is not Σ¹₁. The set IF of codes of ill-founded trees is Σ¹₁-complete. 定义. 对 x ∈ 2ω，令 m ≤x n ⇔ x(⟨m,n⟩) = 1，域为 Fx = {n : x(⟨n,n⟩) = 1}。 LO = {x : ≤x 是 Fx 上的线序}，这是算术集（Π⁰₁）。 WO = {x ∈ LO : ∀f ∈ ωω ∃k ¬(f(k+1) <x f(k))}（没有无穷降链），这是 Π¹₁ 集。对 x ∈ WO，|x| 表示 ≤x 的序型；每个可数序数都等于某个 |x|。
定理. WO 是 Π¹₁-完全的：对每个 Π¹₁ 集 A ⊆ ωω，存在递归（因而连续）的 F 使 A = F−1[WO]。（把 x 映到 Tx 的 Kleene–Brouwer 序；Tx 良基当且仅当该序是良序。）同样，指标集 W = {e : φe 是某个 x ∈ WO 的特征函数} 在 ω 的子集中是 Π¹₁-完全的。特别地，WO 和 W 都不是 Σ¹₁ 的。非良基树的编码之集 IF 是 Σ¹₁-完全的。

Descent game. Pick an order, then click points to build a strictly descending sequence x₀ > x₁ > …. Each descending sequence is a node of the tree of descending sequences; the order is a well-order iff this tree is well-founded, and then the node ending at x has rank = the ordinal position of x. The matrix on the right is (a corner of) the actual code x: row m, column n is 1 iff (the element numbered) m ≤ n. 下降游戏. 选一个序，然后点击各点，造一个严格下降序列 x₀ > x₁ > …。每个下降序列都是下降序列树中的一个结点；序是良序当且仅当这棵树良基，此时以 x 结尾的结点的秩恰好等于 x 的序数位置。右边的矩阵是编码 x 本身（的左上角）：第 m 行第 n 列为 1 当且仅当（编号为）m 的元素 ≤ n 的元素。

⚠ Common pitfall常见误区In a well-order descents are always finite but not uniformly bounded: from ω you may jump to any n and then take n more steps. “Every descent stops” is weaker than “there is a bound on the length of descents”. Also, LO is only Π⁰₁; all the difficulty of WO sits in the single quantifier ∀f. 在良序中，下降总是有限的，但长度没有统一上界：从 ω 可以跳到任意 n，再走 n 步。“每次下降都会停”比“下降长度有统一上界”弱。另外 LO 只是 Π⁰₁；WO 的难度全部集中在那一个 ∀f 上。
Step 4 · Church–Kleene
Prerequisites前置: §3 WOL8 ordinal arithmetic序数运算L11 computability可计算性

Recursive ordinals and the Church–Kleene ordinal递归序数与丘奇–克莱尼序数

Core idea: the ordinals you can compute form an initial segment of the countable ordinals. It ends at a countable ordinal, ω₁CK. 核心思想：能被计算出来的序数构成可数序数的一个前段，它终止于一个可数序数 ω₁CK。

Definition. An ordinal α is recursive (computable) if α = |x| for some recursive x ∈ WO, i.e. α is the order type of a recursive well-ordering of a recursive subset of ω. ω₁CK = sup{α : α recursive}.
Facts. (i) Recursive ordinals are closed downward (an initial segment of a recursive well-order is recursive) and under +1, +, ·, exponentiation. (ii) Hence ω₁CK is a limit ordinal and is the least non-recursive ordinal; the recursive ordinals are exactly the α < ω₁CK. (iii) ω₁CK is countable: there are only countably many recursive x, so it is a countable sup of countable ordinals. (iv) ω₁CK is the least admissible ordinal > ω (stated only). 定义. 若存在递归的 x ∈ WO 使 α = |x|，即 α 是 ω 的某个递归子集上某个递归良序的序型，则称序数 α 是递归的（可计算的）。ω₁CK = sup{α : α 递归}。
事实. (i) 递归序数向下封闭（递归良序的前段仍递归），并对 +1、+、·、幂运算封闭。(ii) 因此 ω₁CK 是极限序数，是最小的非递归序数；递归序数恰好是所有 α < ω₁CK。(iii) ω₁CK 是可数的：递归的 x 只有可数多个，可数多个可数序数的上确界仍可数。(iv) ω₁CK 是大于 ω 的最小容许序数（仅陈述）。

Click a rung to see a recursive well-order of that type, or why there is none. Then press Climb. 点击梯子上的刻度，查看该序型的一个递归良序，或者为什么不存在。然后按攀登。

⚠ Common pitfalls常见误区(1) “Non-recursive” does not mean “uncountable”: ω₁CK < ω₁. (2) Every α < ω₁CK has a recursive code, but there is no algorithm deciding whether an index e codes a well-order: W is Π¹₁-complete. (3) A recursive linear order with no recursive descending sequence need not be a well-order. Harrison's order is recursive, ill-founded, and has no hyperarithmetic descending sequence; its type is ω₁CK·(1+η) (η = type of ℚ). (1) “非递归”不等于“不可数”：ω₁CK < ω₁。(2) 每个 α < ω₁CK 都有递归编码，但没有算法能判定指标 e 是否编码良序：W 是 Π¹₁-完全的。(3) 没有递归降链的递归线序未必是良序。Harrison 序是递归的、非良基的，却没有超算术的降链；其序型为 ω₁CK·(1+η)（η 为 ℚ 的序型）。
Step 5 · O
Prerequisites前置: §4 recursive ordinals递归序数L11 indices φe指标 φe

Kleene's O: names for every recursive ordinal克莱尼 O：给每个递归序数起名字

Core idea: a notation is a natural number that tells you how to build an ordinal: “successor of a” or “limit of the sequence computed by program e”. 核心思想：记号是一个自然数，它告诉你怎样造出一个序数：“a 的后继”，或者“程序 e 算出的序列的极限”。

Definition (Kleene; convention of Rogers and Sacks). O and <O are defined by simultaneous induction, O being the least set closed under the rules: (1) 1 ∈ O, |1| = 0. (2) If a ∈ O then 2a ∈ O, |2a| = |a| + 1, and a <O 2a. (3) If φe is total and φe(0) <O φe(1) <O ⋯ (all in O), then 3·5e ∈ O, |3·5e| = supn |φe(n)|, and φe(n) <O 3·5e for all n. <O is the transitive closure of these relations. (Some texts use 0 instead of 1 for the zero notation.)
Theorem. {|a| : a ∈ O} = ω₁CK, i.e. exactly the recursive ordinals have notations. For a ∈ O, {b : b <O a} is r.e. uniformly in a and is well-ordered by <O with type |a|. O is Π¹₁-complete: every Π¹₁ A ⊆ ω is many-one reducible to O. Finite ordinals have exactly one notation; every infinite recursive ordinal has infinitely many. 定义（克莱尼；采用 Rogers 与 Sacks 的约定）. O 与 <O 同时归纳定义，O 是对下列规则封闭的最小集合： (1) 1 ∈ O，|1| = 0。(2) 若 a ∈ O，则 2a ∈ O，|2a| = |a| + 1，且 a <O 2a。(3) 若 φe 全定义且 φe(0) <O φe(1) <O ⋯（都属于 O），则 3·5e ∈ O，|3·5e| = supn |φe(n)|，且对所有 n 有 φe(n) <O 3·5e。<O 取上述关系的传递闭包。（有些书用 0 而不是 1 作为零的记号。）
定理. {|a| : a ∈ O} = ω₁CK，即恰好递归序数有记号。对 a ∈ O，{b : b <O a} 关于 a 一致地递归可枚举，并在 <O 下良序，序型为 |a|。O 是 Π¹₁-完全的：每个 Π¹₁ 集 A ⊆ ω 都可多一归约到 O。有限序数恰有一个记号；每个无穷递归序数都有无穷多个记号。

Build part of O. Select a node, then add a successor or a limit. Use Compare to test two nodes under <O. Challenge: make two different notations for ω and compare them. 亲手搭建 O 的一部分。选中一个结点，再添加后继或极限。用比较检验两个结点在 <O 下的关系。挑战：造出 ω 的两个不同记号并比较它们。

⚠ Common pitfalls常见误区(1) <O is a tree order, not a linear order: two notations for ω are <O-incomparable, and the predecessors of a notation form a single path. (2) The limit rule demands φe(n) be <O-increasing, not merely that |φe(n)| increase. (3) You cannot decide membership 3·5e ∈ O by running φe: one must check totality and that every value is again in O, all the way down. That is why O is Π¹₁-complete, not arithmetical. (1) <O 是树序而不是线序：ω 的两个记号在 <O 下不可比较，而一个记号的所有前驱构成一条路径。(2) 极限规则要求 φe(n) 在 <O 下递增，而不只是 |φe(n)| 递增。(3) 不能靠运行 φe 来判定 3·5e ∈ O：必须检查全定义性，还要检查每个值本身又属于 O，一路查到底。正因为如此，O 是 Π¹₁-完全的，而不是算术集。
Step 6 · Σ¹₁ boundingΣ¹₁ 有界性
Prerequisites前置: §3 WO§4 ω₁CK

The boundedness theorem有界性定理

Core idea: a Σ¹₁ family of well-orders cannot reach all the way up. In the lightface case it stops strictly below ω₁CK. 核心思想：一族 Σ¹₁ 的良序够不到顶。在细体情形下，它停在 ω₁CK 严格下方。

Boundedness theorem. (a) If A ⊆ WO is Σ¹₁ (lightface), then sup{|x| : x ∈ A} < ω₁CK. (b) If A ⊆ WO is boldface Σ¹₁ (Σ¹₁ in some real parameter), then sup{|x| : x ∈ A} < ω₁. (c) Number form: if X ⊆ O is Σ¹₁, then sup{|a| : a ∈ X} < ω₁CK. 有界性定理. (a) 若 A ⊆ WO 是（细体）Σ¹₁ 的，则 sup{|x| : x ∈ A} < ω₁CK。(b) 若 A ⊆ WO 是粗体 Σ¹₁ 的（以某个实数为参数的 Σ¹₁），则 sup{|x| : x ∈ A} < ω₁。(c) 数的形式：若 X ⊆ O 是 Σ¹₁ 的，则 sup{|a| : a ∈ X} < ω₁CK。

Choose a subset of WO and watch where its order types land.选一个 WO 的子集，看它的序型落在哪里。

Proof of (a), step 1. Suppose not: every recursive ordinal is < |x| for some x ∈ A. (This covers sup = ω₁CK even when it is not attained.)(a) 的证明，第 1 步. 假设结论不成立：每个递归序数都小于某个 x ∈ A 的 |x|。（sup = ω₁CK 但取不到的情形也包含在内。）
Step 2. Then for an index e: e ∈ W ⇔ ≤e is a linear order ∧ ∃x ∃g (x ∈ A ∧ g is an order-embedding of ≤e into ≤x). “⇒” by the assumption, since |≤e| is recursive. “⇐” because a linear order that embeds into a well-order is a well-order.第 2 步. 于是对指标 e：e ∈ W ⇔ ≤e 是线序 ∧ ∃x ∃g (x ∈ A ∧ g 是 ≤e 到 ≤x 的保序嵌入)。“⇒”由假设得到，因为 ≤e 的序型是递归序数；“⇐”是因为能嵌入良序的线序本身是良序。
Step 3. The right-hand side is Σ¹₁ (existential real quantifiers over an arithmetical matrix plus x ∈ A). So W would be Σ¹₁, contradicting that W is Π¹₁-complete and not Σ¹₁. ∎ For (b), run the same argument with WO in place of W and the parameter of A carried along.第 3 步. 右边是 Σ¹₁ 的（对实数的存在量词，加上算术母式和 x ∈ A）。于是 W 就是 Σ¹₁ 的，与 W 为 Π¹₁-完全且不是 Σ¹₁ 矛盾。∎ 对 (b)，用 WO 代替 W、带着 A 的参数，同样论证即可。
Corollaries推论WO is not Σ¹₁ (its ranks reach every countable ordinal). If x ∈ WO is hyperarithmetic, then |x| < ω₁CK: the singleton {x} is Δ¹₁, hence a Σ¹₁ subset of WO. So hyperarithmetic well-orders are no longer than recursive ones. WO 不是 Σ¹₁ 的（它的秩取遍所有可数序数）。若 x ∈ WO 是超算术的，则 |x| < ω₁CK：单点集 {x} 是 Δ¹₁ 的，从而是 WO 的 Σ¹₁ 子集。所以超算术良序不比递归良序更长。
⚠ Common pitfall常见误区Boundedness is about Σ¹₁ subsets. A Π¹₁ subset of WO can be unbounded (WO itself), and so can {x ∈ WO : x recursive}, whose types fill all of ω₁CK. By (a), that set is therefore not Σ¹₁. And the bound is strict: “< ω₁CK”, not “≤”. 有界性说的是 Σ¹₁ 子集。WO 的 Π¹₁ 子集可以无界（WO 本身就是），{x ∈ WO : x 递归} 也一样，它的序型填满整个 ω₁CK；由 (a)，这个集合因此不是 Σ¹₁ 的。并且界是严格的：“< ω₁CK”，而不是“≤”。
Step 7 · HYP
Prerequisites前置: L17 Turing jump, Post's theorem图灵跳跃、波斯特定理§5 O

Iterating the jump into the transfinite: ∅(α)把跳跃迭代到超限：∅(α)

Core idea: continue the L17 ladder ∅, ∅′, ∅″, … past ω by taking joins at limits. A notation in O tells you exactly how. 核心思想：把第 17 课的梯子 ∅, ∅′, ∅″, … 越过 ω 继续往上搭，在极限处取并（join）。O 中的记号恰好告诉你怎么做。

Definition (H-sets). For a ∈ O define H(a) by effective transfinite recursion along <O: H(1) = ∅;  H(2a) = H(a)′ (Turing jump);  H(3·5e) = {⟨n, m⟩ : m ∈ H(φe(n))}.
Spector's theorem (1955). If a, b ∈ O and |a| ≤ |b|, then H(a) ≤T H(b). So for α < ω₁CK, ∅(α) := H(a) for any a with |a| = α is well defined up to Turing degree, and α < β ⇒ ∅(α) <T ∅(β).
A ⊆ ω is hyperarithmetic (A ∈ HYP) if A ≤T H(a) for some a ∈ O, i.e. A ≤T ∅(α) for some α < ω₁CK. 定义（H 集）. 对 a ∈ O，沿 <O 作能行超限递归定义 H(a)： H(1) = ∅；  H(2a) = H(a)′（图灵跳跃）；  H(3·5e) = {⟨n, m⟩ : m ∈ H(φe(n))}。
Spector 定理（1955）. 若 a, b ∈ O 且 |a| ≤ |b|，则 H(a) ≤T H(b)。因此对 α < ω₁CK，取任意满足 |a| = α 的 a，令 ∅(α) := H(a)，它在图灵度意义下是良定义的，且 α < β ⇒ ∅(α) <T ∅(β)。
若存在 a ∈ O 使 A ≤T H(a)，即存在 α < ω₁CK 使 A ≤T ∅(α)，则称 A ⊆ ω 是超算术的（A ∈ HYP）。

Climb the ladder: Jump adds one ′; Limit joins the whole ω-sequence below into one set (drawn as stacked rows: row n is the n-th set of the sequence). 爬梯子：跳跃加一撇；极限把下方整条 ω 序列并成一个集合（画成叠起来的行：第 n 行是序列中的第 n 个集合）。

⚠ Common pitfalls常见误区(1) ∅(ω) is not arithmetical: every arithmetical set is ≤T some ∅(n) (Post), while ∅(n+1) ≤T ∅(ω) and ∅(n+1) ≰T ∅(n). (2) H(a) depends on the notation a. Only its Turing degree depends on |a| alone. (3) The ladder stops at ω₁CK because there are no notations beyond it, not because jumping becomes impossible. Every hyperarithmetic set is recursive in O, and O is not hyperarithmetic. (1) ∅(ω) 不是算术集：每个算术集都 ≤T 某个 ∅(n)（波斯特定理），而 ∅(n+1) ≤T ∅(ω) 且 ∅(n+1) ≰T ∅(n)。(2) H(a) 依赖于记号 a；只有它的图灵度只依赖于 |a|。(3) 梯子停在 ω₁CK，是因为那之后没有记号了，而不是跳跃做不下去。每个超算术集都递归于 O，而 O 本身不是超算术的。
Step 8 · Kleene's theorem克莱尼定理
Prerequisites前置: §2 tree form树形式§6 boundedness有界性§7 H-sets

Δ¹₁ = HYPΔ¹₁ = HYP

Core idea: the sets definable both by “∃ real” and by “∀ real” are exactly the sets computable from some transfinite jump below ω₁CK. 核心思想：既能用“∃ 实数”又能用“∀ 实数”定义的集合，恰好是能由 ω₁CK 以下某个超限跳跃计算出来的集合。

Kleene's theorem (1955). For A ⊆ ω: A is Δ¹₁ ⇔ A is hyperarithmetic ⇔ A ≤T ∅(α) for some α < ω₁CK. 克莱尼定理（1955）. 对 A ⊆ ω：A 是 Δ¹₁ 的 ⇔ A 是超算术的 ⇔ 存在 α < ω₁CK 使 A ≤T ∅(α)。

The map of sets of natural numbers. Click a set to see where it lives and why.自然数集合的地图。点击一个集合，看它住在哪里以及为什么。

Proof sketch证明概要

1 · HYP ⊆ Δ¹₁, uniqueness. For a ∈ O, let Hier(a, Y) say: “Y codes a family (Yb)b ≤O a with Y1 = ∅, Y2b = (Yb)′, Y3·5e = ⊕n Yφe(n)”. Since {b : b ≤O a} is r.e., Hier is arithmetical. By transfinite induction along the well-order <O below a, there is exactly one such Y, and Ya = H(a). 1 · HYP ⊆ Δ¹₁：唯一性. 对 a ∈ O，令 Hier(a, Y) 表示：“Y 编码一族 (Yb)b ≤O a，满足 Y1 = ∅，Y2b = (Yb)′，Y3·5e = ⊕n Yφe(n)”。由于 {b : b ≤O a} 递归可枚举，Hier 是算术的。沿 a 以下的良序 <O 作超限归纳，这样的 Y 恰有一个，且 Ya = H(a)。
2 · Two definitions. Hence n ∈ H(a) ⇔ ∃Y (Hier(a,Y) ∧ n ∈ Ya) ⇔ ∀Y (Hier(a,Y) → n ∈ Ya): Σ¹₁ and Π¹₁. Δ¹₁ is closed under ≤T (if A ≤T B, A is arithmetical in B, i.e. Δ⁰₁ in B), so every A ≤T H(a) is Δ¹₁. 2 · 两种定义. 于是 n ∈ H(a) ⇔ ∃Y (Hier(a,Y) ∧ n ∈ Ya) ⇔ ∀Y (Hier(a,Y) → n ∈ Ya)：既是 Σ¹₁ 又是 Π¹₁。Δ¹₁ 对 ≤T 封闭（若 A ≤T B，则 A 是 B 中的 Δ⁰₁ 集），所以每个 A ≤T H(a) 都是 Δ¹₁ 的。
3 · Δ¹₁ ⊆ HYP, trees. Let A be Δ¹₁. Since A is Π¹₁, by §2 there are uniformly recursive trees Tn with n ∈ A ⇔ Tn is WF. 3 · Δ¹₁ ⊆ HYP：树. 设 A 是 Δ¹₁ 的。因为 A 是 Π¹₁ 的，由 §2，存在一致递归的树 Tn，使 n ∈ A ⇔ Tn 良基。
4 · Bounding. Since A is also Σ¹₁, the set {code of KB(Tn) : n ∈ A} is a Σ¹₁ subset of WO. By boundedness its order types, and hence the ranks ρ(Tn) ≤ |KB(Tn)| for n ∈ A, are all < some recursive α. 4 · 有界. 因为 A 同时是 Σ¹₁ 的，集合 {KB(Tn) 的编码 : n ∈ A} 是 WO 的 Σ¹₁ 子集。由有界性定理，它的序型，从而 n ∈ A 时的秩 ρ(Tn) ≤ |KB(Tn)|，都小于某个递归序数 α。
5 · Computing. Now n ∈ A ⇔ ρ(Tn) < α (for n ∉ A, Tn is ill-founded and has no rank). The relation “σ ∈ Tn and ρ(σ) < β” is built by effective transfinite recursion along a recursive well-order of type α: each successor step is Π⁰₁ in the previous stage (one jump), each limit is a join. So A ≤T H(b) for a suitable b ∈ O, i.e. A ∈ HYP. ∎ 5 · 计算. 于是 n ∈ A ⇔ ρ(Tn) < α（n ∉ A 时 Tn 非良基，没有秩）。关系“σ ∈ Tn 且 ρ(σ) < β”可以沿一个序型为 α 的递归良序作能行超限递归构造：每个后继步相对前一阶段是 Π⁰₁ 的（多一次跳跃），每个极限步取并。所以对适当的 b ∈ O 有 A ≤T H(b)，即 A ∈ HYP。∎
⚠ Common pitfall常见误区Step 1 needs uniqueness, not just existence: with only existence, “∀Y (Hier → n ∈ Ya)” could fail on a fake Y. Uniqueness holds because <O below a is a genuine well-order. Along ill-founded recursive orders (Harrison's) “jump hierarchies” can exist without being unique or hyperarithmetic. 第 1 步需要的是唯一性，不只是存在性：若只有存在性，“∀Y (Hier → n ∈ Ya)”可能被某个冒牌的 Y 破坏。唯一性成立，是因为 a 以下的 <O 是真正的良序。沿着非良基的递归序（如 Harrison 序），“跳跃层级”可能存在，但既不唯一，也不是超算术的。
Step 9 · Spector–Gandy · Kondo–Addison
Prerequisites前置: §8 Δ¹₁ = HYP§3 ranks秩

Two structure theorems for Π¹₁ (stated)Π¹₁ 的两个结构定理（只陈述）

Core idea: a universal quantifier over all reals can be traded for an existential quantifier over the countably many hyperarithmetic reals; and Π¹₁ relations can choose a single witness definably. 核心思想：对所有实数的全称量词，可以换成对可数多个超算术实数的存在量词；并且 Π¹₁ 关系可以可定义地挑出唯一的见证。

Spector–Gandy theorem (1960). A ⊆ ω is Π¹₁ ⇔ there is an arithmetical R with n ∈ A ⇔ ∃Y ∈ HYP R(n, Y). Equivalently, the Π¹₁ subsets of ω are exactly the sets Σ₁-definable over Lω₁CK. Spector–Gandy 定理（1960）. A ⊆ ω 是 Π¹₁ 的 ⇔ 存在算术关系 R 使 n ∈ A ⇔ ∃Y ∈ HYP R(n, Y)。等价地，ω 的 Π¹₁ 子集恰好是在 Lω₁CK 上 Σ₁ 可定义的集合。
Π¹₁ uniformization (Kondo 1938; lightface: Addison 1959). If P ⊆ ωω × ωω is Π¹₁, there is a Π¹₁ set P* ⊆ P such that for every x: if ∃y P(x, y), then there is exactly one y with P*(x, y). (The boldface version holds as well.) Consequence: Σ¹₂ relations can be uniformized by Σ¹₂ relations. Π¹₁ 单值化定理（近藤 1938；细体版本：Addison 1959）. 若 P ⊆ ωω × ωω 是 Π¹₁ 的，则存在 Π¹₁ 集 P* ⊆ P，使得对每个 x：若 ∃y P(x, y)，则恰有一个 y 满足 P*(x, y)。（粗体版本同样成立。）推论：Σ¹₂ 关系可以被 Σ¹₂ 关系单值化。

A cartoon of P (columns = x, cells = candidate y). Click cells to edit P, then Uniformize: in each nonempty column, keep the candidate with least norm, ties broken by least y. Kondo's real proof does this along y digit by digit, interleaving Π¹₁-norms, so that the choice stays Π¹₁. P 的示意图（列 = x，格子 = 候选的 y）。点击格子修改 P，再按单值化：在每个非空列里，留下范数最小的候选，范数相同则取 y 最小的。近藤的真正证明是沿着 y 一位一位地做，并穿插 Π¹₁ 范数，从而保证选择仍是 Π¹₁ 的。

⚠ Common pitfall常见误区The chosen y need not be simple. Kleene: there is a nonempty Π⁰₁ set of reals (the branches of a recursive tree on ω) with no hyperarithmetic member. Uniformizing it picks a y such that {y} is Π¹₁, yet y ∉ HYP. Similarly, “a recursive ill-founded tree has a hyperarithmetic branch” is false. What is true is that it has a branch recursive in O (Kleene basis theorem). 被选出的 y 未必简单。克莱尼：存在一个非空的 Π⁰₁ 实数集（ω 上某棵递归树的分支集），它没有超算术元素。对它单值化，选出的 y 满足 {y} 是 Π¹₁ 的，但 y ∉ HYP。同理，“非良基的递归树一定有超算术分支”是错的；正确的是：它有一条递归于 O 的分支（克莱尼基定理）。
Step 10 · Relativization, Σ¹₂相对化、Σ¹₂
Prerequisites前置: §1L15 constructible universe L可构成宇宙 LL16 forcing力迫preview预告: L19L20

Lightface vs boldface, and Shoenfield absoluteness细体与粗体，以及 Shoenfield 绝对性

Core idea: allowing a real parameter a gives Σ¹ₙ(a); boldface Σ¹ₙ is the union over all a. For sets of numbers that union is trivial; for sets of reals it is the projective hierarchy of L19. 核心思想：允许一个实数参数 a，就得到 Σ¹ₙ(a)；粗体 Σ¹ₙ 是对所有 a 取并。对自然数集合而言这个并是平凡的；对实数集合而言，它就是第 19 课的投影层级。

Relativization. Σ¹ₙ(a), Π¹ₙ(a), Oa, ω₁a (sup of order types of a-recursive well-orders), Ha-sets: everything above with “recursive” replaced by “recursive in a”. All theorems relativize, e.g. Δ¹₁(a) = HYP(a) and boundedness below ω₁a. Boldface: Σ¹ₙ = ⋃a∈ωω Σ¹ₙ(a), etc. For subsets of ωω: boldface Σ¹₁ = analytic sets, boldface Δ¹₁ = Borel sets (Suslin), see L19. Lightface Δ¹₁ subsets of ωω are the “effectively Borel” sets (Kleene–Suslin), a countable family. 相对化. Σ¹ₙ(a)、Π¹ₙ(a)、Oa、ω₁a（a-递归良序序型的上确界）、Ha 集：把上面所有的“递归”换成“相对 a 递归”。所有定理都可以相对化，例如 Δ¹₁(a) = HYP(a)，有界性的界变为 ω₁a。粗体：Σ¹ₙ = ⋃a∈ωω Σ¹ₙ(a)，其余类似。对 ωω 的子集：粗体 Σ¹₁ = 解析集，粗体 Δ¹₁ = 博雷尔集（Suslin 定理），见第 19 课。细体 Δ¹₁ 的 ωω 子集是“能行博雷尔集”（Kleene–Suslin），只有可数多个。

Click a column to choose the parameter a. The table shows the best classification relative to a.点击某一列选择参数 a。表中显示相对于 a 的最佳分类。

⚠ Common pitfall常见误区For sets of numbers, boldface is useless: every A ⊆ ω is Δ⁰₁(A), hence boldface Δ⁰₁. Lightface is the meaningful notion for subsets of ω; boldface is for sets of reals. Also ω₁a ≥ ω₁CK always, with equality for every hyperarithmetic a. By Spector, ω₁a > ω₁CK iff O ∈ HYP(a). 对自然数集合，粗体没有意义：每个 A ⊆ ω 都是 Δ⁰₁(A) 的，从而是粗体 Δ⁰₁。对 ω 的子集，有意义的是细体；粗体是为实数集合准备的。另外总有 ω₁a ≥ ω₁CK，a 超算术时取等号；由 Spector 定理，ω₁a > ω₁CK 当且仅当 O ∈ HYP(a)。

One level up: Σ¹₂ and Shoenfield absoluteness再往上一层：Σ¹₂ 与 Shoenfield 绝对性

Σ¹₂ normal form. A is Σ¹₂ iff n ∈ A ⇔ ∃f ∀g ∃m R(n, f↾m, g↾m) with R recursive, i.e. ∃f (the recursive tree Tn,f is WF): a projection of a Π¹₁ set.
Mostowski absoluteness. Σ¹₁(a) statements are absolute between V and any transitive model of ZF containing a.
Shoenfield absoluteness theorem. If M is an inner model of ZF + DC and a ∈ M ∩ ωω, then every Σ¹₂(a) (and Π¹₂(a)) statement is true in M iff it is true in V. In particular this holds for M = L with a ∈ L. So forcing cannot change the truth value of a Σ¹₂ sentence. (More generally it holds for transitive models of ZF + DC containing ω₁; details in L20.) Σ¹₂ 范式. A 是 Σ¹₂ 的，当且仅当 n ∈ A ⇔ ∃f ∀g ∃m R(n, f↾m, g↾m)，R 递归；即 ∃f（递归树 Tn,f 良基），也就是 Π¹₁ 集的投影。
Mostowski 绝对性. Σ¹₁(a) 陈述在 V 与任何包含 a 的 ZF 传递模型之间是绝对的。
Shoenfield 绝对性定理. 若 M 是 ZF + DC 的内模型且 a ∈ M ∩ ωω，则每个 Σ¹₂(a)（以及 Π¹₂(a)）陈述在 M 中成立当且仅当在 V 中成立。特别地，对 M = L（a ∈ L）成立。所以力迫无法改变 Σ¹₂ 语句的真值。（更一般地，对包含 ω₁ 的 ZF + DC 传递模型也成立；细节见第 20 课。）

Drop a sentence into the universes: L inside V, where V is a universe containing a non-constructible real (for example after adding a Cohen real; this is consistent if ZFC is). 把一句话放进两个宇宙：V 里面套着 L，这里的 V 含有一个非可构成实数（例如添加一个 Cohen 实数之后；只要 ZFC 一致，这就是一致的）。

⚠ Common pitfall常见误区Absoluteness ≠ decidability. Shoenfield says L and V agree on Σ¹₂ sentences, not that ZFC proves or refutes them: Con(ZFC) is even arithmetical (Π⁰₁), so absolute, yet unprovable in ZFC if ZFC is consistent. And the agreement stops at Σ¹₃: “∃x (x ∉ L)” is Σ¹₃ (the set of constructible reals is Σ¹₂), false in L, true after adding a Cohen real. 绝对性 ≠ 可判定性。Shoenfield 说的是 L 与 V 在 Σ¹₂ 语句上意见一致，而不是 ZFC 能证明或否证它们：Con(ZFC) 甚至是算术语句（Π⁰₁），因此是绝对的，但若 ZFC 一致，它在 ZFC 中不可证。而且这种一致在 Σ¹₃ 就停止了：“∃x (x ∉ L)”是 Σ¹₃ 的（可构成实数之集是 Σ¹₂ 的），它在 L 中为假，添加 Cohen 实数之后为真。
