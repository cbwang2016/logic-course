Computability & the Halting Problem可计算性与停机问题

What does it mean for a function to be computable “by a mechanical procedure”? We build the machines, run them, encode them as numbers, and then turn Cantor's diagonal argument against them: some perfectly precise questions have no algorithm at all. 一个函数“能被机械程序算出来”，究竟是什么意思？我们动手造机器、运行机器、把机器编码成数，再把康托尔的对角线论证对准它们：有些表述得清清楚楚的问题，根本不存在算法。

§1

A Turing machine, live现场运行一台图灵机

Definition. A (deterministic, one-tape) Turing machine is a finite set of states Q with a start state, a finite tape alphabet Γ ∋ _ (blank), and a partial transition function δ : Q × Γ ⇀ Q × Γ × {L, R, N}. A rule q a → q' b R reads: “in state q reading a, write b, move right, go to q'”. The machine halts when no rule applies. 定义. 一台（确定型、单带）图灵机由以下几样东西组成：有限状态集 Q（含一个初始状态）、有限带字母表 Γ ∋ _（空白符），以及部分转移函数 δ : Q × Γ ⇀ Q × Γ × {L, R, N}。规则 q a → q' b R 的意思是：“处于状态 q 且读到 a 时，写下 b，右移一格，转入 q'”。没有规则可用时，机器停机。
Transition table (editable)转移表（可编辑）

One rule per line: state read -> next write move. _ is blank, move ∈ L/R/N, # starts a comment. The first state is the start state; the machine halts when no rule matches. Halting in a state named acc…/rej… means accept/reject. 每行一条规则：状态 读入 -> 新状态 写入 移动。_ 表示空白，移动取 L/R/N，# 后为注释。第一条规则的状态为初始状态；没有规则匹配时停机。停在名为 acc…/rej… 的状态表示接受/拒绝。

Step-count convention. Every applied rule counts as one step, including the final rule that moves the machine into the halt state H. With this convention the 2-state busy beaver writes 4 ones in 6 steps and the 3-state champion writes 6 ones in 14 steps. Let Σ(n) be the maximum number of 1s left on the tape by an n-state machine over the alphabet {_, 1} that halts when started on a blank tape (the halt state H is not counted among the n). Radó (1962) showed that Σ is not computable; in fact for every computable f we have Σ(n) > f(n) for all sufficiently large n. 步数约定. 每执行一条规则记一步，包括把机器送进停机状态 H 的最后那条规则。按此约定，2 状态忙碌海狸在 6 步内写出 4 个 1，3 状态冠军机在 14 步内写出 6 个 1。记 Σ(n) 为字母表 {_, 1} 上、从空白带出发且最终停机的 n 状态机器（停机状态 H 不计入 n）在带上最多能留下的 1 的个数。拉多（1962）证明了 Σ 不可计算；事实上，对任意可计算函数 f，当 n 充分大时都有 Σ(n) > f(n)。
§2

Primitive recursive functions: built from five kinds of blocks原始递归函数：用五种积木搭出来

Definition. The primitive recursive functions are the smallest class of functions ℕᵏ → ℕ that contains zero Z(x) = 0 (in any number of variables, including the constant 0 with no variables, so that a one-variable f can start with f(0) = 0), successor S(x) = x+1, the projections Pⁿᵢ(x₁,…,xₙ) = xᵢ, and is closed under composition f(x) = h(g₁(x),…,gₘ(x)) and primitive recursion: f(x, 0) = g(x), f(x, y+1) = h(x, y, f(x, y)). 定义. 原始递归函数类是满足下列条件的最小函数类（函数 ℕᵏ → ℕ）：包含零函数 Z(x) = 0（变元个数任意，也包括无变元的常数 0，这样单变元函数 f 也能以 f(0) = 0 起步）、后继函数 S(x) = x+1、投影函数 Pⁿᵢ(x₁,…,xₙ) = xᵢ；并且对复合 f(x) = h(g₁(x),…,gₘ(x)) 和原始递归 f(x, 0) = g(x)，f(x, y+1) = h(x, y, f(x, y)) 封闭。

Pick a function. Left: its construction tree (gold = basic functions, blue = composition, purple = primitive recursion; a dashed green box is a function defined earlier, so click it to unfold it). Right: the recursion running on your inputs, one rung at a time. 选一个函数。左边是它的构造树（金色＝基本函数，蓝色＝复合，紫色＝原始递归；绿色虚线框是先前定义好的函数，点击可以展开）。右边是递归在你给的输入上一级一级地展开。

Every primitive recursive function is total and computable by a program that uses only bounded for-loops: the number of iterations of each loop is known before the loop starts. Primitive recursion is exactly a “for i = 0 … y−1” loop. 每个原始递归函数都是全函数，而且可以由只含有界 for 循环的程序计算：每个循环跑几圈，在进入循环之前就已确定。原始递归正好就是一个“for i = 0 … y−1”循环。

The Ackermann function: computable, but not primitive recursive阿克曼函数：可计算，却不是原始递归的

A(0, n) = n + 1  ·  A(m+1, 0) = A(m, 1)  ·  A(m+1, n+1) = A(m, A(m+1, n))

Each row iterates the row above it, so the rows climb the ladder successor → addition → multiplication → exponentiation → towers. The purple diagonal n ↦ A(n, n) races up all rows at once. Click a small cell to watch the call stack of the recursion while it computes. 每一行都是上一行的迭代，于是各行沿着阶梯往上爬：后继 → 加法 → 乘法 → 乘方 → 指数塔。紫框对角线 n ↦ A(n, n) 同时冲上所有行。点击较小的格子，可以看到计算过程中递归调用栈的起伏。

Why A is not primitive recursive为什么 A 不是原始递归函数

Lemma (domination). For every primitive recursive f(x₁,…,xₖ) there is an m with f(x) < A(m, max x) for all x. 引理（控制）. 对每个原始递归函数 f(x₁,…,xₖ)，存在 m，使得对所有 x 都有 f(x) < A(m, max x)。
Proof idea. Induction on the construction of f. Z, S, Pⁿᵢ are bounded by row 0 or 1. If h and the gᵢ are bounded by row m, then the composition is bounded by row m+2. If g and h are bounded by row m, one shows f(x, y) < A(m+1, y + max x), since each step of the recursion applies row m once more and row m+1 is iterated row m. A sum inside the argument is absorbed by going a few rows further. So every construction step raises the row by only a fixed amount. 证明思路. 对 f 的构造归纳。Z、S、Pⁿᵢ 被第 0 或第 1 行控制。若 h 和各 gᵢ 都被第 m 行控制，则复合被第 m+2 行控制。若 g、h 被第 m 行控制，可以证明 f(x, y) < A(m+1, y + max x)，因为递归每走一步就多用一次第 m 行，而第 m+1 行正是第 m 行的迭代。自变量里的和式，再往下多走几行就能吸收掉。所以每一步构造只把行号抬高一个固定的量。
Diagonal. If g(n) = A(n, n) were primitive recursive, so would be g(n)+1, giving m with A(n,n) + 1 < A(m, n) for all n. Put n = m: A(m,m) + 1 < A(m,m). Contradiction. ∎ (A diagonal argument again, as in Cantor's theorem!) 对角线. 若 g(n) = A(n, n) 是原始递归的，则 g(n)+1 也是，于是有 m 使对所有 n 都有 A(n,n) + 1 < A(m, n)。取 n = m 得 A(m,m) + 1 < A(m,m)，矛盾。∎（又是一次对角线论证，和康托尔定理如出一辙！）
Yet A is computable. The recursion always terminates because each call decreases the pair (m, n) in the lexicographic order on ω × ω, a well-order of type ω² (Lesson 8). A well-order has no infinite descending sequence, so the recursion cannot go on forever. 但 A 是可计算的. 递归一定终止，因为每次调用都让数对 (m, n) 在 ω × ω 的字典序下严格变小，而这是一个序型为 ω² 的良序（第 8 课）。良序里没有无穷降链，所以递归不可能无休止。
§4

The μ-operator and the Church–Turing thesisμ 算子与丘奇–图灵论题

Unbounded search. μy[g(x, y) = 0] is the least y with g(x, y) = 0, provided g(x, z) is defined for all z ≤ y; otherwise it is undefined. The smallest class containing the basic functions and closed under composition, primitive recursion and μ is the class of partial recursive (μ-recursive) functions; its total members are the (general) recursive functions. This is a while-loop: nobody tells you in advance how many rounds it takes. 无界搜索. μy[g(x, y) = 0] 表示使 g(x, y) = 0 的最小 y，前提是对所有 z ≤ y，g(x, z) 都有定义；否则它无定义。包含基本函数、并对复合、原始递归以及 μ 算子都封闭的最小函数类，就是部分递归函数（μ 递归函数）类；其中的全函数称为（一般）递归函数。μ 算子就是一个 while 循环：事先没人告诉你要转多少圈。

Many definitions, one class定义各异，殊途同归

In the 1930s several people formalized “algorithm” in completely different ways, and every one of them turned out to define exactly the same functions. Click a model. 20 世纪 30 年代，好几位学者用截然不同的方式把“算法”形式化，结果每一种定义出来的函数类都一模一样。点击各个模型看看。

Church–Turing thesis. A function ℕᵏ ⇀ ℕ is effectively computable (by any finite, mechanical procedure) if and only if it is Turing computable. This is not a theorem: it identifies an informal notion with a formal one. The evidence is that all the formal models are provably equivalent, and that no counterexample has ever been found. 丘奇–图灵论题. 一个函数 ℕᵏ ⇀ ℕ 能行可计算（即能被某种有限的机械程序计算），当且仅当它图灵可计算。这不是定理：它把一个直观概念等同于一个形式概念。支持它的证据有两条：各种形式模型之间可以严格证明等价，而且至今没有人找到反例。
§5

Machines are numbers: the universal machine机器就是数：通用图灵机

Number the states q₁, q₂, … (start = q₁), the symbols s₁ = _, s₂, …, and the moves L=1, R=2, N=3. A rule (qᵢ, sⱼ) → (qₖ, sₗ, m) becomes 0ⁱ 1 0ʲ 1 0ᵏ 1 0ˡ 1 0ᵐ, and rules are glued with 11. So every machine M has a code ⟨M⟩ ∈ {0,1}*; putting a 1 in front (so that no leading zeros are lost) and reading the result in binary gives a number e, and we write Mₑ for the machine with code e. By convention, a number that codes no machine denotes a machine with no rules (it halts at once), so every e ∈ ℕ names some machine. Hence there are only countably many machines. 把状态编号为 q₁, q₂, …（初始状态为 q₁），符号编号为 s₁ = _, s₂, …，移动记 L=1, R=2, N=3。规则 (qᵢ, sⱼ) → (qₖ, sₗ, m) 编码成 0ⁱ 1 0ʲ 1 0ᵏ 1 0ˡ 1 0ᵐ，规则之间用 11 隔开。这样每台机器 M 都有一个编码 ⟨M⟩ ∈ {0,1}*；在前面补一个 1（免得丢掉开头的 0）再读成二进制数，就得到一个数 e，编码为 e 的机器记作 Mₑ。约定：不是任何机器编码的数，代表一台没有任何规则（立即停机）的机器，于是每个 e ∈ ℕ 都对应一台机器。所以图灵机只有可数多台。

Theorem (Turing 1936). There is a single machine U such that for every machine M and input w: U(⟨M⟩, w) halts iff M(w) halts, with the same output. U is a fixed program that reads other programs, the way an interpreter does. Below, U keeps three tapes: the program, M's tape, and M's current state 0ⁱ. (A multi-tape machine can always be simulated by a one-tape machine, so this is no loss of generality.) 定理（图灵，1936）. 存在一台固定的机器 U，使得对任意机器 M 和输入 w：U(⟨M⟩, w) 停机当且仅当 M(w) 停机，并且输出相同。U 是一个读取别的程序的固定程序，就像解释器。下面的 U 用三条带：程序带、M 的带、M 的当前状态 0ⁱ。（多带机总能用单带机模拟，所以这样做不失一般性。）

tape 3: state带 3：状态
§6

The halting problem, by diagonalization停机问题：对角线论证

List all machines M₀, M₁, M₂, … (by code) and feed each one every code as input. Entry (e, i) says whether Mₑ halts (↓) or runs forever (↑) on input i. Now do to this table exactly what Cantor did to a list of 0/1 sequences. 按编码列出所有机器 M₀, M₁, M₂, …，再把每个编码都当作输入喂给每台机器。第 (e, i) 格记录 Mₑ 在输入 i 上是停机（↓）还是永远运行（↑）。接下来对这张表做的事，和康托尔对 0/1 序列清单做的事一模一样。

Run D on its own code让 D 运行自己的编码

Cantor. Given f : ℕ → 𝒫(ℕ), let S = {n : n ∉ f(n)}. Then S ≠ f(n) for every n, since they differ at n. 康托尔. 给定 f : ℕ → 𝒫(ℕ)，令 S = {n : n ∉ f(n)}。则对每个 n 都有 S ≠ f(n)，因为二者在 n 处不同。
Turing. Given a supposed decider H, let D(e)↓ ⇔ H says Mₑ(e)↑. Then D ≠ Mₑ for every e, since they differ at e. But D is a machine, so it must be on the list. 图灵. 假设有判定器 H，令 D(e)↓ ⇔ H 判定 Mₑ(e)↑。则对每个 e 都有 D ≠ Mₑ，因为二者在 e 处不同。可 D 本身是一台机器，必然在清单上。

The proof, step by step逐步展开证明

Theorem. HALT = {(e, x) : Mₑ halts on x} is not decidable: no Turing machine halts on every input and outputs 1 exactly on HALT. 定理. HALT = {(e, x) : Mₑ 在 x 上停机} 不可判定：不存在一台在所有输入上都停机、且恰在 HALT 上输出 1 的图灵机。
Suppose H decides HALT. Build D: on input e, run H on (e, e); if H answers 1, loop forever; if H answers 0, halt. D is a Turing machine (it calls H as a subroutine), so D = Md for some d. 假设 H 判定 HALT。构造 D：输入 e 时，在 (e, e) 上运行 H；若 H 回答 1，就进入死循环；若回答 0，就停机。D 是一台图灵机（把 H 当子程序调用），所以对某个 d 有 D = Md。
Then Md(d)↓ ⇔ D(d)↓ ⇔ H(d,d) = 0 ⇔ Md(d)↑. Contradiction, so H does not exist. ∎ 于是 Md(d)↓ ⇔ D(d)↓ ⇔ H(d,d) = 0 ⇔ Md(d)↑，矛盾，所以 H 不存在。∎
The same proof shows the diagonal halting set K = {e : Mₑ(e)↓} is undecidable: D is exactly a machine that would halt on the complement of K. Note what we did not claim: that some single pair (e, x) has no answer. Each pair has a definite answer (and for a single pair, one of the two trivial machines “output 1” / “output 0” gives it). What does not exist is one uniform algorithm that is correct for all pairs. 同样的证明说明对角停机集 K = {e : Mₑ(e)↓} 不可判定：D 恰好是一台在 K 的补集上停机的机器。注意我们并没有断言某一对 (e, x) 没有答案。每一对都有确定的答案（而且对单独一对，“输出 1”和“输出 0”这两台平凡机器之一就能给出它）。不存在的是一个对所有输入都正确、一致适用的算法。
§7

Decidable, r.e., co-r.e.可判定、递归可枚举、余递归可枚举

Definitions. A ⊆ ℕ is decidable (recursive) if its characteristic function is computable. A is recursively enumerable (r.e.) if A = Wₑ := {x : Mₑ(x)↓} for some e; equivalently, A is empty or the range of a computable total function, i.e. some machine lists exactly A. A is co-r.e. if ℕ ∖ A is r.e. 定义. 若 A ⊆ ℕ 的特征函数可计算，则称 A 可判定（递归）。若对某个 e 有 A = Wₑ := {x : Mₑ(x)↓}，则称 A 递归可枚举（r.e.）；等价地，A 为空集或者是某个可计算全函数的值域，也就是有一台机器恰好把 A 的元素一一列出。若 ℕ ∖ A 递归可枚举，则称 A 余递归可枚举（co-r.e.）。

Click a problem to place it on the map.点击一个问题，把它放到图上。

Complementation theorem (Post 1944). A is decidable ⇔ A is both r.e. and co-r.e. (⇐: say A = Wₑ and ℕ ∖ A = We′. Given x, run Mₑ(x) and Me′(x) alternately one step at a time; exactly one of them halts, after finitely many steps, and that tells us whether x ∈ A.) So K is r.e. but not co-r.e., and ℕ ∖ K is not r.e. 补集定理（波斯特，1944）. A 可判定 ⇔ A 既递归可枚举又余递归可枚举。（⇐：设 A = Wₑ，ℕ ∖ A = We′。给定 x，轮流让 Mₑ(x) 和 Me′(x) 各走一步；二者恰有一个会在有限步内停机，由此就知道 x 是否属于 A。）因此 K 递归可枚举但不是余递归可枚举，ℕ ∖ K 则不是递归可枚举的。

Why K is r.e.: dovetailingK 为什么递归可枚举：交错运行（dovetailing）

We cannot run M₀(0) to completion first: it might never stop, and then we would never even start M₁(1). Instead, at stage s, run each Mₑ(e) with e ≤ s for one more step, sweeping along the diagonals of the grid. Each halting computation is found after finitely many stages, and the ones that run forever block nothing. 不能先把 M₀(0) 跑完再说：它可能永不停机，那 M₁(1) 就永远轮不上。正确做法是：在第 s 阶段，让每个 e ≤ s 的 Mₑ(e) 各多跑一步，沿着网格的斜线扫过去。每个会停机的计算都会在有限个阶段后被发现，而永不停机的那些也挡不住别人。

§8

Reductions and Rice's theorem归约与莱斯定理

Many-one reduction. A ≤ₘ B if there is a total computable f with x ∈ A ⇔ f(x) ∈ B. If B is decidable then so is A; contrapositively, if A is undecidable then so is B. Reductions carry undecidability forward, from K to everything K reduces to. 多一归约. 若存在可计算全函数 f，使 x ∈ A ⇔ f(x) ∈ B，则记 A ≤ₘ B。若 B 可判定，则 A 也可判定；换个说法，若 A 不可判定，则 B 也不可判定。归约把不可判定性往前传：从 K 传到所有 K 能归约过去的问题。

Rice's theorem: no non-trivial semantic property is decidable莱斯定理：任何非平凡的语义性质都不可判定

Each dot is a program, and programs are grouped into clouds by the partial function they compute. A semantic property is a union of whole clouds. Click clouds to choose a property P. 每个点是一个程序，计算同一个部分函数的程序归成一朵云。语义性质就是若干朵完整的云的并。点击云朵来选定性质 P。

Rice's theorem. Write φₑ for the (unary) partial function computed by Mₑ. Let 𝒞 be a set of unary partial computable functions with ∅ ≠ 𝒞 ≠ all of them. Then {e : φₑ ∈ 𝒞} is undecidable. 莱斯定理. 记 φₑ 为 Mₑ 计算的（一元）部分函数。设 𝒞 是一个一元部分可计算函数的集合，且 ∅ ≠ 𝒞 ≠ 全体一元部分可计算函数。则 {e : φₑ ∈ 𝒞} 不可判定。
Proof. WLOG the everywhere-undefined function ∅ ∉ 𝒞 (otherwise use the complement). Pick some ψ ∈ 𝒞, computed by a machine N. Given e, let Mf(e) be: “on input x, first run Mₑ(e); if that halts, run N(x)”. f is computable (it just edits code). 证明. 不妨设处处无定义函数 ∅ ∉ 𝒞（否则改看补集）。取某个 ψ ∈ 𝒞，设由机器 N 计算。给定 e，令 Mf(e) 为：“输入 x 时，先运行 Mₑ(e)；若它停机，再运行 N(x)”。f 可计算（它只是在改写代码）。
If e ∈ K, then φf(e) = ψ ∈ 𝒞. If e ∉ K, then φf(e) = ∅ ∉ 𝒞. So K ≤ₘ {e : φₑ ∈ 𝒞}, and the latter is undecidable. ∎ 若 e ∈ K，则 φf(e) = ψ ∈ 𝒞；若 e ∉ K，则 φf(e) = ∅ ∉ 𝒞。所以 K ≤ₘ {e : φₑ ∈ 𝒞}，后者不可判定。∎
