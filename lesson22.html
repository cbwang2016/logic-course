Part V · Lesson 22

Ordinal definable sets: OD & HOD序数可定义集：OD 与 HOD

L collects the sets that can be built by definitions from earlier stages of a construction. Gödel suggested a more generous notion: a set counts if some first-order formula, with ordinals as parameters, picks it out in the whole universe V. The first formal problem is that “definable in V” cannot be written down directly (Tarski). The reflection theorem gets around it. What comes out is HOD, an inner model of ZFC that the ZF axioms alone produce and that sits between L and V. L 收集的是在构造过程中由前面各层逐步“定义出来”的集合。哥德尔提出了一个更宽松的想法：只要在整个宇宙 V 中能用某个一阶公式、以序数为参数把它唯一刻画出来，就算数。第一道形式化难关是“在 V 中可定义”无法直接写成公式（塔斯基定理），而反射原理恰好能绕过它。最后得到的是 HOD：一个仅凭 ZF 公理就能造出来的 ZFC 内模型，介于 L 与 V 之间。

Step 1第 1 步

From L to OD: let ordinals be parameters, and define over V从 L 到 OD：允许序数作参数，在 V 上定义

Prerequisites预备: L14 · VαL15 · L, Def

In L (Lesson 15), stage Lα+1 = Def(Lα) only contains sets definable over the small structure Lα. Gödel's broader idea changes two things. First, you may define over V itself, so a formula can quantify over all sets, all reals included. Second, any ordinals may appear as parameters. Pick an ordinal β and a formula template below. Each choice defines one set from the single parameter β, so the set is “ordinal definable”. Then look at whether it has to be in L. 在 L 中（第 15 课），Lα+1 = Def(Lα) 只含在小结构 Lα 上可定义的集合。哥德尔的新想法改了两处：其一，允许在 V 本身上定义，公式中的量词可以跑遍所有集合（包括所有实数）；其二，任何序数都可以作参数。在下面选一个序数 β 和一个公式模板，每种选择都用唯一的参数 β 定义出一个集合，所以它是“序数可定义”的。再看看它是否一定属于 L。

Informal definition (Gödel 1946). A set x is ordinal definable if there are a formula φ(z, y1,…,yn) and ordinals β1,…,βn such that x is the unique set with φ(x, β1,…,βn), where all quantifiers of φ range over V. Step 2 explains why this is not yet a definition inside ZF, and Step 3 repairs it. 非正式定义（哥德尔，1946）. 若存在公式 φ(z, y1,…,yn) 和序数 β1,…,βn，使得 x 是满足 φ(x, β1,…,βn) 的唯一集合（φ 的量词跑遍 V），则称 x 为序数可定义的。第 2 步说明为什么这还不是 ZF 内部的定义，第 3 步给出修正。
⚠ Common pitfall. “Ordinal definable” does not mean “definable without parameters”. A meta-theoretic count gives only countably many parameter-free definitions, yet every ordinal is OD, since β is defined by z = β with parameter β. Parameters other than ordinals (say an arbitrary real) are not allowed. ⚠ 常见误区. “序数可定义”不是“无参数可定义”。在元理论中数一数，无参数的定义只有可数多个，但每个序数都是 OD 的：用公式 z = β 以 β 为参数即可。序数以外的参数（比如任意一个实数）不允许使用。
Step 2第 2 步

Tarski's wall: “definable over V” is not one formula塔斯基之墙：“在 V 上可定义”不是一条公式

Prerequisites预备: L13 · TarskiL20 · Σn-Sat§1

To turn the informal definition into a class {x : x is OD} we would need one formula D(x) saying “there is a formula φ and ordinals β such that φ(·, β) defines x in V”. That quantifies over formulas (as codes ⌜φ⌝ ∈ ω) and then has to evaluate their truth in V, so it needs a truth predicate SatV(⌜φ⌝, ā) for V. For a set-sized structure such a predicate exists: it is built by recursion on formulas, and the result is a set. Switch the domain below and watch. 要把非正式定义变成一个类 {x : x 是 OD}，就需要一条公式 D(x) 表达“存在公式 φ 和序数 β，使 φ(·, β) 在 V 中定义出 x”。这要对公式（即编码 ⌜φ⌝ ∈ ω）作量词，再判断它们在 V 中是否为真，也就是需要 V 的真谓词 SatV(⌜φ⌝, ā)。对集合大小的结构，这样的谓词是存在的：沿公式递归构造，得到的是一个集合。切换下面的论域看看。

Facts. (i) There is a single formula Sat(M, E, k, s) such that ZF proves: for every set structure (M, E), formula code k ∈ ω and assignment s, Sat holds iff (M,E) ⊨ k[s] (Tarski's clauses, recursion on k). For each actual formula φ, ZF proves Sat(M, ∈, ⌜φ⌝, ā) ↔ φM(ā).
(ii) Tarski (L13): no formula T(k, s) satisfies T(⌜φ⌝, ā) ↔ φ(ā) in V for all φ.
(iii) For each fixed n ≥ 1, Σn-truth in V is definable by a Σn formula (L20). So the obstruction is uniformity over all n, not any single level. 事实. (i) 存在单独一条公式 Sat(M, E, k, s)，ZF 证明：对任意集合结构 (M, E)、公式编码 k ∈ ω 和赋值 s，Sat 成立当且仅当 (M,E) ⊨ k[s]（塔斯基条款，对 k 递归）。对每条具体公式 φ，ZF 证明 Sat(M, ∈, ⌜φ⌝, ā) ↔ φM(ā)。
(ii) 塔斯基（第 13 课）：不存在公式 T(k, s) 使得对所有 φ 都有 T(⌜φ⌝, ā) ↔ φ(ā) 在 V 中成立。
(iii) 对每个固定的 n ≥ 1，V 中的 Σn 真是可以用一条 Σn 公式定义的（第 20 课）。所以障碍在于对所有 n 一致地定义，而不在任何单独一层。
⚠ Common pitfall. Tarski does not say that the class OD is undefinable. It says the naive route, which goes through truth in V, is blocked. Step 3 takes another route to the same class. ⚠ 常见误区. 塔斯基定理并没有说 OD 这个类不可定义，它只说明经过“V 中的真”这条朴素路线走不通。第 3 步换一条路，得到的是同一个类。
Step 3第 3 步

The fix: reflect the definition down to some Vα修正：把定义反射到某个 Vα 上

Prerequisites预备: L20 · reflection theorem反射原理L14 · Vα§2

Suppose a formula φ (one actual formula, fixed in the metatheory) defines x in V from ordinals β1, β2. The reflection theorem says that for any β there is α > β such that φ is absolute between Vα and V. Climb α. A level counts only when three lamps are green at once. When they are, Vα is a set whose own truth already pins down x. 设某条公式 φ（元理论中固定的一条具体公式）在 V 中以序数 β1, β2 为参数定义出 x。反射原理说：对任意 β，存在 α > β 使 φ 在 Vα 与 V 之间绝对。来攀登 α。只有三盏灯同时变绿，这一层才算数。那时 Vα 是一个集合，而它自己的真已经足以确定 x。

    Illustration: the heights are schematic. In reality the reflecting α form a closed unbounded class of (limit) ordinals.示意图：高度只是示意。实际上能反射 φ 的 α 构成一个闭无界的（极限）序数类。

    Definition (in ZF, one formula). x ∈ OD :⇔ ∃α ∃k∈ω ∃β ∈ α<ω [ x ∈ Vα ∧ ∀z∈Vα ( Sat(Vα, ∈, k, z, β) ↔ z = x ) ].
    In words, x is OD iff x is definable over some set-structure (Vα, ∈) from ordinals < α. Here β ranges over finite sequences of ordinals < α (a single variable, since n may vary), and Sat takes the assignment z⌢β. Only Sat for set structures occurs, so this is a legitimate (in fact Σ2) formula and OD is a definable class.
    Metatheorem (schema). For each formula φ(z, y1,…,yn), ZF proves: ∀β ∈ Ord ∀x [ ∀z (φ(z, β) ↔ z = x) → x ∈ OD ].
    Conversely (a single theorem of ZF, no schema): if x ∈ OD, witnessed by α, k, β, then x is defined in V by the single formula χ(z, α, k, β) :≡ z ∈ Vα ∧ ∀z′∈Vα(Sat(Vα,∈,k,z′,β) ↔ z′ = z), whose parameters α, k, β are ordinals or a finite sequence of ordinals. (k ∈ ω is an ordinal too, and a finite sequence of ordinals can be coded by one ordinal via the definable pairing of Ord × Ord with Ord.)     定义（在 ZF 中，一条公式）. x ∈ OD :⇔ ∃α ∃k∈ω ∃β ∈ α<ω [ x ∈ Vα ∧ ∀z∈Vα ( Sat(Vα, ∈, k, z, β) ↔ z = x ) ]。
    也就是说，x 是 OD 当且仅当 x 在某个集合结构 (Vα, ∈) 上以小于 α 的序数为参数可定义。这里 β 跑遍由小于 α 的序数组成的有限序列（用单个变元表示，因为长度 n 可变），Sat 使用赋值 z⌢β。式中只出现集合结构的 Sat，所以这是一条合法的公式（实际上是 Σ2 公式），OD 是一个可定义类。
    元定理（模式）. 对每条公式 φ(z, y1,…,yn)，ZF 证明： ∀β ∈ Ord ∀x [ ∀z (φ(z, β) ↔ z = x) → x ∈ OD ]。
    反之（ZF 的单独一条定理，不是模式）：若 x ∈ OD，由 α, k, β 见证，则 x 在 V 中由单独一条公式 χ(z, α, k, β) :≡ z ∈ Vα ∧ ∀z′∈Vα(Sat(Vα,∈,k,z′,β) ↔ z′ = z) 定义，其参数 α、k、β 是序数或序数的有限序列（k ∈ ω 也是序数；序数的有限序列可借助 Ord × Ord 与 Ord 之间的可定义配对编码成单个序数）。

    Proof of the schema, step by step模式的证明，逐步展开

    1. Fix, in the metatheory, a formula φ(z, ȳ). Work in ZF: let β be ordinals and x a set with ∀z (φ(z, β) ↔ z = x). 1. 在元理论中固定一条公式 φ(z, ȳ)。在 ZF 中推理：设 β 是序数，x 是满足 ∀z (φ(z, β) ↔ z = x) 的集合。

    2. Reflection (this is where it is used). The reflection theorem for the single formula φ (with its subformulas) gives some α > max(rank(x), β1,…,βn) such that ∀z, ȳ ∈ Vα (φVα(z, ȳ) ↔ φ(z, ȳ)). Then x ∈ Vα and β ∈ Vα. 2. 反射（用在这里）. 对这一条公式 φ（连同其子公式）应用反射原理，得到某个 α > max(rank(x), β1,…,βn)，使 ∀z, ȳ ∈ Vα (φVα(z, ȳ) ↔ φ(z, ȳ))。于是 x ∈ Vα，β ∈ Vα。

    3. For z ∈ Vα: φVα(z, β) ⇔ φ(z, β) ⇔ z = x. So x is the unique element of Vα satisfying φVα(·, β). Uniqueness inside Vα also needed absoluteness: without it, Vα could contain a “fake” z′ ≠ x with φVα(z′, β). 3. 对 z ∈ Vα：φVα(z, β) ⇔ φ(z, β) ⇔ z = x。所以 x 是 Vα 中唯一满足 φVα(·, β) 的元素。Vα 内部的唯一性同样要用到绝对性：没有它，Vα 里可能出现某个满足 φVα(z′, β) 的“冒牌” z′ ≠ x。

    4. By fact (i) of Step 2, φVα(z, β) ↔ Sat(Vα, ∈, ⌜φ⌝, z, β). Taking k = ⌜φ⌝ witnesses the defining formula of OD, so x ∈ OD. ∎ 4. 由第 2 步事实 (i)，φVα(z, β) ↔ Sat(Vα, ∈, ⌜φ⌝, z, β)。取 k = ⌜φ⌝ 即满足 OD 的定义公式，故 x ∈ OD。∎

    5. The converse needs no reflection. If x ∈ OD via (α, k, β), the formula χ above defines x in V. χ talks only about the set Vα, so no truth predicate for V is involved. 5. 反方向不需要反射. 若 x 由 (α, k, β) 见证属于 OD，上面的 χ 就在 V 中定义了 x。χ 只谈论集合 Vα，不涉及 V 的真谓词。

    ⚠ Common pitfall: schema vs single theorem. “Every set definable in V from ordinals is OD” is not one theorem of ZF. It is infinitely many theorems, one for each φ (each proof uses reflection for that φ). Also, inside ZF the variable k ranges over the set ω of formula codes. In a model whose ω is nonstandard, k may be a nonstandard “formula”; the class OD of that model is still perfectly well defined. ⚠ 常见误区：模式与单条定理. “在 V 中由序数可定义的集合都是 OD”不是 ZF 的一条定理，而是无穷多条定理，每个 φ 一条（每条的证明都对那个 φ 用一次反射）。另外，在 ZF 内部变元 k 跑遍的是公式编码的集合 ω。在 ω 非标准的模型中，k 可能是非标准的“公式”，但该模型里的类 OD 依然定义得好好的。
    Step 4第 4 步

    The Wikipedia formulation: S is defined in Vα₁ from α₂, …, αₙ维基百科的表述：S 在 Vα₁ 中由 α₂, …, αₙ 定义

    Prerequisites预备: §3L14 · rank
    Equivalent definition. S ∈ OD iff there are ordinals α1, …, αn and a formula φ such that S is the unique z ∈ Vα₁ with (Vα₁, ∈) ⊨ φ[z, α2, …, αn]. Here α2,…,αn < α1 is forced, because parameters must be elements of the structure and an ordinal β lies in Vα₁ iff β < α₁. This is Step 3's definition with α₁ = α. 等价定义. S ∈ OD 当且仅当存在序数 α1, …, αn 和公式 φ，使 S 是 Vα₁ 中满足 (Vα₁, ∈) ⊨ φ[z, α2, …, αn] 的唯一 z。这里必然有 α2,…,αn < α1：参数必须是结构中的元素，而序数 β 属于 Vα₁ 当且仅当 β < α₁。这正是第 3 步的定义，只是把 α 记作 α₁。

    Choose a target set S and climb α₁. Two things must be true at once: S has to be in the structure (rank(S) < α₁), and so do the parameters. The formulas used here are absolute for all Vα₁ above the threshold, so once a level works, every higher level on this ruler works too. That holds for these formulas, not for formulas in general (compare Step 3). 选一个目标集合 S，然后攀登 α₁。两件事要同时成立：S 必须在结构里（rank(S) < α₁），参数也必须在。这里用到的公式对门槛以上的所有 Vα₁ 都是绝对的，所以某一层一旦成功，尺子上更高的层也都成功。这是这些公式的性质，一般的公式未必如此（对照第 3 步）。

    Step 5第 5 步

    OD has a definable well-orderingOD 有一个可定义的良序

    Prerequisites预备: §3L8 · well-orders良序

    Every OD set has many definitions. Give each one its least definition. A definition is a triple (α, k, β), where α is least such that x is definable over Vα, then k is the least formula code that works over that Vα, then β is the lexicographically least parameter tuple for that k. Sorting by these keys orders all of OD. Press “Sort”, then click two rungs to see which key decides between them. 每个 OD 集合都有许多定义，给它挑出最小的那个。一个定义是三元组 (α, k, β)：先取最小的 α 使 x 在 Vα 上可定义，再取在该 Vα 上可用的最小公式编码 k，最后取该 k 下字典序最小的参数组 β。按这些关键字排序，就把整个 OD 排好了。点“排序”，再点两级梯子，看看是哪个关键字分出先后。

    The codes #k and the exact least α are made up for the picture. Real values depend on a fixed Gödel numbering. What matters is that every OD set has exactly one least key. The rung numbers only rank these ten sets: in the full order infinitely many OD sets lie between, e.g., 2 and ω. 图中的编码 #k 和最小 α 只是为了作图而设定的，真实数值取决于选定的哥德尔编码。要紧的是：每个 OD 集合恰有一个最小关键字。梯级编号只是这十个集合之间的名次：在完整的序里，例如 2 和 ω 之间还夹着无穷多个 OD 集合。

    Theorem (ZF). Let key(x) = (αx, kx, βx) be the least witness as above, and put x <OD y iff key(x) precedes key(y) lexicographically (α first, then k, then β lexicographically; the length n of β is determined by k). Then <OD is a definable well-ordering of the class OD. Each initial segment {y : y <OD x} is a set (a subset of Vαx+1). Hence the map F(x) = order type of {y : y <OD x} is a definable injection OD → Ord. It is in fact a bijection onto Ord, because OD ⊇ Ord is a proper class (Jech Ch. 13). 定理（ZF）. 令 key(x) = (αx, kx, βx) 为上述最小见证，定义 x <OD y 当且仅当 key(x) 按字典序先于 key(y)（先比 α，再比 k，再按字典序比 β；β 的长度 n 由 k 决定）。 则 <OD 是类 OD 上的一个可定义良序。每个前段 {y : y <OD x} 都是集合（是 Vαx+1 的子集）。因此映射 F(x) = {y : y <OD x} 的序型，是一个从 OD 到 Ord 的可定义单射。由于 OD ⊇ Ord 是真类，它其实是到 Ord 上的双射（Jech 第 13 章）。
    ⚠ Common pitfall. The lexicographic order on all finite sequences of ordinals is not a well-order: (1) > (0,1) > (0,0,1) > … descends forever. It is fine here because k fixes the length n, and lexicographic order on n-tuples of ordinals is a well-order. Also, this ordering uses no choice: every step is “take the least”. ⚠ 常见误区. 所有有限序数序列上的字典序不是良序：(1) > (0,1) > (0,0,1) > … 可以无穷下降。这里没问题，是因为 k 固定了长度 n，而 n 元序数组上的字典序是良序。此外，这个排序完全不用选择公理：每一步都只是“取最小”。
    Step 6第 6 步

    OD is not transitive, and (OD, ∈) can fail ExtensionalityOD 不传递，(OD, ∈) 还可能违反外延公理

    Prerequisites预备: §4L16 · Cohen reals科恩实数

    ℝ (here ℝ = P(ω)) is OD: it is defined without parameters. Its elements need not be OD. Start from L and add one Cohen real c. In L[c] the OD reals are exactly the constructible ones, and c is not OD. (This follows from the homogeneity of Cohen forcing: HODL[c] = L. See the theory of weakly homogeneous forcing in Jech.) Toggle the universe, then put on “OD glasses”, which show only OD sets. ℝ（这里取 ℝ = P(ω)）是 OD 的：不用任何参数就能定义。但它的元素未必是 OD 的。从 L 出发添加一个科恩实数 c。在 L[c] 中，OD 实数恰好就是可构成的实数，而 c 不是 OD 的。（这来自科恩力迫的齐性：HODL[c] = L，见 Jech 中关于弱齐性力迫的部分。）切换宇宙，再戴上只看得见 OD 集合的“OD 眼镜”。

    Facts (ZF). (a) OD need not be transitive: in L[c], ℝ ∈ OD but c ∈ ℝ, c ∉ OD. (b) The structure (OD, ∈) can fail Extensionality. In L[c], both ∅ and ℝ ∖ OD are OD, since OD is a definable class and so ℝ ∖ OD = {r ∈ ℝ : r ∉ OD} is definable without parameters. They are different sets, but neither has an OD element. (c) OD is closed under definability: anything definable from finitely many OD sets and ordinals is OD (combine their definitions). 事实（ZF）. (a) OD 未必传递：在 L[c] 中 ℝ ∈ OD，但 c ∈ ℝ 且 c ∉ OD。 (b) 结构 (OD, ∈) 可能违反外延公理。在 L[c] 中，∅ 与 ℝ ∖ OD 都是 OD：OD 是可定义类，所以 ℝ ∖ OD = {r ∈ ℝ : r ∉ OD} 无需参数即可定义。两者是不同的集合，却都没有 OD 元素。 (c) OD 对可定义性封闭：由有限个 OD 集合和序数可定义的集合仍是 OD（把它们的定义合起来即可）。
    ⚠ Common pitfall. “c is not OD” is a theorem about L[c]. In L itself every set is OD (V = L ⇒ V = OD). Whether a given real is OD depends on the universe you work in. Also, “every OD set of reals is a set of OD reals” is false: ℝ in L[c] is a counterexample. ⚠ 常见误区. “c 不是 OD”是关于 L[c] 的定理。在 L 中每个集合都是 OD（V = L ⇒ V = OD）。一个实数是否为 OD，取决于你在哪个宇宙里工作。另外，“每个 OD 实数集都只含 OD 实数”是错的：L[c] 中的 ℝ 就是反例。
    Step 7第 7 步

    HOD: hereditarily ordinal definable setsHOD：遗传序数可定义集

    Prerequisites预备: §6L14 · transitive closure传递闭包
    Definition. x ∈ HOD :⇔ trcl({x}) ⊆ OD, i.e. x is OD, its elements are OD, their elements are OD, and so on all the way down. 定义. x ∈ HOD :⇔ trcl({x}) ⊆ OD，即 x 是 OD，x 的元素是 OD，元素的元素也是 OD，一直到底。

    Choose a set (universe: L[c]). The checker walks down its ∈-tree, which is trcl({x}) drawn with infinitely many elements grouped. Every node it visits must be OD. 选一个集合（宇宙：L[c]）。检查器沿它的 ∈-树往下走，这棵树就是 trcl({x})，无穷多个元素按类归并画出。访问到的每个节点都必须是 OD。

    Where HOD sitsHOD 的位置

    Theorem (ZF). (1) HOD is a transitive class: if x ∈ HOD and y ∈ x then trcl({y}) ⊆ trcl({x}) ⊆ OD. (2) Ord ⊆ HOD, since each ordinal is OD and its elements are ordinals. (3) HOD ⊆ OD, but in general OD ⊄ HOD (ℝ in L[c]). (4) L ⊆ HOD ⊆ V: HOD is an inner model (Step 8), and L is the smallest inner model. 定理（ZF）. (1) HOD 是传递类：若 x ∈ HOD 且 y ∈ x，则 trcl({y}) ⊆ trcl({x}) ⊆ OD。(2) Ord ⊆ HOD：每个序数都是 OD，而它的元素也都是序数。(3) HOD ⊆ OD，但一般 OD ⊄ HOD（L[c] 中的 ℝ）。(4) L ⊆ HOD ⊆ V：HOD 是内模型（第 8 步），而 L 是最小的内模型。
    Intuition. OD is “ordinal definable at the top level only”. HOD asks the same at every level of the tree. That repairs both defects of Step 6: transitivity, and with it Extensionality. 直观. OD 只要求“最上面一层”序数可定义，HOD 则要求树的每一层都如此。这就修补了第 6 步的两个缺陷：传递性，以及随之而来的外延性。
    Step 8第 8 步

    HOD ⊨ ZFC, even when V ⊭ ACHOD ⊨ ZFC，即使 V ⊭ AC

    Prerequisites预备: §5§7L15 · Gödel operations哥德尔运算L10 · AC
    ZF ⊢Theorem (Gödel; Myhill–Scott; Jech Thm 13.26). HOD is a transitive class model of ZFC containing all ordinals. Precisely, for each axiom σ of ZFC, ZF ⊢ σHOD. Corollary: Con(ZF) ⇒ Con(ZFC). This is a second proof, alongside the one via L. ZF ⊢定理（哥德尔；Myhill–Scott；Jech 定理 13.26）. HOD 是包含所有序数的传递类模型，且满足 ZFC。确切地说，对 ZFC 的每条公理 σ，都有 ZF ⊢ σHOD。推论：Con(ZF) ⇒ Con(ZFC)。这是继 L 之后的第二个证明。

    1. Transitive and contains Ord. Shown in Step 7.1. 传递且包含 Ord. 见第 7 步。

    2. Closed under Gödel operations. If x, y ∈ HOD then each Gödel operation Gi(x, y) is definable from x and y, so it is OD (Step 6(c)). Its elements are built from elements of trcl({x, y}) by the same operations (pairs, products, …), so they are OD as well, and Gi(x, y) ∈ HOD. 2. 对哥德尔运算封闭. 若 x, y ∈ HOD，则每个哥德尔运算 Gi(x, y) 都由 x、y 可定义，因而是 OD（第 6 步 (c)）。它的元素由 trcl({x, y}) 中的元素经同样的运算（配对、乘积……）造出，也都是 OD，所以 Gi(x, y) ∈ HOD。

    3. Almost universal. If X ⊆ HOD is a set, pick α with X ⊆ Vα. Then Y = HOD ∩ Vα is OD (definable from α), all its elements are in HOD, so Y ∈ HOD and X ⊆ Y. 3. 几乎全域. 若 X ⊆ HOD 是集合，取 α 使 X ⊆ Vα。则 Y = HOD ∩ Vα 由 α 可定义，是 OD；它的元素都在 HOD 中，所以 Y ∈ HOD，且 X ⊆ Y。

    4. ZF. A transitive class closed under Gödel operations and almost universal is a model of ZF (Jech Thm 13.9; this is the same criterion used for L). 4. ZF. 对哥德尔运算封闭且几乎全域的传递类是 ZF 的模型（Jech 定理 13.9；L 用的也是这一判据）。

    5. AC, without using AC. Let x ∈ HOD. The relation R = <OD ∩ (x × x) is a well-ordering of x (x ⊆ HOD ⊆ OD). R is OD (definable from x), and its elements are ordered pairs of HOD sets, so R ∈ HOD. HOD therefore sees a well-ordering of every set. No choice was used anywhere: Step 5's ordering only takes least elements. 5. 选择公理，而且不用选择公理. 设 x ∈ HOD。关系 R = <OD ∩ (x × x) 是 x 上的良序（x ⊆ HOD ⊆ OD）。R 由 x 可定义，是 OD；它的元素是 HOD 集合构成的有序对，所以 R ∈ HOD。于是 HOD 能看到每个集合上的良序。整个过程没有用选择：第 5 步的排序只是“取最小”。

    Where do failures of AC live? Outside HOD: Cohen's symmetric model选择公理的失效在哪里？在 HOD 之外：科恩的对称模型

    Cohen's model of ZF + ¬AC: force over L to add Cohen reals a0, a1, …, and let A = {an : n ∈ ω} (an unordered set). The model N consists of the sets hereditarily definable in L[G] from ordinals, A, and finitely many elements of A. This is a relative HOD; Jech presents it equivalently as a symmetric model. Each set in N has a finite support S ⊆ A, and it is fixed by every automorphism that fixes S pointwise. (Formally the automorphisms permute the coordinates of the forcing and act on names.) Pin a support, then apply automorphisms. 科恩的 ZF + ¬AC 模型：在 L 上力迫加入科恩实数 a0, a1, …，令 A = {an : n ∈ ω}（一个无序集合）。模型 N 由在 L[G] 中由序数、A 以及 A 的有限个元素遗传可定义的集合组成。这是一个相对化的 HOD，Jech 用等价的对称模型方式来表述它。N 中每个集合都有一个有限支撑 S ⊆ A，凡逐点固定 S 的自同构都保持它不变。（形式上，这些自同构置换力迫的坐标，并作用在名字上。）先钉住一个支撑，再施加自同构。

    Moral. A well-ordering of A would have a finite support S. Take two reals outside S and swap them: the ordering is moved, which is a contradiction. So N ⊨ “A cannot be well-ordered”, while HODN ⊨ ZFC still holds by the theorem above. A itself is not in HODN: otherwise HODN ⊨ AC would give a well-ordering of A that lies in HODN ⊆ N. The failure of AC lives outside HOD. 启示. A 上若有良序，它就有有限支撑 S。在 S 之外取两个实数对换，这个良序就被移动了，矛盾。所以 N ⊨ “A 不可良序化”，而由上面的定理，HODN ⊨ ZFC 依然成立。A 本身不在 HODN 中：否则由 HODN ⊨ AC，A 会有一个属于 HODN ⊆ N 的良序。选择公理的失效发生在 HOD 之外。
    ⚠ Common pitfall. Do not read “HOD ⊨ AC” as “HOD proves AC holds in V”. AC is a statement about all sets of V, and HOD may miss many of them. Also, ZF + ¬AC is not obtained from HOD; HOD only yields models of AC. ¬AC needs forcing (symmetric models). ⚠ 常见误区. 不要把“HOD ⊨ AC”读成“HOD 证明了 V 中 AC 成立”。AC 谈的是 V 中所有集合，而 HOD 可能漏掉很多集合。另外，ZF + ¬AC 的模型不是从 HOD 得到的，HOD 只能给出满足 AC 的模型；¬AC 要靠力迫（对称模型）。
    Step 9第 9 步

    V = HOD: equivalences, separations, non-absolutenessV = HOD：等价形式、分离例子与非绝对性

    Prerequisites预备: §8L15 · V = LL16 · forcing力迫
    ZF ⊢Theorem. The following are equivalent: (a) V = OD; (b) V = HOD; (c) there is a well-ordering of V definable with ordinal parameters; (d) there is a well-ordering of V definable without parameters. Moreover V = L ⇒ V = HOD ⇒ AC. ZF ⊢定理. 以下等价：(a) V = OD；(b) V = HOD；(c) V 上存在一个以序数为参数可定义的良序；(d) V 上存在一个无参数可定义的良序。此外 V = L ⇒ V = HOD ⇒ AC。

    (a)⇔(b). HOD ⊆ OD always. If V = OD, every element of every trcl is OD, so V = HOD.(a)⇔(b). 总有 HOD ⊆ OD。若 V = OD，则任何传递闭包的元素都是 OD，故 V = HOD。

    (a)⇒(d). <OD is parameter-free definable (Step 5) and is then a well-ordering of all of V.(a)⇒(d). <OD 无需参数即可定义（第 5 步），这时它就是整个 V 的良序。

    (c)⇒(a). Let ◁ be a well-ordering of V defined by ψ(·,·,γ). Given x, let α = rank(x)+1. Then x is the δ-th element of Vα under ◁ for some ordinal δ, so x is defined in V from the ordinals α, δ, γ. By Step 3, x ∈ OD.(c)⇒(a). 设 ◁ 是由 ψ(·,·,γ) 定义的 V 的良序。给定 x，令 α = rank(x)+1，则对某个序数 δ，x 是 Vα 在 ◁ 下的第 δ 个元素，于是 x 在 V 中由序数 α、δ、γ 定义。由第 3 步，x ∈ OD。

    V = L ⇒ V = HOD. L ⊆ HOD always. V = HOD ⇒ AC. HOD ⊨ AC and HOD = V.V = L ⇒ V = HOD. 总有 L ⊆ HOD。V = HOD ⇒ AC. HOD ⊨ AC，而 HOD = V。

    The converses fail: pick a universe逆命题不成立：选一个宇宙看看

    ⚠ Common pitfall: “V = HOD” is not absolute. L always satisfies V = L, because LL = L. HOD need not satisfy V = HOD, because HOD computed inside HOD may be smaller. Con McAloon (1974) built models in which the iterated HODs HOD1 = HOD, HODn+1 = HODHODn strictly decrease for every n. In particular HODHOD ≠ HOD is consistent. (Harrington further showed that the intersection need not even be a class; the result appears in Zadrożny 1983. See Hamkins–Kirmayer–Perlmutter.) ⚠ 常见误区：“V = HOD”不是绝对的. L 总满足 V = L，因为 LL = L。但 HOD 未必满足 V = HOD：在 HOD 内部计算的 HOD 可能更小。Con McAloon（1974）构造了这样的模型：迭代 HOD HOD1 = HOD, HODn+1 = HODHODn 对每个 n 都严格递减。特别地，HODHOD ≠ HOD 是一致的。（Harrington 进一步证明了它们的交甚至可以不是类，该结果发表于 Zadrożny 1983；见 Hamkins–Kirmayer–Perlmutter。）
    Step 10第 10 步

    HOD and large cardinals: the HOD dichotomy and the HOD ConjectureHOD 与大基数：HOD 二分定理与 HOD 猜想

    Prerequisites预备: §9L9 · singular / regular奇异 / 正则L23–25 · large cardinals (ahead)大基数（后续）

    L cannot contain a measurable cardinal (Scott), so L is “far” from V once large cardinals exist. HOD is different. Every large cardinal axiom known to be compatible with AC was, classically, also known to be compatible with V = HOD (via McAloon-style coding forcing), so HOD can hold essentially all known large cardinals. Fine-structural core models, by contrast, have not yet been constructed for cardinals as strong as a supercompact. Two cautions. HOD need not inherit V's large cardinals: a supercompact of V can fail to be even weakly compact in HOD (Cheng–Friedman–Hamkins 2015). And in 2024 Aguilera–Bagaria–Lücke proposed new “exacting” cardinals that imply V ≠ HOD. Click the two branches. L 中不可能有可测基数（Scott），所以一旦有大基数，L 就离 V“很远”。HOD 不一样：按经典认识，凡是已知与 AC 相容的大基数公理，也都已知与 V = HOD 相容（用 McAloon 式的编码力迫），所以 HOD 能容纳几乎所有已知的大基数。相比之下，精细结构的核心模型至今还没能为超紧基数这样强的基数构造出来。有两点要注意。第一，HOD 未必继承 V 的大基数：V 中的超紧基数在 HOD 中可以连弱紧都不是（Cheng–Friedman–Hamkins 2015）。第二，2024 年 Aguilera–Bagaria–Lücke 提出了新的“exacting”基数，它蕴涵 V ≠ HOD。点击两个分支。

    ZFC ⊢HOD Dichotomy (Woodin). Suppose δ is an extendible cardinal. Then exactly one of the following holds.
    (1) HOD is close to V: every singular cardinal γ > δ is singular in HOD, and (γ+)HOD = γ+.
    (2) HOD is far from V: every regular cardinal > δ is measurable in HOD. (Woodin's sharper form: they are ω-strongly measurable in HOD.)
    In case (1), HOD is moreover a weak extender model for the supercompactness of δ. This is an analogue of Jensen's covering dichotomy for L, but with no “0# for HOD” known.     ZFC ⊢HOD 二分定理（Woodin）. 设 δ 是可扩张基数，则以下恰有一条成立。
    (1) HOD 离 V 很近：每个奇异基数 γ > δ 在 HOD 中仍奇异，且 (γ+)HOD = γ+。
    (2) HOD 离 V 很远：每个大于 δ 的正则基数在 HOD 中都是可测基数。（Woodin 的更强形式：它们在 HOD 中是 ω-强可测的。）
    在情形 (1) 中，HOD 还是 δ 的超紧性的弱扩张子模型。这类似于 L 的詹森覆盖二分，只是目前不知道有任何“HOD 的 0#”。
    OPENHOD Hypothesis. There is a proper class of regular cardinals that are not ω-strongly measurable in HOD.
    HOD Conjecture (Woodin). The HOD Hypothesis is provable in ZFC + “there is an extendible cardinal”. Given an extendible, this amounts to saying that case (2) never occurs. The naming varies: some papers call the Hypothesis itself “the HOD Conjecture”. Whether the HOD Hypothesis is provable (from ZFC, or from ZFC plus large cardinals) is open.
    Conditional Aguilera–Bagaria–Lücke (arXiv 2024–25): an exacting cardinal above an extendible yields case (2). So if that hypothesis is consistent, the HOD Conjecture fails. Its consistency is not known.     未解决HOD 假设. 存在真类多个在 HOD 中不是 ω-强可测的正则基数。
    HOD 猜想（Woodin）. HOD 假设可以在 ZFC + “存在可扩张基数”中证明。在有可扩张基数的前提下，这等于说情形 (2) 永远不会出现。名称并不统一：有些文献直接把“HOD 假设”叫作“HOD 猜想”。HOD 假设能否被证明（从 ZFC，或从 ZFC 加大基数公理）尚未解决。
    有条件 Aguilera–Bagaria–Lücke（arXiv 2024–25）：可扩张基数之上的一个 exacting 基数会导致情形 (2)。所以如果这一假设是一致的，HOD 猜想就不成立。但它是否一致，目前并不知道。
    ⚠ Common pitfall. Do not say “Woodin proved HOD is close to V” or “the HOD Conjecture was refuted”. Woodin proved the dichotomy, a ZFC theorem under an extendible. Which side holds is the open problem, and the 2024 work is a conditional refutation. ⚠ 常见误区. 不要说“Woodin 证明了 HOD 离 V 很近”，也不要说“HOD 猜想已被推翻”。Woodin 证明的是二分定理，即在有可扩张基数时的一条 ZFC 定理。究竟哪一边成立，才是未解决的问题；2024 年的工作只是有条件的反驳。
