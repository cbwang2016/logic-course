Large Cardinals II: Measurables & Elementary Embeddings大基数（二）：可测基数与初等嵌入

A measurable cardinal is defined by a voting system on its subsets. From that voting system we build a copy of the whole universe, and a map j: V → M that fixes every set in Vκ (in particular every ordinal below κ) and moves κ. Each step adds one idea and gives you something to click. 可测基数是用它的子集上的一套投票制度来定义的。从这套投票制度出发，我们能造出整个宇宙的一个副本，以及一个映射 j: V → M：它固定 Vκ 中的每个集合（特别是 κ 以下的每个序数），却把 κ 本身挪走。每一步只讲一个想法，都配有可以上手操作的图。

Legend for status tags. ZFC provable in ZFC · Con consistent relative to the stated hypothesis · ≡ equiconsistent · open unsolved. “A ⇒ B” always means: ZFC proves that A implies B. 标签说明. ZFC 可在 ZFC 中证明 · Con 相对于所述假设一致 · ≡ 等一致 · open 未解决。“A ⇒ B”一律指：ZFC 证明 A 蕴涵 B。
§1

Filters and ultrafilters: voting on a finite set滤子与超滤：有限集上的投票

Prerequisites前置知识: L10 · AC & ultrafilters选择公理与超滤

Core idea: a filter is a family of “decisive coalitions” (“large” sets). An ultrafilter decides every question. On a finite set, every ultrafilter has a dictator. 核心想法：滤子就是一族“有决定权的联盟”（“大”集合）。超滤对每一个问题都作出裁决。在有限集上，每个超滤都有一位独裁者。

Definition. Let X ≠ ∅. A filter on X is a family F ⊆ 𝒫(X) with
(F1) X ∈ F and ∅ ∉ F;
(F2) if A ∈ F and A ⊆ B ⊆ X then B ∈ F (upward closed);
(F3) if A, B ∈ F then A ∩ B ∈ F.
F is an ultrafilter if moreover (U) for every A ⊆ X: A ∈ F or X∖A ∈ F (by F1+F3, never both). The ultrafilter {A ⊆ X : x₀ ∈ A} is the principal ultrafilter at x₀; an ultrafilter of any other form is non-principal. 定义. 设 X ≠ ∅。X 上的滤子是满足下列条件的子集族 F ⊆ 𝒫(X)：
(F1) X ∈ F 且 ∅ ∉ F；
(F2) 若 A ∈ F 且 A ⊆ B ⊆ X，则 B ∈ F（向上封闭）；
(F3) 若 A, B ∈ F，则 A ∩ B ∈ F。
若还满足 (U)：对每个 A ⊆ X，A ∈ F 或 X∖A ∈ F（由 F1、F3 知二者不会同时成立），则称 F 为超滤。超滤 {A ⊆ X : x₀ ∈ A} 称为在 x₀ 处的主超滤；不是这种形式的超滤称为非主超滤。

Below, the four voters X = {1,2,3,4} and all 16 coalitions form a lattice. Click coalitions to put them into (or out of) your family F. The checker tests F1–F3 and (U) live, and marks the coalitions that break a rule. 下图中，四位投票人 X = {1,2,3,4} 的全部 16 个联盟排成一个格。点击联盟可以把它放进（或移出）你的子集族 F。检查器实时检验 F1–F3 和 (U)，并标出违反规则的联盟。

Theorem ZF. Every ultrafilter on a finite set X is principal. Proof. U is finite, so B = ⋂U is a finite intersection and lies in U by (F3); B ≠ ∅ by (F1). If b ∈ B and {b} ∉ U, then X∖{b} ∈ U by (U), so B ⊆ X∖{b}, contradicting b ∈ B. Hence {b} ∈ U and, by (F2), U contains every set containing b; by (F1)+(F3) it contains no set missing b. ∎ 定理 ZF. 有限集 X 上的每个超滤都是主超滤。证明. U 是有限族，故 B = ⋂U 是有限交，由 (F3) 属于 U；由 (F1)，B ≠ ∅。若 b ∈ B 而 {b} ∉ U，由 (U) 得 X∖{b} ∈ U，于是 B ⊆ X∖{b}，与 b ∈ B 矛盾。所以 {b} ∈ U；由 (F2)，U 含所有包含 b 的集合；由 (F1)+(F3)，U 不含任何不包含 b 的集合。∎
⚠ Common pitfall. “Majority rule” is not a filter: {1,2,3} and {2,3,4} are majorities, but their intersection {2,3} is not (F3 fails). Also, (U) alone is not enough: the family of all sets with ≥ 2 voters contains A or X∖A for every A ⊆ {1,2,3,4}, yet {1,2} ∩ {3,4} = ∅ breaks (F3). Check every axiom. ⚠ 常见误区. “多数决”不是滤子：{1,2,3} 与 {2,3,4} 都是多数，交集 {2,3} 却不是（F3 不成立）。另外，单有 (U) 也不够：“至少 2 人的联盟”这一族对每个 A ⊆ {1,2,3,4} 都含 A 或 X∖A，但 {1,2} ∩ {3,4} = ∅ 破坏了 (F3)。每条公理都要逐一检验。
§2

Non-principal ultrafilters on ℕ: they exist, but nobody can show you oneℕ 上的非主超滤：它存在，但谁也拿不出一个来

Prerequisites前置知识: §1 L10 · Zorn's lemma佐恩引理

Core idea: on ℕ an ultrafilter can avoid every finite set. Then it must contain all cofinite sets, and it has to make infinitely many free choices that no finite rule can make for it. 核心想法：在 ℕ 上，超滤可以不含任何有限集。这时它必然包含所有余有限集，并且要作无穷多次自由选择，这些选择没有任何有限规则能替它作出。

Facts. (a) ZF An ultrafilter U on ℕ is non-principal ⇔ U contains no finite set ⇔ U contains every cofinite set (U extends the Fréchet filter {A : ℕ∖A finite}).
(b) ZFC Ultrafilter lemma: every filter extends to an ultrafilter (Zorn: a maximal filter is ultra). Applied to the Fréchet filter, this gives a non-principal ultrafilter on ℕ.
(c) Con Without choice this can fail: if ZF is consistent, so is ZF + “every ultrafilter on ℕ is principal” (Feferman 1965). So any proof that a non-principal ultrafilter exists must use some form of choice, and no explicit construction can be carried out in ZF. 事实. (a) ZF ℕ 上的超滤 U 是非主的 ⇔ U 不含有限集 ⇔ U 包含每个余有限集（即 U 扩张了弗雷歇滤子 {A : ℕ∖A 有限}）。
(b) ZFC 超滤引理：每个滤子都能扩张为超滤（佐恩引理：极大滤子必是超滤）。用到弗雷歇滤子上，就得到 ℕ 上的非主超滤。
(c) Con 没有选择公理时这可能不成立：若 ZF 一致，则 ZF +“ℕ 上的每个超滤都是主超滤”也一致（Feferman 1965）。所以任何证明非主超滤存在的论证都必须用到某种形式的选择，在 ZF 中不可能给出明确的构造。

Be the ultrafilter. For each set below, decide whether it or its complement is “large”. U must also contain every cofinite set. The 12-hour clock shows which residues mod 12 are still alive in the intersection of everything you have chosen. The sets here are all periodic mod 12 up to a finite error, so a finite intersection of them is infinite exactly when some residue is still alive. If a choice would kill every residue, it is forced the other way. 你来当超滤. 对下面每个集合，决定它和它的补集哪一个是“大”的。U 还必须包含所有余有限集。12 点钟面显示：在你选出的所有集合的交中，哪些模 12 的余数还“活着”。这里的集合除有限个例外之外都是模 12 周期的，所以它们的有限交是无穷集，当且仅当还有余数活着。如果某个选择会让所有余数死光，它就被强制选另一边。

⚠ Common pitfall. The game only decides U on a finite Boolean algebra of sets. A full ultrafilter decides all 2ℵ₀ subsets of ℕ, and there are 22ℵ₀ non-principal ultrafilters on ℕ. Zorn's lemma makes all these decisions at once, without telling you what they are. ⚠ 常见误区. 这个游戏只在一个有限的集合布尔代数上确定了 U。真正的超滤要对 ℕ 的全部 2ℵ₀ 个子集作出裁决，而 ℕ 上的非主超滤共有 22ℵ₀ 个。佐恩引理一下子作出所有这些裁决，却不告诉你裁决结果是什么。
§3

κ-completeness and measurable cardinalsκ-完全性与可测基数

Prerequisites前置知识: §2 L9 · cardinals基数

Core idea: a non-principal ultrafilter on ℕ is only closed under finite intersections. A measurable cardinal κ carries one that is closed under intersections of fewer than κ sets. 核心想法：ℕ 上的非主超滤只对有限交封闭。可测基数 κ 上有一个对少于 κ 个集合之交封闭的非主超滤。

Watch what goes wrong on ℕ. Every set ℕ∖{0,…,k−1} is cofinite, hence in U. Their intersection over all k is empty. 先看 ℕ 上出了什么问题。每个 ℕ∖{0,…,k−1} 都是余有限集，因而属于 U。可是对所有 k 取交，结果是空集。

k = 0
Definition. Let κ be an infinite cardinal. A filter F is κ-complete if for every γ < κ and every family {Xξ : ξ < γ} ⊆ F, we have ⋂ξ<γ Xξ ∈ F. (“ℵ₁-complete” = countably complete; every filter is ℵ₀-complete.)
Definition. A cardinal κ is measurable if κ is uncountable and there is a κ-complete non-principal ultrafilter on κ. 定义. 设 κ 为无穷基数。称滤子 F 是 κ-完全的，如果对每个 γ < κ 和每个子族 {Xξ : ξ < γ} ⊆ F，都有 ⋂ξ<γ Xξ ∈ F。（ℵ₁-完全即可数完全；任何滤子都是 ℵ₀-完全的。）
定义. 称基数 κ 为可测基数，如果 κ 不可数，并且 κ 上存在一个 κ-完全的非主超滤。
⚠ Common pitfalls. (1) “κ-complete” means closed under intersections of fewer than κ sets, never κ many: the κ sets κ∖{α} are all in U, but their intersection is ∅. (2) “Uncountable” is essential: ω carries non-principal ultrafilters, and every filter is trivially ω-complete. (3) If U is κ-complete and non-principal on κ, then no set of size < κ is in U, because such a set is a union of fewer than κ singletons. ⚠ 常见误区. (1) “κ-完全”指对少于 κ 个集合的交封闭，而不是 κ 个：κ 个集合 κ∖{α} 都在 U 中，交却是 ∅。(2) “不可数”这个条件不能少：ω 上有非主超滤，而任何滤子都平凡地 ω-完全。(3) 若 U 是 κ 上 κ-完全的非主超滤，则基数小于 κ 的集合都不在 U 中，因为这样的集合是少于 κ 个单点集的并。
Origin (briefly). Ulam (1930) asked about measures defined on all subsets of a set. Call κ real-valued measurable if there is a κ-additive probability measure on 𝒫(κ) vanishing on singletons. Ulam showed such a κ is either ≤ 2ℵ₀ or a (two-valued) measurable, and in ZFC: κ measurable ⇔ κ real-valued measurable and inaccessible. Solovay showed that “2ℵ₀ is real-valued measurable” is equiconsistent with a measurable cardinal ≡. In this lesson “measurable” always means the two-valued notion above. 来历（简述）. 乌拉姆（1930）研究定义在一个集合的全部子集上的测度。如果 𝒫(κ) 上有一个在单点集上为 0 的 κ-可加概率测度，就称 κ 为实值可测基数。乌拉姆证明：这样的 κ 要么 ≤ 2ℵ₀，要么是（二值）可测基数；并且在 ZFC 中，κ 可测 ⇔ κ 实值可测且不可达。索洛维证明“2ℵ₀ 是实值可测基数”与“存在可测基数”等一致 ≡。本课中“可测”一律指上面那种二值的概念。
§4

Measurable ⇒ regular strong limit ⇒ inaccessible可测 ⇒ 正则强极限 ⇒ 不可达

Prerequisites前置知识: §3 L23 · inaccessible不可达基数

Core idea: if 2λ ≥ κ, then κ distinct 0/1-strings of length λ can be told apart by λ coordinate questions. Taking the U-majority answer to every question singles out at most one string. That would put a set with at most one element into U. 核心想法：若 2λ ≥ κ，就有 κ 个互不相同的长度为 λ 的 0/1 串，它们可以用 λ 个“坐标问题”区分开。对每个问题都取 U 的多数答案，最终至多剩下一个串，于是一个至多含一个元素的集合进了 U。

Toy picture: 16 rows (playing the role of κ) are all the distinct 0/1-strings of length 4 (playing λ). For each column ξ, U contains exactly one of “rows with 0 at ξ” and “rows with 1 at ξ”. Click a column header to change U's vote there. Then run the intersection. 玩具图：16 行（扮演 κ）是长度 4（扮演 λ）的全部不同 0/1 串。对每一列 ξ，U 恰好包含“在 ξ 处为 0 的行”与“在 ξ 处为 1 的行”中的一个。点击列标题可以改变 U 在该列的投票，然后运行求交。

Theorem ZFC. If κ is measurable, then κ is regular and a strong limit (λ < κ ⇒ 2λ < κ); hence κ is (strongly) inaccessible. 定理 ZFC. 若 κ 可测，则 κ 正则且为强极限（λ < κ ⇒ 2λ < κ），因此 κ 是（强）不可达基数。

Step 1 · Small sets are null第 1 步 · 小集合不在 U 中

Fix a κ-complete non-principal ultrafilter U on κ. For each α, {α} ∉ U (non-principal), so κ∖{α} ∈ U. If |A| < κ, then κ∖A = ⋂α∈A(κ∖{α}) ∈ U by κ-completeness, so A ∉ U. 取定 κ 上 κ-完全的非主超滤 U。对每个 α，{α} ∉ U（非主），故 κ∖{α} ∈ U。若 |A| < κ，由 κ-完全性，κ∖A = ⋂α∈A(κ∖{α}) ∈ U，所以 A ∉ U。

Step 2 · Regular第 2 步 · 正则

Suppose κ = ⋃i<μ Ai with μ < κ and each |Ai| < κ. By Step 1 each κ∖Ai ∈ U, so ∅ = ⋂i<μ(κ∖Ai) ∈ U, contradicting (F1). So cf(κ) = κ. 设 κ = ⋃i<μ Ai，其中 μ < κ 且每个 |Ai| < κ。由第 1 步，每个 κ∖Ai ∈ U，于是 ∅ = ⋂i<μ(κ∖Ai) ∈ U，与 (F1) 矛盾。所以 cf(κ) = κ。

Step 3 · Strong limit: set up the matrix第 3 步 · 强极限：搭好矩阵

Suppose λ < κ ≤ 2λ. Choose distinct fα ∈ {0,1}λ for α < κ (the rows of the picture). For each column ξ < λ, the sets {α : fα(ξ)=0} and {α : fα(ξ)=1} partition κ, so exactly one is in U. Call it Xξ, and let ε(ξ) be its bit. 设 λ < κ ≤ 2λ。取互不相同的 fα ∈ {0,1}λ（α < κ，即图中的各行）。对每一列 ξ < λ，集合 {α : fα(ξ)=0} 与 {α : fα(ξ)=1} 构成 κ 的划分，恰有一个属于 U，记为 Xξ，并记它对应的比特为 ε(ξ)。

Step 4 · Intersect第 4 步 · 求交

X = ⋂ξ<λ Xξ ∈ U by κ-completeness, since λ < κ. But α ∈ X ⇔ fα = ε, and the rows are distinct, so |X| ≤ 1. This contradicts Step 1. Hence 2λ < κ. ∎ 因为 λ < κ，由 κ-完全性得 X = ⋂ξ<λ Xξ ∈ U。但 α ∈ X ⇔ fα = ε，而各行互不相同，所以 |X| ≤ 1，与第 1 步矛盾。因此 2λ < κ。∎
Much more is true ZFC: a measurable κ is weakly compact, Mahlo, Ramsey, and the set of weakly compact cardinals below κ belongs to every normal ultrafilter on κ, so κ is the κ-th weakly compact cardinal. With the embedding j these proofs become short (§8). 实际上还有更多结论 ZFC：可测基数 κ 是弱紧的、马洛的、拉姆齐的，并且 κ 以下弱紧基数之集属于 κ 上每个正规超滤，所以 κ 是第 κ 个弱紧基数。有了嵌入 j，这些证明都会变得很短（§8）。
⚠ Common pitfall. “Measurable ⇒ inaccessible” uses AC (we chose the rows, and AC is used throughout). Under ZF + AD, ω₁ is measurable, yet ω₁ is certainly not inaccessible. Everything in this lesson is in ZFC. ⚠ 常见误区. “可测 ⇒ 不可达”用到了选择公理。在 ZF + AD（决定性公理）下 ω₁ 是可测的，但 ω₁ 显然不是不可达基数。本课所有内容都在 ZFC 中进行。
§5

Ultrapowers and Łoś's theorem: truth by vote超幂与沃什定理：真假由投票决定

Prerequisites前置知识: §2 L3 · structures & truth结构与真 L5 · elementary maps初等映射

Core idea: a new object is a whole row f = (f(0), f(1), …) of old objects. A statement about rows is true exactly when the set of coordinates where it holds is in U. 核心想法：一个新对象是由旧对象组成的一整行 f = (f(0), f(1), …)。关于这些行的一个命题为真，当且仅当它成立的坐标之集属于 U。

Definition (ultrapower of the universe). Let U be an ultrafilter on κ. For functions f, g : κ → V put
f =U g ⇔ {α<κ : f(α) = g(α)} ∈ U,   f ∈U g ⇔ {α<κ : f(α) ∈ g(α)} ∈ U.
[f] is the =U-class of f, cut down to its members of least rank (Scott's trick, so that [f] is a set). Ult(V,U) = ({[f] : f : κ → V}, ∈U).
Łoś's theorem ZFC. For every formula φ(x₁,…,xₙ):
Ult(V,U) ⊨ φ([f₁],…,[fₙ]) ⇔ {α<κ : φ(f₁(α),…,fₙ(α))} ∈ U. 定义（宇宙的超幂）. 设 U 为 κ 上的超滤。对函数 f, g : κ → V，令
f =U g ⇔ {α<κ : f(α) = g(α)} ∈ U，  f ∈U g ⇔ {α<κ : f(α) ∈ g(α)} ∈ U。
[f] 是 f 的 =U-等价类中秩最小的那些成员组成的集合（斯科特技巧，保证 [f] 是集合）。Ult(V,U) = ({[f] : f : κ → V}, ∈U)。
沃什定理 ZFC. 对每个公式 φ(x₁,…,xₙ)：
Ult(V,U) ⊨ φ([f₁],…,[fₙ]) ⇔ {α<κ : φ(f₁(α),…,fₙ(α))} ∈ U。

A toy you can compute: the ultrapower of (ℕ, <, Even)一个能动手算的玩具：(ℕ, <, Even) 的超幂

Take U a non-principal ultrafilter on ℕ. Exactly one residue class {n : n ≡ r mod 6} is in U, because the six classes partition ℕ. For our rows (each is linear on each residue class mod 6), the set where a relation holds is, up to finitely many n, a union of residue classes. So knowing r is enough to compute every vote, even though U itself cannot be written down. Pick r, pick two rows, pick a relation. 取 ℕ 上的非主超滤 U。六个模 6 剩余类构成 ℕ 的划分，所以恰有一个剩余类 {n : n ≡ r mod 6} 属于 U。我们的各行在每个模 6 剩余类上都是线性的，因此关系成立的集合在除去有限个 n 之后是若干剩余类的并。所以只要知道 r，就能算出每一次投票的结果，尽管 U 本身写不出来。选好 r，选两行，再选一个关系。

⚠ Common pitfall (metamathematics). For the class ultrapower of V, Łoś's theorem is a schema: one theorem of ZFC for each formula φ. §6

Well-foundedness needs countable completeness; then collapse良基性需要可数完全性，然后坍塌

Prerequisites前置知识: §3 §5 L14 · Mostowski collapse莫斯托夫斯基坍塌

Core idea: in the toy ultrapower of ℕ there is an infinite descending chain. Countable completeness is exactly what forbids such chains. Once the ultrapower is well-founded, Mostowski collapse turns it into a transitive class M. 核心想法：ℕ 的玩具超幂里有无穷下降链。可数完全性恰好禁止这样的链。超幂一旦良基，莫斯托夫斯基坍塌就把它变成一个传递类 M。

The embedding j: V → M stretches the ordinals at κ嵌入 j: V → M 在 κ 处拉伸序数

Core idea: send each set x to the constant row c_x. By Łoś this map is elementary. It fixes every ordinal below κ, and it moves κ up to j(κ) > κ. 核心想法：把每个集合 x 送到常值行 c_x。由沃什定理，这个映射是初等的。它固定 κ 以下的每个序数，却把 κ 推高到 j(κ) > κ。

Theorem ZFC. Let U be a κ-complete non-principal ultrafilter on κ, M the collapse of Ult(V,U), and j = jU : V → M, j(x) = [c_x]. Then:
(1) j is elementary: V ⊨ φ(a₁,…,aₙ) ⇔ M ⊨ φ(j(a₁),…,j(aₙ)) (a schema, by Łoś). M is a transitive class containing all ordinals.
(2) j(α) = α for all α < κ; in fact j(x) = x for all x ∈ Vκ.
(3) κ < j(κ), so crit(j) = κ, the least ordinal moved. Moreover κ ≤ [id] < j(κ), with [id] = κ when U is normal.
(4) κM ⊆ M (M is closed under κ-sequences); in particular 𝒫(κ) ⊆ M.

(4) κM ⊆ M（M 对 κ-序列封闭）；特别地 𝒫(κ) ⊆ M。

U ∉ M: every ordinal below j(κ) is [f] for some f : κ → κ. ⚠ Common pitfall. j fixes every element of Vκ, but in general it moves sets outside Vκ. Core idea: the ultrafilter can be read back off the embedding. A set X ⊆ κ is “large” exactly when κ belongs to j(X). 核心想法：超滤可以从嵌入中读回来。集合 X ⊆ κ 是“大”的，当且仅当 κ 属于 j(X)。

Measurable ⇒ tree property可测 ⇒ 树性质

Let T be a κ-tree; WLOG its nodes are the ordinals below κ. Each level T_ξ (ξ < κ) has size < κ, and κ is regular, so T_ξ ∈ Vκ and j(T)_ξ = j(T_ξ) = T_ξ. Also j(<_T) ∩ (κ×κ) = <_T. Consequences: every singular cardinal of V is singular in L, λ⁺ = (λ⁺)L for every singular λ, and SCH holds. So either L is “close to” V, or 0♯ exists and every uncountable V-cardinal (e.g. ℵω) is inaccessible in L. Kunen ZFC：0♯ 存在 ⇔ 存在非平凡初等嵌入 j : L → L（j 是类，按 §8 的方式理解）。
Jensen 覆盖引理 ZFC：若 0♯ 不存在，则每个不可数序数集 X 都被某个 Y ∈ L 覆盖：X ⊆ Y 且 |Y| = |X|。推论：V 的每个奇异基数在 L 中也奇异；对每个奇异基数 λ，λ⁺ = (λ⁺)L；SCH 成立。所以，要么 L “贴近” V，要么 0♯ 存在，且 V 的每个不可数基数（例如 ℵω）在 L 中都是不可达的。
⚠ Common pitfall. “Between weakly compact and measurable” is about consistency strength, not about which cardinals are bigger. The least ω₁-Erdős cardinal is not weakly compact, and a Jónsson cardinal can be singular. Inaccessible, Mahlo and weakly compact cardinals are all consistent with V = L, but the existence of 0♯ is not. ⚠ 常见误区. “介于弱紧与可测之间”说的是一致性强度，而不是哪个基数更大。最小的 ω₁-埃尔德什基数不是弱紧的；琼森基数可以是奇异的。不可达、马洛、弱紧基数都与 V = L 相容，而 0♯ 的存在与 V = L 不相容。
§11

Inner models L[U] and the core model; the ladder so far内模型 L[U] 与核心模型；目前的阶梯

Prerequisites前置知识: §10 L15 · L L19 · projective hierarchy投影层级

Core idea: L is too thin for a measurable. Adding a single measure U gives L[U], the smallest canonical universe with a measurable cardinal. In it the measurable is unique and GCH holds. 核心想法：L 太“瘦”，容不下可测基数。加进一个测度 U，就得到 L[U]，这是含有可测基数的最小典范宇宙。在其中可测基数唯一，且 GCH 成立。

Inner model for one measurable ZFC. If U is a normal ultrafilter on κ, then in L[U] the set U ∩ L[U] is a normal ultrafilter on κ, so κ is measurable in L[U]. Moreover:
• Silver: L[U] ⊨ GCH.
• Kunen: in L[U], κ is the only measurable cardinal, and for each κ the model is unique: if L[U] ⊨ “U is a normal measure on κ” and L[W] ⊨ “W is a normal measure on κ”, then L[U] = L[W].
Core model idea. K is the largest “L-like” inner model compatible with the large cardinals that actually exist. Below 0♯, K = L (Jensen covering). Below an inner model with a measurable, the Dodd–Jensen core model satisfies a covering lemma of the same kind. Mitchell and later Steel extended this to stronger hypotheses (L25). 一个可测基数的内模型 ZFC. 若 U 是 κ 上的正规超滤，则在 L[U] 中 U ∩ L[U] 是 κ 上的正规超滤，所以 κ 在 L[U] 中可测。此外：
• Silver：L[U] ⊨ GCH。
• Kunen：在 L[U] 中 κ 是唯一的可测基数；并且对每个 κ 该模型唯一：若 L[U] ⊨“U 是 κ 上的正规测度”，L[W] ⊨“W 是 κ 上的正规测度”，则 L[U] = L[W]。
核心模型的想法. K 是与实际存在的大基数相容的、最大的“类 L”内模型。在 0♯ 以下，K = L（Jensen 覆盖）。在“存在含可测基数的内模型”以下，Dodd–Jensen 核心模型满足同类的覆盖引理。Mitchell 以及后来的 Steel 把这套理论推广到更强的假设（L25）。
Measurables and the reals ZFC (link to L19):
• Solovay (1965): if there is a measurable cardinal, every Σ¹₂ set of reals is Lebesgue measurable, has the Baire property and the perfect set property. Contrast: in L there is a Δ¹₂ set that is not Lebesgue measurable.
• Martin (1970): if there is a measurable cardinal, every Π¹₁ (co-analytic) game is determined. (Martin; Harrington: Π¹₁-determinacy is equivalent to “every real has a sharp”.) Projective determinacy needs Woodin cardinals (L25). 可测基数与实数 ZFC（见 L19）：
• Solovay（1965）：若存在可测基数，则每个 Σ¹₂ 实数集都是勒贝格可测的，具有贝尔性质和完美集性质。对照：在 L 中存在不勒贝格可测的 Δ¹₂ 集。
• Martin（1970）：若存在可测基数，则每个 Π¹₁（余解析）博弈都是决定的。（Martin；Harrington：Π¹₁-决定性等价于“每个实数都有升”。）投影决定性需要伍丁基数（L25）。
