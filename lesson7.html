Part II · Lesson 7

Building ℕ, ℤ, ℚ, ℝ from Sets用集合构造 ℕ、ℤ、ℚ、ℝ

Lesson 6 gave us safe construction rules. Now we use them to manufacture all of analysis from the empty set. Each number system is built from the previous one by a single idea: pairs, equivalence classes, or cuts. 第 6 课给了我们一套安全的构造规则。现在就用它们从空集出发，把整个分析学的地基造出来。每个数系都由前一个借助一个想法搭成：有序对、等价类，或者分割。

§1

Kuratowski ordered pairs库拉托夫斯基有序对

Definition. (a, b) := {{a}, {a, b}}. Characteristic property: (a, b) = (c, d) ⇔ a = c ∧ b = d. That property is all we ever use. The set itself is just a convenient implementation. 定义. (a, b) := {{a}, {a, b}}。基本性质：(a, b) = (c, d) ⇔ a = c ∧ b = d。我们用到的只有这条性质，那个集合本身不过是一种方便的实现方式。

Pick a, b and c, d (von Neumann numerals and a few other sets). Try to fool the definition: find two different pairs giving the same set. Compare with the naive attempt {a, b}. 选定 a, b 与 c, d（冯·诺伊曼自然数或其他几个集合）。试着骗过这个定义：找两个不同的有序对，使它们是同一个集合。再与天真的写法 {a, b} 比较。

Decoding p = (a, b) with ∈ only只用 ∈ 解码 p = (a, b)

Proof, case a = b. Then (a, a) = {{a}} has one member. If (c, d) = {{a}}, then {c} = {c, d} = {a}, so c = d = a.证明，情形 a = b. 此时 (a, a) = {{a}} 只有一个元素。若 (c, d) = {{a}}，则 {c} = {c, d} = {a}，故 c = d = a。

Case a ≠ b. Then (a, b) has two members, a singleton {a} and a doubleton {a, b}. So c ≠ d too (otherwise one member). Matching singletons: {c} = {a}, so c = a.情形 a ≠ b. 此时 (a, b) 有两个元素：单元素集 {a} 与二元集 {a, b}。所以也有 c ≠ d（否则只有一个元素）。单元素集对单元素集：{c} = {a}，故 c = a。

Matching doubletons: {a, d} = {a, b} with d ≠ a, so d = b. ∎二元集对二元集：{a, d} = {a, b} 且 d ≠ a，故 d = b。∎

With pairs we get everything relational: A × B = {p ∈ 𝒫(𝒫(A ∪ B)) : ∃a ∈ A ∃b ∈ B, p = (a, b)} (Power set + Separation, since {a}, {a, b} ⊆ A ∪ B). A relation is a subset of A × B, and a function is a relation in which each a has exactly one partner. 有了有序对，一切关系概念就都有了：A × B = {p ∈ 𝒫(𝒫(A ∪ B)) : ∃a ∈ A ∃b ∈ B, p = (a, b)}（幂集 + 分离公理，因为 {a}, {a, b} ⊆ A ∪ B）。关系就是 A × B 的子集，函数就是每个 a 恰有一个对应元的关系。

0 := ∅,   n + 1 := n ∪ {n}. So n = {0, 1, …, n − 1}: each number is the set of its predecessors, and has exactly n members. 0 := ∅，  n + 1 := n ∪ {n}。于是 n = {0, 1, …, n − 1}：每个数就是比它小的数组成的集合，恰有 n 个元素。

§3

ω, the smallest inductive set, and inductionω：最小的归纳集，以及数学归纳法

Definition. Let I be inductive (Axiom of Infinity). ω := {n ∈ I : n belongs to every inductive set} (Separation). It does not depend on the choice of I, it is inductive, and it is a subset of every inductive set: the smallest one, just like the set of formulas in Lesson 1. 定义. 设 I 是归纳集（无穷公理）。ω := {n ∈ I : n 属于每一个归纳集}（分离公理）。它与 I 的选取无关，本身是归纳集，并且包含于每个归纳集：它是最小的归纳集，和第 1 课里的公式集一模一样。

Induction = minimality归纳法 = 最小性

Principle of induction. If S ⊆ ω, 0 ∈ S, and n ∈ S ⇒ n + 1 ∈ S, then S = ω. Proof: S is inductive, so ω ⊆ S by minimality. Toggle numbers to build your own S. Any gap breaks the chain at a precise spot. 归纳原理. 若 S ⊆ ω，0 ∈ S，且 n ∈ S ⇒ n + 1 ∈ S，则 S = ω。证明：S 是归纳集，由最小性 ω ⊆ S。点击数字自己造一个 S。只要有缺口，链条就会在一个确定的位置断开。

§4

The recursion theorem: defining + and ·递归定理：定义 + 与 ·

Recursion Theorem. For any set A, any a ∈ A and any function g : A → A, there is a unique function h : ω → A with h(0) = a and h(n + 1) = g(h(n)). 递归定理. 对任意集合 A、任意 a ∈ A 和任意函数 g : A → A，存在唯一的函数 h : ω → A，使 h(0) = a 且 h(n + 1) = g(h(n))。

Fix m. Addition is the h with a = m, g = S: m + 0 = m, m + (k+1) = S(m + k). Multiplication uses a = 0, g(x) = x + m: m · 0 = 0, m · (k+1) = m · k + m. Watch the recursion unroll. 固定 m。加法就是取 a = m、g = S 得到的 h：m + 0 = m，m + (k+1) = S(m + k)。乘法取 a = 0、g(x) = x + m：m · 0 = 0，m · (k+1) = m · k + m。看递归一步步展开。

m = 3   n = 4

Proof sketch of the recursion theorem递归定理的证明梗概

1. Attempts. Call a function f an attempt if dom f = k for some k ∈ ω, f(0) = a (if k > 0), and f(i + 1) = g(f(i)) whenever i + 1 < k. Attempts are subsets of ω × A, so the set of all attempts exists (Power set + Separation). 1. 尝试函数. 称函数 f 为尝试，若对某个 k ∈ ω 有 dom f = k，f(0) = a（当 k > 0），并且只要 i + 1 < k 就有 f(i + 1) = g(f(i))。尝试都是 ω × A 的子集，所以全体尝试构成集合（幂集 + 分离公理）。

2. Attempts agree. By induction on i: any two attempts agree at every i in both domains. 2. 尝试彼此相容. 对 i 归纳：任意两个尝试在公共定义域的每个 i 上取值相同。

3. Attempts reach everywhere. By induction on k: an attempt with domain k exists (extend one with domain k by one more value using g). 3. 尝试可以无限延伸. 对 k 归纳：定义域为 k 的尝试总存在（用 g 把定义域为 k 的尝试再延长一位）。

4. Glue. h := ⋃{attempts}. By 2 it is a function, by 3 its domain is ω, and it satisfies the equations. Uniqueness: two solutions agree at 0, and agreement at n gives agreement at n + 1, so by induction they are equal. ∎ 4. 粘合. 令 h := ⋃{全体尝试}。由第 2 步它是函数，由第 3 步其定义域为 ω，且满足递归等式。唯一性：两个解在 0 处相等，在 n 处相等则在 n + 1 处相等，归纳即得处处相等。∎

§5

ℤ: equivalence classes of pairs of naturalsℤ：自然数对的等价类

Think of (a, b) as “a − b”, but define it without subtraction: (a, b) ~ (c, d) ⇔ a + d = b + c. This is an equivalence relation on ω × ω (transitivity uses cancellation for +), and ℤ := (ω × ω)/~. 把 (a, b) 想成“a − b”，但定义时不用减法：(a, b) ~ (c, d) ⇔ a + d = b + c。这是 ω × ω 上的等价关系（传递性要用加法消去律），而 ℤ := (ω × ω)/~。

Each lattice point is a pair (a, b). Click one: its whole equivalence class lights up, and it is a diagonal line. In add mode, click two points and see that the sum's class does not depend on which representatives you picked. 每个格点都是一个数对 (a, b)。点一个：它所在的整个等价类会亮起来，恰好是一条斜线。在加法模式下点两个点，可以看到和所在的类与代表元的选取无关。

[(a,b)] + [(c,d)] = [(a+c, b+d)]
[(a,b)] · [(c,d)] = [(ac+bd, ad+bc)]
[(a,b)] < [(c,d)] ⇔ a+d < b+c
n ↦ [(n, 0)] : ω ↪ ℤ
Operations are defined on representatives, so each definition comes with a duty: prove it is well-defined, i.e. independent of the representatives (try E6 for an operation that fails). 运算是借助代表元定义的，所以每个定义都附带一项义务：证明它良定义，即与代表元的选取无关（E6 里有一个不良定义的反例）。
§6

ℚ: equivalence classes of fractionsℚ：分数的等价类

On ℤ × (ℤ ∖ {0}) put (a, b) ~ (c, d) ⇔ a·d = b·c, and ℚ := (ℤ × (ℤ∖{0}))/~. Think of (a, b) as a/b. [(a,b)] + [(c,d)] = [(ad + bc, bd)], [(a,b)] · [(c,d)] = [(ac, bd)]. 在 ℤ × (ℤ ∖ {0}) 上令 (a, b) ~ (c, d) ⇔ a·d = b·c，而 ℚ := (ℤ × (ℤ∖{0}))/~。把 (a, b) 想成 a/b。[(a,b)] + [(c,d)] = [(ad + bc, bd)]，[(a,b)] · [(c,d)] = [(ac, bd)]。

Horizontal axis a, vertical axis b. Click a point: its class is every lattice point on the line through the origin. Each rational number is a line through the origin (minus the origin). 横轴为 a，纵轴为 b。点一个点：它的等价类就是过原点那条直线上的所有格点。每个有理数就是一条过原点的直线（去掉原点）。

Why b ≠ 0? The point (0, 0) satisfies a·0 = b·0 for every (a, b), so it would be equivalent to everything, and transitivity would collapse all of ℚ into one class. Transitivity uses cancellation of the nonzero d. 为什么要求 b ≠ 0？ 点 (0, 0) 对每个 (a, b) 都满足 a·0 = b·0，于是它与一切等价，传递性会把整个 ℚ 并成一个类。证明传递性时要消去非零的 d。
§7

ℝ: Dedekind cutsℝ：戴德金分割

Definition. A Dedekind cut is a set L ⊆ ℚ with (i) ∅ ≠ L ≠ ℚ; (ii) downward closed: q ∈ L, p < q ⇒ p ∈ L; (iii) no greatest element. ℝ := the set of all cuts (a subset of 𝒫(ℚ)), ordered by ⊆. Each rational r becomes the cut {q : q < r}. 定义. 戴德金分割是满足下列条件的集合 L ⊆ ℚ：(i) ∅ ≠ L ≠ ℚ；(ii) 向下封闭：q ∈ L, p < q ⇒ p ∈ L；(iii) 没有最大元。ℝ := 全体分割组成的集合（是 𝒫(ℚ) 的子集），按 ⊆ 排序。每个有理数 r 对应分割 {q : q < r}。

Drag the knife along the line of rationals. Blue ticks are in L, orange ticks are not. Then press √2 and zoom: no matter how far you zoom, no rational sits exactly at the cut. 沿着有理数直线拖动“刀”。蓝色刻度属于 L，橙色的不属于。然后按 √2 再放大：无论放大多少倍，切口处都找不到一个有理数。

Why √2 ∉ ℚ. If p² = 2q² in lowest terms, p is even, say p = 2r; then q² = 2r², so q is even too, which contradicts lowest terms. The set {q : q < 0 ∨ q² < 2} is a cut (no greatest element, because the inequality is strict), and since no rational has square exactly 2, its complement {q ≥ 0 : q² > 2} has no least element either: a gap in ℚ, which the cut itself fills. 为什么 √2 ∉ ℚ. 若 p² = 2q² 且为既约分数，则 p 是偶数，设 p = 2r；于是 q² = 2r²，q 也是偶数，与既约矛盾。集合 {q : q < 0 ∨ q² < 2} 是分割（不等式是严格的，所以没有最大元）；又因为没有平方恰为 2 的有理数，它的补集 {q ≥ 0 : q² > 2} 也没有最小元：这是 ℚ 中的一个缺口，而这个分割本身正好把它填上。

Least upper bounds: take the union最小上界：取并集即可

Cuts are ordered by inclusion, so the supremum of a nonempty family of cuts that is bounded above is simply their union (proof in E5). Add the cuts at 1, 1.4, 1.41, … one by one. Their union is exactly the √2 cut, a least upper bound that ℚ itself lacks. 分割按包含关系排序，所以一族非空且有上界的分割，其上确界就是它们的并集（证明见 E5）。逐个加入 1、1.4、1.41……处的分割，它们的并恰好就是 √2 分割。这个最小上界在 ℚ 里是找不到的。

§8

The alternative: Cauchy sequences另一条路：柯西列

A sequence (qₙ) of rationals is Cauchy if ∀ε ∈ ℚ⁺ ∃N ∀m, n ≥ N: |qₘ − qₙ| < ε. Two are equivalent if qₙ − rₙ → 0. Cantor's ℝ is the set of equivalence classes. It satisfies the same axioms as the Dedekind reals (a complete ordered field), and any two complete ordered fields are isomorphic, by a unique isomorphism. 有理数列 (qₙ) 称为柯西列，若 ∀ε ∈ ℚ⁺ ∃N ∀m, n ≥ N: |qₘ − qₙ| < ε。若 qₙ − rₙ → 0，则称两个柯西列等价。康托尔的 ℝ 就是等价类全体。它与戴德金实数满足同样的公理（完备有序域），而任意两个完备有序域都同构，且同构唯一。

Two different rational sequences heading for the same gap: decimal truncations of √2 and Newton's iteration q ↦ q/2 + 1/q. Drag ε: the band shows where the tail must stay. Each row is one term. 两个不同的有理数列奔向同一个缺口：√2 的十进制截断，以及牛顿迭代 q ↦ q/2 + 1/q。拖动 ε：色带标出数列尾部必须待在的范围。每一行是一项。

§9

How many? |ℕ| = |ℤ| = |ℚ| < |ℝ|有多少？|ℕ| = |ℤ| = |ℚ| < |ℝ|

Each construction embeds the previous system: n ↦ [(n,0)], z ↦ [(z,1)], r ↦ {q : q < r}. (Strictly speaking ℕ ⊄ ℤ as sets; we identify each system with its image.) Pairs and classes do not increase size, but cuts do. 每次构造都把前一个数系嵌入进来：n ↦ [(n,0)]，z ↦ [(z,1)]，r ↦ {q : q < r}。（严格说来，作为集合 ℕ ⊄ ℤ；我们把每个数系与它的像等同起来。）取数对、取等价类都不会让集合变大，取分割却会。

Exactly: |ℝ| = |𝒫(ℕ)| = 2ℵ₀. Cuts are subsets of the countable set ℚ, so |ℝ| ≤ 2ℵ₀. Conversely X ↦ Σn∈X 2·3−(n+1) injects 𝒫(ℕ) into ℝ. Whether anything lies strictly between ℵ₀ and 2ℵ₀ is the Continuum Hypothesis (Lesson 16). 准确地说：|ℝ| = |𝒫(ℕ)| = 2ℵ₀。分割是可数集 ℚ 的子集，所以 |ℝ| ≤ 2ℵ₀；反过来，X ↦ Σn∈X 2·3−(n+1) 把 𝒫(ℕ) 单射到 ℝ 中。ℵ₀ 与 2ℵ₀ 之间是否还有别的基数，就是连续统假设（第 16 课）。

E5The union of cuts is their supremum分割之并就是上确界

Claim. Let 𝒞 be a nonempty set of cuts, bounded above by a cut B (every L ∈ 𝒞 has L ⊆ B). Then U = ⋃𝒞 is a cut, and it is the least upper bound of 𝒞. Prove it, then compare. 命题. 设 𝒞 是一个非空的分割族，且有上界分割 B（每个 L ∈ 𝒞 都满足 L ⊆ B）。则 U = ⋃𝒞 是分割，并且是 𝒞 的最小上界。先自己证明，再对照。

(i) U ⊆ ℚ and U ≠ ∅. U exists by the Union axiom, and it is a subset of ℚ. Pick any L ∈ 𝒞 (𝒞 ≠ ∅). Then ∅ ≠ L ⊆ U.(i) U ⊆ ℚ 且 U ≠ ∅. 由并集公理 U 存在，且是 ℚ 的子集。任取 L ∈ 𝒞（𝒞 ≠ ∅），则 ∅ ≠ L ⊆ U。

U ≠ ℚ. Every L ⊆ B, so U ⊆ B ≠ ℚ.U ≠ ℚ. 每个 L ⊆ B，所以 U ⊆ B ≠ ℚ。

(ii) Downward closed. If q ∈ U and p < q, then q ∈ L for some L ∈ 𝒞, so p ∈ L ⊆ U.(ii) 向下封闭. 若 q ∈ U 且 p < q，则对某个 L ∈ 𝒞 有 q ∈ L，于是 p ∈ L ⊆ U。

(iii) No maximum. If q ∈ U, then q ∈ L for some L ∈ 𝒞. L has no maximum, so some r ∈ L has r > q, and r ∈ U.(iii) 无最大元. 若 q ∈ U，则对某个 L ∈ 𝒞 有 q ∈ L。L 没有最大元，故有 r ∈ L 使 r > q，而 r ∈ U。

Least upper bound. Each L ⊆ U, so U is an upper bound. If every L ∈ 𝒞 satisfies L ⊆ B′, then U ⊆ B′. Hence U = sup 𝒞, and (ℝ, ⊆) has the least-upper-bound property. ∎最小上界. 每个 L ⊆ U，所以 U 是上界。若每个 L ∈ 𝒞 都满足 L ⊆ B′，则 U ⊆ B′。所以 U = sup 𝒞，从而 (ℝ, ⊆) 具有最小上界性质。∎
