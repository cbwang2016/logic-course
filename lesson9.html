Part II · Lesson 9

Cardinals: ℵ numbers, cardinal arithmetic, cofinality基数：阿列夫数、基数运算、共尾性

Ordinals measure length; cardinals measure size. ω, ω+1 and ω² are different lengths, but they all have the same size. In this lesson we pick one representative for each size, then learn to add, multiply and exponentiate sizes, and find that exponentiation is where ZFC stops giving answers. 序数量“长度”，基数量“大小”。ω、ω+1、ω² 长度各不相同，大小却一样。本课先为每种大小挑一个代表，再学大小的加法、乘法和乘方，然后会发现：到了乘方这一步，ZFC 就答不上来了。

§1

Cardinals are initial ordinals基数就是初始序数

Definition. An ordinal κ is a cardinal (an initial ordinal) if it is not in bijection with any smaller ordinal β < κ. 定义. 序数 κ 称为基数（初始序数），如果它不与任何更小的序数 β < κ 等势。
Definition (uses AC). For any set X, its cardinality |X| is the least ordinal in bijection with X. AC (well-ordering theorem) guarantees such an ordinal exists, and the least one is automatically a cardinal. 定义（要用选择公理）. 对任意集合 X，它的基数 |X| 是与 X 等势的最小序数。选择公理（良序定理）保证这样的序数存在，而最小的那个自动是基数。

Below, the top row is an ordinal α drawn as matchsticks, and the bottom row is ℕ = ω. Press play to watch a bijection list α in ω steps. Every countably infinite ordinal is “ω in disguise” as far as size goes, so none of them except ω is a cardinal. (Finite ordinals are not touched by this: each natural number is a cardinal.) 下面上排是用火柴画的序数 α，下排是 ℕ = ω。按播放键，看一个双射如何用 ω 步把 α 数完。就“大小”而言，每个可数无穷序数都是“乔装的 ω”，所以除了 ω 本身，它们都不是基数。（有限序数不受影响：每个自然数都是基数。）

Consequences: every infinite cardinal is a limit ordinal (α+1 ≈ α for infinite α, by the Hilbert-hotel shift in the first picture), and the finite cardinals are exactly the natural numbers. 推论：每个无穷基数都是极限序数（无穷序数 α 满足 α+1 ≈ α，就是第一张图里“希尔伯特旅馆”式的平移），而有限基数恰好就是自然数。
§2

Cantor–Schröder–Bernstein: two injections give a bijection康托尔–施罗德–伯恩斯坦定理：两个单射给出一个双射

Theorem (ZF, no Choice). If f: A → B and g: B → A are both injective, then there is a bijection h: A → B. So |A| ≤ |B| and |B| ≤ |A| imply |A| = |B|. 定理（ZF，不用选择公理）. 若 f: A → B 与 g: B → A 都是单射，则存在双射 h: A → B。因此 |A| ≤ |B| 且 |B| ≤ |A| 蕴涵 |A| = |B|。

Follow the arrows backwards from any element. The arrows fall apart into chains of four kinds: chains that start in A, chains that start in B, finite cycles, and chains infinite in both directions. On each chain, pick f or g⁻¹ to pair everything up. 从任何一个元素出发，沿箭头往回追。所有箭头会分解成四类链：起点在 A 的链、起点在 B 的链、有限的圈、以及两头都无穷的链。在每条链上选用 f 或 g⁻¹，就能把元素一一配对。

Proof. For x in A or B, trace back: from a ∈ A go to g⁻¹(a) if it exists, from b ∈ B go to f⁻¹(b) if it exists. Either the trace stops at an element of A ∖ g[B] (an A-chain), or it stops at an element of B ∖ f[A] (a B-chain), or it never stops (a cycle or a ℤ-chain). Each element lies on exactly one chain, because f and g are injective. 证明. 对 A 或 B 中的元素往回追：a ∈ A 若有 g⁻¹(a) 就走过去，b ∈ B 若有 f⁻¹(b) 就走过去。追踪要么停在 A ∖ g[B] 的某个元素（A 链），要么停在 B ∖ f[A] 的某个元素（B 链），要么永不停止（圈或 ℤ 链）。由于 f、g 都是单射，每个元素恰好落在一条链上。
Define h(a) = f(a) if a lies on an A-chain, a cycle or a ℤ-chain, and h(a) = g⁻¹(a) if a lies on a B-chain (there every a ∈ A has a g-preimage). On each chain h is a bijection between its A-part and its B-part, so h is a bijection A → B. ∎ No choices were made, so this is a ZF proof. 定义：若 a 在 A 链、圈或 ℤ 链上，令 h(a) = f(a)；若 a 在 B 链上，令 h(a) = g⁻¹(a)（B 链上每个 a ∈ A 都有 g 原像）。在每条链上，h 是该链 A 部分与 B 部分之间的双射，所以 h: A → B 是双射。∎ 整个过程没有做任何选择，所以这是 ZF 中的证明。
§3

The ℵ hierarchy: ℵ₁ is the set of countable ordinals阿列夫序列：ℵ₁ 就是全体可数序数之集

Definition (by transfinite recursion, using Hartogs numbers from Lesson 8): ℵ₀ = ω,   ℵα+1 = ℵα⁺ = h(ℵα) (the least ordinal that does not inject into ℵα),   ℵλ = supα<λ ℵα for limit λ. We also write ωα for ℵα when we think of it as an ordinal. The infinite cardinals are exactly the ℵα. 定义（超限递归，用第 8 课的哈托格斯数）： ℵ₀ = ω，ℵα+1 = ℵα⁺ = h(ℵα)（不能单射到 ℵα 的最小序数），对极限序数 λ 令 ℵλ = supα<λ ℵα。把它当作序数看时也记作 ωα。无穷基数恰好就是这些 ℵα。

Click an ordinal: the marker shows where it sits on the (not to scale) ordinal line, and the readout gives its cardinality. Gold posts are cardinals; between two posts every ordinal has the size of the post on its left. 点击一个序数：标记会显示它在序数轴上的位置（不按比例），并给出它的基数。金色立柱是基数；两根立柱之间的每个序数，大小都等于左边那根立柱。

Why is ω₁ uncountable? ω₁ = h(ω) is the set of all countable ordinals. If ω₁ were countable it would be an element of itself. It is the first ordinal you can never reach by “countable means”: a countable sup of countable ordinals is still countable (using countable choice). ω₁ 为什么不可数？ω₁ = h(ω) 是全体可数序数之集。若 ω₁ 可数，它就会是自己的元素。它是用“可数手段”永远到不了的第一个序数：可数个可数序数的上确界仍然可数（要用可数选择）。
§4

κ · κ = κ: the Gödel pairing orderκ · κ = κ：哥德尔配对序

Order κ × κ like this: first by the maximum max(α, β), then lexicographically. Each square “shell” is walked in turn: along its top row, then up its right column. Play it on ω × ω, and click any cell to see the cells before it. 这样给 κ × κ 排序：先比最大值 max(α, β)，再按字典序比。于是一层层“方壳”依次走过：先沿顶上一行往右，再沿右边一列往上。在 ω × ω 上播放，点任意一个格子，看看排在它前面的格子。

(α, β) ◁ (γ, δ) ⇔ max(α,β) < max(γ,δ), or或 max equal and相等且 (α,β) <lex (γ,δ)
Key point: the cells before (α, β) all lie in the square (m+1) × (m+1), where m = max(α, β). In ω × ω that square is finite, so every proper initial segment is finite and the order type is exactly ω. 关键：排在 (α, β) 之前的格子都落在方块 (m+1) × (m+1) 中，其中 m = max(α, β)。在 ω × ω 里这个方块是有限的，所以每个真前段都有限，序型恰好是 ω。

The theorem for every infinite κ (proof sketch)对一切无穷基数 κ 成立（证明梗概）

Theorem (Hessenberg). For every infinite cardinal κ, |κ × κ| = κ. Induction on κ: suppose it holds for all infinite cardinals below κ. The order ◁ is a well-order of κ × κ. 定理（黑森贝格）. 对每个无穷基数 κ，|κ × κ| = κ。对 κ 归纳：设对小于 κ 的无穷基数都成立。序 ◁ 是 κ × κ 上的良序。
Take (α, β) ∈ κ × κ and let γ = max(α, β) + 1 < κ (κ is a limit ordinal). Its initial segment is contained in γ × γ, and |γ × γ| = |γ|·|γ| < κ: by induction if γ is infinite, trivially if finite. 任取 (α, β) ∈ κ × κ，令 γ = max(α, β) + 1 < κ（κ 是极限序数）。它的前段包含于 γ × γ，而 |γ × γ| = |γ|·|γ| < κ：γ 无穷时由归纳假设，γ 有限时显然。
So every proper initial segment of (κ × κ, ◁) has size < κ, hence the order type is ≤ κ, so |κ × κ| ≤ κ. The reverse inequality is obvious (α ↦ (α, 0)). ∎ 因此 (κ × κ, ◁) 的每个真前段的大小都 < κ，于是序型 ≤ κ，即 |κ × κ| ≤ κ。反向不等式显然（α ↦ (α, 0)）。∎
Corollary. If κ, λ are cardinals, at least one infinite and both nonzero, then κ + λ = κ · λ = max(κ, λ). (With μ = max: μ ≤ κ + λ ≤ μ + μ = 2·μ ≤ μ·μ = μ.) 推论. 若基数 κ, λ 中至少有一个无穷，且都不为零，则 κ + λ = κ · λ = max(κ, λ)。（记 μ = max：μ ≤ κ + λ ≤ μ + μ = 2·μ ≤ μ·μ = μ。）

§5

2κ > κ: Cantor's diagonal, one more time2κ > κ：再用一次康托尔对角线

Definition. κλ = |λκ|, the size of the set of all functions λ → κ. In particular 2κ = |𝒫(κ)|, by identifying a subset with its characteristic function. Cantor: no f: κ → 𝒫(κ) is onto, so κ < 2κ. 定义. κλ = |λκ|，即所有函数 λ → κ 构成的集合的大小。特别地，把子集与其特征函数等同，得 2κ = |𝒫(κ)|。康托尔：任何 f: κ → 𝒫(κ) 都不是满射，所以 κ < 2κ。

Here X = {0,1,2,3,4}. Row x shows the set f(x): click cells to toggle membership. The purple row is the diagonal set D = {x : x ∉ f(x)}. Try to make D equal to some row, for instance with the “copy D into row x” buttons. Each copy flips the diagonal cell, so D moves away again. 取 X = {0,1,2,3,4}。第 x 行表示集合 f(x)，点格子可切换隶属关系。紫色行是对角线集合 D = {x : x ∉ f(x)}。试着让 D 等于某一行，比如用“把 D 抄到第 x 行”按钮。每抄一次，对角格就跟着翻转，D 又跑开了。

|𝒫(X)| = 2⁵ = 32 subsets, only 5 rows. For infinite κ the counting argument is gone, but the diagonal argument still works word for word. |𝒫(X)| = 2⁵ = 32 个子集，却只有 5 行。κ 无穷时计数论证失效，但对角线论证一字不改照样成立。
§6

The continuum 2ℵ₀: CH, GCH and what ZFC cannot decide连续统 2ℵ₀：连续统假设、广义连续统假设与 ZFC 判定不了的事

CH (Continuum Hypothesis): 2ℵ₀ = ℵ₁, i.e. every infinite subset of ℝ is countable or the same size as ℝ.
GCH: 2κ = κ⁺ for every infinite cardinal κ. 连续统假设 CH：2ℵ₀ = ℵ₁，即 ℝ 的每个无穷子集要么可数，要么与 ℝ 等势。
广义连续统假设 GCH：对每个无穷基数 κ，2κ = κ⁺。
Gödel (1938): GCH holds in L, so ZFC cannot refute it, if ZFC is consistent (Lesson 15). Cohen (1963): forcing makes 2ℵ₀ = ℵ₂, so ZFC cannot prove CH, again if ZFC is consistent (Lesson 16). Easton (1970): for regular κ, the only ZFC constraints on κ ↦ 2κ are monotonicity and cf(2κ) > κ (König, §8). 哥德尔（1938）：GCH 在 L 中成立，所以只要 ZFC 相容，ZFC 就驳不倒它（第 15 课）。科恩（1963）：力迫法可以造出 2ℵ₀ = ℵ₂ 的模型，所以同样在 ZFC 相容的前提下，ZFC 证不出 CH（第 16 课）。伊斯顿（1970）：对正则基数 κ，ZFC 对函数 κ ↦ 2κ 的约束只有单调性和 cf(2κ) > κ（柯尼希定理，§8）。

Which values of 2ℵ₀ are possible? Click a rung of the ℵ ladder.2ℵ₀ 可能取哪些值？点击阿列夫梯子上的一级。

At singular cardinals things are different and deep. Silver: if GCH holds below a singular κ of uncountable cofinality, it holds at κ. Shelah: if ℵω is a strong limit, then 2ℵω < ℵω₄. 在奇异基数处情况大不相同，而且很深刻。西尔弗：若 GCH 在一个共尾性不可数的奇异基数 κ 以下处处成立，则它在 κ 处也成立。谢拉赫：若 ℵω 是强极限基数，则 2ℵω < ℵω₄。
§7

Cofinality: how many steps to reach the top?共尾性：要走多少步才能到顶？

Definition. A subset S ⊆ α is cofinal if it is unbounded in α: for every β < α there is s ∈ S with β ≤ s. The cofinality cf(α) is the least order type of a cofinal subset. A cardinal κ is regular if cf(κ) = κ and singular if cf(κ) < κ. 定义. 子集 S ⊆ α 称为共尾的，如果它在 α 中无界：对每个 β < α 都有 s ∈ S 使 β ≤ s。α 的共尾性 cf(α) 是共尾子集序型的最小值。基数 κ 称为正则基数，若 cf(κ) = κ；称为奇异基数，若 cf(κ) < κ。

The ℵ ladder: regular or singular?阿列夫梯子：正则还是奇异？

regular正则singular奇异unknown: cannot be proved to exist无法证明其存在
Facts. cf(α) is always a regular cardinal, and cf(cf(α)) = cf(α). For limit λ, cf(ℵλ) = cf(λ).事实. cf(α) 总是正则基数，且 cf(cf(α)) = cf(α)。对极限序数 λ，cf(ℵλ) = cf(λ)。
Successor cardinals are regular (AC): for infinite κ, if κ⁺ = ⋃i<μ Sᵢ with μ ≤ κ and each |Sᵢ| ≤ κ, then |κ⁺| ≤ κ·κ = κ by §4, a contradiction.后继基数都是正则的（选择公理）：对无穷基数 κ，若 κ⁺ = ⋃i<μ Sᵢ，μ ≤ κ 且每个 |Sᵢ| ≤ κ，则由 §4 得 |κ⁺| ≤ κ·κ = κ，矛盾。
§8

König's theorem: Σ κᵢ < Π λᵢ柯尼希定理：Σ κᵢ < Π λᵢ

Theorem (König, AC). If κᵢ < λᵢ for every i ∈ I, then Σi∈I κᵢ < Πi∈I λᵢ. 定理（柯尼希，选择公理）. 若对每个 i ∈ I 都有 κᵢ < λᵢ，则 Σi∈I κᵢ < Πi∈I λᵢ。

The proof is a block diagonal argument. The rows below are the elements of Σκᵢ: block i has κᵢ rows. Each row is an attempted element F(i, ξ) of Πλᵢ, a tuple whose i-th entry lies in λᵢ = {0, …, λᵢ−1}. Click cells to change the values. In block i, look only at column i (purple frames): those κᵢ values cannot cover all λᵢ possibilities, so pick a missing value for g(i). 证明是一个分块对角线论证。下面每一行是 Σκᵢ 的一个元素，第 i 块有 κᵢ 行。每一行是一个试图列出的 Πλᵢ 元素 F(i, ξ)，即一个元组，第 i 个分量取值于 λᵢ = {0, …, λᵢ−1}。点格子可以改值。在第 i 块只看第 i 列（紫框）：这 κᵢ 个值盖不住 λᵢ 种可能，所以从缺的值里挑一个作 g(i)。

Proof. Let F: Σκᵢ → Πλᵢ be any map, where Σκᵢ = ⋃ᵢ {i} × κᵢ. For each i, the set Vᵢ = {F(i, ξ)(i) : ξ < κᵢ} has size ≤ κᵢ < λᵢ, so (AC) choose g(i) ∈ λᵢ ∖ Vᵢ. Then g ∈ Πλᵢ differs from F(i, ξ) at coordinate i, for every (i, ξ). So F is not onto. Also Σκᵢ ≤ Πλᵢ (easy if all λᵢ ≥ 2), so the inequality is strict. ∎ 证明. 设 F: Σκᵢ → Πλᵢ 是任意映射，其中 Σκᵢ = ⋃ᵢ {i} × κᵢ。对每个 i，集合 Vᵢ = {F(i, ξ)(i) : ξ < κᵢ} 的大小 ≤ κᵢ < λᵢ，于是（用选择公理）取 g(i) ∈ λᵢ ∖ Vᵢ。则 g ∈ Πλᵢ，且对每个 (i, ξ)，g 与 F(i, ξ) 在第 i 个坐标上不同。所以 F 不是满射。又 Σκᵢ ≤ Πλᵢ（各 λᵢ ≥ 2 时容易验证），故严格不等式成立。∎
Corollary 1. κᵢ = 1, λᵢ = 2 for i < κ gives κ < 2κ: Cantor's theorem is the special case.推论 1. 取 κᵢ = 1，λᵢ = 2（i < κ），得 κ < 2κ：康托尔定理是它的特例。
Corollary 2. κ < κcf(κ) for infinite κ: write κ = Σi<cf κ κᵢ with κᵢ < κ, then Σκᵢ < Πi<cf κ κ = κcf κ. E.g. ℵωℵ₀ > ℵω.推论 2. 对无穷基数 κ，κ < κcf(κ)：把 κ 写成 Σi<cf κ κᵢ，κᵢ < κ，则 Σκᵢ < Πi<cf κ κ = κcf κ。例如 ℵωℵ₀ > ℵω。
Corollary 3. cf(2κ) > κ. If 2κ = Σi<κ μᵢ with all μᵢ < 2κ, König gives Σμᵢ < Πi<κ 2κ = 2κ·κ = 2κ, a contradiction. So 2ℵ₀ ≠ ℵω, since cf(ℵω) = ω.推论 3. cf(2κ) > κ。若 2κ = Σi<κ μᵢ，各 μᵢ < 2κ，由柯尼希定理 Σμᵢ < Πi<κ 2κ = 2κ·κ = 2κ，矛盾。所以 2ℵ₀ ≠ ℵω，因为 cf(ℵω) = ω。
