Part II · Lesson 6

Russell's Paradox & the ZF Axioms罗素悖论与 ZF 公理

“A set is any collection you can describe” sounds harmless, and it is inconsistent. This lesson watches it break, then rebuilds set theory from a short list of safe construction rules, each one a machine you can operate. “凡能描述的汇集都是集合”，听起来人畜无害，其实自相矛盾。本课先看它怎样崩塌，再用一小组安全的“构造规则”把集合论重建起来。每条规则都是一台可以亲手操作的机器。

§1

Naive comprehension and Russell's paradox朴素概括原则与罗素悖论

Naive comprehension (Frege). For every property φ(x) there is a set of exactly the things having it: ∃y ∀x (x ∈ y ↔ φ(x)). 朴素概括原则（弗雷格）. 对任意性质 φ(x)，都存在一个集合，恰好由具有该性质的对象组成：∃y ∀x (x ∈ y ↔ φ(x))。

Russell (1901) took φ(x) to be x ∉ x. The box below is R = {x : x ∉ x}. Click each candidate to send it to the door. The doorkeeper admits x exactly when x ∉ x. Save R for last. 罗素（1901）取 φ(x) 为 x ∉ x。下面的方框就是 R = {x : x ∉ x}。点击候选对象送到门口，门卫只在 x ∉ x 时放行。把 R 留到最后。

The formal version. Comprehension gives a y with ∀x (x ∈ y ↔ x ∉ x). Specialize the universal statement to x := y: y ∈ y ↔ y ∉ y, which is a propositional contradiction (p ↔ ¬p is unsatisfiable, Lesson 1). So naive comprehension proves everything and is useless. 形式化版本. 概括原则给出某个 y，使 ∀x (x ∈ y ↔ x ∉ x)。把全称命题特化到 x := y，得 y ∈ y ↔ y ∉ y。这是命题层面的矛盾（第 1 课：p ↔ ¬p 不可满足）。于是朴素概括原则什么都能推出，也就毫无用处。

Theorem (in ZF, no paradox). For every set A, the set RA = {x ∈ A : x ∉ x} is not a member of A. Proof: if RA ∈ A, then RA ∈ RA ⇔ RA ∉ RA, which is the diagonal cell. ∎ Russell's paradox is this theorem applied to a nonexistent “set of all sets”. 定理（在 ZF 中，不是悖论）. 对任意集合 A，集合 RA = {x ∈ A : x ∉ x} 不属于 A。证明：若 RA ∈ A，则 RA ∈ RA ⇔ RA ∉ RA，问题就出在对角线那一格。∎ 罗素悖论不过是把这条定理用到了一个并不存在的“全体集合之集”上。
§3

Sets as nested boxes and membership trees集合即嵌套的盒子与隶属树

In pure set theory everything is a set, and the empty box ∅ is where it all starts. A hereditarily finite set is a finite set whose members are hereditarily finite. You can draw one as nested boxes (a box holds its members) or as a tree (children = members). Type one, or pick a preset. (Digits are accepted as shorthand for von Neumann numerals: 0 = ∅, n+1 = n ∪ {n}.) 在纯集合论里一切都是集合，一切从空盒子 ∅ 开始。遗传有限集是指本身有限、且其元素也都是遗传有限集的集合。可以把它画成嵌套的盒子（盒子里装着它的元素），也可以画成树（子结点＝元素）。输入一个集合，或点选预设。（可以用数字作为冯·诺伊曼自然数的简写：0 = ∅，n+1 = n ∪ {n}。）

Extensionality: two drawings, one set外延公理：两幅图，同一个集合

Axiom of Extensionality. ∀x ∀y (∀z (z ∈ x ↔ z ∈ y) → x = y). A set is determined by its members alone. Order and repetition in how you write it mean nothing. 外延公理. ∀x ∀y (∀z (z ∈ x ↔ z ∈ y) → x = y)。集合完全由它的元素决定，写法上的次序和重复都无关紧要。
§4

The language of set theory has just one symbol: ∈集合论的语言只有一个符号：∈

ZF is a first-order theory (Lessons 3–5) in the language {∈}; equality is part of the logic. Every other symbol (⊆, ∅, ∪, ⋃, 𝒫, (a,b), “function”) is an abbreviation for a formula in ∈ and =. Press unfold to expand the purple abbreviations one layer at a time. The bar shows the formula's length. ZF 是语言 {∈} 上的一阶理论（见第 3–5 课），等号属于逻辑本身。其余一切符号（⊆、∅、∪、⋃、𝒫、(a,b)、“函数”）都只是用 ∈ 和 = 写成的公式的缩写。按展开，紫色的缩写会一层层被拆开，下方的条表示公式长度。

The membership relation is the only structure. A model of ZF is just a pair (M, E) where E is a binary relation on M, so everything in Lessons 3–5 (completeness, compactness, Löwenheim–Skolem) applies to set theory itself. That is why, if ZF is consistent, it has a countable model (Skolem's paradox, revisited in Lesson 14). 隶属关系是唯一的结构。ZF 的模型就是一个二元组 (M, E)，其中 E 是 M 上的二元关系。所以第 3–5 课的一切（完备性、紧致性、勒文海姆–斯科伦定理）都适用于集合论本身。正因如此，若 ZF 一致，则它有可数模型（斯科伦悖论，第 14 课再谈）。

§6

Separation instead of Comprehension用分离公理代替概括原则

Separation schema (Aussonderung). For each formula φ(x, p₁, …, pₙ) in which y is not free: ∀p₁…∀pₙ ∀A ∃y ∀x (x ∈ y ↔ (x ∈ A ∧ φ)). You may only filter an existing set A: {x ∈ A : φ(x)}. 分离公理模式. 对每个 y 不在其中自由出现的公式 φ(x, p₁, …, pₙ)：∀p₁…∀pₙ ∀A ∃y ∀x (x ∈ y ↔ (x ∈ A ∧ φ))。只允许对已有的集合 A 做筛选：{x ∈ A : φ(x)}。

Pick a set A and a property, then run the sieve. Members are tested one at a time; only those passing φ drop into the new set. 选一个集合 A 和一个性质，然后启动筛子。元素逐个接受检验，只有满足 φ 的才落入新集合。

A = φ(x) =
How Separation blocks Russell. The best you can form is RA = {x ∈ A : x ∉ x}, and §2 shows RA ∉ A. The argument no longer yields a contradiction; it yields a theorem: no set contains every set (proved in E4). Collections like “all sets” are proper classes: we may talk about them through formulas, but they are not objects of the theory. 分离公理如何挡住罗素悖论. 我们最多只能造出 RA = {x ∈ A : x ∉ x}，而 §2 已证 RA ∉ A。同样的论证不再导出矛盾，而是给出一条定理：不存在包含一切集合的集合（证明见 E4）。像“全体集合”这样的汇集叫真类：可以借助公式谈论它们，但它们不是理论中的对象。
§7

Replacement: the image of a set under a definable map替换公理：集合在可定义映射下的像

Replacement schema (Fraenkel). For each formula φ(x, y, p₁, …, pₙ): ∀p₁…∀pₙ ∀A [∀x ∈ A ∃!y φ(x, y) → ∃B ∀y (y ∈ B ↔ ∃x ∈ A φ(x, y))]. If φ defines a function on A, then its image F[A] is a set. 替换公理模式（弗兰克尔）. 对每个公式 φ(x, y, p₁, …, pₙ)：∀p₁…∀pₙ ∀A [∀x ∈ A ∃!y φ(x, y) → ∃B ∀y (y ∈ B ↔ ∃x ∈ A φ(x, y))]。只要 φ 在 A 上定义了一个函数，它的像 F[A] 就是集合。

Choose a domain and a rule. Arrows go from each x to F(x); collisions merge (Extensionality). Numerals abbreviate von Neumann sets here. 选定定义域和规则。箭头从每个 x 指向 F(x)；撞到一起的值会合并（外延公理）。这里用数字简写冯·诺伊曼集合。

Why it is needed. For finite sets, Pairing and Union already give images. Replacement matters for infinite ones: without it you cannot prove that {ω, 𝒫(ω), 𝒫(𝒫(ω)), …} is a set, nor that the ordinal ω + ω exists (Lesson 8). Indeed Vω+ω satisfies every axiom of Zermelo set theory Z but not Replacement. 为什么需要它. 对有限集，配对加并集就足以得到像。替换公理真正起作用的是无穷集：没有它，就证明不了 {ω, 𝒫(ω), 𝒫(𝒫(ω)), …} 是集合，也证明不了序数 ω + ω 存在（第 8 课）。事实上 Vω+ω 满足策梅洛集合论 Z 的所有公理，却不满足替换公理。
§8

Infinity: an inductive set exists无穷公理：存在归纳集

Axiom of Infinity. ∃I (∅ ∈ I ∧ ∀x (x ∈ I → x ∪ {x} ∈ I)). A set with this closure property is called inductive. 无穷公理. ∃I (∅ ∈ I ∧ ∀x (x ∈ I → x ∪ {x} ∈ I))。具有这种封闭性的集合叫做归纳集。

Each press applies the successor S(x) = x ∪ {x}: the new box contains copies of all the previous boxes. Switch to Zermelo's successor x ↦ {x} for comparison (it gives onion-like nesting). 每按一次就做一次后继运算 S(x) = x ∪ {x}：新盒子里装着之前所有的盒子。可以切换到策梅洛的后继 x ↦ {x} 作对比（得到洋葱式的层层包裹）。

Every finite stage is a set already, using Pairing and Union. The axiom's real content is the dotted ellipsis: it collects all stages into one set. Without it, the hereditarily finite sets Vω form a model of all the other ZFC axioms together with “every set is finite”, so (if ZFC is consistent) Infinity is independent of the rest. 每个有限阶段本身已经是集合，配对和并集就能造出来。这条公理真正的内容在于那串省略号：它把所有阶段一网打尽，收进同一个集合。没有它，遗传有限集全体 Vω 构成其余所有 ZFC 公理外加“每个集合都有限”的模型，所以（若 ZFC 一致）无穷公理独立于其余公理。
§9

Foundation (Regularity), and a preview of Choice正则公理（基础公理），以及选择公理预览

Axiom of Foundation. ∀x (x ≠ ∅ → ∃y (y ∈ x ∧ y ∩ x = ∅)). Every nonempty set has an ∈-minimal member, one sharing no element with the set. Consequences: no x ∈ x, no x ∈ y ∈ x, no infinite descending chain x₀ ∋ x₁ ∋ x₂ ∋ ⋯. 正则公理（基础公理）. ∀x (x ≠ ∅ → ∃y (y ∈ x ∧ y ∩ x = ∅))。每个非空集合都有一个 ∈-极小元，它与该集合没有公共元素。推论：不存在 x ∈ x，不存在 x ∈ y ∈ x，也不存在无穷递降链 x₀ ∋ x₁ ∋ x₂ ∋ ⋯。

The ∈-graph: an arrow u → v means u ∈ v. Click a node, then another, to toggle an arrow (click the same node twice for a loop u ∈ u). Red marks cycles, which Foundation forbids. Green marks ∈-minimal nodes (no arrows coming in). ∈ 图：箭头 u → v 表示 u ∈ v。先点一个结点，再点另一个，即可添加或删除箭头（同一结点连点两次得到自环 u ∈ u）。红色标出环，这是正则公理禁止的；绿色标出 ∈-极小结点（没有箭头指向它）。

For a finite graph, “every nonempty subset has a minimal node” is equivalent to “no cycles”. A cycle u₁ ∈ u₂ ∈ ⋯ ∈ u₁ is exactly a nonempty set {u₁, …, uₖ} with no ∈-minimal member. For infinite graphs the danger is also an infinite descending path. Foundation is what lets us do ∈-induction and build the cumulative hierarchy V (Lesson 14). 对有限图，“每个非空子集都有极小结点”等价于“没有环”。一个环 u₁ ∈ u₂ ∈ ⋯ ∈ u₁ 恰好给出一个没有 ∈-极小元的非空集合 {u₁, …, uₖ}。对无穷图，还要防范无穷递降路径。有了正则公理，才能做 ∈-归纳，才能搭起累积层级 V（第 14 课）。

Preview: the Axiom of Choice预览：选择公理

AC: every family of nonempty sets has a choice function: f(X) ∈ X for each X in the family. Click one element in each box. For a finite family you can always do this by hand (an induction in ZF). AC asserts it for infinite families where no rule is available. ZF + AC = ZFC, and Lesson 10 is devoted to it. 选择公理：每个由非空集合组成的族都有选择函数：对族中每个 X，f(X) ∈ X。在每个盒子里点选一个元素。有限族总能“手工”选完（在 ZF 中对个数归纳即可）；选择公理断言的是：即使对无穷族、没有任何规则可循，选择函数也存在。ZF 加上选择公理就是 ZFC，第 10 课专门讨论它。

E6No set is a member of itself没有集合属于自身

Foundation speaks about the members of a nonempty set. To rule out x ∈ x, you must apply it to a cleverly chosen set. (a) Which set? 正则公理说的是非空集合的元素。要排除 x ∈ x，得把它用到一个精心挑选的集合上。(a) 挑哪个集合？

(b) And to rule out a 2-cycle x ∈ y ∈ x?(b) 要排除二元环 x ∈ y ∈ x 呢？

(a) Apply Foundation to {x} (exists by Pairing). Its only member is x, so x ∩ {x} = ∅, i.e. x ∉ x. ∎
(b) Apply it to {x, y}. Some member is disjoint from {x, y}. It cannot be x (since y ∈ x) nor y (since x ∈ y). ∎ The same trick with {x₀, x₁, x₂, …} (a set by Replacement on ω) kills infinite descending chains. (a) 对 {x}（由配对公理存在）用正则公理。它唯一的元素是 x，于是 x ∩ {x} = ∅，即 x ∉ x。∎
(b) 对 {x, y} 用正则公理，得到一个与 {x, y} 不交的元素。它不能是 x（因为 y ∈ x），也不能是 y（因为 x ∈ y）。∎ 用同样的办法处理 {x₀, x₁, x₂, …}（对 ω 用替换公理得到的集合），就能排除无穷递降链。
