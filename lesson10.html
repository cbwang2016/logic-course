The Axiom of Choice, Zorn's Lemma, Banach–Tarski选择公理、佐恩引理与巴拿赫–塔斯基悖论

One innocent-looking axiom: from any family of nonempty sets you may pick one element from each. It powers bases, ultrafilters, and maximal ideals, and it also produces a non-measurable set and a ball that splits into two balls. Every picture below can be clicked, stepped through, or animated. 一条看似无害的公理：从任意一族非空集合中，可以每个集合各取一个元素。有了它，就有了基、超滤子、极大理想；也正是它，造出了不可测集，还能把一个球拆开拼成两个球。下面的每张图都可以点击、单步或播放动画。

§1

One sock from each drawer: choice functions每个抽屉拿一只袜子：选择函数

Axiom of Choice (AC). For every set X of nonempty sets there is a function f : X → ⋃X with f(A) ∈ A for every A ∈ X. Such an f is a choice function. Equivalently: a product ∏ᵢ Aᵢ of nonempty sets is nonempty. 选择公理（AC）. 对任意由非空集合构成的集合 X，存在函数 f : X → ⋃X，使得对每个 A ∈ X 都有 f(A) ∈ A。这样的 f 称为选择函数。等价地说：一族非空集合的笛卡儿积 ∏ᵢ Aᵢ 非空。

Russell's picture: infinitely many drawers, each holding a pair. With shoes there is a rule (“take the left one”), and Separation turns that rule into a function, so no axiom is needed. With socks the two are indistinguishable, so no formula picks one. Pick socks by hand, try the ∞ setting, then press the buttons. 罗素的比喻：无穷多个抽屉，每个装着一双。若是鞋，有现成的规则（“拿左脚那只”），由分离公理即可把规则变成函数，不需要额外公理。若是袜子，两只一模一样，没有任何公式能挑出其中一只。先手动挑几只袜子，再切换到 ∞，最后按按钮试试。

§3

Zorn's lemma: climbing chains in a poset佐恩引理：在偏序集里顺着链往上爬

Zorn's Lemma. Let (P, ≤) be a nonempty partial order in which every chain (a totally ordered subset) has an upper bound in P. Then P has a maximal element: some m with no x > m. 佐恩引理. 设 (P, ≤) 是非空偏序集，且其中每条链（全序子集）在 P 中都有上界。则 P 有极大元：即某个 m，不存在 x > m。

Hasse diagram: a line going up means “less than”. Click elements to build a set S. The panel says whether S is a chain and rings its upper bounds in gold. Then press Climb to watch the proof of Zorn run: at each stage the choice function g picks a strict upper bound of the chain built so far. 哈斯图：连线往上表示“小于”。点击元素组成集合 S，右侧会判断 S 是否为链，并用金色圈出它的上界。然后按往上爬，看佐恩引理的证明如何运行：每一阶段，选择函数 g 都为已建好的链挑一个严格上界。

Application: every vector space has a basis应用：每个向量空间都有基

Start small: V = 𝔽₂³ has 7 nonzero vectors, drawn as the Fano plane. Each line is a triple u, v, u+v. Click points to build a linearly independent set. A dependent choice is rejected and the relation is shown. On the right is the poset of independent sets, ordered by ⊆: every click moves you up one step, and the gold top row holds the maximal elements, which are exactly the bases. 先看小例子：V = 𝔽₂³ 有 7 个非零向量，画成法诺平面，每条线是三元组 u, v, u+v。点击点来组建线性无关组；若会导致线性相关，就拒绝加入并显示相关关系。右边是线性无关集按 ⊆ 构成的偏序集：每点一次就往上走一层，最上面金色的一行是极大元，恰好就是所有的基。

The Zorn argument (works for any vector space)佐恩论证（对任何向量空间都成立）

ℝ as a vector space over ℚ把 ℝ 看作 ℚ 上的向量空间

Toggle reals into a set and the tool keeps it ℚ-linearly independent. It uses the fact that 1, √2, √3, √6, π are ℚ-independent (π is transcendental). Zorn extends any such set to a Hamel basis of ℝ over ℚ. That basis has size 2ℵ₀, and nobody can write one down: in Solovay's model of ZF + DC no Hamel basis exists. 点选实数加入集合，工具会保持它在 ℚ 上线性无关。这里用到 1, √2, √3, √6, π 在 ℚ 上线性无关（π 是超越数）。佐恩引理可以把任何这样的集合扩充成 ℝ 在 ℚ 上的哈默尔基。这种基的势是 2ℵ₀，却没有人能把它具体写出来：在 ZF + DC 的索洛维模型中，哈默尔基根本不存在。

Payoff. Fix a Hamel basis H and some h₀ ∈ H. Let f(x) be the coefficient of h₀ when x is written in the basis H. Then f(x + y) = f(x) + f(y), yet f takes only rational values and is not of the form cx. So f is an additive function ℝ → ℝ that is not continuous. 收获. 取定哈默尔基 H 及某个 h₀ ∈ H，令 f(x) 为 x 在 H 下展开时 h₀ 的系数。则 f(x + y) = f(x) + f(y)，但 f 只取有理值，不可能形如 cx。于是 f 是一个不连续的可加函数 ℝ → ℝ。
§5

Application: every filter extends to an ultrafilter应用：每个滤子都能扩张为超滤子

A filter on S is F ⊆ 𝒫(S) with S ∈ F, ∅ ∉ F, closed under ∩ and under supersets. It is an ultrafilter if for every A ⊆ S, either A ∈ F or S∖A ∈ F. Think of F as the family of “large” sets: an ultrafilter decides every question of the form “is A large?”. 滤子是 S 上满足以下条件的 F ⊆ 𝒫(S)：S ∈ F，∅ ∉ F，对 ∩ 封闭，且对取超集封闭。若对每个 A ⊆ S，A ∈ F 与 S∖A ∈ F 必居其一，则称为超滤子。不妨把 F 看作“大集合”的全体：超滤子对每个“A 算不算大”的问题都给出了裁决。

Below is the lattice 𝒫({1,2,3,4}). Click sets to use them as generators: the generated filter lights up in blue. Hover a set to compare it with its complement. Then press Extend. 下图是格 𝒫({1,2,3,4})。点击集合把它们作为生成元，生成的滤子以蓝色显示。鼠标悬停可对比该集合与其补集。然后按扩张。

On ℕ: the non-principal ultrafilter you cannot describe在 ℕ 上：说不出模样的非主超滤子

On a finite set every ultrafilter is principal, of the form {A : k ∈ A}. On ℕ, extend the Fréchet filter of cofinite sets to an ultrafilter U. This needs choice, and ZF alone does not prove that any such U exists. Click a set and ask: is it in U? 有限集上的超滤子都是主超滤子，即形如 {A : k ∈ A}。在 ℕ 上，把由余有限集构成的弗雷歇滤子扩张为超滤子 U。这一步要用选择公理，仅凭 ZF 甚至证明不了这样的 U 存在。点一个集合，问问：它在 U 里吗？

Preview of nonstandard analysis. Sequences of reals modulo “agree on a set in U” form the hyperreals ℝ^ℕ/U. The class of (0,1,2,3,…) exceeds every standard n, because {k : k > n} is cofinite and therefore in U. It is an infinite number, and its reciprocal is an infinitesimal. §7

The free group F₂: a group that is twice itself自由群 F₂：一个等于“两份自己”的群

F₂ consists of the reduced words in a, a⁻¹, b, b⁻¹ (no aa⁻¹, bb⁻¹, … next to each other), multiplied by concatenation followed by cancellation. Its Cayley graph is the 4-regular tree below. Colors show the first letter: W(x) is the set of reduced words beginning with x. Press the animation buttons: left-multiplying by a blows the small orange piece W(a⁻¹) up into everything except W(a). F₂ 由 a, a⁻¹, b, b⁻¹ 组成的既约字构成（不出现 aa⁻¹、bb⁻¹ 等相邻抵消的情形），乘法是拼接后再约简。它的凯莱图就是下面这棵 4 正则树。颜色表示首字母：W(x) 是以 x 开头的既约字全体。按动画按钮：左乘 a 会把小小的橙色块 W(a⁻¹) 撑大成除 W(a) 以外的全部。

F₂ = {e} ⊔ W(a) ⊔ W(a⁻¹) ⊔ W(b) ⊔ W(b⁻¹)    but also但同时    F₂ = W(a) ⊔ a·W(a⁻¹) = W(b) ⊔ b·W(b⁻¹)
Why it works. If w does not start with a, then a⁻¹w is reduced and starts with a⁻¹, and w = a·(a⁻¹w). Conversely, if w starts with a⁻¹, the a cancels and a·w does not start with a. So a·W(a⁻¹) = F₂ ∖ W(a) exactly. Four disjoint pieces W(a), W(a⁻¹), W(b), W(b⁻¹) reassemble, by left multiplications, into two copies of F₂. This is a paradoxical decomposition. 为什么成立. 若 w 不以 a 开头，则 a⁻¹w 是以 a⁻¹ 开头的既约字，且 w = a·(a⁻¹w)。反之，若 w 以 a⁻¹ 开头，左乘 a 后首字母被消掉，a·w 不以 a 开头。所以恰好 a·W(a⁻¹) = F₂ ∖ W(a)。四个两两不交的块 W(a)、W(a⁻¹)、W(b)、W(b⁻¹) 经过左乘，能重新拼成两份 F₂。这就是悖论分解。
§8

Banach–Tarski: from F₂ to the ball巴拿赫–塔斯基：从 F₂ 到实心球

Theorem (Banach–Tarski 1924, ZFC). The closed unit ball B ⊂ ℝ³ can be partitioned into finitely many pieces (5 suffice) which, moved by rotations and translations, reassemble into two disjoint copies of B. 定理（巴拿赫–塔斯基，1924，ZFC）. ℝ³ 中的闭单位球 B 可以分割成有限多块（5 块就够），这些块经旋转和平移后，可以重新拼成两个互不相交、与 B 全等的球。

Ingredient 1: two rotations that generate a free group要素一：两个生成自由群的旋转

Let ρ be the rotation about the z-axis and σ the rotation about the x-axis, both by the angle arccos(1/3). Build a reduced word with the buttons. The tool applies it to (1,0,0) one letter at a time, right to left. (σ fixes (1,0,0), so if the word ends in σ±1 the tool tests the conjugate ρ·w·ρ⁻¹ instead, which ends in ρ⁻¹ and is the identity iff w is.) For a reduced word ending in ρ±1, every point that appears has the exact form (a, b√2, c)/3ᵏ with integers a, b, c, and b is never divisible by 3. So the point never returns to (1,0,0), and the word is not the identity. The sphere on the right shows the path. 令 ρ 为绕 z 轴、σ 为绕 x 轴旋转 arccos(1/3) 角的旋转。用按钮拼一个既约字。工具从右往左逐个字母地把它作用到 (1,0,0) 上。（σ 固定 (1,0,0)，所以若字以 σ±1 结尾，工具改测它的共轭 ρ·w·ρ⁻¹：它以 ρ⁻¹ 结尾，并且它是恒等变换当且仅当 w 是。）对以 ρ±1 结尾的既约字，途中出现的每个点都恰好形如 (a, b√2, c)/3ᵏ，其中 a, b, c 为整数，而且 b 始终不被 3 整除。所以这个点永远回不到 (1,0,0)，该字不是恒等变换。右边的球面画出了点的轨迹。
