Tarski: Truth is Undefinable塔斯基：真不可定义

Gödel fed ¬Prov to the diagonal machine and got a sentence that escapes proof. Feed it ¬True instead and the machine explodes: no formula of arithmetic can say “x is the code of a true sentence”. 哥德尔把 ¬Prov 喂给对角线机器，得到一个逃脱证明的句子。换成 ¬True 喂进去，机器就炸了：没有任何算术公式能表达“x 是一个真语句的编码”。

§2

The diagonal family tree对角线家族谱

Six famous arguments, one shape: a table indexed by A × A, its diagonal, and a twist f with no fixed point. Click a node to see its table run. 六个著名论证，同一个骨架：一张由 A × A 索引的表、它的对角线，以及一个没有不动点的“扭转” f。点击节点，看它那张表怎么运转。

Lawvere's fixed-point theorem (set version). If g : A → B^A is surjective, then every f : B → B has a fixed point. Proof: let h(a) = f(g(a)(a)); then h = g(a₀) for some a₀, and h(a₀) = f(g(a₀)(a₀)) = f(h(a₀)). ∎ Cantor, Russell, Turing, Tarski: f = negation has no fixed point, so no such g. Gödel: the enumeration of formulas is onto, so ¬Prov must have a fixed point (up to provable equivalence), namely G. 劳维尔不动点定理（集合版本）. 若 g : A → B^A 是满射，则每个 f : B → B 都有不动点。证明：令 h(a) = f(g(a)(a))，则存在 a₀ 使 h = g(a₀)，于是 h(a₀) = f(g(a₀)(a₀)) = f(h(a₀))。∎ 康托尔、罗素、图灵、塔斯基：f 取否定，没有不动点，所以这样的 g 不存在。哥德尔：公式的枚举确实是满的，所以 ¬Prov 必有（在可证等价意义下的）不动点，那就是 G。
§3

Tarski's undefinability theorem塔斯基真之不可定义性定理

Theorem (Tarski 1933/36). There is no formula True(x) in the language of arithmetic {0, S, +, ×} such that for every sentence φ, ℕ ⊨ True(⌜φ⌝) ↔ φ. Equivalently, the set Th(ℕ) = {⌜φ⌝ : ℕ ⊨ φ} is not arithmetically definable. 定理（塔斯基 1933/36）. 算术语言 {0, S, +, ×} 中不存在公式 True(x)，使得对每个语句 φ 都有 ℕ ⊨ True(⌜φ⌝) ↔ φ。等价地说，集合 Th(ℕ) = {⌜φ⌝ : ℕ ⊨ φ} 不是算术可定义的。
1. Suppose True(x) were such a formula.1. 假设 True(x) 是这样一个公式。
2. Apply the diagonal lemma (L12 §4) to ψ(x) := ¬True(x): there is a sentence L with Q ⊢ L ↔ ¬True(⌜L⌝).2. 对 ψ(x) := ¬True(x) 应用对角线引理（第 12 课 §4）：存在语句 L，使 Q ⊢ L ↔ ¬True(⌜L⌝)。
3. Q is true in ℕ, so ℕ ⊨ L ↔ ¬True(⌜L⌝).3. Q 在 ℕ 中为真，所以 ℕ ⊨ L ↔ ¬True(⌜L⌝)。
4. By the assumed property of True with φ = L: ℕ ⊨ True(⌜L⌝) ↔ L.4. 由 True 的假定性质（取 φ = L）：ℕ ⊨ True(⌜L⌝) ↔ L。
5. Combining: ℕ ⊨ L ↔ ¬L, which is impossible. So no such True(x) exists. ∎5. 两式合并：ℕ ⊨ L ↔ ¬L，这不可能。所以这样的 True(x) 不存在。∎
Notice: the proof uses no provability and no consistency assumption about any theory. It is a statement about definability in the structure ℕ. The same argument works in any structure that can carry out the diagonal lemma.注意：这个证明完全不涉及可证性，也不需要对任何理论作一致性假设。它是关于在结构 ℕ 中的可定义性的命题。只要某个结构能执行对角线引理，同样的论证就适用。

§4

The arithmetical hierarchy: a ladder truth cannot stand on算术分层：真站不上去的梯子

Classify formulas by quantifier alternations in front of a bounded (Δ₀) core: Σₙ = ∃∀∃⋯ (n blocks), Πₙ = ∀∃∀⋯, and Δₙ = Σₙ ∩ Πₙ. Click a set to place it on the ladder. 按照有界（Δ₀）核心前面量词交替的次数给公式分类：Σₙ = ∃∀∃⋯（n 个量词块），Πₙ = ∀∃∀⋯，Δₙ = Σₙ ∩ Πₙ。点击某个集合，把它放上梯子。

Facts. (1) Provability Prov_T for recursively axiomatized T is Σ₁. (2) For each n ≥ 1 there is a Σₙ formula True_Σₙ(x) with ℕ ⊨ True_Σₙ(⌜φ⌝) ↔ φ for all Σₙ sentences φ. (3) Th(ℕ) ∩ Σₙ is Σₙ-complete, so the hierarchy is proper, and Th(ℕ) = ⋃ₙ (Th(ℕ) ∩ Σₙ) lies on no rung: if it were Σₙ, then Th(ℕ) ∩ Σₙ₊₁ would be Σₙ, a contradiction. That is Tarski's theorem again. 事实. (1) 对递归可公理化的 T，可证性 Prov_T 是 Σ₁ 的。(2) 对每个 n ≥ 1，存在 Σₙ 公式 True_Σₙ(x)，使得对所有 Σₙ 语句 φ 都有 ℕ ⊨ True_Σₙ(⌜φ⌝) ↔ φ。(3) Th(ℕ) ∩ Σₙ 是 Σₙ-完全的，所以层级是真包含的；而 Th(ℕ) = ⋃ₙ (Th(ℕ) ∩ Σₙ) 不在任何一层上：若它是 Σₙ 的，则 Th(ℕ) ∩ Σₙ₊₁ 也是 Σₙ 的，矛盾。这又是一次塔斯基定理。

§6

The T-schema and the recursive definition of truthT 模式与真的递归定义

Tarski's material adequacy condition: a truth predicate must satisfy every instance of the T-schema True(⌜φ⌝) ↔ φ. On the left the sentence is mentioned (we talk about its code, a number); on the right it is used. Pick a sentence and disquote it. 塔斯基的实质充分性条件：一个真谓词必须满足 T 模式 True(⌜φ⌝) ↔ φ 的每个实例。左边的语句是被提及的（我们谈论的是它的编码，一个数）；右边的语句是被使用的。选一个语句，去掉引号试试。

Truth by recursion on formulas (Lesson 3's satisfaction, for ℕ)沿公式递归定义“真”（第 3 课的满足关系，用在 ℕ 上）

ℕ ⊨ (t₁ = t₂)[s] ⇔ t₁ˢ = t₂ˢ
ℕ ⊨ ¬φ[s] ⇔ ℕ ⊭ φ[s]
ℕ ⊨ (φ ∧ ψ)[s] ⇔ ℕ ⊨ φ[s] and ℕ ⊨ ψ[s]
ℕ ⊨ ∃x φ[s] ⇔ for some n ∈ ℕ: ℕ ⊨ φ[s(x↦n)]
ℕ ⊨ ∀x φ[s] ⇔ for all n ∈ ℕ: ℕ ⊨ φ[s(x↦n)]
Click a node to unfold the clause. A quantifier node has infinitely many children. Each fixed depth of nesting can be expressed in arithmetic (that is True_Σₙ), but the recursion over formulas of every depth needs to quantify over whole satisfaction relations: sets, not numbers. That is exactly what the metalanguage (e.g. set theory) supplies. 点击节点展开对应的条款。量词节点有无穷多个子节点。固定的嵌套深度都能在算术中表达（这就是 True_Σₙ），但要对所有深度的公式做递归，就必须对整个满足关系量化：那是集合，不是数。元语言（例如集合论）提供的正是这个。
§7

Truth in set theory: definable for every set, not for V集合论中的真：对每个集合可定义，对 V 不可定义

Drag the slider up the cumulative hierarchy (Lesson 14 builds it properly). For every set structure (V_α, ∈), ZFC defines satisfaction by the recursion of §6, since now the satisfaction relation is itself a set. At the top, V is a proper class, and Tarski strikes again. 拖动滑块沿累积层级往上走（第 14 课会正式构造它）。对每个集合结构 (V_α, ∈)，ZFC 都能用 §6 的递归定义满足关系，因为此时满足关系本身就是一个集合。到了顶端，V 是真类，塔斯基定理再次发威。

α :
Tarski in ZFC. For every formula Tr(x) of set theory there is a sentence σ with ZFC ⊢ σ ↔ ¬Tr(⌜σ⌝). So no formula defines truth in V. Yet for each n there is a formula Sat_Σₙ defining truth for Σₙ formulas (Lévy), and the reflection principle gives, for any finitely many formulas, an α such that they are absolute between V_α and V. ZFC 中的塔斯基定理. 对集合论的每个公式 Tr(x)，都存在语句 σ 使 ZFC ⊢ σ ↔ ¬Tr(⌜σ⌝)。所以没有公式能定义 V 中的真。但对每个 n 都有公式 Sat_Σₙ 定义 Σₙ 公式的真（莱维），而反射原理保证：对任意有限多个公式，存在 α 使它们在 V_α 与 V 之间绝对。
Preview of Lesson 14. For each finite fragment Φ of ZFC, ZFC proves “Φ has a set model” (some V_α, by reflection). This is a scheme: one separate theorem for each Φ. ZFC does not prove the single statement “every finite fragment has a model” (by compactness that already gives Con(ZFC)), let alone “all of ZFC has a model”: if ZFC is consistent, either would contradict the second incompleteness theorem. So independence proofs must work with relative consistency: “if ZFC is consistent, then so is ZFC + CH”. 第 14 课预告. 对 ZFC 的每个有限片段 Φ，ZFC 都能证明“Φ 有集合模型”（由反射原理，某个 V_α 即可）。这是一个定理模式：每个 Φ 各对应一条独立的定理。ZFC 证明不了“每个有限片段都有模型”这一单个命题（由紧致性它已推出 Con(ZFC)），更证明不了“整个 ZFC 有模型”：若 ZFC 一致，两者都与第二不完全性定理矛盾。所以独立性证明只能采用相对一致性的形式：“若 ZFC 一致，则 ZFC + CH 也一致”。

E6Gödel from Tarski由塔斯基推出哥德尔

Let T be a sound, recursively axiomatized theory of arithmetic. Which argument correctly derives that T is incomplete from Tarski's theorem? 设 T 是一个可靠且递归可公理化的算术理论。下列哪个论证能正确地由塔斯基定理推出 T 不完全？

Proof. Thm_T = {⌜φ⌝ : T ⊢ φ} is Σ₁-definable, by Prov_T. Th(ℕ) is not definable at all (Tarski). So Thm_T ≠ Th(ℕ). Soundness gives Thm_T ⊆ Th(ℕ), so some true σ has T ⊬ σ; and ¬σ is false, so by soundness T ⊬ ¬σ. Hence σ is undecided. ∎ (This version needs soundness. Gödel's original proof needs only ω-consistency, Rosser's refinement only consistency, and both produce an explicit Π₁ sentence.) 证明. Thm_T = {⌜φ⌝ : T ⊢ φ} 可由 Prov_T 以 Σ₁ 方式定义。而 Th(ℕ) 根本不可定义（塔斯基）。所以 Thm_T ≠ Th(ℕ)。由可靠性 Thm_T ⊆ Th(ℕ)，故存在真语句 σ 使 T ⊬ σ；又 ¬σ 为假，由可靠性 T ⊬ ¬σ。所以 σ 在 T 中不可判定。∎（这个版本需要可靠性。哥德尔原来的证明只需 ω-一致性，罗瑟的改进只需一致性，而且两者都给出一个具体的 Π₁ 语句。）
