Part IV · Lesson 14

Models of ZFC and the Cumulative Hierarchy VZFC 的模型与累积层级 V

To prove that CH is independent we must build other universes of sets. This lesson builds the tools: the universe V layered by rank, the Mostowski collapse, transitive models and absoluteness, the reflection principle, and the pattern “Con(ZF) ⇒ Con(ZF + X)”. 要证明连续统假设独立，就得造出别的集合宇宙。本课准备工具：按秩分层的宇宙 V、莫斯托夫斯基坍塌、传递模型与绝对性、反射原理，以及“Con(ZF) ⇒ Con(ZF + X)”这一论证模式。

§1

The cumulative hierarchy: a universe grown in layers累积层级：一层层长出来的宇宙

Definition (by transfinite recursion). V₀ = ∅,   Vα+1 = 𝒫(Vα),   Vλ = ⋃α<λ Vα for limit λ.   V = ⋃α∈Ord Vα is the von Neumann universe. 定义（超限递归）。V₀ = ∅，Vα+1 = 𝒫(Vα)，λ 为极限序数时 Vλ = ⋃α<λ Vα。V = ⋃α∈Ord Vα 称为冯·诺伊曼宇宙。

Each Vα is transitive and α < β ⇒ Vα ⊆ Vβ: layers only ever accumulate. Press Grow to add a layer, then click a level label to open it. A set is drawn as a box, and its elements are the boxes inside it. An empty box is ∅. 每个 Vα 都是传递集，而且 α < β ⇒ Vα ⊆ Vβ：各层只会不断累积。按 生长 增加一层，再点击右侧的层名展开该层。一个集合画成一个盒子，它的元素就是盒子里的小盒子；空盒子就是 ∅。

The sizes explode: |Vn+1| = 2|Vn|, so 0, 1, 2, 4, 16, 65 536, 265 536, … Every Vn is finite, Vω (the hereditarily finite sets) is countable, and |Vω+α| = ℶα. The gold boxes are the new elements, those of rank exactly n − 1. 规模爆炸式增长：|Vn+1| = 2|Vn|，依次为 0, 1, 2, 4, 16, 65 536, 265 536, …。每个 Vn 都有限，Vω（遗传有限集全体）可数，并且 |Vω+α| = ℶα。金色框是该层新出现的元素，即秩恰为 n − 1 的集合。
§2

The rank of a set: its height in V集合的秩：它在 V 中的高度

Definition. For x ∈ ⋃Vα, rank(x) = the least α with x ⊆ Vα (equivalently, x ∈ Vα+1). Then rank(x) = sup{ rank(y) + 1 : y ∈ x }, and Vα = { x : rank(x) < α }. 定义. 对 x ∈ ⋃Vα，rank(x) 是使 x ⊆ Vα（等价地，x ∈ Vα+1）的最小 α。于是 rank(x) = sup{ rank(y) + 1 : y ∈ x }，且 Vα = { x : rank(x) < α }。

Type a hereditarily finite set. Use ∅ (or {}), braces and commas; a digit n abbreviates the von Neumann ordinal n = {0,…,n−1}. The picture is the transitive closure, layered by rank. The purple path is a longest ∈-chain down to ∅, and its length is the rank. 输入一个遗传有限集。可用 ∅（或 {}）、花括号和逗号；数字 n 是冯·诺伊曼序数 n = {0,…,n−1} 的缩写。下图画出它的传递闭包，按秩分层排列。紫色路径是一条通往 ∅ 的最长 ∈-链，其长度就是秩。

§3

Foundation ⇔ V = ⋃ Vα正则公理 ⇔ V = ⋃ Vα

Foundation says that every nonempty x has an ∈-minimal element: some m ∈ x with m ∩ x = ∅. Below, the elements of x sit at the height of their rank. Click any element to test whether it is ∈-minimal. The lowest one always works, because its members are strictly lower than every element of x. 正则公理（基础公理）说：每个非空集 x 都有 ∈-极小元，即存在 m ∈ x 使 m ∩ x = ∅。下图把 x 的元素按秩摆在不同高度。点击任一元素，检验它是否 ∈-极小。最低的那个一定行：它的元素都比 x 的所有元素还低。

Theorem (ZF without Foundation). Foundation ⇔ every set lies in some Vα.定理（在去掉正则公理的 ZF 中）：正则公理 ⇔ 每个集合都属于某个 Vα。

(⇐) Let x ≠ ∅ with every set ranked. Pick m ∈ x of least rank (ordinals are well-ordered). Every y ∈ m has rank(y) < rank(m), so y ∉ x. Hence m ∩ x = ∅. This is exactly the picture above. (⇐) 设 x ≠ ∅ 且每个集合都有秩。取 x 中秩最小的元素 m（序数是良序的）。对任意 y ∈ m 有 rank(y) < rank(m)，故 y ∉ x。所以 m ∩ x = ∅。这正是上图展示的情形。
(⇒) Setup. Write WF = ⋃αVα. Suppose x ∉ WF. Let T = TC({x}), the transitive closure (the smallest transitive set containing x). Then B = { z ∈ T : z ∉ WF } is a nonempty set (it contains x), by Separation. (⇒) 准备. 记 WF = ⋃αVα。设 x ∉ WF。令 T = TC({x}) 为传递闭包（包含 x 的最小传递集）。由分离公理，B = { z ∈ T : z ∉ WF } 是一个集合，且非空（x ∈ B）。
(⇒) Use Foundation. Take z ∈ B with z ∩ B = ∅. Since T is transitive, every w ∈ z lies in T but not in B, so every element of z is in WF. (⇒) 用正则公理. 取 z ∈ B 使 z ∩ B = ∅。T 是传递集，所以 z 的每个元素 w 都在 T 中而不在 B 中，即 z 的元素全都属于 WF。
(⇒) Use Replacement. α = sup{ rank(w) + 1 : w ∈ z } is an ordinal (Replacement + Union). Then z ⊆ Vα, so z ∈ Vα+1 ⊆ WF, a contradiction. ∎   Without Foundation, WF is still a transitive class that satisfies all of ZF, so Foundation can be added at no cost in consistency strength. (⇒) 用替换公理. α = sup{ rank(w) + 1 : w ∈ z } 是序数（替换公理 + 并集公理）。于是 z ⊆ Vα，故 z ∈ Vα+1 ⊆ WF，矛盾。∎   即使不假设正则公理，WF 依然是满足全部 ZF 的传递类，因此添加正则公理不会增加一致性强度。
§4

Models (M, E) and the Mostowski collapse模型 (M, E) 与莫斯托夫斯基坍塌

A model of set theory is just a structure (M, E): a set of points and a binary relation E that plays the role of ∈. Draw it as a directed graph, with an arrow a → b meaning a E b. Nothing forces E to be the real ∈. 集合论的模型不过是一个结构 (M, E)：一些点，加上一个扮演 ∈ 的二元关系 E。把它画成有向图，箭头 a → b 表示 a E b。E 不必是真正的 ∈。

Mostowski Collapse Lemma. If E is well-founded (and set-like) and extensional on M, there is a unique transitive set (or class) T and a unique isomorphism π : (M, E) ≅ (T, ∈), defined by recursion: π(b) = { π(a) : a E b }. 莫斯托夫斯基坍塌引理. 若 E 在 M 上良基（且类似集合）并且满足外延性，则存在唯一的传递集（或传递类）T 和唯一的同构 π : (M, E) ≅ (T, ∈)，由递归给出：π(b) = { π(a) : a E b }。

Edit the graph: click a node to select it, then click another node to toggle the arrow selected → clicked. Drag nodes to move them. Then press Collapse. Try the presets that break each hypothesis. 编辑图：先点一个节点选中它，再点另一个节点，即可添加或删除箭头“选中 → 被点”。节点可以拖动。然后按 坍塌。也试试那些故意破坏某个条件的预设。

Why it matters. Any well-founded model of ZF can be replaced by an isomorphic transitive model (M, ∈), where membership is the real one. Transitive models are where absoluteness works (next section). Löwenheim–Skolem (Lesson 5) applied to a transitive model, plus collapse, gives countable transitive models (§8 explains which ones ZFC can actually produce). 意义何在. ZF 的任何良基模型都可以换成一个同构的传递模型 (M, ∈)，其中的属于关系就是真正的 ∈。绝对性正是在传递模型上起作用（见下一节）。对传递模型用勒文海姆–斯科伦定理（第 5 课），再做坍塌，就得到可数传递模型（ZFC 究竟能造出哪些这样的模型，见 §8）。
§5

Transitive models and absoluteness传递模型与绝对性

Definitions. A formula φ is Δ₀ if every quantifier in it is bounded: ∀z∈y or ∃z∈y. φ(x₁,…,xₙ) is absolute between M ⊆ N if for all a₁,…,aₙ ∈ M: M ⊨ φ[a₁,…,aₙ] ⇔ N ⊨ φ[a₁,…,aₙ].
Theorem. If M ⊆ N are transitive, every Δ₀ formula is absolute between M and N. 定义. 若公式 φ 中的量词全都有界，即形如 ∀z∈y 或 ∃z∈y，则称 φ 为 Δ₀ 公式。若对所有 a₁,…,aₙ ∈ M 都有 M ⊨ φ[a₁,…,aₙ] ⇔ N ⊨ φ[a₁,…,aₙ]，则称 φ(x₁,…,xₙ) 在 M ⊆ N 之间绝对。
定理. 若 M ⊆ N 都是传递的，则每个 Δ₀ 公式在 M 与 N 之间绝对。

Laboratory. The big world is N = V₄ (16 sets, standing in for V). Click chips to choose a small model M ⊆ V₄, pick or type a formula φ(y), and compare N ⊨ φ[y] with M ⊨ φ[y] for each y ∈ M. Bounded quantifiers are green and unbounded ones are red. Make M non-transitive and watch even Δ₀ formulas fail. 实验室. 大世界取 N = V₄（16 个集合，充当 V 的替身）。点击芯片选出小模型 M ⊆ V₄，选择或输入公式 φ(y)，然后对每个 y ∈ M 比较 N ⊨ φ[y] 与 M ⊨ φ[y]。有界量词标绿，无界量词标红。把 M 弄成非传递的，你会看到连 Δ₀ 公式都失效。

Why Δ₀ formulas are absolute: induction on φΔ₀ 公式为何绝对：对 φ 归纳

Atomic. a ∈ b and a = b mean the same thing in M and N, since both use the real ∈.原子公式. a ∈ b 与 a = b 在 M 和 N 中意思相同，因为两边用的都是真正的 ∈。
¬, ∧. Immediate from the induction hypothesis.¬、∧. 由归纳假设直接得到。
Bounded ∃. Take ∃z∈b ψ with b ∈ M. In N, z ranges over b. In M, z ranges over b ∩ M. Since M is transitive, b ⊆ M, so b ∩ M = b: both search the same set, and ψ is absolute by induction. ∎ 有界 ∃. 考虑 ∃z∈b ψ，b ∈ M。在 N 中 z 取遍 b；在 M 中 z 取遍 b ∩ M。由于 M 是传递的，b ⊆ M，从而 b ∩ M = b：两边搜索的是同一个集合，再由归纳假设 ψ 绝对即可。∎
Where it breaks. An unbounded ∃z searches all of M in one case and all of N in the other. A witness may exist in N but not in M. Such Σ₁ statements are only upward absolute (M ⊨ φ ⇒ N ⊨ φ), and Π₁ statements are only downward absolute. 何处失效. 无界的 ∃z 在一边搜遍 M，在另一边搜遍 N。证据可能在 N 里有、在 M 里没有。这类 Σ₁ 命题只向上绝对（M ⊨ φ ⇒ N ⊨ φ），Π₁ 命题只向下绝对。

§6

Skolem's paradox, seen through absoluteness从绝对性看斯科伦悖论

Let M be a countable transitive model (of enough of ZFC; §8 explains how to get one). M contains ω and ω is the same in M and V, since “x = ω” is Δ₀. Yet M ⊨ “𝒫(ω) is uncountable”. Toggle the point of view. 设 M 是可数传递模型（满足足够多的 ZFC 公理；§8 说明如何得到）。M 包含 ω，而且 ω 在 M 和 V 中是同一个，因为“x = ω”是 Δ₀ 的。然而 M ⊨ “𝒫(ω) 不可数”。切换视角看看。

The same object, two verdicts同一个对象，两种判决

Resolution (Lesson 5 revisited). “Uncountable” means “there is no bijection with ω”, a Π₁ statement. The bijection exists in V but is not an element of M. Likewise 𝒫(ω)M = 𝒫(ω) ∩ M: M computes the power set correctly relative to its own sets. Countability and power set are not absolute. 悖论的化解（回顾第 5 课）. “不可数”的意思是“与 ω 之间不存在双射”，这是 Π₁ 命题。双射在 V 中存在，但它不是 M 的元素。同理 𝒫(ω)M = 𝒫(ω) ∩ M：M 只是相对于自己拥有的集合正确地计算幂集。可数性和幂集都不是绝对的。
§7

Which Vα are models of set theory?哪些 Vα 是集合论的模型？

(a) Vω: the closure machine(a) Vω：封闭性机器

Pick a (and b) from the palette and apply set operations. The rank bounds rank{a,b} = max+1, rank ⋃a ≤ rank a, rank 𝒫(a) = rank a + 1 keep every result finite-rank, so Vω is closed under all of them. Then try to build ω. 从调色板里选 a（和 b），施加集合运算。由秩的估计 rank{a,b} = max+1、rank ⋃a ≤ rank a、rank 𝒫(a) = rank a + 1，结果的秩永远有限，所以 Vω 对这些运算都封闭。然后试着造出 ω。

Theorem. (Vω, ∈) ⊨ ZFC − Infinity + ¬Infinity. So Infinity is independent of the other axioms, provided ZFC is consistent. Fun fact: Ackermann's coding x ↦ Σy∈x 2code(y) is an isomorphism (Vω, ∈) ≅ (ℕ, “the y-th binary digit of x is 1”). For example V₄ is exactly the codes 0–15. 定理. (Vω, ∈) ⊨ ZFC − 无穷公理 + ¬无穷公理。因此（在 ZFC 一致的前提下）无穷公理独立于其余公理。趣闻：阿克曼编码 x ↦ Σy∈x 2code(y) 给出同构 (Vω, ∈) ≅ (ℕ, “x 的二进制第 y 位是 1”)。例如 V₄ 恰好对应编码 0–15。

(b) Vω+ω: everything except Replacement(b) Vω+ω：除替换公理外全都成立

For any limit λ > ω, Vλ satisfies Zermelo set theory with Choice (ZC). But Replacement can fail. The map n ↦ ω+n is definable in Vω+ω and its domain ω is there, yet its image would have rank ω+ω. 对任意极限序数 λ > ω，Vλ 满足带选择公理的策梅洛集合论（ZC）。但替换公理可能失败：映射 n ↦ ω+n 在 Vω+ω 中可定义，其定义域 ω 也在里面，可像集的秩却是 ω+ω。

(c) Vκ for κ inaccessible: a model of all of ZFC(c) κ 不可达时的 Vκ：全部 ZFC 的模型

Definition. κ is (strongly) inaccessible if κ > ω, κ is regular, and κ is a strong limit: 2λ < κ for all λ < κ. Theorem. Then Vκ ⊨ ZFC. Strong limit and regularity give |Vα| < κ for α < κ (by induction on α), so every x ∈ Vκ has |x| < κ. Regularity then says the ranks of F[x] are bounded below κ, so F[x] ∈ Vκ: Replacement holds. 定义. 若 κ > ω、κ 正则，且 κ 是强极限（对所有 λ < κ 有 2λ < κ），则称 κ 为（强）不可达基数。定理. 此时 Vκ ⊨ ZFC。强极限与正则性保证对 α < κ 有 |Vα| < κ（对 α 归纳），所以每个 x ∈ Vκ 满足 |x| < κ；再由正则性，F[x] 中元素的秩有界于 κ 之下，于是 F[x] ∈ Vκ，替换公理成立。

Click the rungs of the consistency-strength ladder. Each theory proves that the one below it has a model. 点击一致性强度阶梯的各级。每个理论都能证明它下面那个理论有模型。

Claim. If ZFC is consistent, ZFC does not prove “an inaccessible exists” (IC).断言. 若 ZFC 一致，则 ZFC 证明不了“存在不可达基数”（IC）。
Suppose ZFC ⊢ IC. Since ZFC ⊢ (IC → Vκ ⊨ ZFC), we get ZFC ⊢ “ZFC has a set model”, hence ZFC ⊢ Con(ZFC) by soundness, which is formalizable in ZFC. By Gödel's second theorem (Lesson 12) ZFC is inconsistent. ∎ 设 ZFC ⊢ IC。由于 ZFC ⊢ (IC → Vκ ⊨ ZFC)，得 ZFC ⊢ “ZFC 有集合模型”，再由可靠性定理（可在 ZFC 内形式化）得 ZFC ⊢ Con(ZFC)。由哥德尔第二不完全性定理（第 12 课），ZFC 不一致。∎
Stronger. ZFC cannot even prove Con(ZFC) → Con(ZFC + IC) (if ZFC + IC is consistent). Otherwise ZFC + IC, which proves Con(ZFC), would prove Con(ZFC + IC), contradicting Gödel 2 for ZFC + IC. So relative consistency results over plain ZFC, like those in Lessons 15–16, are impossible for large cardinals: they really are stronger. 更强的结论. （若 ZFC + IC 一致）ZFC 甚至证明不了 Con(ZFC) → Con(ZFC + IC)。否则 ZFC + IC 既能证明 Con(ZFC)，就能证明 Con(ZFC + IC)，与 ZFC + IC 的哥德尔第二定理矛盾。所以像第 15–16 课那样仅以 ZFC 为基础的相对一致性结果，对大基数是不可能的：它们是真正更强的假设。
Conversely, if κ is the least inaccessible then Vκ ⊨ ZFC + ¬IC, because inaccessibility of λ < κ is computed correctly in Vκ. Hence Con(ZFC) ⇒ Con(ZFC + ¬IC): if there is no inaccessible, V itself satisfies ¬IC; otherwise cut at the least one. (Formally this is Route A of §9: relativize to the class “Vκ for the least inaccessible κ if there is one, else V”; no set model of ZFC is needed.) 反过来，若 κ 是最小的不可达基数，则 Vκ ⊨ ZFC + ¬IC，因为对 λ < κ，“λ 不可达”在 Vκ 中的判断是正确的。因此 Con(ZFC) ⇒ Con(ZFC + ¬IC)：若不可达基数不存在，V 本身就满足 ¬IC；否则在最小的那个处截断。（严格地说，这是 §9 的路线 A：相对化到类“若存在不可达基数则取最小者 κ 对应的 Vκ，否则取 V”；不需要 ZFC 的任何集合模型。）
§8

The reflection principle and countable transitive models反射原理与可数传递模型

Reflection Principle (a theorem scheme of ZF). For every finite list of formulas φ₁, …, φₙ, ZF proves: for every β there is α > β such that each φᵢ is absolute between Vα and V. 反射原理（ZF 的一个定理模式）。对任意有限个公式 φ₁, …, φₙ，ZF 证明：对任意 β，存在 α > β，使每个 φᵢ 在 Vα 与 V 之间绝对。

Choose finitely many axioms, then press Reflect. The proof builds α₀ < α₁ < α₂ < …, where αk+1 is large enough that every existential subformula with parameters in Vαk that has a witness in V already has one in Vαk+1 (by Replacement). Then α = sup αk works, by the Tarski–Vaught test. 勾选有限条公理，按 反射。证明中构造 α₀ < α₁ < α₂ < …：取 αk+1 足够大，使得每个参数取自 Vαk 的存在型子公式，只要在 V 中有证据，在 Vαk+1 中就已有证据（用替换公理）。然后 α = sup αk 即满足要求（塔斯基–沃特判别法）。

Honest metamathematics. For each finite fragment Φ ⊆ ZFC, the theorem “there is a countable transitive model of Φ” is provable in ZFC: reflect Φ to Vα, take a countable elementary submodel (Löwenheim–Skolem), then collapse it (Mostowski). But (if ZFC is consistent) ZFC does not prove “there is a countable transitive model of all of ZFC”: that would imply Con(ZFC), contradicting Gödel 2. The quantifier “for every finite Φ” lives in the metatheory, as a scheme of separate theorems, one per Φ. It is not a single theorem of ZFC: the single sentence “every finite Φ ⊆ ZFC has a model” would, by the formalized compactness theorem, already prove Con(ZFC). 诚实的元数学. 对每个有限片段 Φ ⊆ ZFC，“存在 Φ 的可数传递模型”都是 ZFC 的定理：先把 Φ 反射到某个 Vα，再取可数初等子模型（勒文海姆–斯科伦），最后做坍塌（莫斯托夫斯基）。但（若 ZFC 一致）ZFC 不能证明“存在整个 ZFC 的可数传递模型”，否则可推出 Con(ZFC)，与哥德尔第二定理矛盾。“对每个有限 Φ”这个量词处在元理论层面，表示一族各自独立的定理，每个 Φ 一条，而不是 ZFC 内部的一条定理：单个命题“每个有限 Φ ⊆ ZFC 都有模型”借助形式化的紧致性定理就已能证明 Con(ZFC)。
§9

The relative consistency pattern: Con(ZF) ⇒ Con(ZF + X)相对一致性的论证模式：Con(ZF) ⇒ Con(ZF + X)

By Gödel 2, ZF cannot prove that ZF has a model (unless ZF is inconsistent), so independence proofs are relative: if ZF is consistent, so is ZF + X. There are two standard routes. Pick one and run it. 由哥德尔第二定理，ZF 无法证明 ZF 有模型（除非 ZF 不一致），所以独立性证明都是相对的：若 ZF 一致，则 ZF + X 也一致。标准路线有两条，选一条运行看看。
